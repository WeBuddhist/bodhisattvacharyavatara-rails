Enumeration Block 1:
གཉིས་པ་ཕྱི་རྙེད་བཀུར་སོགས་ལ་ཆགས་པ་སྤང་བ་ལ་གཉིས། ཡུལ་ཅན་གྱི་ཉེས་པ་དང༌། ཡུལ་གྱི་ཉེས་པའོ། །

Enumeration Block 2:
དང་པོ་ལ་གཉིས། ང་རྒྱལ་གྱི་ཉེས་དམིགས་དང༌། ཆགས་པའི་ཉེས་དམིགས་སོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། འདོད་པའི་ཡུལ་ལ་ཡིད་བརྟན་དུ་མི་རུང་བ་དང༌། བསྟོད་སྨད་ལ་ཕན་གནོད་མེད་པའོ། །

Enumeration Block 4:
གསུམ་པ་འདུ་འཛིའི་ཉེས་དམིགས་ལ་གཉིས། བྱིས་པ་དང་འགྲོགས་པར་དཀའ་བས་དེའི་འདུ་འཛི་ལ་ཆགས་པར་མི་བྱ་བ་དང༌། དེ་ལ་ཤེས་བྱེད་དགོད་པའོ། །

Enumeration Block 5:
བཞི་པ་དབེན་པ་བསྟེན་པའི་ཕན་ཡོན་ལ་ལྔ། གྲོགས་དང༌། གནས་དང༌། འཚོ་བའི་ཁྱད་པར་དང༌། སོ་སོར་རྟོག་པའི་ཁྱད་པར་དང༌། མི་གཡེང་བའི་ཁྱད་པར་རོ། །

Enumeration Block 6:
བཞི་པ་ལ་གཉིས། ལུས་ལ་ཆགས་པའི་གཉེན་པོ་ལ་སོ་སོར་རྟོག་པ་དང༌། མཛའ་བཤེས་ལ་ཆགས་པའི་གཉེན་པོ་ལ་སོ་སོར་རྟོག་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ་གསུམ། མཛའ་བཤེས་ལ་ཆགས་པར་མི་རིགས་པ་དང༌། དེའི་རྒྱུ་མཚན་དང༌། གནས་གཅིག་ཏུ་ཞག་གཅིག་གི་འགྲོན་པོ་དང་མཚུངས་པར་བསམ་པའོ། །

Enumeration Block 8:
ལྔ་པ་མི་གཡེང་བའི་ཁྱད་པར་ལ་གཉིས། མགྷས་པས་དབེན་པ་བསྟེན་པར་རིགས་པ་དང༌། དབེན་པ་བསྟེན་པའི་ཕན་ཡོན་ནོ། །

Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། མྱ་ངན་གྱིས་གདུངས་པ་སོགས་མེད་པ་དང༌། དགེ་བའི་ཕྱོགས་མི་ཉམས་ཤིང་འཕེལ་བ་དང༌། དེས་ན་བདག་ཉིད་དབེན་པ་བསྟེན་པར་རིགས་པའོ། །

Enumeration Block 10:
གཉིས་པ་ཕྱིན་ཅི་ལོག་གི་རྣམ་རྟོག་སྤང་བ་ལ་གཉིས། འདོད་པ་ལ་སྐྱོ་བ་བསྒོམ་པ་དང༌། དབེན་པ་ལ་དགའ་བ་བསྒོམ་པའོ། །

Enumeration Block 11:
དང་པོ་ལ་གསུམ། འདོད་པ་ལ་སྦྱང་བའི་འབྲས་བུ་འཇིགས་པ་དང་བཅས་པར་བསམ་པ་དང༌། ལུས་ལ་སོགས་པའི་ངོ་བོ་མི་གཙང་བར་བསམ་པ་དང༌། མི་འདོད་པ་དུ་མ་བསྐྱེད་པར་བསམ་པའོ། །

Enumeration Block 12:
དང་པོ་ལ་གཉིས། དགེ་བ་ལ་བརྩོན་པར་གདམས་པ་དང༌། འདོད་པའི་ཉེས་དམིགས་བསམ་པའོ། །
