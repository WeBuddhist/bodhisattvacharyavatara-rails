Enumeration Block 1:
དེ་ལ་བྱང་ཆུབ་སེམས་དཔའི་སྤྱོད་པ་ལ་འཇུག་པ་ལ་དོན་གསུམ་སྟེ། རྩོམ་པ་དང་འབྲེལ་པའི་དོན་དང་། བསྟན་བཅོས་ཀྱི་རང་བཞིན་དང་། རྩོམ་པ་ཡོངས་སུ་རྫོགས་པའི་བྱ་བའོ། །དེ་རྒྱས་པར་དབྱེ་ན་ལྔར་འགྱུར་ཏེ། དགོས་འབྲེལ་དང་། གཞི་རྟེན་གྱི་གང་ཟག་དང་། ཉེར་བར་ལེན་པའི་རྒྱུ་བྱང་ཆུབ་ཏུ་སེམས་བསྐྱེད་པ་དང་། ལྷན་ཅིག་བྱེད་པའི་རྐྱེན་བསླབ་པ་རྗེས་སུ་བསྒྲུབ་པ་དང་། དེ་ལྟར་བསླབས་པའི་འབྲས་བུ་མངོན་པར་གྲུབ་པའོ། །དེ་ལ་ཡང་དང་པོ་ནི་དངོས་སུ་བརྗོད་པའི་དོན་གསུམ་དང་། ཤུགས་ཀྱིས་གནས་པའི་དོན་དགོས་འབྲེལ་ཡན་ལག་བཞིའོ། །དངོས་སུ་གནས་པའི་དོན་ནི། མཆོད་པར་བརྗོད་པ་དང༌། བཤད་པར་དམ་བཅའ་བ་དང་། ཁེངས་བསྐྱུང་བ་གསུམ་རྐང་པ་གཉིས་དང་གཉིས་དང་བརྒྱད་ཀྱིས་རིམ་པ་བཞིན་ནོ། །དེ་ལ་དངོས་སུ་བརྗོད་པའི་དོན་གསུམ་ལའང་ངག་ཉེ་བར་བཀོད་པའི་དགོས་པ་དང་། བསྡུས་པའི་དོན་དང་། ཚིག་གི་དོན་གསུམ་གྱིས་ངེས་པར་བྱའོ། །

Enumeration Block 2:
དབྱེ་བ་ནི་གསུམ་སྟེ། སྡོམ་པའི་རང་བཞིན་སྡོམ་པའི་ཚུལ་ཁྲིམས་དང་། བརྩོན་འགྲུས་ཀྱི་རང་བཞིན་དགེ་བ་ཆོས་སྡུད་པ་དང་། སེམས་ཅན་གྱི་དོན་བྱེད་པའི་ཚུལ་ཁྲིམས་སོ། །

Enumeration Block 3:
གསུམ་པ་ཁེངས་བསྐྱང་བ་ལ་གསུམ་སྟེ། གཞན་རྟོགས་པ་གཙོ་བོ་མ་ཡིན་པ་དང་། རང་རྟོགས་པ་གཙོ་བོ་མ་ཡིན་པ་དང་། གཞན་གྱི་དོན་ལ་ལྟོས་པ་ཡོད་པའོ། །

Enumeration Block 4:
སོ་སོའི་རང་བཞིན་ལ་གསུམ་སྟེ། གཉེན་པོ་གྲུབ་པ་དང་གནས་པའི་གེགས་སྤང་བ་དང་། རྗེས་སུ་མཐུན་པའི་སྦྱོར་བ་ལ་བརྟེན་པ་དང་། གཉེན་པོ་ཉིད་ཀྱི་རང་བཞིན་ཞི་གནས་དང་ལྷག་མཐོང་ཟུང་དུ་འབྲེལ་བའི་ལམ་མོ། །

Enumeration Block 5:
དེ་ལྟར་གནས་པ་དེ་ལས་དང་པོ་གཞི་རྟེན་གྱི་གང་ཟག་ནི་གཉིས་ཏེ། ལུས་ཀྱི་རྟེན་རྙེད་པར་དཀའ་བའི་དལ་འབྱོར་དང་། བསམ་པའི་རྟེན་བསོད་ནམས་དང་ལྡན་པའི་བློ་གྲོས་སོ། །

Enumeration Block 6:
འབྱོར་པ་ནི་རང་གི་འབྱོར་པ་ལྔ་སྟེ། མིའི་ལུས་ཐོབ་པ་དང་། དབང་པོ་ཚང་བ་དང་། ལས་ཀྱི་མཐའ་མ་ལོག་པ་དང་། ཡུལ་དབུས་སུ་སྐྱེས་པ་དང་། གནས་ལ་དད་པའོ། །གཞན་གྱི་འབྱོར་པ་ལ་ལྔ་སྟེ། སངས་རྒྱས་འབྱུང་བ་དང་། དེས་ཆོས་གསུང་བ་དང་། བསྟན་པ་ལ་གནས་པ་དང་། གནས་པའི་རྗེས་སུ་འཇུག་པ་དང༌། གཞན་གྱི་ཕྱིར་སྙིང་བརྩེ་བའོ། །

Enumeration Block 7:
དེ་ལྟར་གཞི་རྟེན་གྱི་གང་ཟག་བཤད་ནས། ཉེ་བར་ལེན་པའི་རྒྱུ་བྱང་ཆུབ་ཏུ་སེམས་བསྐྱེད་པ་འཆད་པ་ན་གཉིས་ཏེ། ཕན་ཡོན་རྗེས་སུ་བསྔགས་པ་དང་། གཟུང་བའི་ཆོ་གའོ། །དང་པོ་ལ་གསུམ་སྟེ། མ་མཐོང་བའི་དང་། མཐོང་བའི་ཕན་ཡོན་དང་། ཕན་ཡོན་དཔེས་བསྔགས་པའོ། །དང་པོ་ལ་བཞི་སྟེ། སྡིག་པ་ཐམས་ཅད་འཇོམས་པ་དང་། རང་ལ་ཕན་པ་དང༌། གཞན་རྗེས་སུ་འཛིན་པའི་ནུས་པ་ཡོད་པ་དང་། འཇིག་རྟེན་སོ་སོའི་འདོད་པ་བསྐང་བའོ། །དང་པོ་ནི་སྡིག་པའི་རང་བཞིན་དང་། དེ་འཇོམས་པའི་ཚུལ་གཉིས་སོ། །

Enumeration Block 8:
ཕན་ཡོན་དཔེས་བསྔགས་པ་ལ་རྣམ་པ་དྲུག་སྟེ། དམན་པ་མཆོག་ཏུ་བསྒྱུར་པ་གསེར་འགྱུར་གྱི་རྩི་དང་། རྙེད་དཀའ་ཞིང་མཐུ་མངའ་བ་ཡིད་བཞིན་གྱི་ནོར་བུ་དང་། འབྲས་བུ་ཟད་མི་ཤེས་པ་དཔག་བསམ་གྱི་ཤིང་དང་། མྱོང་བར་ངེས་པའི་སྡིག་པའི་ལས་ཟིལ་གྱིས་གནོན་པ་དཔའ་བོའི་དཔེ་དང་། མྱོང་བར་མ་ངེས་པའི་སྡིག་པ་དྲུངས་ནས་འབྱིན་པ་དུས་མཐའི་མེ་དང་། དཔེའི་ཁྱད་པར་གཞན༌བསྟན༌པའོ། །

Enumeration Block 9:
དེ་ལྟར་ཐུན་མོང་གི་ཕན་ཡོན་བཤད་ནས་ཁྱད་པར་གྱི་ཕན་ཡོན་སྟོན་པ་ནི་བཞི་སྟེ། དབྱེ་བ་དང་། མཚན་ཉིད་དང་། སྨོན་པའི་ཕན་ཡོན་དང་། འཇུག་པའི་ཕན་ཡོན་ནོ། །

Enumeration Block 10:
ཕན་ཡོན་དང་ལྡན་པའི་འཐད་པ་ལ་གཉིས་ཏེ། ལུང་དང་རིགས་པའོ། །

Enumeration Block 11:
རིགས་པས་འཐད་པ་ལ་གཉིས་ཏེ། སྨོན་པ་ཕན་ཡོན་དང་ལྡན་པའི་འཐད་པ་དང༌། འཇུག་པ་ཕན་ཡོན་དང་ལྡན་པའི་འཐད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། དམིགས་པ་རྒྱ་ཆེ་བ་དང་། དཀོན་པ་དང་། ཕན་འདོགས་ཆེ་བའོ། །

Enumeration Block 12:
གཉིས་པ་དཀོན་པ་ལ་གསུམ་སྟེ། ཕན་པར་འདོད་པའི་སྐྱེ་བོ་གཞན་ལ་མེད་པ་དང་། རང་ལ་མེད་པ་དང་། དེ་ཉིད་ཀྱིས་སེམས་བསྐྱེད་པ་དེ་ཕན་ཡོན་ཆེན་པོར་གྲུབ་པའོ། །
