Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། རང་གི་སྐྱོན་བརྟག་པ་དང༌། སེམས་ཅན་ལ་ཉེས་པ་བྱས་པ་བཤགས་པ་དང༌། དམན་པའི་གནས་ལྷུར་བླང་བའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་བཞི། རྒོད་བག་ཏུ་གནས་པ་ཚར་བཅད་པའི་ཚུལ་དང༌། རང་དོན་འབའ་ཞིག་ལ་སྦྱོར་བའི་ཉེས་དམིགས་དང༌། ལུས་ཀྱི་ཉེས་པ་ལ་བརྟག་པ་དང༌། སེམས་དབང་དུ་བྱ་བའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། ཉེས་དམིགས་བསམས་ནས་རང་དོན་འབའ་ཞིག་བསྒྲུབ་པ་དོར་བ་དང༌། གཞན་དོན་ལ་སྦྱོར་བ་དང༌། བསྡུས་ཏེ་བསྟན་པའོ། །

Enumeration Block 4:
གསུམ་པ་ལ་གསུམ། ཆོག་མི་ཤེས་པའི་ཉེས་པ་དང༌། གཡོ་བ་མེད་པའི་ཉེས་པ་དང༌། རྨོངས་པའི་ཉེས་པའོ། ། དང་པོ་ལ་གཉིས། ལུས་ལ་སྲེད་པའི་ཉེས་དམིགས་དང༌། དེས་ན་ལུས་ལ་ཆགས་བྲལ་བསྒོམ་རིགས་པའོ། །

Enumeration Block 5:
གསུམ་པ་ལ་བཞི། ལེགས་ཉེས་ལ་རྨོངས་པ་དང༌། བསྟོད་སྨད་ལ་རྨོངས་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ་དང༌།
ལུས་ལ་སྲེད་པ་ཉེས་པ་དུ་མའི་འབྱུང་གནས་ཡིན་ཡང་དལ་འབྱོར་ལ་སྙིང་པོ་བླང་བའི་ཆེད་དུ་བསྲུང་བར་བྱ་བའོ། །

Enumeration Block 6:
བཞི་པ་ལ་གསུམ། དགེ་བའི་བར་ཆད་ལོག་པར་བྱ་བ་དང༌། གཉེན་པོ་ལ་བརྩོན་པའི་སྟོབས་བསྐྱེད་པ་དང༌། དགེ་བའི་དམིགས་པ་ལ་རྩེ་གཅིག་ཏུ་མཉམ་པར་བཞག་པར་བྱ་བའོ། །
