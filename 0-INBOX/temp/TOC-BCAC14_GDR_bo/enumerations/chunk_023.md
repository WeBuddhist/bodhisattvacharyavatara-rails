Enumeration Block 1:
གཉིས་པ་ལ་གཉིས།
བརྩོན་འགྲུས་ཀྱི་མི་མཐུན་ཕྱོགས་སྤང་བ་དང༌།
གཉེན་པོ་བརྩོན་འགྲུས་ཀྱི་སྟོབས་སྤེལ་བའོ། །
དང་པོ་ལ་གཉིས།
མི་མཐུན་ཕྱོགས་ངོས་བཟུང་བ་དང༌།
དེ་ཇི་ལྟར་སྤོང་བའི་ཚུལ་ལོ། །

Enumeration Block 2:
གཉིས་པ་ལ་གསུམ།
སྙོམ་ལས་ལ་རོ་མྱང་བའི་ལེ་ལོ་སྤང་བ་དང༌།
བྱ་བ་ངན་པ་ལ་ཞེན་པའི་ལེ་ལོ་སྤང་བ་དང༌།
དགེ་བ་ལ་སྒྱིད་ལུག་པའི་ལེ་ལོ་སྤང་བའོ། །
དང་པོ་ལ་གཉིས།
ལེ་ལོའི་རྒྱུ་བརྟགས་ནས་སྤང་བ་དང༌།
ཇི་ལྟར་སྤོང་བའི་ཚུལ་ལོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གཉིས།
ཚེ་འདིའི་ཉེས་དམིགས་བསམས་ནས་ལེ་ལོ་སྤང་བ་དང༌།
ཚེ་ཕྱི་མའི་སྡུག་བསྔལ་བསམས་ནས་ལེ་ལོ་སྤང་བའོ། །
དང་པོ་ལ་གསུམ།
མྱུར་དུ་འཆི་བས་འཇོམས་པ་དཔེས་བཤད་པ་དང༌།
རང་ཉིད་ཀྱང་འཆི་བའི་གཞན་དབང་དུ་གྱུར་པས་ལོང་ཡོད་བྱར་མི་རུང་བ་དང༌།
དགེ་བ་ལ་མ་འབད་ན་སྡུག་བསྔལ་གྱིས་གདུངས་པར་འགྱུར་བའོ། །
དང་པོ་ལ་གཉིས།
འཆི་བས་འཇོམས་པ་མངོན་སུམ་དུ་མཐོང་བ་དང༌།
དེ་དཔེས་བཤད་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལ་བཞི།
རང་ཉིད་འཆི་བདག་གི་དབང་དུ་གྱུར་པས་ལེ་ལོ་མི་བྱ་བ་དང༌།
མྱུར་བར་འཆི་བས་དགེ་བ་ལ་འབད་པ་དང༌།
འཆི་བའི་ཚེ་ལེ་ལོ་སྤོང་བ་དུས་མ་ཡིན་པ་དང༌།
འདོད་པའི་ལས་མ་བྱས་པར་གློ་བུར་དུ་འཆི་བས་ལེ་ལོ་མི་བྱ་བའོ། །

Enumeration Block 5:
གསུམ་པ་ལ་གཉིས།
འཆི་བའི་ཚེ་མྱ་ངན་གྱིས་གདུངས་པ་དང༌།
ད་ལྟ་ཉིད་ནས་དགེ་བ་ལ་བརྩོན་པར་མ་བྱས་ན་དགོས་པ་མི་འགྲུབ་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་བཞི།
སྡུག་བསྔལ་འབྱུང་ངེས་པ་དང༌།
དེ་བཟོད་དཀའ་བ་དང༌།
བདེ་བ་འདོད་པ་དང༌།
དགེ་བ་ལ་མི་བརྩོན་པ་འགལ་བ་དང༌།
སྡུག་བསྔལ་ལས་ཐར་པའི་ཐབས་ལ་བརྩོན་པར་བསྐུལ་བའོ། །

Enumeration Block 7:
གསུམ་པ་སྒྱིད་ལུག་པའི་ལེ་ལོ་སྤང་བ་ལ་གསུམ།
སྒྱིད་ལུག་པའི་གཉེན་པོ་ལ་འབད་པར་གདམས་པ་དང༌།
གཉེན་པོ་ཇི་ལྟར་ཉམས་སུ་ལེན་པའི་ཚུལ་ལུང་ལས་གསུངས་པ་དང༌།
འབད་ན་ལེ་ལོ་བཀག་ནས་བྱང་ཆུབ་སྒྲུབ་ནུས་པའོ། །

Enumeration Block 8:
གསུམ་པ་ལ་བཞི།
བརྩོན་པའི་སྟོབས་བསྐྱེད་ན་བྱང་ཆུབ་ཐོབ་ནུས་པར་བསམ་པ་དང༌།
བྱང་ཆུབ་སྒྲུབ་པའི་དཀའ་སྤྱད་ལ་ངན་འགྲོའི་སྡུག་བསྔལ་གྱི་ཆ་ཙམ་ཡང་མེད་པས་བཟོད་རིགས་པ་དང༌།
སྨན་པའི་རྒྱལ་པོས་ཆོ་ག་འཇམ་པོས་ནད་ཆེན་པོ་གསོ་བར་མཛད་པས་བཟོད་རིགས་པ་དང༌།
དེ་ལ་སྡུག་བསྔལ་མེད་ཅིང་བདེ་བས་རྒྱས་པས་དགའ་བར་རིགས་པའོ། །

Enumeration Block 9:
གཉིས་པ་ལ་གསུམ།
རྐང་ལག་སོགས་གཏོང་བའི་དཀའ་སྤྱད་ཀྱིས་འཇིགས་མི་རིགས་པ་དང༌།
ངན་འགྲོའི་སྡུག་བསྔལ་ཆ་ཙམ་ཡང་མྱོང་མི་དགོས་པ་དང༌།
ནད་ཆེན་པོ་གཞོམ་པའི་ཆེད་དུ་སྡུག་བསྔལ་ཆུང་ངུ་བཟོད་རིགས་པའི་དཔེའོ། །
