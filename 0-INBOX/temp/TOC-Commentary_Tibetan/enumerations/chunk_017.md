Enumeration Block 1:
**ཇི་ལྟར་འབད་པ་ལའང་གཉིས་ལས།**

Enumeration Block 2:
**(ལྔ་པ་)རྗེས་སུ་ཡི་རང་བའི་ཡན་ལག་ལ་གཉིས་ལས།**

Enumeration Block 3:
**(བརྒྱད་པ་)བསྔོ་བ་ལ།**
སྡུག་བསྔལ་ཞི་བའི་དོན་དུ་བསྔོ་བ། ལུས་སོགས་གཞན་གྱི་དོན་དུ་བསྒྱུར་བ། ཁྱད་པར་སྨོན་ལམ་རྒྱ་ཆེར་གདབ་པའོ། །
**དང་པོ་ལ་བཞི་ལས།**

Enumeration Block 4:
**(གཉིས་པ་)ལུས་སོགས་གཞན་དོན་དུ་བསྒྱུར་བ་ལ་གསུམ་ལས།**

Enumeration Block 5:
**(གསུམ་པ་)སྨོན་ལམ་གདབ་པ་ལ་གཉིས་ལས།**
