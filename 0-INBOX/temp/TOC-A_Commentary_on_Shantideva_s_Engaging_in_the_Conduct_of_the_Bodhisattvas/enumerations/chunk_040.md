Enumeration Block 1:
གཉིས་པ་རྒྱས་བཤད་ལ།
འདུ་འཛི་སྤང་ཚུལ་དང༌། དབེན་པ་བསྟེན་ཚུལ་ལོ། །
དང་པོ་ལ།
མཛའ་བཤེས་ལ་ཆགས་པའི་ཉེས་དམིགས། བྱིས་པ་དང་འགྲོགས་པ་སྤང་བ། རྙེད་བཀུར་ལ་སྙིང་པོ་མེད་ཚུལ། འཇིག་རྟེན་ལ་ཞེན་པ་སྤང་བའོ། །
དང་པོ་ལ་གཉིས་ལས།
དང་ པོ་གདུང་བ་སྐྱེད་ཚུལ་ནི།

Enumeration Block 2:
གཉིས་པཆོས་ལས་ཉམས་ཚུལ་ནི།

Enumeration Block 3:
གཉིས་པ་བྱིས་པ་སྤང་པ་ལ་བཞི་ལས།
དང་པོ་སྤོང་ཚུལ་མདོར་བསྟན་ནི།

Enumeration Block 4:
གཉིས་པ་ཉེས་དམིགས་རྒྱས་བཤད་ནི།

Enumeration Block 5:
གསུམ་པ་བསྡུས་ཏེ་གདམས་པ་ནི།

Enumeration Block 6:
བཞི་པ་ཕྲད་ན་སྤྱོད་ཚུལ་ནི།

Enumeration Block 7:
གསུམ་པ་རྙེད་བཀུར་ལ་སྙིང་པོ་མེད་ཚུལ་ནི།

Enumeration Block 8:
བཞི་པ་འཇིག་རྟེན་ལ་ཞེན་པ་སྤང་པ་ནི།

Enumeration Block 9:
གཉིས་པ་དབེན་པ་བསྟེན་པ་ལ།
དབེན་པའི་ཡོན་ཏན་བསམ་པ་དང༌། དེ་ཉིད་བསྟེན་པར་གདམས་པའོ། །
དང་པོ་ལ་ལྔ་ལས།
དང་པོ་འགྲོགས་ན་བདེ་བ་གྲོགས་ཀྱི་ཡོན་ཏན་བསམ་པ་ནི།

Enumeration Block 10:
གཉིས་པ་རང་དབང་ཐོབ་པ་གནས་ཀྱི་ཡོན་ཏན་བསམ་པ་ནི།

Enumeration Block 11:
གསུམ་པ་བསྒྲུབ་པར་སླ་བ་ཉེར་མཁོའི་ཡོན་ཏན་བསམ་པ་ནི།

Enumeration Block 12:
བཞི་པ་ཆོས་ལ་སྐུལ་བའི་རྐྱེན་གྱི་ཁྱད་པར་བསམ་པ་ནི།
