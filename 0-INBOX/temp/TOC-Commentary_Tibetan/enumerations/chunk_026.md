Enumeration Block 1:
**(གཉིས་པ་)ཤེས་བཞིན་ལ།**
ཤེས་བཞིན་བརྟན་པར་སྲུང་ཚུལ། དེ་ཉིད་རྒྱས་པར་བཤད་ པ། མཚན་ཉིད་བསྡུས་ཏེ་བསྟན་པའོ། །
**དང་པོ་ནི།**

Enumeration Block 2:
**(གཉིས་པ་)རྒྱས་བཤད་ལ།**
ལུས་དང་སེམས་ལ་བརྟག་པ། བརྟགས་ནས་དབང་དུ་བྱ་བ། དེའི་སྤྱོད་ལམ་སྦྱང་བ། བསླབ་བྱ་ཉམས་སུ་བླང་ཚུལ་ལོ། །
**དང་པོ་ལ་བཞི་ལས།**
**(དང་པོ་)ལུས་ལ་བརྟགས་ནས་སྤྱོད་ཚུལ་ནི།**

Enumeration Block 3:
**(གཉིས་པ་)སེམས་ལ་བརྟགས་ནས་འཇོག་ཚུལ་ནི།**

Enumeration Block 4:
**(གསུམ་པ་)གནང་བའི་གནས་སྐབས་ཤེས་ཚུལ་ནི།**

Enumeration Block 5:
**(བཞི་པ་)གང་ལ་ཞུག་པ་ཐོག་མར་སྒྲུབ་ཚུལ་ནི།**

Enumeration Block 6:
**དབང་དུ་བྱ་བ་ལ།**
ཚུལ་མིན་ལས་བཟློག་ཚུལ། ཚུལ་བཞིན་ལ་འཇུག་ཚུལ། དལ་བའི་དོན་སྒྲུབ་ཚུལ་ལོ།
**དང་པོ་ལ་ལྔ་ལས།**
**(དང་པོ་)རྣམ་གཡེང་ལ་ཆགས་པ་སྤོང་ཚུལ་ནི།**

Enumeration Block 7:
**(གཉིས་པ་)དོན་མེད་ཀྱི་བྱ་བ་སྤོང་ཚུལ་ནི།**

Enumeration Block 8:
**(གསུམ་པ་)དོན་ཐམས་ཅད་རིགས་པས་སྒྲུབ་ཚུལ་ནི།**

Enumeration Block 9:
**(བཞི་པ་)ཉོན་མོངས་ལ་གཉེན་པོ་བསྐྱེད་ཚུལ་ནི།**

Enumeration Block 10:
**(ལྔ་པ་)ཐམས་ཅད་དུ་བརྟགས་ནས་འཇུག་ཚུལ་ནི།**

Enumeration Block 11:
**ཚུལ་བཞིན་ལ་འཇུག་ཚུལ་ལ་གཉིས་ལས།**
**(དང་པོ་)གཞན་དོན་ལ་སྤྲོ་བས་འཇུག་ཚུལ་ནི།**

Enumeration Block 12:
**(གཉིས་པ་)གཞན་རྐྱེན་གྱིས་སྐྱོ་བ་སྤོང་ཚུལ་ནི།**

Enumeration Block 13:
**(གསུམ་པ་)དལ་བའི་དོན་ལ།**
དལ་འབྱོར་དཀོན་པ་བསམ་པ། ལུས་ལ་ཆགས་པ་སྤང་བ། དགེ་བའི་ལས་ལ་བཀོལ་བའོ། །
**དང་པོ་ནི།**

Enumeration Block 14:
**(གཉིས་པ་)ཆགས་པ་སྤོང་བ་ནི།**
