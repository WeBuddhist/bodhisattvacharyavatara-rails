Enumeration Block 1:
གཉིས་པ་གཉེན་པོ་ལའང་གཉིས་ལས།

Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ལ།
དཔུང་ཚོགས་བསྐྱེད་པ་དང༌། བརྩོན་འགྲུས་སྤེལ་བའོ།།
དང་པོ་ལ། འདུན་པ་དང༌། བརྟན་པ་དང༌། དགའ་བ་དང༌། དོར་བའི་དཔུང་ཚོགས་བསྐྱེད་པའོ།།
དང་པོ་འདུན་པ་ལའང༌། འདུན་པ་མེད་ན་དོན་གཉིས་ཉམས་ཚུལ། འདུན་པ་ཆོས་ཀྱི་རྩ་བར་གསུངས་ཚུལ། དེའི་ཡང་རྩ་བ་ལས་འབྲས་བསམ་པ། དེས་ན་འདུན་པ་བསྐྱེད་པར་གདམས་པའོ།།

Enumeration Block 3:
གསུམ་པ་ལས་འབྲས་བསམ་པ་ལ་གཉིས་ལས།

Enumeration Block 4:
གཉིས་པ་དེ་དག་གི་ཁྱད་པར་ལའང་གཉིས་ལས།

Enumeration Block 5:
གཉིས་པ་བརྟན་པའི་དཔུང་ལ།
བརྟགས་ནས་བརྟན་པར་བྱ་བ། དེ་ལས་བཟློག་པའི་ཉེས་དམིགས། གསུམ་ལ་ང་རྒྱལ་བྱ་བའོ།།

Enumeration Block 6:
གསུམ་པ་ང་རྒྱལ་ལ་གཉིས་ལས།

Enumeration Block 7:
གཉིས་པ་རྒྱས་བཤད་ལ། ལས་དང༌། ནུས་པ་དང༌།
ཉོན་མོངས་པའི་ང་རྒྱལ་བཤད་པ་གསུམ་ལས།
