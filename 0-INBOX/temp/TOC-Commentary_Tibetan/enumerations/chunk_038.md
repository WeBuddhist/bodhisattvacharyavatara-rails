Enumeration Block 2:
**(གཉིས་པ་)རྒྱས་བཤད་ལ།**
ལས་དང༌། ནུས་པ་དང༌། ཉོན་མོངས་པའི་ང་རྒྱལ་བཤད་པ་གསུམ་ལས།

Enumeration Block 3:
**(གཉིས་པ་)ནུས་པའི་ང་རྒྱལ་ལ་གསུམ་ལས།**

Enumeration Block 4:
**(གསུམ་པ་)དགའ་བའི་དཔུང་ལ་གསུམ་ལས།**

Enumeration Block 5:
**(གཉིས་པ་)བརྩོན་འགྲུས་སྤེལ་པ་ལ།**
གཉེན་པོ་བསྐྱེད་དེ་... དབང་དུ་བྱས་ཏེ་...

Enumeration Block 6:
**དང་པོ་ལ་བཞི་ལས།**

Enumeration Block 7:
**(གཉིས་པ་)དབང་དུ་བྱས་ཏེ་བརྩོན་འགྲུས་སྤེལ་པ་ལ་གཉིས་ལས།**

Enumeration Block 8:
ད་ནི་བསམ་གཏན་གྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཉམས་སུ་བླང་ཚུལ་ལ་སྤྱི་དོན་བཞི་སྟེ། བྱེད་ལས་མཚན་ཉིད་དབྱེ་བ་ཕན་ཡོན་ནོ། །
