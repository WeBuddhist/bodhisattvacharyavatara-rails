Enumeration Block 1:
**(གཉིས་པ་)དང་པོའི་ཁྱབ་བསྒྲུབ་ལ་གསུམ་ལས།**
**(དང་པོ་)མཚུངས་པའི་སྒོ་ནས་བསྒྲུབ་ཚུལ་ནི།**

Enumeration Block 2:
**(གཉིས་པ་)མི་མཚུངས་པའི་རྒྱུ་མཚན་དགག་པ་ནི།**

Enumeration Block 3:
**(གསུམ་པ་)དེ་དག་ལ་རྩོད་པ་སྤང་པ་ནི།**

Enumeration Block 4:
**(བཞི་པ་)ཕན་ཡོན་ནི།**

Enumeration Block 5:
**(གསུམ་པ་)གདམས་པ་ནི།**

Enumeration Block 6:
**(གཉིས་པ་)བདག་གཞན་བརྗེ་བ་བསྒོམ་པ་ལ།**
རྒྱུ་མཚན་མདོར་བསྟན། རྒྱས་པར་བཤད་པ། ཇི་ལྟར་བརྗེ་ཚུལ། བརྗེས་ནས་བསྒྲུབ་ཚུལ་ལོ། །
**དང་པོ་ནི།**

Enumeration Block 7:
**(གཉིས་པ་)རྒྱས་བཤད་ལ།**
གཞན་གྱི་སྡུག་བསྔལ་བླང་ཚུལ། བདག་ཉིད་གཞན་ལ་གཏོང་ཚུལ། བདག་གཞན་གཙོ་བོའི་སྐྱོན་ཡོན། མ་བརྗེས་པ་ཡི་ཉེས་དམིགས། རྩ་བ་བདག་འཛིན་སྤང་ཚུལ་ལོ། །
**དང་པོ་ལ་གསུམ་ལས།**
**(དང་པོ་)རྒྱུ་མཚན་བསམས་ཏེ་བསྒོམ་ཚུལ་ནི།**

Enumeration Block 8:
**(གཉིས་པ་)ཆུང་ངུ་ཉིད་ནས་བསྒོམ་ཚུལ་ནི།**

Enumeration Block 9:
**(གསུམ་པ་)དཀའ་ཡང་དོན་གཉིས་འགྲུབ་ཚུལ་ནི།**

Enumeration Block 10:
**(གཉིས་པ་)བདག་ཉིད་གཞན་ལ་གཏོང་ཚུལ་ལ་གཉིས་ལས།**
**(དང་པོ་)ཚེ་འདིའི་འཇིགས་པ་བསམས་ཏེ་གཏང་ཚུལ་ནི།**

Enumeration Block 11:
**(གཉིས་པ་)ཕྱི་མའི་སྡུག་བསྔལ་བསམས་ཏེ་གཏང་ཚུལ་ནི།**

Enumeration Block 12:
**(གསུམ་པ་)བདག་གཞན་གཙོ་བོའི་སྐྱོན་ཡོན་ལ་གཉིས་ལས།**
**(དང་པོ་)ཁྱད་པར་རྒྱས་པར་བཤད་པ་ནི།**

Enumeration Block 13:
**(གཉིས་པ་)བསྡུས་ཏེ་དཔེ་དང་སྦྱར་བ་ནི།**

Enumeration Block 14:
**(བཞི་པ་)མ་བརྗེས་པའི་ཉེས་དམིགས།**

Enumeration Block 15:
**(ལྔ་པ་)རྩ་བ་བདག་འཛིན་སྤང་ཚུལ་ནི།**
