Enumeration Block 1:
གནོད་པ་བྱེད་པ་ལ་ཇི་མི་སྙམ་པའི་བཟོད་པ་ལ་བཞི་སྟེ། ཁྲོ་བའི་མཚན་མ་མ་གྲུབ་པ་དང༌། མི་རིགས་པར་བརྟག་པ་དང༌། རང་གི་ཉེས་པ་བརྟག་པ་དང༌། འབྲས་བུ་ཡིད་ལ་བྱ་བའོ། །

Enumeration Block 2:
བཞི་པ་ནི་བསོད་ནམས་མི་ཉམས་པ་དང༌། སྡུག་བསྔལ་བཟློག་པ་དང༌། དོན་ཆེན་པོ་བསྒྲུབ་པའོ། །

Enumeration Block 3:
བདག་གི་དགྲ་ལ་ལེགས་པ་བྱེད་པ་ལ་མི་བཟོད་པ་དོར་བ་ལ་གསུམ་སྟེ། བསྟོད་གྲགས་ལ་མི་བཟོད་པ་དོར་བ་དང༌། བདེ་བ་བསྒྲུབ་པ་ལ་མི་བཟོད་པ་དོར་བ་དང༌། རྙེད་པ་བསྒྲུབ་པ་ལ་མི་བཟོད་པ་དོར་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། རང་ལ་བདེ་བའི་རྒྱུ་ཡིན་པས་མི་བཟོད་པ་དོར་བ་དང༌། གཞན་བདེ་བའི་རྒྱུ་ཡིན་པས་མི་བཟོད་པ་དོར་བའོ། །

Enumeration Block 4:
རྙེད་པ་བསྒྲུབ་པ་ལ་མི་བཟོད་པ་དོར་བ་ནི་གཉིས་ཏེ། འདོད་པ་གྲུབ་པ་དང༌། མི་འདོད་པ་མེད་པའོ། །

Enumeration Block 5:
འདོད་པའི་གེགས་བྱེད་པ་ལ་མི་བཟོད་པ་འདོར་བ་ནི་གཉིས་ཏེ། དགྲ་ལ་ཉེས་པ་འགྲུབ་པའི་གེགས་བྱེད་པ་ལ་མི་བཟོད་པར་འདོར་བ་དང༌། བདག་དང་བདག་གི་ཕྱོགས་ལ་ལེགས་པའི་གེགས་བྱེད་པ་ལ་མི་བཟོད་པ་དོར་བའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ཏེ། འཇིག་རྟེན་པའི་ཆོས་འགོག་པ་ལ་མི་བཟོད་པ་དོར་བ་དང༌། བསོད་ནམས་ཀྱི་གེགས་བྱེད་པ་ལ་མི་བཟོད་པར་དོར་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། བསྟོད་གྲགས་འཇིག་པ་ལ་གནོད་བྱེད་དུ་མི་ལྟ་བ་དང༌། འཇིག་རྟེན་པའི་ཆོས་འགོག་པ་ལ་ཕན་འདོགས་སུ་ལྟ་བའོ། །དང་པོ་ལ་བཞི་སྟེ། བསྟོད་གྲགས་ལ་ཕན་བདེ་མེད་པ་དང༌། དགའ་བ་ཙམ་དོན་མ་ཡིན་པ་དང༌། དོན་དུ་འཛིན་པ་ཕྱིན་ཅི་ལོག་ཡིན་པ་དང༌། དགའ་བ་ཉིད་ཕྱིན་ཅི་ལོག་ལས་གྱུར་པའོ། །

Enumeration Block 7:
བཞི་པ་ནི་སྒྲ་ཙམ་དགའ་བའི་རྒྱུར་མི་རུང་བ་དང༌། བསྟོད་པ་པོའི་ཀུན་སློང་དགའ་བའི་རྒྱུར་མི་རུང་བ་དང༌། དེ་ཉིད་བཟློག་པས་བསྒྲུབ་པ་དང༌། དོན་བསྡུ་བ་བཞིའོ། །

Enumeration Block 8:
གཉིས་པ་འཇིག་རྟེན་གྱི་ཆོས་འགོག་པ་ལ་ཕན་འདོགས་བྱེད་དུ་ལྟ་བ་ནི། ངན་འགྲོ་འགོག་པ་དང༌། ཐར་པ་བསྒྲུབ་པའོ། །

Enumeration Block 9:
གཉིས་པ་བསོད་ནམས་ཀྱི་གེགས་བྱེད་པ་ལ་མི་བཟོད་པ་དོར་བ་ལ་གསུམ་སྟེ། བསོད་ནམས་ཀྱི་གེགས་ཀྱིས་ཁྲོ་བར་འགལ་བ་དང༌། གེགས་ཉིད་མ་ཡིན་པ་དང༌། གུས་པའི་ཡུལ་དུ་བརྟག་པའོ། །

Enumeration Block 10:
གུས་པའི་ཡུལ་དུ་བརྟག་པ་ལ་གཉིས་ཏེ། རང་གི་ཡོན་ཏན་གྱིས་གུས་པར་བྱ་བ་དང༌། སྟོན་པ་ལ་དད་པས་གུས་པར་བྱ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། ཕན་འདོགས་ཆེ་བ་དང༌། བསམ་པའི་ཡོན་ཏན་ལ་མི་ལྟོས་པ་དང༌། དེས་ན་སྟོན་པ་དང་འདྲ་བར་བལྟ་བའོ། །

Enumeration Block 11:
དེ་ལ་ལྔ་སྟེ། ལུང་གི་མདོར་གཞག་པ་དང༌། དེ་ཉིད་བསྒྲུབ་པ་དང༌། དེས་ན་གུས་པའི་ཡུལ་དུ་མཉམ་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ་དང༌། དོན་བསྡུ་བའོ། །
