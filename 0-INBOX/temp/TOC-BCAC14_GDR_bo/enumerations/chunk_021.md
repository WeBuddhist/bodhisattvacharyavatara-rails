Enumeration Block 1:
གཉིས་པ་ལ་གཉིས།
བསྟོད་གྲགས་ཀྱི་གེགས་བྱེད་པ་ངན་འགྲོ་འགོག་བྱེད་ཡིན་པས་དེ་ལ་ཁྲོ་མི་རིགས་པ་དང༌།
སྲིད་པ་ལས་གྲོལ་བྱེད་ཡིན་པས་ཁྲོ་མི་རིགས་པའོ། །
དང་པོ་ལ་གཉིས།
བསྟོད་གྲགས་ལ་ཞེན་པས་ཉེས་པ་ཀུན་བསྐྱེད་པ་དང༌།
དེ་འགོག་བྱེད་ངན་འགྲོ་འགོག་བྱེད་ཡིན་པའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་གཉིས།
བསྟོད་སོགས་ལ་གེགས་བྱེད་པ་སྲིད་པ་ལས་གྲོལ་བྱེད་ཡིན་པས་ཁྲོ་བར་མི་རིགས་པ་དང༌།
སྡུག་བསྔལ་གྱི་སྒོ་གཅོད་བྱེད་ཡིན་པས་ཁྲོ་བར་མི་རིགས་པའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གསུམ།
བསོད་ནམས་ཀྱི་གེགས་བྱས་པས་ཁྲོ་བར་མི་རིགས་པ་དང༌།
བསོད་ནམས་ཀྱི་གེགས་མ་ཡིན་པ་དང༌།
གུས་པར་བྱ་བའི་ཡུལ་དུ་བསམ་པའོ། །
དང་པོ་ལ་གཉིས།
དཀའ་ཐུབ་ཀྱི་མཆོག་ལ་གནས་པར་བྱ་བ་དང༌།
དེ་ལ་གེགས་བྱེད་ན་རང་ཉིད་བསོད་ནམས་ཀྱི་བར་ཆད་དུ་འགྱུར་བའོ། །

Enumeration Block 4:
གཉིས་པ་ལ་གཉིས།

གཉིས་པ་ལ་གཉིས།
ཡོན་ཏན་སྐྱེད་བྱེད་ཡིན་པས་གུས་པར་བྱ་བ་དང༌།
སྟོན་པ་ལ་དད་པས་གུས་པར་བྱ་བའོ། །
དང་པོ་ལ་གསུམ།
རང་ལ་ཕན་འདོགས་ཆེ་བ་དང༌།
བསམ་པའི་ཕན་ཡོན་ལ་མི་ལྟོས་པ་དང༌།
སྟོན་པ་དང་འདྲ་བར་བལྟ་བའོ། །
དང་པོ་ལ་གསུམ།
ཞིང་ཁྱད་པར་ཅན་དཀོན་པ་དང༌།
དེ་ལ་དགའ་བར་རིགས་པ་དང༌།
དེ་ལ་ཕན་པའི་བསམ་པ་བྱ་བར་རིགས་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་གསུམ།
ཕན་པའི་བསམ་པ་མེད་པས་མཆོད་ཡུལ་མིན་པ་མི་འཐད་པ་དང༌།
གནོད་པའི་བསམ་པ་ཡོད་པས་མཆོད་ཡུལ་མིན་པ་མི་འཐད་པ་དང༌།
དེས་ན་བཟོད་པའི་དམིགས་རྐྱེན་བྱེད་པས་མཆོད་པར་འོས་པའོ། །

Enumeration Block 7:
གསུམ་པ་ལ་གཉིས།
རྒྱས་པར་བཤད་པ་དང༌།
དོན་བསྡུ་བའོ། །
དང་པོ་ལ་གསུམ།
སེམས་ཅན་དང་སངས་རྒྱས་བསོད་ནམས་ཀྱི་ཞིང་དུ་མཚུངས་པར་ལུང་ལས་གསུངས་པ་དང༌།
དེ་རིགས་པས་བསྒྲུབ་པ་དང༌།
རྩོད་པ་སྤང་བའོ། །
གཉིས་པ་ལ་གཉིས།
སངས་རྒྱས་དང་སེམས་ཅན་ལ་དད་པས་འདོད་བྱ་མཐར་ཐུག་ཐོབ་པ་དང༌།
གཉིས་ཀ་ལ་དད་པས་སངས་རྒྱས་ཐོབ་པར་མཚུངས་པ་ལ་འདོར་ལེན་མི་རིགས་པའོ། །

Enumeration Block 8:
གསུམ་པ་ལ་གསུམ།
ཡོན་ཏན་མི་མཉམ་པས་དད་པ་མཚུངས་པར་བསྒོམ་པ་མི་འཐད་པ་སྤང་བ་དང༌།
གཉིས་ཀ་ལ་དད་པའི་ཆེ་བ་སངས་རྒྱས་ཀྱི་རྒྱུར་མཚུངས་པས་དད་པ་མཚུངས་པར་སྒོམ་རིགས་པ་དང༌།
སངས་རྒྱས་ཀྱི་ཡོན་ཏན་ཆ་ཤས་ཙམ་ལྡན་པའི་སེམས་ཅན་ལ་མཆོད་པའི་བསོད་ནམས་མཐའ་ཡས་པས་དད་པར་རིགས་པའོ། །

Enumeration Block 9:
གཉིས་པ་སྟོན་པ་ལ་དད་པས་གུས་པར་བྱ་བ་ལ་གཉིས།
སེམས་ཅན་མཐའ་དག་བུ་གཅིག་པ་ལྟར་བདག་གིར་མཛད་པས་གུས་པར་བྱ་བ་དང༌།
དེས་ན་སེམས་ཅན་ལ་ཡང་གུས་པར་བྱ་བ་བསྡུས་ཏེ་བསྟན་པའོ། །
དང་པོ་ལ་གསུམ།

མི་མཉེས་པ་སྔར་བྱས་བཤགས་པ་དང༌།
ཕྱིས་འབྱུང་སྡོམ་པའོ།
དང་པོ་ལ་གཉིས།
སངས་རྒྱས་ལ་བྱས་ཤེས་དྲིན་དུ་གཟོ་བའི་ཐབས་ཀྱི་གཙོ་བོ་ངོས་བཟུང་བ་དང༌།
དེ་ཉིད་བསྒྲུབ་པའོ། །

Enumeration Block 10:
གཉིས་པ་ལ་གསུམ།
སེམས་ཅན་གྱིས་གནོད་པ་བྱས་པ་བཟོད་པར་བྱ་བ་དང༌།
སེམས་ཅན་ལ་དམིགས་པའི་ཁེངས་པ་སྤང་བ་དང༌།
