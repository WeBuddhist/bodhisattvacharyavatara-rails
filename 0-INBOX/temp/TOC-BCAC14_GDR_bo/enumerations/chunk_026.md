Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། ལས་ཀྱི་ང་རྒྱལ་དང༌། ནུས་པ་ལ་ང་རྒྱལ་བྱ་བ་དང༌། ཉོན་མོངས་པ་ལ་ང་རྒྱལ་བྱ་བའོ། །

Enumeration Block 2:
དང་པོ་ལ་གསུམ། ལས་ཀྱི་ང་རྒྱལ་ངོས་བཟུང་བ་དང༌། དེ་ལྟར་བྱེད་པའི་རྒྱུ་མཚན་དང༌། གཞན་གྱི་དམན་པའི་ལས་ལ་ཡང་ཁུར་འཛིན་པའི་ང་རྒྱལ་བྱ་བའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་ལྔ། ནུས་པ་ལ་ང་རྒྱལ་མེད་པའི་ཉེས་པ་དང༌། ང་རྒྱལ་བྱས་པའི་ཕན་ཡོན་དང༌། གཉེན་པོའི་ང་རྒྱལ་ལ་གནས་པར་བྱ་བ་དང་། ཉོན་མོངས་པའི་ང་རྒྱལ་བྱ་བར་མི་རིགས་པ་དང༌། གཉེན་པོའི་ང་རྒྱལ་གྱི་ཕན་ཡོན་ནོ། །

Enumeration Block 4:
བཞི་པ་ལ་གསུམ། ཉོན་མོངས་པའི་ང་རྒྱལ་ལ་སྨད་པ་དང༌། དེའི་ཉེས་དམིགས་དང༌། དེ་སྤང་བར་རིགས་པའོ། །

Enumeration Block 5:
གསུམ་པ་ལ་གསུམ། ཉོན་མོངས་ཀྱི་གཉེན་པོའི་སྟོབས་བསྐྱེད་པར་བྱ་བ་དང༌། དེའི་དབང་དུ་ཅུང་ཟད་ཙམ་ཡང་མི་འགྱུར་བར་བྱ་བ་དང༌། གཉེན་པོ་བརྟན་པའི་བསམ་པ་ཁྱད་པར་ཅན་བསྐྱེད་པར་བྱ་བའོ། །

Enumeration Block 6:
གསུམ་པ་དགའ་བའི་སྟོབས་ལ་གསུམ། རྣམ་སྨིན་ལ་མི་ལྟོས་པར་དགེ་བ་ལ་འབད་པར་བྱ་བ་དང༌། འབྲས་བུ་ཡིད་ལ་བྱས་ཏེ་དགེ་བ་བསྒྲུབ་པ་དང༌། དགའ་བའི་སྟོབས་ལ་སྦྱར་བའི་ཚུལ་ལོ། །

Enumeration Block 7:
བཞི་པ་དོར་བའི་སྟོབས་ལ་གཉིས། རེ་ཤིག་དོར་བ་དང༌། གཏན་དོར་བའོ། །

Enumeration Block 8:
གཉིས་པ་དྲན་པ་དང་ཤེས་བཞིན་གྱིས་སྤྱོད་པ་ཉམས་སུ་བླང་བ་ལྷུར་བྱ་བ་ལ་ལྔ། བག་ཡོད་ལྷུར་བླང་བ་དང༌། དྲན་པ་དང་ཤེས་བཞིན་ལྷུར་བླང་བ་དང༌། དྲན་ཤེས་ཀྱིས་ཉེས་པའི་སྐབས་མི་དབྱེ་བ་དང༌། ཉེས་པ་བྱུང་བ་དེ་མ་ཐག་ལྡོག་པར་བྱ་བ་དང༌། རིགས་པའི་ལས་ལ་འབད་པར་བྱ་བའོ། །

Enumeration Block 9:
གསུམ་པ་སྤྱོད་པ་བསྒྲུབ་པ་ལ་བདག་ཉིད་དབང་དུ་བྱ་བ་ལ་གཉིས། ལུས་སེམས་ཤིན་ཏུ་སྦྱངས་པས་དགེ་བ་ལ་ལྡང་བ་ཡང་བར་བྱ་བ་དང༌། དཔེ་དོན་སྦྱར་བའོ། །

Enumeration Block 10:
དང་པོ་ལ་ཡང་གཉིས་ཏེ་ད་དུང་ལོང་ཡོད་སྙམ་པའི་ཕྱི་ཤོལ་བྱེད་པ་དང༌། བྱ་བ་ངན་པ་ལ་ཆགས་པས་ཟིལ་གྱིས་ནོན་པའོ། །
