# BCA Hindi Translation — Commentary Fact-Check (BCAC19_KS_bo) — general

Method: each verse's Hindi rendering in `bca-hi-general.md` is checked against
Khenpo Zhenga's Tibetan interlinear commentary. This is a preliminary
self-check, not a scholarly sign-off — a domain specialist should review
before treating this grade as final, per this vault's standing rule that an
LLM never marks its own translation output complete.

Note on scope: the `commentary-fact-check` skill is written against the
English translation track (`bo-en-translation/bca-en-<grade>.md`). It was
applied here, unmodified in method, to the Hindi "general" track
(`bo-hi-translations/bca-hi-general.md`) at the user's request. The report
file therefore lives alongside the Hindi translation it checks, following the
skill's own naming convention (`commentary-fact-check-report-<grade>.md`).
