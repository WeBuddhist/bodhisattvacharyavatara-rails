Enumeration Block 1:
གསུམ་པ་གདམས་པ་ནི།

Enumeration Block 2:
གཉིས་པ་བདག་གཞན་བརྗེ་བ་བསྒོམ་པ་ལ།
རྒྱུ་མཚན་མདོར་བསྟན། རྒྱས་པར་བཤད་པ། ཇི་ལྟར་བརྗེ་ཚུལ། བརྗེས་ནས་བསྒྲུབ་ཚུལ་ལོ། །
དང་པོ་ནི།

Enumeration Block 3:
གཉིས་པ་རྒྱས་བཤད་ལ།
གཞན་གྱི་སྡུག་བསྔལ་བླང་ཚུལ། བདག་ཉིད་གཞན་ལ་གཏོང་ཚུལ། བདག་གཞན་གཙོ་བོའི་སྐྱོན་ཡོན། མ་བརྗེས་པ་ཡི་ཉེས་དམིགས། རྩ་བ་བདག་འཛིན་སྤང་ཚུལ་ལོ། །
དང་པོ་ལ་གསུམ་ལས།
དང་པོ་རྒྱུ་མཚན་བསམས་ཏེ་བསྒོམ་ཚུལ་ནི།

Enumeration Block 4:
གཉིས་པ་ཆུང་ངུ་ཉིད་ནས་བསྒོམ་ཚུལ་ནི།

Enumeration Block 5:
གསུམ་པ་དཀའ་ཡང་དོན་གཉིས་འགྲུབ་ཚུལ་ནི།

Enumeration Block 6:
གཉིས་པ་བདག་ཉིད་གཞན་ལ་གཏོང་ཚུལ་ལ་གཉིས་ལས།
དང་པོ་ཚེ་འདིའི་འཇིགས་པ་བསམས་ཏེ་གཏང་ཚུལ་ནི།

Enumeration Block 7:
གཉིས་པ་ཕྱི་མའི་སྡུག་བསྔལ་བསམས་ཏེ་གཏང་ཚུལ་ནི།

Enumeration Block 8:
གསུམ་པ་བདག་གཞན་གཙོ་བོའི་སྐྱོན་ཡོན་ལ་གཉིས་ལས།
དང་པོ་ཁྱད་པར་རྒྱས་པར་བཤད་པ་ནི།

Enumeration Block 9:
གཉིས་པ་བསྡུས་ཏེ་དཔེ་དང་སྦྱར་བ་ནི།

Enumeration Block 10:
བཞི་པ་མ་བརྗེས་པའི་ཉེས་དམིགས་ནི།

Enumeration Block 11:
ལྔ་པ་རྩ་བ་བདག་འཛིན་སྤང་ཚུལ་ནི།

Enumeration Block 12:
གསུམ་པ་ཇི་ལྟར་བརྗེ་ཚུལ་ལ་གསུམ་ལས།
དང་པོ་དོན་དངོས་བསྟན་པ་ནི།

Enumeration Block 13:
གཉིས་པ་བསམ་པས་འཇུག་ཚུལ་ནི།

Enumeration Block 14:
གསུམ་པ་སྦྱོར་བས་འཇུག་ཚུལ་ནི།

Enumeration Block 15:
གསུམ་པ་བཞི་པབརྗེས་ནས་འགྲུབ་ཚུལ་ལ།
བསམ་པས་བསྒྲུབ་ཚུལ་དང༌། སྦྱོར་བས་བསྒྲུབ་ཚུལ་ལོ། །
དང་པོ་ལ།
བསྒོམ་ཚུལ་མདོར་བསྟན། རྒྱས་པར་བཤད་པ། བརྟགས་ནས་འཇུག་ཚུལ་ལོ། །
དང་པོ་ནི།

Enumeration Block 16:
གཉིས་པ་རྒྱས་བཤད་ལ།
མཐོ་བ་ལ་ཕྲག་དོག་བསྒོམ་ཚུལ། མཉམ་པ་ལ་འགྲན་སེམས་བསྒོམ་ཚུལ། དམའ་བ་ལ་ང་རྒྱལ་བསྒོམ་ཚུལ་ལོ། །
དང་པོ་ལ་གཉིས་ལས།
