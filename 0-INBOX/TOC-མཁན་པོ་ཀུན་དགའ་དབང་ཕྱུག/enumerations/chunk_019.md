Enumeration Block 1:
གཉིས་པ་དངོས་གཞི་དམ་བཅའ་བ་ནི།

Enumeration Block 2:
སྤྱིར་སེམས་བསྐྱེད་ཙམ་ལ། ཉན་ཐོས་ཀྱི་སེམས་བསྐྱེད་དང་། ཐེག་པ་ཆེན་པོའི་ལུགས་ཀྱི་སེམས་བསྐྱེད་བཅས་རྣམ་པ་གཉིས་ཡོད་པ་ལ།

Enumeration Block 3:
ཉན་ཐོས་རྣམས་ཀྱི་ལུགས་ལ་དགྲ་བཅོམ་པའི་གོ་འཕང་དུ་སེམས་བསྐྱེད་པ་དང༌། རང་སངས་རྒྱས་ཀྱི་གོ་འཕང་དུ་སེམས་བསྐྱེད་པ་དང༌། སངས་རྒྱས་ཀྱི་གོ་འཕང་དུ་སེམས་བསྐྱེད་པ་དང་བཅས་ཏེ་གསུམ་ཡོད་ན་ཡང་།

Enumeration Block 4:
གཉིས་པ་ཐེག་པ་ཆེན་པོའི་ལུགས་ཀྱི་སེམས་བསྐྱེད་ལ། སྤྱིར་རྣལ་འབྱོར་སྤྱོད་པ་སེམས་ཙམ་པ་རྣམས་ཀྱི་ལུགས་དང་། དབུ་མ་པ་རྣམས་ཀྱི་ལུགས་ཏེ་གཉིས་ཡོད་པ་ལས།

Enumeration Block 5:
གང་བླང་བར་བྱ་བའི་གཞིའམ་སེམས་བསྐྱེད་ཀྱི་སྡོམ་པ་དེ་ཉིད་ནི། ཉེས་སྤྱོད་སྡོམ་པའི་ཚུལ་ཁྲིམས་དང་། དགེ་བ་ཆོས་སྡུད་པའི་ཚུལ་ཁྲིམས་དང༌། སེམས་ཅན་དོན་བྱེད་ཀྱི་ཚུལ་ཁྲིམས་བཅས་གསུམ་ཡིན་ལ།

Enumeration Block 6:
ལེན་པའི་ཆོ་གའི་དབང་དུ་བྱས་ན། ད་ལྟ་སྤྱོད་འཇུག་གི་གཞུང་འདི་ཉིད་ལས་ཇི་ལྟར་གསུངས་པ་ལྟར་སྦྱོར་བ་སྔོན་དུ་འགྲོ་བའི་ཆོས་ལ་ཡན་ལག་བདུན་ནམ་བརྒྱད། དངོས་གཞི་རྗེས་ཟློས་ལན་གསུམ་གྱི་སྒོ་ནས་དམ་བཅའ་བ། མཇུག་རང་གཞན་དགའ་བ་སྒོམ་པ་དང་བཅས་པ་རྣམ་པ་གསུམ་ཀ་ཚང་བའི་སྒོ་ནས་ལེན་པར་བྱེད་པ་སྟེ།
