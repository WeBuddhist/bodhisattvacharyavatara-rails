Enumeration Block 1:
གཉིས་པ་ལོངས་སྤྱོད་པའི་བྱེད་པ་མེད་པ་ལ་དབུལ་བ་ནི་དམ་ཆོས་ཞེས་ཏེ།
གསུམ་པ་ཇི་ལྟར་མཆོད་པའི་ཚུལ་ནི་ཇི་ལྟར་ཞེས་དང༌།

Enumeration Block 2:
གཉིས་པ་ཕྱག་འཚལ་བ་ལ་ཡང་གཉིས་ཀྱི་དང་པོ་ངག་གིས་ཡོན་ཏན་བརྗོད་པ་ནི་ཡོན་ཏན་ཞེས་དང༌།
གཉིས་པ་ལུས་ཀྱིས་འདུད་པ་ནི་དུས་གསུམ་ཞེས་ཏེ།

Enumeration Block 3:
གསུམ་པ་སྐྱབས་འགྲོ་ནི་བྱང་ཆུབ་སྙིང་པོ་ཞེས་ཤོ་ལོ་ཀ་གཅིག་སྟེ།
འདིར་སྐྱབས་འགྲོ་དགེ་བའི་སྔོན་དུ་འགྲོ་བའི་ཚུལ་དང༌། དེའི་རང་བཞིན་ངེས་པར་བྱ་བ་དང༌། དོན་ཏེ་རྗེས་སུ་སྒྲུབ་པ་དང་གསུམ་གྱིས་ངེས་པར་བྱ་བ་ལས་དང་པོ་སྐྱབས་སུ་འགྲོ་བ་ནི་ཐར་པའི་རྒྱུ་ཚོགས་སུ་གྱུར་པའི་དགེ་བ་ཐམས་ཅད་ཀྱི་སྔོན་དུ་ངེས་པར་འགྲོ་སྟེ།

Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་སྟེ། ངོ་བོ་དང༌། རྒྱུ་དང༌། འབྲས་བུའོ། །
དང་པོ་ལ་ཡང་གསུམ་གྱི་དང་པོ་མཚན་ཉིད་ནི་འཇིགས་པ་ལས་ཐར་པའི་ཐབས་སུ་སྟོབ་ནས་སུ་མཐོང་བ་འགའ་ཞིག་ལ་བསམ་པ་ལྟོས་པར་བྱེད་པ་སྟེ།

Enumeration Block 5:
གསུམ་པ་དབྱེ་བ་ལ་གསུམ་སྟེ། ངོ་བོ་དང༌། ཕྲ་རགས་དང༌། ཐེག་པའི་སྒོ་ནས་དབྱེ་བའོ། །

Enumeration Block 6:
གཉིས་པ་རྒྱུ་ལ་གཉིས་ཀྱི་དང་པོ་ཐོབ་པའི་རྒྱུ་ནི་ལུས་ཀྱི་རྟེན་འདུ་ཤེས་མེད་པ་ལས་གཞན་པའི་འགྲོ་བ་གང་རུང་དང༌།

Enumeration Block 7:
གསུམ་པ་འབྲས་བུ་ལ་གཉིས་ཀྱི་དང་པོ་ཐོབ་པ་ཕན་ཡོན་གྱི་འབྲས་བུ་ནི་སངས་རྒྱས་པའི་ཁོངས་སུ་ཆུད་ཅིང་སྡོམ་པ་ཐམས་ཅད་སྐྱེར་རུང་བའི་སྒོ་ནས་རྟེན་ཁྱད་པར་དུ་འགྱུར་བ་དང༌།

Enumeration Block 8:
གསུམ་པ་དོན་དེ་རྗེས་སུ་སྒྲུབ་པ་ལ་གསུམ་སྟེ། ཡང་དག་པར་བླང་བ་དང༌། བླངས་ནས་བསླབ་པར་བྱ་བ་དང་། ཉམས་ན་ཕྱིར་བཅོས་པའོ། །
དང་པོ་ལ་གསུམ་ལས་སྦྱོར་སློབ་དཔོན་ནི་སློབ་མས་དཀོན་མཆོག་དང་སློབ་དཔོན་ལ་མཆོད་པ་ཕུལ་ནས་ཞུ་བ་དང༌།

Enumeration Block 9:
གཉིས་པ་ཡང་གཉིས་ལས་དང་པོ་ཐུན་མོང་གི་བསླབ་བྱ་ནི་ཕན་ཡོན་ལ་སྤྲོ་བས་བདག་ཀྱང་བྱེད་ཅིང་གཞན་ཡང་སྦྱོར་བའི་སྒོ་ནས་སྐྱབས་འགྲོ་ལ་བརྩོན་པར་བྱ་བ་དང༌།

Enumeration Block 10:
བཞི་པ་སྡིག་པ་བཤགས་པ་ལ་སྤྱི་དོན་དང་གཞུང་དོན་གཉིས་ཀྱི་དང་པོ་སྤྱི་དོན་ལ་གསུམ་སཏེ། སྦྱང་བྱ་སྡིག་པའི་སྒོ་དྲུག་དང༌། སྦྱོང་བྱེད་གཉེན་པོའི་སྟོབས་བཞི་དང༌། སྦྱོང་ཚུལ་སྦྱོར་དངོས་རྗེས་གསུམ་མོ། །

Enumeration Block 11:
གཉིས་པ་གཞུང་དོན་ལ་བཞིའི་དང་པོ་སུན་འབྱིན་པའི་སྟོབས་ལ་གཉིས་ལས་དང་པོ་བཤགས་པའི་ཡུལ་མངོན་སུམ་ད་བྱ་བ་ནི་ཕྱོགས་རྣམས་ཞེས་ཤཱཀ་གཅིག་གོ །

Enumeration Block 12:
གཉིས་པ་གསུམ་སྟེ། གང་གིས་སྐྱབས་སུ་འགྲོ་བའི་རྒྱུ་མཚན་དང༌། གང་ལ་འགྲོ་བའི་ཡུལ་དང༌། ཇི་ལྟར་སོང་བའི་དོན་ནོ། །
དང་པོ་ལ་བསྟན་བཤད་གཉིས་ལས་དང་པོ་བདག་ནི་ཞེས་ཤོཀ་གཅིག་སྟེ།
གཉིས་པ་ལ་གཉིས་ཏེ། སྡིག་པ་དོན་མེད་པར་བྱེད་པ་དང༌། དེའི་འཇིགས་པ་ལས་སྐྱབས་དགོས་པའོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མདོར་བསྟན་ནི་གློཀ་གཉིས་ཏེ།
