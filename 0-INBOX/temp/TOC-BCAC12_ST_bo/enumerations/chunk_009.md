Enumeration Block 1:
གྲངས་ཅན་པའི་འདོད་པ་འགོག་པ་ན། གཙོ་བོ་དགག་པ་དང༌། རྣམ་འགྱུར་དགག་པ་དང༌། སྐྱེས་བུ་དགག་པའོ། །

Enumeration Block 2:
སྐྱེས་བུ་དགག་པ་ལ་བྱེད་པ་པོ་ལ་འགལ་བ་དང༌། ཡུལ་ལ་ལོངས་སྤྱོད་པ་རེས་འགའ་བ་དང་འབྲེལ་པ་དགག་པའོ། །

Enumeration Block 3:
གནོད་པ་བྱེད་པ་ལ་ཇི་མི་སྙམ་པའི་བཟོད་པ་ལ་གསུམ་སྟེ། བརྩེ་བའི་མཚན་མ་ཡིད་ལ་བྱ་བ་དང༌། ཁྲོ་བའི་མཚན་མ་མ་དམིགས་པ་དང༌། རང་གི་ཉེས་པ་བརྟག་པའོ། །
དང་པོ་ལ་ཉོན་མོངས་པའི་འཁྲུལ་པས་ཚེ་འདིར་གནོད་པ་བྱེད་པ་དང༌། ཕྱི་མར་གནོད་པ་བྱེད་པ་དང༌། དེས་གཞན་ལ་གནོད་པ་བྱེད་པ་ལ་མི་རིགས་པ་མེད་པ་དང༌། དེས་ན་བརྩེ་བའི་དམིགས་པ་ཡིན་པ་དང༌། དེ་ལ་ཁྲོ་བའི་མཚན་མ་དགག་པ་ལྔ། བག་མེད་པ་ཞེས་པ་དང༌། བསོད་ནམས་ཞེས་པ་དང༌། གང་ཚེ་ཞེས་པ་དང༌། ཉོན་མོངས་ཞེས་པ་དང༌། ཁྲོ་བར་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །

Enumeration Block 4:
གཉིས་པ་ནི་རང་བཞིན་ལ་ཁྲོ་བར་མི་རིགས་པ་དང༌། གནས་སྐབས་ལ་ཁྲོ་བར་མི་རིགས་པ་དང༌། དངོས་དང་བརྒྱུད་པའི་རྒྱུ་བརྟགས་ནས་ཁྲོ་བར་མི་རིགས་པ་གསུམ། གལ་ཏེ་ཞེས་པ་དང༌། འོན་ཏེ་ཞེས་པ་དང༌། དབྱུག་པ་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །

Enumeration Block 5:
གསུམ་པ་ལ་དྲུག་སྟེ། རང་གི་ཉེས་པ་ཡིན་པ་དང༌། སྡུག་བསྔལ་གྱི་རྒྱུའི་ལུས་གཟུང་བའི་ཉེས་པ་ཡིན་པ་དང༌། སྡུག་བསྔལ་གྱི་རྒྱུ་ལ་བརྐམ་པའི་ཉེས་པ་དང༌། གཞན་མི་ཕན་པ་ལ་སྦྱོར་བའི་ཉེས་པ་དང༌། ཁྲོ་བ་ཡིད་ཕྱིན་ཅི་ལོག་ཡིན་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 6:
དྲུག་པ་རྩོད་པ་སྤང་བ་ལ་གསུམ་སྟེ། གཞན་ཕན་འདོགས་བྱེད་དུ་མི་འཐད་པ་སྤང་བ་དང༌། བདག་གནོད་བྱེད་དུ་མི་འཐད་པ་སྤང་བ་དང༌། བདག་ལན་ལ་ལ་སོགས་པ་ཞུགས་པ་དགག་པའོ། །

Enumeration Block 7:
བདག་ལ་བརྙས་སོགས་བསྒྲུབ་པ་ལ་བཟོད་པ་བསྒོམ་པ་ལ་བཞི་སྟེ། ལུས་ལ་མི་གནོད་པ་དང༌། སྡང་བ་དང་འབྲེལ་བས་ཁྲོ་བར་མི་རིགས་པ་དང༌། རྙེད་པའི་བར་ཆད་དུ་འགྱུར་བས་ཁྲོ་བར་མི་རིགས་པ་དང༌། སེམས་ཅན་མ་དད་པ་ལ་ཁྲོ་བའི་ཡུལ་དུ་མི་འོས་པའོ། །

Enumeration Block 8:
དང་པོ་ནི་མི་སྙན་པའི་ཚིག་གིས་ཡིད་ལ་གནོད་པ་དགག་པ་དང༌། བདག་གིར་བཟུང་བའི་ལུས་ལ་སྡུག་བསྔལ་གནོད་བྱེད་ཡིན་པ་དང༌། བརྙས་སོགས་གནོད་བྱེད་མ་ཡིན་པ་གསུམ་ཡིད་ནི་ཞེས་པ་དང༌། ལུས་ལ་ཞེས་པ་དང༌། བརྙས་དང་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །

Enumeration Block 9:
གསུམ་པ་རྙེད་པའི་བར་ཆད་བྱེད་པ་ལ་ཁྲོ་བར་མི་འོས་པ་ནི་དྲུག་སྟེ། རྙེད་པ་ཉིད་ལ་དོན་མེད་པ་དང༌། དེས་ན་བདག་ལ་ལོག་པའི་ཉེས་པ་སྒྲུབ་པ་དགག་པ་དང༌། དོན་མེད་པ་ཉིད་དཔེས་གསལ་བར་བྱེད་པ་དང༌། དོན་མེད་པའི་རྣམ་པ་དང༌། དེ་ཉིད་བསྒྲུབ་པའོ། །

Enumeration Block 10:
བདག་གི་ཕྱོགས་ལ་བརྙས་པ་ལ་སོགས་པ་བྱེད་པ་ལ་མི་བཟོད་ན་དགག་པ་ལ་གཉིས་ཏེ། ཆོས་ལ་ངེས་པར་རྟོག་པ་དང༌། གནོད་པ་བྱེད་པ་ལ་ཇི་མི་སྙམ་པའོ། །

Enumeration Block 11:
གནོད་པ་བྱེད་པ་ལ་ཇི་མི་སྙམ་པའི་བཟོད་པ་ལ་བཞི་སྟེ། ཁྲོ་བའི་མཚན་མ་མ་གྲུབ་པ་དང༌། མི་རིགས་པར་བརྟག་པ་དང༌། རང་གི་ཉེས་པ་བརྟག་པ་དང༌། འབྲས་བུ་ཡིད་ལ་བྱ་བའོ། །

Enumeration Block 12:
བཞི་པ་ནི་བསོད་ནམས་མི་ཉམས་པ་དང༌། སྡུག་བསྔལ་བཟློག་པ་དང༌། དོན་ཆེན་པོ་བསྒྲུབ་པའོ། །
