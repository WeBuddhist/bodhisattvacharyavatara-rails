Enumeration Block 1:
གསུམ་པ་ཡུན་རིང་ཐོགས་ཚུལ་ནི།
གསུམ་པ་སྒྲུབ་པར་གདམས་པ་ནི།
གཉིས་པ་སྦྱོར་བ་ལ།
བརྩོན་པས་དགེ་བ་སྒྲུབ་ཚུལ་དང༌། ཉོན་མོངས་སྤང་བར་གདམས་པའོ།།
དང་པོ་ལ་དྲུག་ལས།
དང་པོ་བརྩོན་འགྲུས་མེད་ན་ཉམས་ཚུལ་ནི།

Enumeration Block 2:
གཉིས་པ་འབྱོར་པ་དཀོན་ཞིང་འཇིག་ཚུལ་ནི།

Enumeration Block 3:
གསུམ་པ་བདེ་འགྲོ་དཀོན་པར་གསུང་ཚུལ་ནི།

Enumeration Block 4:
བཞི་པ་དེ་ཉིད་རིག་པས་བསྒྲུབ་པ་ནི།

Enumeration Block 5:
ལྔ་པ་དལ་བའི་དུས་སུ་འབད་ཚུལ་ནི།

Enumeration Block 6:
དྲུག་པ་མིན་ན་འགྱོད་པས་གདུང་ཚུལ་ནི།

Enumeration Block 7:
གཉིས་པ་ཉོན་མོངས་སྤང་བ་ལ།
སྤོང་བའི་བློ་བསྐྱེད་པ། སྤོང་བའི་ཐབས་བསྟེན་པ། སྤོང་ནུས་པའི་ཚུལ་ལོ།།
དང་པོ་ལ། དགྲའི་མཆོག་ཏུ་བརྟགས་ཏེ་སྤང་ཚུལ་དང༌། བདག་ལ་གནོད་པར་བསམས་ཏེ་སྤང་ཚུལ་ལོ།།
དང་པོ་ལ་བཞི་ལས།
དང་པོ་བྲན་དུ་བྱེད་པས་སྤང་ཚུལ་ནི།

Enumeration Block 8:
གཉིས་པ་སྡུག་བསྔལ་ལ་སྦྱོར་བས་སྤང་ཚུལ་ནི།

Enumeration Block 9:
གསུམ་པ་ཡུན་རིང་གནོད་པས་སྤང་ཚུལ་ནི།

Enumeration Block 10:
བཞི་པ་བསྟེན་པར་དཀའ་བས་སྤང་ཚུལ་ནི།

Enumeration Block 11:
གཉིས་པ་གནོད་པར་བསམས་ཏེ་སྤང་ཚུལ་ནི།

Enumeration Block 12:
གཉིས་པ་ཐབས་ལ་བརྩོན་པས་ཉོན་མོངས་གཞོམ་ཚུལ། དེའི་སྡུག་བསྔལ་བཟོད་ཚུལ། གཉེན་པོ་སྟོབས་ལྡན་བསྐྱེད་ཚུལ་ལོ།།
དང་པོ་ནི།

Enumeration Block 13:
གཉིས་པ་བཟོད་ཚུལ་ལ་གསུམ་ལས།
དང་པོ་ཤིན་ཏུ་རིགས་པས་བཟོད་ཚུལ་ནི།

Enumeration Block 14:
གཉིས་པ་དོན་ཆེན་འགྲུབ་པས་བཟོད་ཚུལ་ནི།

Enumeration Block 15:
གསུམ་པ་ཁས་བླངས་དྲན་པས་བཟོད་ཚུལ་ནི།

Enumeration Block 16:
གསུམ་པ་གཉེན་པོ་བསྐྱེད་ཚུལ་ནི།
