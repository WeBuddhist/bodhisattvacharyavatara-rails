Enumeration Block 1:

Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ལ། ནང་སེམས་ཅན་ལ་ཆགས་པའི་རྣམ་རྟོག་སྤང་བ་དང༌། ཕྱི་ཡོ་བྱད་ལ་ཆགས་པའི་རྣམ་རྟོག་སྤང་བའོ།།
དང་པོ་ལ། རང་བཞིན་ལ་བརྟགས་ཏེ་ཆགས་པ་སྤང་བ་དང༌། མི་གཙང་བར་དྲན་པས་ཆགས་པ་སྤང་བའོ།།
དང་པོ་ལ་གསུམ་ལས།

Enumeration Block 3:
གཉིས་པ་མི་གཙང་བ་དྲན་པས་ཆགས་པ་སྤང་བ་ལ།
ངོ་བོ་ལ་བསམས་ཏེ་ཆགས་པ་སྤང་བ་དང༌། གཞན་ལའང་དཔགས་ཏེ་ཆགས་པ་སྤང་བའོ།།
དང་པོ་ལ་གསུམ་ལས།

Enumeration Block 4:
གཉིས་པ་གཞན་ལའང་དཔགས་ཏེ་ཆགས་པ་སྤང་བ་ལ་བརྒྱད་ལས།

Enumeration Block 5:
གཉིས་པ་ཕྱི་ཡོ་བྱད་ལ་ཆགས་པའི་རྣམ་རྟོག་སྤང་བ་ལ།
འདོད་པ་སྤྱད་པའི་གནས་སྐབས་མེད་ཚུལ། ཚེ་འདིར་སྡུག་བསྔལ་མང་པོ་བསྐྱེད་ཚུལ། གཏན་དུ་འཁོར་བའི་གནས་སུ་འཆིང་ཚུལ། དེས་ན་འདོད་པས་སྐྱོ་བ་བསྐྱེད་ཚུལ་ལོ།།
