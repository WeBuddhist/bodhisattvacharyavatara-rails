Enumeration Block 1:
**(བཞི་པ་)རང་གི་ཉེས་ཚུལ་ལ་གསུམ་ལས།**
**(དང་པོ་)ལེ་ལན་ཡིན་པས་ཉེས་ཚུལ་ནི།**

Enumeration Block 2:
**(གཉིས་པ་)གནོད་བྱར་བཟུང་བས་ཉེས་ཚུལ་ནི།**

Enumeration Block 3:
**(གསུམ་པ་)སྡིག་པ་སྤྱད་པས་ཉེས་ཚུལ་ནི།**

Enumeration Block 4:
**(ལྔ་པ་)གནོད་བྱེད་ཁྲོ་བར་རིགས་ཚུལ་ལ་གསུམ་ལས།**
**(དང་པོ་)རྒྱུ་མཚན་མདོར་བསྟན་ནི་**

Enumeration Block 5:
**(གཉིས་པ་)རྒྱས་པར་བཤད་པ་ནི།**

Enumeration Block 6:
**(གསུམ་པ་)འཁྲུལ་བ་སྤང་པ་ནི།**

Enumeration Block 7:
**(གཉིས་པ་)བརྙས་སོགས་བྱུང་དུས་བསྒོམ་པ་ལ།**
བརྙས་སོགས་གནོད་བྱེད་མིན་པས་ བཟོད་ཚུལ། རྙེད་པའི་བར་ཆད་བྱེད་ཀྱང་བཟོད་ཚུལ། ཁྱད་པར་མི་སྙན་པ་ལ་བཟོད་ཚུལ་ལོ། །
**དང་པོ་ལ་གཉིས་ལས།**
**(དང་པོ་)སེམས་དང་ལུས་ལ་གནོད་པ་མེད་ཚུལ་ནི།**

Enumeration Block 8:
**(གཉིས་པ་)འདི་དང་ཕྱི་མར་གནོད་པ་མེད་ཚུལ་ནི།**

Enumeration Block 9:
**(གཉིས་པ་)རྙེད་པའི་བར་ཆད་བྱེད་ཀྱང་བཟོད་ཚུལ་ལ་གསུམ་ལས།**
**(དང་པོ་)ལོག་འཚོའི་སྡིག་པ་ལྕི་བར་བསྟན་པ་ནི།**

Enumeration Block 10:
**(གཉིས་པ་)རྙེད་པས་འཆི་དུས་ཕན་པ་མེད་ཚུལ་ནི།**

Enumeration Block 11:
**(གསུམ་པ་)གསོན་པའི་དུས་སུའང་ཕན་པ་དཀོན་ཚུལ་ནི།**

Enumeration Block 12:
**(གསུམ་པ་)མི་སྙན་པ་ལ་བཟོད་ཚུལ་ནི།**

Enumeration Block 13:
**(གཉིས་པ་)བཤེས་ལ་ཉེས་པ་བྱུང་དུས་བཟོད་པ་བསྒོམ་པ་ལ།**
ཆོས་ལ་ངེས་པར་སེམས་ པའི་བཟོད་པ། གནོད་པས་ཇི་མི་སྙམ་པའི་བཟོད་པ། སྡུག་བསྔལ་དང་དུ་ལེན་པའི་བཟོད་པའོ། །
**དང་པོ་ནི།**

Enumeration Block 14:
**(གཉིས་པ་)གནོད་པས་ཇི་མི་སྙམ་པ་ལ་བཞི་ལས།**
**(དང་པོ་)རྒྱུ་མཚན་བརྟགས་ཏེ་བཟོད་ཚུལ་ནི།**

Enumeration Block 15:
**(གཉིས་པ་)ལས་ལ་བསམས་ཏེ་བཟོད་ཚུལ་ནི།**

Enumeration Block 16:
**(གསུམ་པ་)གཉེན་པོ་བྱམས་པ་བསྐྱེད་ཚུལ་ནི།**

Enumeration Block 17:
**(བཞི་པ་)སྤང་བྱ་གཞི་ནས་གཞོམ་ཚུལ་ནི།**

Enumeration Block 18:
**(གསུམ་པ་)སྡུག་བསྔལ་དང་དུ་ལེན་པ་ལ་གཉིས་ལས།**
**(དང་པོ་)སྡུག་བསྔལ་སེལ་བས་དང་དུ་བླང་པ་ནི།**
