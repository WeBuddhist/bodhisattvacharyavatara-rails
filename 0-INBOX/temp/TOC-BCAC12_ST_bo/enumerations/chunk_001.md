Enumeration Block 1:
ཕན་ཡོན་དང་ལྡན་པའི་འཐད་པ་ལ་གཉིས་ཏེ། ལུང་དང་རིགས་པའོ། །

Enumeration Block 2:
རིགས་པས་འཐད་པ་ལ་གཉིས་ཏེ། སྨོན་པ་ཕན་ཡོན་དང་ལྡན་པའི་འཐད་པ་དང༌། འཇུག་པ་ཕན་ཡོན་དང་ལྡན་པའི་འཐད་པའོ། །
དང་པོ་ལ་གསུམ་སྟེ། དམིགས་པ་རྒྱ་ཆེ་བ་དང་། དཀོན་པ་དང་། ཕན་འདོགས་ཆེ་བའོ། །

Enumeration Block 3:
གཉིས་པ་དཀོན་པ་ལ་གསུམ་སྟེ། ཕན་པར་འདོད་པའི་སྐྱེ་བོ་གཞན་ལ་མེད་པ་དང་། རང་ལ་མེད་པ་དང་། དེ་ཉིད་ཀྱིས་སེམས་བསྐྱེད་པ་དེ་ཕན་ཡོན་ཆེན་པོར་གྲུབ་པའོ། །

Enumeration Block 4:
འཇུག་པ་ཕན་ཡོན་དང་ལྡན་པའི་འཐད་པ་ལ་ལྔ་སྟེ། སྦྱོར་བས་ཟིན་པ་དང་། བྱེད་པ་མང་བ་དང་། ལན་ལ་མ་ལྟོས་པ་དང་། སྒྲུབ་པ་རྒྱ་ཆེ་བ་དང་། ཞར་ལས་ཞིང་ཁྱད་པར་དུ་འཕགས་པ་བསྟན་པའོ། །

Enumeration Block 5:
དེ་ལྟར་ཕན་ཡོན་བསྔགས་ནས་ད་ནི་སེམས་དེ་རྒྱུད་ལ་བསྐྱེད་པ་ནི་སྦྱོར་བ་དང་། དངོས་གཞི་དང་། རྗེས་གསུམ་མོ། །
དང་པོ་ལ་བདུན་ལས་མཆོད་པའོ། །
དེ་ལ་དྲུག་སྟེ། བདག་དབང་བ་དང་། མི་དབང་བའི་དངོས་པོ་འཇིག་རྟེན་གྱི་ཁམས་གཞན་ན་ཡོད་པ་ཡོངས་སུ་བཟུང་བ་མེད་པ་དང་། ལུས་ཀྱི་དངོས་པོས་མཆོད་པ་དང་། ཡིད་ཀྱིས་སྤྲུལ་པའི་མཆོད་པ་དང་། བླ་ན་མེད་པའི་མཆོད་པ་དང་། བཀུར་སྟིའི་མཆོད་པའོ། །
དེ་རྣམས་ལ་དང་པོ་ལྔ་ནི་རྙེད་པ་ལ། དྲུག་པ་ནི་བཀུར་སྟིའོ། །
རྙེད་པ་ལའང་དང་པོ་བཞི་བླ་ན་ཡོད་པ་ལ། ཐ་མ་བླ་ན་མེད་པའོ། །
བླ་ན་ཡོད་པ་ལའང༌དང་པོ་གསུམ་དངོས་སུ་ཡོད་པ་ལ། བཞི་པ་སྤྲུལ་པའོ། །
དངོས་སུ་ཡོད་པ་ལའང་དང་པོ་གཉིས་ཕྱིའི་མཆོད་པ་དང༌། གསུམ་པ་ནང་གིའོ། །

Enumeration Block 6:
མི་དབང་བ་འཇིག་རྟེན་གྱི་ཁམས་ན་ཡོད་པ་ལ་དྲུག་སྟེ། རྫས་ཀྱི་ཁྱད་པར་ནི་མེ་ཏོག་ཅེས་པ་ནས་རྒྱན་རྣམས་ནི། ཞེས་པའི་བར་ཏེ།

Enumeration Block 7:
ལུས་ཀྱི་དངོས་པོས་མཆོད་པ་ལ་དྲུག་ལས།

Enumeration Block 8:
བློས་སྤྲུལ་པའི་མཆོད་པ་ནི་བཅུ་སྟེ། ཁྲུས་དང་། ན་བཟའ་དང་། རྒྱན་དང་། བྱུག་པ་དང་། མེ་ཏོག་དང་། བདུག་པ་དང་། ཞལ་ཟས་དང་། སྒྲོན་མེ་དང་། བཞུགས་ཁང་དང་། ཆེན་པོ་ལ་འོས་པའི་ཡོ་བྱད་དང་། ལོངས་སྤྱོད་པ་བྱེད་པ་མེད་པ་ལ་མཆོད་པའི་རྣམ་པ་རྒྱུན་མི་འཆད་པར་བྱིན་གྱིས་བརླབ་པའོ། །

Enumeration Block 9:
དྲུག་པ་བཀུར་སྟིའི་མཆོད་པ་ལ་བསྟོད་པ་དང་། ཕྱག་འཚལ་བ་གཉིས་སོ། །

Enumeration Block 10:
སྐྱབས་སུ་འགྲོ་བ་ལ་བསྡུས་པའི་དོན་བདུན་ཏེ། རབ་ཏུ་དབྱེ་བ་དང་། ཁྱད་པར་རྣམ་པར་བཞག་པ་དང་། རང་བཞིན་དང་། འབྲས་བུའི་སྐྱབས་འགྲོ་དང་། སྨོན་པའི་སེམས་བསྐྱེད་ཀྱི་ཁྱད་པར་དང་། དགོས་པ་དང་། སྒྲའི་དོན་དང་། བསླབ་བྱའི་ཁྱད་པར་རོ། །
དབྱེ་བ་ཐུན་མོང་དང་ཐུན་མོང་མ་ཡིན་པ་གཉིས་སོ། ཁྱད་པར་ནི་བཞི་སྟེ། སྐྱབས་གནས་དང་། དུས་ཀྱི་ཁྱད་པར་དང་། རྒྱུ་དང་། ཆེད་དུ་བྱ་བའོ། །
