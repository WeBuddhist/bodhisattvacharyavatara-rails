Enumeration Block 1:
ལྔ་པ་དེས་ན་མགུ་བར་བྱ་བ་ལ་བཞི་ལས།
དང་པོ་རྒྱལ་བའི་བཀའ་དྲིན་བསམས་ཏེ་མགུ་བར་བྱ་བ་ནི།
གཉིས་པ་གཞན་ལ་གནོད་པ་བྱས་ན་མི་དགྱེས་པ་འབྱུང་ཚུལ་ནི།
གསུམ་པ་དེའི་སྡིག་པ་བཤགས་ཏེ་དགྱེས་པ་བསྐྱེད་ཚུལ་ནི།
བཞི་པ་རང་བཞིན་རྣམ་དག་བསམས་ཏེ་གུས་པར་བྱ་བ་ནི།

Enumeration Block 2:
དྲུག་པ་མགུ་བའི་ཕན་ཡོན་བསྟན་པ་ལ།
དོན་གཉིས་འགྲུབ་ཚུལ་མདོར་བསྟན།
དཔེ་ཡི་རྒྱས་པར་བཤད།
སྐབས་དོན་བསྡུས་ཏེ་བསྟན་པའོ།།
དང་པོ་མདོར་བསྟན་ནི།

Enumeration Block 3:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས་ལས།
དང་པོ་གནོད་པ་སྤང་ཚུལ་དཔེ་ཡིས་བཤད་པ་ནི།
གཉིས་པ་མགུ་བར་བྱེད་ཚུལ་དཔེ་ཡིས་བཤད་པ་ནི།

Enumeration Block 4:
གསུམ་པ་དོན་བསྡུ་ནི།

Enumeration Block 5:
གཉིས་པ་གཞུང་དོན་ལ། འབྲེལ་བགོད་དེ་ངོས་བཟུང༌། མི་མཐུན་ཕྱོགས་སྤང་ཚུལ། གཉེན་པོའི་སྟོབས་བསྐྱེད་ཚུལ་ལོ།།
དང་པོ་ནི།

Enumeration Block 6:
གཉིས་པ་མི་མཐུན་ཕྱོགས་ལ་གཉིས་ལས།
དང་པོ་མདོར་བསྟན་ནི།

Enumeration Block 7:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས་ལས།
གང་ལས་ལེ་ལོ་འབྱུང་ཚུལ་ནི།
གཉིས་པ་དེ་ཉིད་རིམ་གྱིས་སྤང་ཚུལ་ལ།
མི་སྦྱོར་བའི་ལེ་ལོ་སྤང་བ། ངན་ཞེན་གྱི་ལེ་ལོ་སྤང་བ། སྒྱིད་ལུག་པའི་ལེ་ལོ་སྤོང་བའོ།།
དང་པོ་ལ་ལྔ་ལས།
དང་པོ་ངེས་པར་འཆི་བ་བསམ་ཏེ་ལེ་ལོ་སྤང་བ་ནི།

Enumeration Block 8:
གཉིས་པ་མྱུར་དུ་འཆི་བ་བསམ་སྟེ་ལེ་ལོ་སྤང་ཚུལ་ནི།
