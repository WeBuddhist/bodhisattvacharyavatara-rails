Enumeration Block 1:
ལྔ་པ་བདག་གཞན་བརྗེ་བ་བསྒོམས་པའི་འབྲས་བུ་ནི་བཞི་སྟེ། མ་བརྗེས་པར་རང་རྗེས་སུ་བཟུང་བའི་ཉེས་པ་དང༌། འབྲས་བུའི་ཤེས་བྱེད་དང༌། འབྲས་བུའི་ཕྱིར་བསྒོམ་པ་ལ་འབད་པའོ། །

Enumeration Block 2:
སྦྱོར་བ་ཇི་ལྟར་བསྒྲུབ་པ་ལ་གཉིས་ཏེ། སྦྱོར་བ་སྒྲུབ་པའི་ཚུལ་དང༌། སྦྱོར་བ་ལ་སེམས་དབང་དུ་བྱ་བའོ། །དང་པོ་ལ་དྲུག་སྟེ། གཞན་ཕན་བདེ་ལ་སྦྱོར་བ་དང༌། ཉེས་པ་ཐམས་ཅད་དང་དུ་བླང་བ་དང༌། གཞན་གྱི་ཕྱིར་དམན་པའི་གནས་ཡང་དག་པར་བླང་བ་དང༌། སྦྱོར་བའི་དོན་བསྡུ་བ་དང༌། གནོད་པ་ཉམས་སུ་བླང་བ་དང༌། སེམས་ཡང་དག་པར་བསྲུང་བའོ། །

Enumeration Block 3:
སྦྱོར་བ་ལ་སེམས་དབང་དུ་བྱ་བ་ནི་བཞི་སྟེ། སེམས་ཚར་གཅད་པའི་ཚུལ་དང༌། རང་ཆེད་དུ་སྦྱོར་བའི་ཉེས་པ་དང༌། འཛིན་པའི་ཡུལ་ལུས་ཀྱི་ཉེས་པ་དང༌། སེམས་དབང་དུ་བྱ་བ་ལ་སྦྱར་བའོ། །

Enumeration Block 4:
རང་ཆེད་དུ་བྱ་བ་མི་རིགས་པ་བསྒྲུབ་པའི་ཕྱིར་འཛིན་པ་དེའི་ཡུལ་ལུས་ཀྱི་ཉེས་དམིགས་བརྗོད་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཆོག་མི་ཤེས་པ་དང༌། གཡོ་བ་མེད་པ་དང༌། རྨོངས་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཆོག་མི་ཤེས་པའི་ཉེས་པ་དངོས་སུ་བསྟན་པ་དང༌། ཞར་ལ་ཆོག་ཤེས་པའི་ཕན་ཡོན་བསྟན་པའོ། །

Enumeration Block 5:
རྨོངས་པ་ལ་བཞི་སྟེ། ལེགས་ཉེས་ལ་རྨོངས་པ་དང༌། བསྟོད་སྨད་ལ་རྨོངས་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ་དང༌། ཉེས་དམིགས་ཀྱི་རྟེན་དེ་དགོས་པ་ལ་སྦྱར་བའོ། །

Enumeration Block 6:
ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་ལེའུ་ལ་དོན་ལྔ་སྟེ། ཤེས་རབ་གཙོ་བོར་བསྟན་པ་དང༌། དེའི་རང་བཞིན་སྟོང་པ་ཉིད་ཤེས་པ་ཡིན་པ་དང༌། སྟོང་པ་ཉིད་བསྒོམ་པ་ལ་འཇུག་པའི་ཚུལ་དང༌། དངོས་པོར་འཛིན་པ་དགག་པ་དང༌། སྟོང་པ་ཉིད་བསྒོམས་པའི་འབྲས་བུའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཤེས་རབ་གཙོ་བོར་བཞག་པའི་འཐད་པ་དང༌། དེ་ཉིད་ཀྱིས་དེ་ལ་འབད་པར་གདམས་པའོ། །

Enumeration Block 7:
དེའི་རང་བཞིན་སྟོང་པ་ཉིད་ཡིན་པ་ནི་གཉིས་ཏེ། ཡུལ་སྟོང་པར་བསྒྲུབ་པ་དང༌། ཡུལ་ཅན་ལམ་དུ་བསྒྲུབ་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། རང་གི་ལུགས་ཀྱི་བདེན་པ་གཉིས་ཀྱི་རང་བཞིན་དང༌། དེ་ལ་ཀུན་རྫོབ་ཀྱི་སྒོ་ཅན་གྱི་གནོད་པ་སྤང་བ་དང༌། དོན་དམ་པའི་སྒོ་ཅན་གྱི་གནོད་པ་སྤང་བའོ། །

Enumeration Block 8:
དང་པོ་ལའང་དབྱེ་གཞི་དང༌། དབྱེ་བའི་དོན་དང༌། གྲངས་ངེས་པ་དང༌། སྒྲའི་དོན་བཞིའོ། །

Enumeration Block 9:
དེ་ལ་རྩོད་པ་སྤང་བ་ལ་གཉིས་ཏེ། སྤྱོད་པ་དོན་མེད་པས་རྩོད་པ་སྤང་བ་དང༌། རྟོགས་པ་ཁྱད་མེད་པའི་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 10:
འདི་ལ་བཞི་སྟེ། ཚོགས་ཀྱི་རྟེན་གསུངས་པས་མི་གནོད་པ་དང༌། ཉིང་མཚམས་སྦྱོར་བར་གསུངས་པས་མི་གནོད་པ་དང༌། ལས་ཀྱི་རྟེན་གསུངས་པས་མི་གནོད་པ་དང༌། འཁོར་བ་དང་མྱ་ངན་ལས་འདས་པའི་ཐ་དད་རྣམ་པར་བཞག་པས་མི་གནོད་པའོ། །
