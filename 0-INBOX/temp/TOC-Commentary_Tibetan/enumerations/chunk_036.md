Enumeration Block 1:
**(གཉིས་པ་)གཞུང་དོན་ལ།**
འབྲེལ་བཀོད་དེ་ངོས་བཟུང༌། མི་མཐུན་ཕྱོགས་སྤང་ཚུལ། གཉེན་པོའི་སྟོབས་བསྐྱེད་ཚུལ་ལོ། །

Enumeration Block 2:
**(གཉིས་པ་)དེ་ཉིད་རིམ་གྱིས་སྤང་ཚུལ་ལ།**
མི་སྦྱོར་བའི་ལེ་ལོ་སྤང་བ། ངན་ཞེན་གྱི་ལེ་ལོ་སྤང་བ། སྒྱིད་ལུག་པའི་ལེ་ལོ་སྤང་བའོ། །
**དང་པོ་ལ་ལྔ་ལས།**

Enumeration Block 3:
**(གསུམ་པ་)སྒྱིད་ལུག་པའི་ལེ་ལོ་སྤང་བ་ལ་གཉིས་ལས།**

Enumeration Block 4:
**(གཉིས་པ་)རྒྱས་བཤད་ལ་གཉིས་ལས།**

Enumeration Block 5:
**(གཉིས་པ་)རྒྱུའི་དཀའ་སྤྱད་ལ་འཇིགས་པ་སྤང་པ་ལ་བཞི་ལས།**
