Enumeration Block 1:
གཙོ་བོ་རང་བཞིན་རྟག་པ་དགག་པ་ལ་བཞི་སྟེ། སྣང་བ་མི་དམིགས་པས་དགག་པ་དང༌། ཕྲ་རགས་འགལ་བ་དང༌། གནས་སྐབས་མི་རྟག་པར་གྲུབ་པ་དང༌། རང་བཞིན་མི་རྟག་པར་བསྒྲུབ་པའོ། །

Enumeration Block 2:
སྐབས་སུ་བབ་པ་རང་ལས་སྐྱེ་བ་དགག་པ་ལ་བཞི་སྟེ། དགག་པའི་ཡུལ་བརྗོད་པ་དང༌། རང་གི་འདོད་པས་མ་ངེས་པ་དང༌། འཇུག་པ་འཆོལ་བ་དང༌། རྩོད་པ་སྤང་བའོ། །

Enumeration Block 3:
བཞི་པ་རྩོད་པ་སྤང་བ་ལ་གསུམ་སྟེ། འཇུག་པ་མཚུངས་པ་དང༌། འཇིག་རྟེན་རྨོངས་པར་འགལ་བ་དང༌། འབྲས་བུའི་འཇུག་པ་སླུ་བར་ཐལ་བའོ། །

Enumeration Block 4:
དེ་ལ་གསུམ་སྟེ། རྒོལ་བ་དགོད་པ་དང༌། ཐལ་འགྱུར་དང་པོའི་ལན་ཡོངས་གཅོད་ཚད་མ་མ་ཡིན་པ་འདོད་པ་དང༌། ཐལ་འགྱུར་གཉིས་པའི་ལན་ཁྱབ་པ་མ་གྲུབ་སྟེ་རྣམ་དཔྱད་ཀྱང་ཚད་མར་མི་འགལ་བའོ། །

Enumeration Block 5:
འདི་ལ་གསུམ་སྟེ། སྐྱེ་བ་བཞི་པོ་དགག་པའི་དོན་བསྡུ་བ་དང༌། དེ་སྐྱེ་མེད་འགག་མེད་དང་འགྲོ་འོང་མེད་པ་ཉིད་དུ་བསྟན་པ་དང༌། དེའི་ཤུགས་ལས་རྟེན་འབྲེལ་སྒྱུ་མ་ཙམ་དུ་བསྟན་པའོ། །

Enumeration Block 6:
གསུམ་པ་རྟེན་འབྲེལ་སྒྱུ་མ་ཙམ་དུ་བརྟག་པ་ལ་གསུམ་སྟེ། སྒྱུ་མ་ལྟ་བུར་བསྟན་པ་དང༌། དེ་རྟེན་འབྲེལ་དུ་བསྟན་པ་དང༌། རྟེན་འགྲེལ་གྱི་ཁྱབ་བསྒྲུབ་ཀྱིས་རྟེན་འབྲེལ་རང་བཞིན་མེད་པར་བསྟན་པའོ། །

Enumeration Block 7:
དེ་ལ་བཞི་སྟེ། རྟགས་དགོད་པ་དང༌། རྗེས་སུ་འགྲོ་བའི་ཁྱབ་པ་བསྟན་པ་དང༌། དེའི་དཔེ་དང༌། དོན་ལ་སྦྱར་བའོ། །

Enumeration Block 8:
དེའི་དོན་ལ་གཉིས་ཏེ། གཏན་ཚིགས་ཀྱི་དོན་དང་རྟགས་ཀྱི་ངེས་པའི་དོན་ཏོ། །
དང་པོ་ལ་གཉིས་ཏེ། ཡོད་པ་སྐྱེ་བ་དགག་པ་དང༌། མེད་པ་སྐྱེ་བ་དགག་པའོ། །

Enumeration Block 9:
མེད་པ་སྐྱེ་བ་དགག་པ་ལ་གསུམ་སྟེ། རིགས་པ་མདོར་གཞག་པ་དང༌། དངོས་མེད་རྒྱུའི་ནུས་པ་ཡུལ་དུ་འགལ་བ་དང༌། ནུས་པའི་ཡུལ་ཉིད་དགག་པའོ། །

Enumeration Block 10:
རྟགས་ཀྱིས་ངེས་པའི་དོན་བསྡུ་བ་ལ་གསུམ་སྟེ། མཐའ་གཉིས་ལས་གྲོལ་བ་དང༌། སྒྱུ་མ་ལྟར་གནས་པ་དང༌། སྲིད་པ་ཞི་བ་མཉམ་པ་ཉིད་དོ། །

Enumeration Block 11:
སྟོང་པ་ཉིད་བསྒོམས་པའི་འབྲས་བུ་ལ་ཁ་ཅིག་འདི་ལྟར་འཆད་དེ། རང་གི་དོན་དང༌། གཞན་གྱི་དོན་གཉིས་སོ། །
དང་པོ་ལ་གཉིས་ཏེ། མངོན་པར་ཞེན་པ་ཞི་བ་དང༌། སྡུག་བསྔལ་ཞི་བའོ། །
དང་པོ་ལ་གཉིས་ཏེ། མངོན་པར་ཞེན་པའི་ཡུལ་འཇིག་རྟེན་པའི་ཆོས་མ་གྲུབ་པ་དང༌། དེ་ལྟར་བརྟེན་པའི་སྲིད་པ་ལྡོག་པའོ། །

Enumeration Block 12:
དེ་ལ་སྟོང་པ་ཉིད་མ་རྟོགས་པའི་སྡུག་བསྔལ་གཉིས་ཏེ། མཐོང་བའི་སྡུག་བསྔལ་རྩོམ་པས་བསྡུས་པ་དང༌། ཚེ་གཞན་གྱི་སྡུག་བསྔལ་ལོ། །

Enumeration Block 13:
མ་མཐོང་བའི་སྡུག་བསྔལ་ལ་བཞི་སྟེ། ངན་སོང་གི་སྡུག་བསྔལ་དང༌། སྡུག་བསྔལ་བརྒྱུད་མར་འཇུག་པ་དང༌། སྡུག་བསྔལ་དུ་མ་ཤེས་པ་དང༌། མྱོང་བར་འགྱུར་བའི་སྡུག་བསྔལ་གྱི་རྣམ་པའོ། །

Enumeration Block 14:
ཅིའི་ཕྱིར་ཞེ་ན། རྒྱུ་མཚན་ལྔ་སྟེ། སྡུག་བསྔལ་གྱི་རྩ་བ་མ་ཞི་བ་དང༌། བཟློག་པའི་ཐབས་མེད་པ་དང༌། བར་ཆོད་མང་བ་དང༌། རྟེན་བརྟེན་དཀའ་བ་དང༌། རྒྱུ་སྤང་དཀའ་བས་སོ། །

Enumeration Block 15:
གསུམ་པ་ནི་གཉིས་ཏེ་ཕྱིའི་བར་ཆོད་དང༌། ནང་གི་བར་ཆོད་དོ། །

Enumeration Block 16:
དེས་ན་གཞན་དོན་ལ་གཉིས་ཏེ། སྡུག་བསྔལ་ཞི་བ་དང༌། མངོན་ཞེན་ཞི་བའོ། །

Enumeration Block 17:
དེ་དག་འདོད་པའི་ཡུལ་དུ་བཞག་པས་བསམ་པའི་དགེ་བ་བསྔོ་བ་ཐབས་ཀྱིས་སྟོན་པ་ནི་ལྔ་སྟེ། ཐབས་དང་འབྲེལ་པའི་བསྔོ་བ་དང༌། གཞན་གྱི་དོན་དུ་བསྔོ་བ་དང༌། རང་གི་དོན་དུ་བསྔོ་བ་དང༌། བདེ་བའི་འབྱུང་གནས་བསྟན་པའི་དོན་དུ་བསྔོ་བ་དང༌། བཀའ་དྲིན་རྗེས་སུ་དྲན་པས་ཕྱག་འཚལ་བའོ། །

Enumeration Block 18:
གཉིས་པ་ལ་གཉིས་ཏེ། འཇིག་རྟེན་པའི་དོན་དུ་བསྔོ་བ་དང༌། འཇིག་རྟེན་ལས་འདས་པའི་དོན་དུ་བསྔོ་བའོ། །
དང་པོ་ལ་གསུམ་སྟེ། སྤྱིར་བསྔོ་བ་དང༌། བྱེ་བྲག་ཏུ་ངན་འགྲོའི་དོན་དུ་བསྔོ་བ་དང༌། བདེ་འགྲོའི་དོན་དུ་བསྔོ་བའོ། །
