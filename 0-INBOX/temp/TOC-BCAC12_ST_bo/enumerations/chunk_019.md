Enumeration Block 1:
བཞི་པ་ཕྲིན་ལས་འཇུག་པ་འདབ་པ་ལ་མི་ལྟོས་པ་ནི་གསུམ་སྟེ། རྒྱུད་དག་པའི་གདུལ་བྱ་ལ་རྒྱལ་བའི་སྐུ་སྣང་བ་དང༌། སྣང་བ་དེས་ཕན་པ་ལ་འཇུག་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 2:
དེ་ལ་རྩོད་པ་སྤང་བ་ལ་གསུམ་སྟེ། རྩོད་པ་དགོད་པ་དང༌། ལུང་གི་རྟགས་དགོད་པ་དང༌། དེའི་ཁྱབ་པ་བསྒྲུབ་པའོ། །

Enumeration Block 3:
དེ་ལྟ་བུའི་ཡུལ་ཅན་ལམ་དུ་བསྒྲུབ་པ་ལ་ཉན་ཐོས་ཀྱི་རྩོད་པ་སྤང་བ་ལ་དྲུག་སྟེ། རྒོལ་བ་དགོད་པ་དང༌། དེ་ལམ་དུ་ལུང་གིས་སྒྲུབ་བྱེད་དང༌། ལུང་དེ་བཀར་བསྒྲུབ་པ་དང༌། ལུང་ངེས་དོན་དུ་བསྒྲུབ་པ་དང༌། སྐབས་ཀྱི་དོན་བསྡུ་བ་དང༌། བཀར་བསྒྲུབ་པའི་སྒྲུབ་བྱེད་རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལུང་བཀར་བསྒྲུབ་པ་ལ་གཉིས་ཏེ། བླང་བའི་རྒྱུ་མཚན་མཚུངས་པ་དང༌། དོར་བའི་རྒྱུ་མཚན་མཚུངས་པའོ། །

Enumeration Block 5:
ཇི་ལྟར་ཞེ་ན་བཞི་སྟེ། གཞན་གྱི་ལུགས་ལ་ཉོན་མོངས་པ་སྤངས་པའི་དགེ་སློང་མི་འཐད་པ་དང༌། སྡུག་བསྔལ་སྤངས་པའི་མྱ་ངན་ལས་འདས་པ་མི་འཐད་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ་དང༌། འཐད་པས་སྦྱར་བའོ། །

Enumeration Block 6:
རྩོད་པ་སྤང་བ་ལ་གཉིས་ཏེ། ཚེ་འདིའི་སྡུག་བསྔལ་ཡོད་པ་དང༌། ཕྱི་མའི་སྡུག་བསྔལ་ཡོད་པའོ། །དང་པོ་ལ་རྒོལ་བ་དང༌། དེའི་ལན་དང༌། དེའི་འདོད་པ་ལ་གནོད་པའོ། །

Enumeration Block 7:
དེ་ལ་གསུམ་སྟེ། རྩོད་པ་དགོད་པ་དང༌། སྲེད་པ་ཉིད་ཡོད་པ་དང༌། དེའི་རྒྱུ་ཚོར་བ་ཡོད་པའོ། །

Enumeration Block 8:
ལྔ་པ་ཐེག་པ་ཆེན་པོའི་ལུང་བཀར་བསྒྲུབ་པའི་སྒྲུབ་བྱེད་རྒྱས་པར་བཤད་པ་ལ་གཉིས་ཏེ། རྒྱུ་མཚན་མཚུངས་པ་དང༌། མ་རྟོགས་པས་སྤོང་བར་མི་འཐད་པའོ། །

Enumeration Block 9:
ཤེས་པ་གཉིས་ཀྱི་བྱེད་པ་བསྡུས་ཏེ་བསྟན་པ་ལ་བཞི་སྟེ། མཆོག་ཏུ་གྱུར་པའི་འབྲས་བུ་བསྐྱེད་པ་དང༌། དེས་ན་སུན་དབྱུང་བའི་གནས་མ་ཡིན་པ་དང༌། བསྒོམ་པའི་གཉེན་པོ་བྱེད་པ་དང༌། སྐྲག་པའི་རྒྱུ་མ་ཡིན་པའོ། །

Enumeration Block 10:
བཞི་པ་ནི་གཉིས་ཏེ། སྡུག་བསྔལ་གྱི་རྒྱུ་མ་ཡིན་པ་དང༌། འཇིགས་པ་པོའི་བདག་མ་གྲུབ་པའོ། །

Enumeration Block 11:
སྟོང་པ་ཉིད་བསྒོམ་པའི་ཚུལ་ལ་འཇུག་པ་ལ་གཉིས་ཏེ། གང་ཟག་གི་བདག་མེད་པ་བསྒོམ་པ་ལ་འཇུག་པའི་ཚུལ་དང༌། ཆོས་ཀྱི་བདག་མེད་པ་བསྒོམ་པ་ལ་འཇུག་པའི་ཚུལ་ལོ། །

Enumeration Block 12:
འདི་ལ་བཞི་སྟེ། ཁམས་དྲུག་བདག་མེད་པ་སྤྱིར་བསྟན་པ་དང༌། ཕུང་པོ་དང་ཁམས་ལ་སོགས་པའི་བདག་མུ་སྟེགས་ཀྱི་བརྟགས་པ་དགག་པ་དང༌། བདག་མེད་པ་ལ་རྩོད་པ་སྤང་བ་དང༌། ཕུང་པོ་དང་ཁམས་ཉིད་ལ་བདག་ཏུ་རྟོགས་པ་དྲན་པ་ཉེ་བར་གཞག་པ་བཞིས་དགག་པའོ། །

Enumeration Block 13:
གཉིས་པ་ཕུང་པོ་ལ་སོགས་པ་བརྟགས་པའི་བདག་དགག་པ་ལ་གཉིས་ཏེ། གྲངས་ཅན་གྱི་དང༌། རིགས་པ་ཅན་གྱིའོ། །

Enumeration Block 14:
དེ་དགག་པ་ལ་གསུམ་སྟེ། སྐྱེས་བུ་སྤྱིར་དགག་པ་དང༌། གནས་སྐབས་དུ་མ་དང་འབྲེལ་པ་དགག་པ་དང༌། རང་བཞིན་གཅིག་དགག་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། ཐལ་བའི་རྟགས་དགོད་པ་དང༌། ཁྱབ་པ་བསྒྲུབ་པ་དང༌། རྩོད་པ་སྤང་བའོ། །

Enumeration Block 15:
གཉིས་པ་ཁྱབ་པ་བསྒྲུབ་པ་ལ་གསུམ་སྟེ། རང་བཞིན་ཉམས་པ་དང༌། ཧ་ཅང་ཐལ་བ་དང༌། སྐབས་བསྡུ་བའོ། །

Enumeration Block 16:
གསུམ་པ་རྩོད་པ་སྤང་བ་ལ་ལྔ་སྟེ། སྒྲ་འཛིན་གཟུགས་ཤེས་སུ་མི་འཐད་པ་དང༌། སྔར་བཤད་པའི་ཉེས་པ་མཚུངས་པ་དང༌། གཅིག་གི་ཐ་སྙད་མི་འཐད་པ་དང༌། དཔེ་མ་གྲུབ་པ་དང༌། གཅིག་པ་ཉིད་དུ་མི་དམིགས་པའོ། །

Enumeration Block 17:
རང་བཞིན་གཅིག་དགག་པ་ལ་དྲི་བ་དང་ལན་གཉིས་སོ། །

Enumeration Block 18:
དེའི་ལན་ལ་གསུམ་སྟེ། འགྲོ་བ་ཐམས་ཅད་གཅིག་ཏུ་ཐལ་བ་དང༌། བློ་དང་སྐྱེས་བུ་གཅིག་ཏུ་ཐལ་བ་དང༌། སྤྱི་ཉིད་མ་གྲུབ་པའོ། །

Enumeration Block 19:
རིག་པ་ཅན་གྱི་བདག་དགག་པ་ལ་གསུམ་སྟེ། རང་བཞིན་བེམ་པོ་ལ་བདག་དགག་པའི་ཐལ་བ་དགོད་པ་དང༌། སེམས་པ་གཞན་དང་ལྡན་པས་ཁྱབ་པ་མ་གྲུབ་པར་སེམས་པ་ལ་དེའི་ཁྱབ་པ་བསྒྲུབ་པ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 20:
བདག་མེད་པ་ལ་རྩོད་པ་སྤང་བ་ལ་ཡང་གཉིས་ཏེ། ལས་འབྲས་འབྲེལ་པར་མི་རིགས་པའི་རྩོད་པ་སྤང་བ་དང༌། སྙིང་རྗེ་བསྒོམ་པའི་ཡུལ་མི་འཐད་པ་སྤང་བའོ། །དང་པོ་ལ་དྲུག་སྟེ། རྩོད་པ་དགོད་པ་དང༌། ཁས་བླངས་མཚུངས་པ་དང༌། དངོས་པོའི་ལན་དང༌། དེ་ལ་ལུང་དང་འགལ་བ་སྤང་བ་དང༌། རྩོད་པ་སྤང་བ་དང༌། དོན་བསྡུ་བའོ། །
