Enumeration Block 1:
གཉིས་པ་བདག་གཞན་བརྗེ་བ་བསྒོམ་པ་ལ།
རྒྱུ་མཚན་མདོར་བསྟན།
རྒྱས་པར་བཤད་པ། ཇི་ལྟར་བརྗེ་ཚུལ། བརྗེས་ནས་བསྒྲུབ་ཚུལ་ལོ།།

Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ལ། གཞན་གྱི་སྡུག་བསྔལ་བླང་ཚུལ། བདག་ཉིད་གཞན་ལ་གཏོང་ཚུལ། བདག་གཞན་གཙོ་བོའི་སྐྱོན་ཡོན། མ་བརྗེས་པ་ཡི་ཉེས་དམིགས། རྩ་བ་བདག་འཛིན་སྤང་ཚུལ་ལོ།།

Enumeration Block 3:
དང་པོ་ལ་གསུམ་ལས།

Enumeration Block 4:
གཉིས་པ་བདག་ཉིད་གཞན་ལ་གཏོང་ཚུལ་ལ་གཉིས་ལས།

Enumeration Block 5:
གསུམ་པ་བདག་གཞན་གཙོ་བོའི་སྐྱོན་ཡོན་ལ་གཉིས་ལས།

Enumeration Block 6:
གསུམ་པ་ཇི་ལྟར་བརྗེ་ཚུལ་ལ་གསུམ་ལས།

Enumeration Block 7:
གསུམ་པ་བརྗེས་ནས་བསྒྲུབ་ཚུལ་ལ།
བསམ་པས་བསྒྲུབ་ཚུལ་དང༌། སྦྱོར་བས་བསྒྲུབ་ཚུལ་ལོ།།
དང་པོ་ལ། བསྒོམ་ཚུལ་མདོར་བསྟན།
རྒྱས་པར་བཤད་པ། བརྟགས་ནས་འཇུག་ཚུལ་ལོ།།
