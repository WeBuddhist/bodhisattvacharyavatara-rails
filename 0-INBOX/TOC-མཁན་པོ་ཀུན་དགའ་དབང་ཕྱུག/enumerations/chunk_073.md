Enumeration Block 1:
གཉིས་པ་དབྱེ་བ་ནི། ཀུན་རྫོབ་ཀྱི་བདེན་པ་དང༌། དོན་དམ་པའི་བདེན་པ་ཞེས་བྱ་བ་རྣམ་པ་གཉིས་ཏེ།

Enumeration Block 2:
གསུམ་པ་གྲངས་ངེས་ནི།

Enumeration Block 3:
བཞི་པ་དབྱེ་བའི་ངོ་བོ་ནི།

Enumeration Block 4:
དྲུག་པ་རྟོགས་བྱེད་ཀྱི་བློ་ནི།

Enumeration Block 5:
བདུན་པ་རྟོགས་ཚུལ་གྱི་དབང་དུ་བྱས་ན།

Enumeration Block 6:
བརྒྱད་པ་བདེན་གཉིས་སོ་སོར་རྟོགས་པའི་གང་ཟག་གི་དབང་དུ་བྱས་ན།

Enumeration Block 7:
གཉིས་པ་བདེན་གཉིས་ཀྱི་མཚན་ཉིད་ནི།

Enumeration Block 8:
གསུམ་པ་བདེན་གཉིས་གཏན་ལ་འབེབས་པའི་གང་ཟག་ནི།

Enumeration Block 9:
གཉིས་པ་དེ་ལ་རྩོད་པ་སྤོང་བ་ལ་གསུམ། གཞི་བདེན་གཉིས་ལ་རྩོད་པ་སྤོང་བ། ལམ་སྟོང་ཉིད་ལ་རྩོད་པ་སྤོང་བ། འབྲས་བུ་གཞན་དོན་ལ་རྩོད་པ་སྤོང་བའོ། །
དང་པོ་ལ་གསུམ། འཇིག་རྟེན་ผལ་བའི་རྩོད་པ་སྤོང་བ། ཉན་ཐོས་ཀྱི་རྩོད་པ་སྤོང་བ། སེམས་ཙམ་པའི་རྩོད་པ་སྤོང་བའོ། །

Enumeration Block 10:
གཉིས་པ་ཉན་ཐོས་ཀྱི་རྩོད་སྤོང་ལ་བྱེ་སྨྲའི་རྩོད་པ་སྤོང་བ་དང་། མདོ་སྡེ་པའི་རྩོད་པ་སྤོང་བ་གཉིས་ལས།
