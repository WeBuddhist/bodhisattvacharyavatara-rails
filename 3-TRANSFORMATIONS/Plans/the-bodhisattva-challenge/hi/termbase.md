# शब्दावली — हिंदी धारा

`hi/Days/` के लिए एक शब्द का एक ही अनुवाद। दिन १–३१ के प्रयोग से संकलित।

मूल नियम: **जो शब्द हिंदी में रोज़ बोला जाता है, वही चुनें।** संस्कृत का भारी पर्याय तभी लें जब सादा शब्द बात को कमज़ोर कर दे।

## जिन्हें सादा शब्द से खोलें

| तिब्बती | हिंदी | टिप्पणी |
|---|---|---|
| བག་ཆགས། | छाप | तिब्बती से सीधे; "संस्कार" या "latent imprint" के रास्ते नहीं। |
| བར་དོ། | बीच की हालत (बरदो) | पहली बार दोनों, फिर "बरदो"। |
| ངན་སོང། | दुर्गति / बुरी गतियाँ | |
| ཉོན་མོངས། | मन के विकार | "क्लेश" अकेला न लिखें। |
| མི་རྟག་པ། | कुछ भी टिकता नहीं | "अनित्यता" संज्ञा की तरह न लिखें। |
| བཤགས་པ། | गलती कबूल करना | "क्षमा-याचना", "पाप देशना", "प्रायश्चित" — तीनों से बचें। |
| སྟོབས་བཞི། | चार ताकतें | पछतावा, सहारा, इलाज, और फिर न करने का इरादा। |
| སུན་འབྱིན་པའི་སྟོབས། | पछतावे की ताकत | चारों में पहली। |

| ཕན་འདོགས་པའི་ཞིང། | उपकार का खेत | |

## व्याख्याकारों के नाम — एक ही रूप

| रेल आईडी | हिंदी |
|---|---|
| kunpal | खेनपो कुनज़ंग पल्देन |
| khenpo-zhengah | खेनपो ज़ेंगा |
| gyaltsab | ग्यालत्सब |
| ngulchu-thogmed | नगुलचु थोगमे |
| sabzang | सज़ंग |
| minyak-kunzang-sonam | मिन्याक कुनसो |
| khenpo-kunga | खेनपो कुंगा वंगचुक |
| tenzin-gyatso | परम पावन दलाई लामा |

ग्रंथों के नाम: "राजा को दी गई सलाह", *उदानवर्ग*, *स्वर्णप्रभास सूत्र*, *स्मृत्युपस्थान*।

आचार्य शांतिदेव — पहली बार "आचार्य शांतिदेव", फिर "शांतिदेव" या "वे"।

**कोरा नाम कभी न रखें।** अगर रेल में नाम है पर कहानी नहीं, तो कहानी दें या नाम हटा दें। "अमुक की कहानी" से पाठक को कुछ नहीं मिलता।
