Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། སྔར་བསགས་པའི་སྡིག་པ་མཐའ་ཡས་པས་དེ་སྤོང་བ་ལ་འབད་པར་རིགས་པ་དང༌།
ངན་འགྲོར་སྡུག་བསྔལ་ལན་ཅིག་མྱོང་བ་ཙམ་གྱིས་དེ་ཐད་ནས་ངན་འགྲོ་ལས་མི་ཐར་པའི་རྒྱུ་མཚན་དང༌། དེས་ན་སྡིག་པའི་གཉེན་པོ་ལ་འབད་པར་རིགས་པའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 2:
གསུམ་པ་ལ་བཞི། དལ་འབྱོར་ཐོབ་ནས་དགེ་བ་ལ་མ་འབད་ན་རང་གིས་རང་བསླུས་པར་འགྱུར་བ་དང༌། ཚེ་འདིར་སྡུག་བསྔལ་མྱོང་དགོས་པ་དང༌། ཕྱི་མར་ངན་འགྲོའི་སྡུག་བསྔལ་གྱིས་གདུང་བར་འགྱུར་བ་དང༌།
དེས་ན་སྡིག་པ་སྤོང་ཞིང་དགེ་བ་ལ་འབད་པར་རིགས་པའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 3:
བཞི་པ་ལ་གཉིས། དལ་འབྱོར་ཆུད་གཟན་ནས་སླར་ཡང་དམྱལ་བར་ཁྲིད་ན་སེམས་མེད་པ་དང་མཚུངས་པ་དང༌། རྨོངས་པའི་རྒྱུ་བསམ་རིགས་པའོ། །

Enumeration Block 4:
གསུམ་པ་ཉོན་མོངས་སྤོང་བ་ལ་བག་བྱ་བ་ལ་གསུམ། ཉོན་མོངས་པའི་ཉེས་དམིགས་བསམ་པ་དང༌། ཉོན་མོངས་སྤོང་བའི་དཀའ་སྤྱད་ལ་སྐྱོ་བར་མི་རིགས་པ་དང༌།
འབད་པས་སྤངས་ན་སྤོང་ནུས་པ་ཉིད་དུ་སྤྲོ་བ་བསྒོམ་པའོ། །
དང་པོ་ལ་གསུམ། ཉོན་མོངས་ཀྱིས་རང་ལ་གནོད་པ་བྱེད་པའི་ཚུལ་བསམ་པ་དང། ཉོན་མོངས་ལ་བཟོད་པ་བསྒོམ་མི་རིགས་པ་དང། དེ་གཞོམ་པའི་ཆེད་དུ་བློའི་སྟོབས་བསྐྱེད་པའོ། །
དང་པོ་ལ་བཞི། རང་དབང་མེད་པར་བྱེད་པ་དང༌། སྡུག་བསྔལ་དཔག་མེད་ལ་སྦྱོར་བ་དང༌། གནོད་པ་བྱེད་པའི་དུས་མཐའ་ཡས་པ་དང༌། ཉོན་མོངས་ཀྱི་གྲོགས་བྱར་མི་རུང་བའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། སེམས་ལ་གནོད་པ་བྱེད་པ་དང༌། ལུས་ལ་གནོད་པ་བྱེད་པར་བསམ་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། ཉོན་མོངས་གཞོམ་ནུས་པའི་གོ་བགོ་ཞིང་དེའི་དཀའ་སྤྱད་ལ་སྐྱོ་བར་མི་བྱ་བ་དང༌། ཉོན་མོངས་གཞོམ་པའི་ཆེད་དུ་བརྩོན་པའི་ཕན་ཡོན་དང༌།
དེས་ན་ཉོན་མོངས་གཞོམ་པའི་སྦྱོར་བ་ལ་བརྩོན་པར་རིགས་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ་གསུམ། རང་དོན་ཕུན་ཚོགས་ཀྱི་རྒྱུ་ཡིན་པས་དཀའ་སྤྱད་བཟོད་རིགས་པ་དང༌། གཞན་དོན་ཕུན་ཚོགས་ཀྱི་རྒྱུ་ཡིན་པས་དཀའ་སྤྱད་བཟོད་རིགས་པ་དང༌།
སྔར་དམ་བཅས་པ་མཐར་ཕྱིན་པར་བྱེད་དགོས་པའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 8:
གསུམ་པ་ལ་གཉིས། ཉོན་མོངས་པའི་གཉེན་པོ་ལ་འབད་པར་བྱ་བ་དང༌། དུས་ནམ་ཡང་ཉོན་མོངས་པའི་དབང་དུ་མི་འགྱུར་བ་ལ་འབད་པར་བྱ་བའོ། །

Enumeration Block 9:
གསུམ་པ་ལ་གསུམ། རང་རྒྱུད་ཀྱི་ཉོན་མོངས་རྩ་བ་ནས་ཕྱུང་ན་དེ་གནས་པའི་རྟེན་མེད་པ་དང༌། རྒྱུ་ཕྱིན་ཅི་ལོག་ལས་བྱུང་བས་བརྩོན་པ་བསྟེན་ན་སྤོང་ནུས་པ་དང༌།
རྩ་བ་ནས་ཕྱུང་ན་དེ་གནས་པའི་རྟེན་གང་ན་ཡང་མེད་ཅིང་སྤོང་རིགས་པའོ། །
