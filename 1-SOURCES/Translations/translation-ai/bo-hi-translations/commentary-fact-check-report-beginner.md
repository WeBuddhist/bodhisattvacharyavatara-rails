# BCA Hindi Translation — Commentary Fact-Check (BCAC19_KS_bo) — beginner

Method: each verse's Hindi rendering in `bca-hi-beginner.md` is checked against
Khenpo Zhenga's Tibetan interlinear commentary. This is a preliminary
self-check, not a scholarly sign-off — a domain specialist should review
before treating this grade as final, per this vault's standing rule that an
LLM never marks its own translation output complete.

Note on scope: the `commentary-fact-check` skill is written against the
English translation track (`bo-en-translation/bca-en-<grade>.md`). It was
applied here, unmodified in method, to the Hindi "beginner" (children's
edition) track (`bo-hi-translations/bca-hi-beginner.md`) at the user's
request. The report file lives alongside the Hindi translation it checks,
following the skill's own naming convention
(`commentary-fact-check-report-<grade>.md`).

Calibration note: because this is a children's/beginner-register
translation, simplification, generic paraphrase, and dropped technical
vocabulary (sutra citations, named sub-classifications, minor supplementary
detail) are expected and were NOT flagged. Only genuine contradictions,
dropped content essential to a verse's own core sense, or flatly wrong named
quantities/entities/sequences were flagged as discrepancies. This is a more
lenient bar than the "general" grade report uses.

Verse-numbering note: this beginner file does not always share the root
text's verse count. Chapter 3 has 34 Hindi blocks against the commentary's
33 (one long verse split into two blocks, located between Hindi 3-2 and
3-3). Chapter 7 has 77 Hindi blocks against 75 (a commentary bucket spanning
three beats split into three Hindi blocks around 7-61–7-63). Chapter 8 has
187 Hindi blocks against 185 (two split points, around Hindi 8-50/8-51 and
8-185/8-186). Chapter 9 is intentionally abridged for this grade: it covers
only root verses 9-1 through 9-80 (the philosophically dense second half of
the Wisdom chapter is omitted for the children's edition), then moves
straight to chapter 10. None of this reflects a translation error — see each
chapter's own note.
