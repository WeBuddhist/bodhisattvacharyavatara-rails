Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། ཆོས་བཤད་དུ་མི་རུང་བའི་ཉན་པ་པོའི་ལུས་ཀྱི་ཀུན་སྤྱོད་དང༌། སྣོད་ཀྱི་བསམ་པའི་ཁྱད་པར་བརྟག་པ་དང༌། རྒྱ་ཆེན་པོ་ལ་མོས་པ་དམན་པ་ལ་སྦྱར་བར་མི་བྱའོ། །

Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 3:
དང་པོ་ལ་གསུམ། ལུས་ཀྱི་སྤྱོད་ལམ་ཉེས་པ་དང་བཅས་ཤིང་གཞན་མ་དད་པ་སྤང་བ་དང༌། ལམ་ལ་སོགས་པ་སྟོན་པའི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། ཉལ་བའི་ཀུན་སྤྱོད་ཇི་ལྟར་བྱ་བའོ། །

Enumeration Block 4:
བཞི་པ་བསླབ་པ་ཕུན་སུམ་ཚོགས་པར་བྱེད་པའི་ཐབས་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། མཇུག་བསྡུ་བའོ། །

Enumeration Block 5:
དང་པོ་ལ་བཞི། བསླབ་པ་དག་བྱེད་ཀྱི་རྒྱུ་དང༌། བསླབ་པའི་གཞི་དང༌། ཆེད་དུ་བྱ་བ་དང༌། གང་ལ་ཐོས་བསམ་བྱེད་པའི་གཞིའོ། །

Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། དགེ་བ་སེམས་ཅན་ཐམས་ཅད་ཀྱི་དོན་དུ་བསྔོ་བ་དང༌། ཐེག་པ་ཆེན་པོའི་བཤེས་གཉེན་དང་བསླབ་པ་ནམ་ཡང་མི་འདོར་བའོ། །

Enumeration Block 7:
བཞི་པ་ལ་གཉིས། མདོ་སྡེ་ལ་བརྟེན་པ་དང༌། བསྟན་བཅོས་ལ་བརྟེན་ནས་བསླབ་པའོ། །

Enumeration Block 8:
གཉིས་པ་ཚིག་ཙམ་མ་ཡིན་པར་དོན་ཉམས་སུ་བླང་དགོས་པའི་ཚུལ་གྱིས་མཇུག་བསྡུ་བ་ལ་གཉིས། བསླབ་པའི་གནས་མཐའ་དག་ལ་དྲན་པ་དང་ཤེས་བཞིན་བསྲུང་དགོས་དང༌། དངོས་ཀྱི་དོན་ནོ། །

Enumeration Block 9:
གསུམ་པ་ཕར་ཕྱིན་ལྷག་མ་བཞི་ལ་སློབ་པའི་ཚུལ་ལ་བཞི། བཟོད་པ་ལ་སློབ་ཚུལ་དང༌། བརྩོན་འགྲུས་ལ་སློབ་ཚུལ་དང༌། ཐུན་མོང་དང་ཐུན་མོང་མ་ཡིན་པའི་ཞི་གནས་ཀྱིས་བསྡུས་པའི་བསམ་གཏན་ལ་སློབ་ཚུལ་དང༌། ལྷག་མཐོང་གི་ངོ་བོ་ཤེས་རབ་ལ་སློབ་ཚུལ་ལོ། ། དང་པོ་ལ་གཉིས། ལེའུའི་གཞུང་བཤད་པ་དང༌། ལེའུའི་མཚན་ནོ། །

Enumeration Block 10:
དང་པོ་ལ་གཉིས། གཉེན་པོ་གྲུབ་པ་དང༌། གནས་པའི་གེགས་སྤང་བ་བཟོད་པ་བསྒོམ་པ་ལྷུར་བྱ་བ་དང༌། བཟོད་པ་སྒྲུབ་པའི་ཐབས་ཡིད་ལ་བྱ་བའོ། ། དང་པོ་ལ་གཉིས། ཁོང་ཁྲོའི་ཉེས་དམིགས་དང༌། བཟོད་པའི་ཕན་ཡོན་བསམ་པའོ། །

Enumeration Block 11:
དང་པོ་ལ་གསུམ། མ་མཐོང་བའི་ཉེས་དམིགས་དང༌། མཐོང་བའི་ཉེས་དམིགས་དང༌། ཉེས་དམིགས་བསྡུས་ཏེ་བསྟན་པའོ། །

Enumeration Block 12:
དང་པོ་ལ་གཉིས། ཁོང་ཁྲོས་དགེ་རྩ་འཇོམས་པ་དང་། ཁྲོ་བ་དང་བཟོད་པའི་སྐྱོན་ཡོན་ཤེས་ནས་བཟོད་པ་བསྒོམ་པ་ལ་འབད་པར་བྱ་བའོ། །
