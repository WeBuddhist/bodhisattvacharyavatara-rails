## Improvement metrics (user request, 2026-10-07)
For every fact-check → fix round (a1 → a2 → a3), keep the pre-fix text (the translation ledgers are append-only, so attempt-1 rows survive) and report:
1. Verdicts pass / minor / major, and errors per 100 segments, before vs after.
2. Locked-term compliance (termbase uses found / expected), before vs after.
3. chrF++ against human translations (en: Padmakara, Wallace, Choephel; zh: four versions) on the fixed segments and on the whole text, before vs after. No human Hindi version: metrics 1, 2 and 4 only.
4. Blind pairwise judgement by the other model (attempt 1 vs fixed, order randomised): win / tie / loss.
Also compute these retroactively for the Diamond Sutra (its a1/a2/a3 data exists; chrF only for zh, against Kumārajīva).
