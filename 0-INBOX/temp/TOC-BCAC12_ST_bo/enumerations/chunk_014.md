Enumeration Block 1:
རྙེད་པ་ལ་སོགས་པ་འཇིག་རྟེན་གྱི་ཆོས་ལ་མ་ཆགས་པ་བསྒྲུབ་པ་ལ་གཉིས་ཏེ། ཡུལ་ཅན་གྱི་ཉེས་པ་དང༌། ཡུལ་གྱི་ཉེས་པའོ། །

Enumeration Block 2:
འདུ་འཛིའི་ཉེས་པ་ལ་གསུམ་སྟེ། གཞན་རྗེས་སུ་འཛིན་པའི་མཐུ་མེད་པ་དང༌། དེའི་འཐད་པ་དང༌། དེ་དག་དང་འདྲེ་བར་མི་བྱེད་པའི་འཐད་པ་རྣམས། སེམས་ཅན་ཞེས་པ་དང༌། གང་ཕྱིར་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །

Enumeration Block 3:
ལྔ་པ་དབེན་པའི་ཡོན་ཏན་ཡིད་ལ་བྱ་བ་ནི་ལྔ་སྟེ། གྲོགས་དང༌། གནས་དང༌། འཚོ་བ་དང༌། སོ་སོར་རྟོག་པ་དང༌། མི་གཡེང་བའོ། །

Enumeration Block 4:
བཞི་པ་ནི་བཞི་སྟེ། མི་གཙང་བ་དང༌། མཛའ་བ་རྣམས་དང་ངེས་པ་གཉིས་པ་ནི་ཕུག་འབྲལ་བ་དང༌། མཛའ་བ་ཉིད་མ་ཡིན་པ་དང༌། ཡིད་བརྟན་པའི་གནས་མ་ཡིན་པར་སོ་སོར་རྟོག་པའོ། །

Enumeration Block 5:
དེ་ལ་གསུམ་སྟེ། འབྲས་བུ་འཇིག་པར་བརྟག་པ་དང༌། རང་གི་ངོ་བོ་མི་གཙང་བར་བརྟག་པ་དང༌། རྒྱུས་གནོད་པ་སྤང་བར་ཡིད་ལ་བྱ་བའོ། །

Enumeration Block 6:
རང་གི་ངོ་བོ་མི་གཙང་བར་བརྟག་པ་ལ་གཉིས་ཏེ། དུར་ཁྲོད་ཀྱི་ཆོས་ལ་སྦྱར་བས་མི་གཙང་བ་དང༌། གསོན་པོའི་ཆོས་ཉིད་ཀྱིས་མི་གཙང་བའོ། །
དང་པོ་ལ་དྲུག་སྟེ། བརྣག་པར་བྱ་བའི་འབྲས་བུ་མེད་པ་དང༌། དུར་ཁྲོད་དུ་བོར་བ་ལས་མ་འདས་པ་དང༌། དེ་ལ་སེར་སྣས་བསྲུང་བར་མི་རིགས་པ་དང༌། རྒྱན་གདགས་པར་མི་རིགས་པ་དང༌། ཤིན་ཏུ་འཇིགས་པར་མི་རིགས་པ་དང༌། གོས་ཀྱིས་བརྒྱན་པ་ཆགས་པའི་གནས་མ་ཡིན་པའོ། །

Enumeration Block 7:
གསོན་པོའི་ཆོས་ཉིད་སྦྱར་བ་ནི་གསུམ་སྟེ། མི་གཙང་བར་མངོན་སུམ་གྱིས་མཐོང་བ་དང༌། རྗེས་སུ་དཔག་པས་ངེས་པ་དང༌། གཙང་བའི་མཚན་མ་དགག་པའོ། །
དང་པོ་ལ་བདུན་ཏེ། རེག་བྱའི་ཁྱད་པར་ཆགས་པའི་གནས་མ་ཡིན་པ་དང༌། རེག་བྱ་འཇམ་པ་ཆགས་པའི་གནས་མ་ཡིན་པ་དང༌། འཁྲིག་པ་ཉིད་ཆགས་པའི་གནས་མ་ཡིན་པ་དང༌། གཙང་བས་ལོག་པར་རྟོག་པ་དགག་པ་དང༌། ལུས་སེམས་སོ་སོར་ཆགས་པའི་གནས་མ་ཡིན་པ་དང༌། གཞན་གཉིས་ཀ་ལ་ཆགས་པའི་གནས་མ་ཡིན་པ་དང༌། དབྱིབས་ཆགས་པའི་གནས་མ་ཡིན་པ་བདུན། ཟས་ན་ཞེས་པ་དང༌། ཤིང་བལ་ཞེས་པ་དང༌། འདོད་ལྡན་ཞེས་པ་དང༌། གལ་ཏེ་ཞེས་པ་དང༌། བདག་ནི་ཞེས་པ་དང༌། མི་གཙང་ཞེས་པ་དང༌། སྤྲིན་བྲལ་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །

Enumeration Block 8:
མི་གཙང་བར་རྗེས་དཔག་གི་ངེས་པ་ལ་ལྔ་སྟེ། མི་གཙང་བ་བསྐྱེད་པའི་རྒྱུ་ཡིན་པས་མི་གཙང་བར་བསྒྲུབ་པ་དང༌། མི་གཙང་བའི་འབྲས་བུ་ཡིན་པས་མི་གཙང་བར་བརྟག་པ་དང༌། མི་གཙང་བ་ལ་སྐམ་པར་མི་རིགས་པ་དང༌། རང་གི་ལུས་མི་གཙང་བར་བསྒྲུབ་པ་དང༌། མི་གཙང་བ་བསྒོམ་པ་ལ་སྦྱར་བས་ཞེན་པ་དང་བྲལ་བ་མདོར་བསྟན་པའོ། །

Enumeration Block 9:
གལ་ཏེ་རྒྱན་ལ་སོགས་པ་དང་ལྡན་པས་ཆགས་པའི་གནས་སུ་འཛིན་ན་གཙང་མའི་མཚན་མ་དགག་པ་ལ་བཞི་སྟེ། བཅོས་པའི་རྒྱན་གྱིས་ལུས་གཙང་བར་མི་འགྱུར་བ་དང༌། བཅོས་པའི་རྒྱན་ཆགས་པའི་གནས་མ་ཡིན་པ་དང༌། ལུས་ཀྱི་རང་བཞིན་འཇིག་པ་ཡིན་པ་དང༌། ཡིད་འབྱུང་བའི་གནས་ཡིན་པ་རྣམས། ལུས་ལ་ཞེས་པ་དང༌། འཇིགས་རྟེན་ཞེས་པ་དང༌། གལ་ཏེ་ཞེས་པ་དང༌། བདག་ལ་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །

Enumeration Block 10:
རྒྱུ་གནོད་པ་མང་བ་ལ་གཉིས་ཏེ། བསྟན་པ་དང༌། བཤད་པའོ། །

Enumeration Block 11:
རྒྱས་པར་སྟོན་པ་ལ་གཉིས་ཏེ། འདོད་པ་ཉིད་མི་ཐོབ་པ་དང༌། དེ་ལས་གཞན་པའི་ཉེས་པ་དང་འབྲེལ་པའོ། །
དང་པོ་ནི་ཚེ་འདིར་འདོད་པ་བསྟེན་པའི་གོ་སྐབས་མེད་པ་དང༌། ཡོངས་སུ་ངལ་བའི་སྡུག་བསྔལ་གྱིས་འདོད་པ་བསྟེན་མི་ནུས་པ་དང༌། ཡུལ་གྱིས་བསྐལ་པས་འདོད་པ་དང་མི་ཕྲད་པ་དང༌། གཞན་དབང་དུ་གྱུར་པས་འདོད་པ་མི་ཐོབ་པ་བཞི་བྱིས་པ་ཞེས་པ་དང༌། འདོད་ལྡན་ཞེས་པ་དང༌། ལ་ལ་ཞེས་པ་དང༌། བདག་ལ་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །
