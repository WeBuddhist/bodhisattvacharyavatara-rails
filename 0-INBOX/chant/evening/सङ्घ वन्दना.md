# सङ्घ वन्दना ^0

सुपटिपन्नो भगवतो सावकसङ्घो, ^1         
उजुपटिपन्नो भगवतो सावकसङ्घो। ^2
ञायपटिपन्नो भगवतो सावकसङ्घो, ^3
सामीचिपटिपन्नो भगवतो सावकसङ्घो। ^4
यदिदं चत्तारि पुरिसयुगानि, ^5
अट्ठ पुरिसपुग्गला। ^6
एस भगवतो सावकसङ्घो, ^7
आहुनेय्यो पाहुनेय्यो दक्खिणेय्यो अञ्जलिकरणीयो। ^8
अनुत्तरं पुञ्ञक्खेत्तं लोकस्साति। ^9
सङ्घ वन्दना ^10
