# BCA Hindi Translation — Commentary Fact-Check (BCAC19_KS_bo) — advanced

Method: each verse's Hindi rendering in `bca-hi-advanced.md` is checked against
Khenpo Zhenga's Tibetan interlinear commentary. This is a preliminary
self-check, not a scholarly sign-off — a domain specialist should review
before treating this grade as final, per this vault's standing rule that an
LLM never marks its own translation output complete.

Note on scope: the `commentary-fact-check` skill is written against the
English translation track (`bo-en-translation/bca-en-<grade>.md`). It was
applied here, unmodified in method, to the Hindi "advanced" (scholarly)
track (`bo-hi-translations/bca-hi-advanced.md`) at the user's request. The
report file therefore lives alongside the Hindi translation it checks,
following the skill's own naming convention
(`commentary-fact-check-report-<grade>.md`).

Calibration note: since this is the "विद्वत संस्करण" (scholarly edition),
verses were checked against a HIGHER bar than the general or beginner
grades — beyond outright contradictions or dropped essential content, named
entities, technical doctrinal terms, and precise numerical/enumerated
categories (sutra citations, named tenet-systems and opponents, specific
similes, and enumerated lists such as "four powers," "three trainings,"
"six recollections," etc.) that a scholarly reader would expect preserved
were flagged when flattened into vague paraphrase, even where the general
sense of the verse survived. This is a stricter bar than was applied to the
general-grade report, so raw discrepancy counts between the two reports are
not directly comparable.

Verse-numbering note: unlike the beginner grade, `bca-hi-advanced.md` has no
verse splits or abridgment — every chapter aligns 1:1 with the commentary's
canonical verse counts (36, 65, 33, 48, 109, 134, 75, 185, 167, 58).

Chapter 3 bucket-shift note: the commentary source file's own verse buckets
for Chapter 3 are internally shifted relative to the standard 34-verse root
numbering (bucket "3-2" merges standard verses 2–3, and every subsequent
bucket through "3-33" contains the commentary for the *next* standard verse).
The Hindi translation file follows this same shifted/compressed 33-verse
scheme, so Hindi[N] was compared directly against Commentary[N] as paired;
verse numbers in the Chapter 3 table below should not be read as standard
BCA verse numbers. See the chapter's note for detail.
