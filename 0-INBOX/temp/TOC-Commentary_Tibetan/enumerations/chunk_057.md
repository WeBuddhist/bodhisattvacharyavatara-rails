Enumeration Block 1:
**(གཉིས་པ་)བདག་མེད་གཉིས་ལ་འཇུག་ཚུལ་ནི།**

Enumeration Block 2:
(གཉིས་ལས་དང་པོ་)
**མདོར་བསྟན་ནི།**

Enumeration Block 3:
**(གཉིས་པ་)རྒྱས་བཤད་ལ།**
གང་ཟག་གི་བདག་མེད་ལ་འཇུག་ཚུལ་དང༌། ཆོས་ཀྱི་བདག་མེད་ལ་འཇུག་ཚུལ་ལོ། །
**དང་པོ་ལ།**
རྣམ་པར་ཕྱེ་སྟེ་དགག་པ། གཞན་གྱིས་བརྟགས་པ་དགག་པ། དེ་ལ་རྩོད་པ་སྤང་པའོ། །
**དང་པོ་ནི།**

Enumeration Block 4:
**(གཉིས་པ་)བརྟགས་པ་དགག་པ་ལ།**
གྲངས་ཅན་པས་བརྟགས་པ་དགག་པ་དང༌། རིགས་པ་ཅན་པས་བརྟགས་པ་དགག་པའོ། །
**དང་པོ་ལ་བཞི་ལས།**
**(དང་པོ་)སྒྲ་འཛིན་རྟག་པ་དགག་པ་ནི།**

Enumeration Block 5:
**(གཉིས་པ་)དེས་གཟུགས་འཛིན་པ་དགག་པ་ནི།**

Enumeration Block 6:
**(གསུམ་པ་)དཔེ་དང་སྦྱོར་བ་དགག་པ་ནི།**

Enumeration Block 7:
**(བཞི་པ་)རྟག་གཅིག་བདེན་པར་དགག་པ་ནི།**

Enumeration Block 8:
**(གཉིས་པ་)རིགས་པ་ཅན་པས་བརྟགས་པ་དགག་པ་ནི།**

Enumeration Block 9:
**(གསུམ་པ་)རྩོད་པ་སྤང་པ་ལ་གཉིས་ལས།**
**(དང་པོ་)ཐུན་མོང་པའི་ལས་འབྲས་མི་འཐད་པ་སྤང་པ་ནི།**
