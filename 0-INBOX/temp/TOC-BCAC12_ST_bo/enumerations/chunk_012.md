Enumeration Block 1:
ཕྱི་མའི་སྡུག་བསྔལ་བརྟགས་ཏེ་བཟློག་པ་ནི་བཞི་སྟེ། སྡུག་བསྔལ་ངེས་པར་འབྱུང་བ་དང༌། བརྣག་པར་དཀའ་བ་དང༌། འགལ་བ་འདུ་བ་དང༌། དེ་ལས་ཐར་པའི་ཐབས་ལས་བསྐུལ་བའོ། །

Enumeration Block 2:
བཞི་པ་ནི་སྒྱིད་ལུག་གི་ལེ་ལོ་སྤང་བ་ལ་གསུམ་སྟེ། གཉེན་པོ་འབྲས་བུ་དང་བཅས་ཏེ་མདོར་བསྟན་པ་དང༌། རྒྱུ་མེད་པས་སྒྱེད་ལུག་པའི་གཉེན་པོ་ཡིད་ལ་བྱ་བ་དང༌། སྦྱོར་མི་བཟོད་པས་སྒྱིད་ལུག་པའི་གཉེན་པོ་ཡིད་ལ་བྱ་བའོ། །

Enumeration Block 3:
གསུམ་པ་སྦྱོར་བ་མི་བཟོད་པས་སྒྱིད་ལུག་པའི་གཉེན་པོ་ཡིད་ལ་བྱ་བ་ནི་དཀའ་བ་དོན་ཆེ་བ་དང༌། སྡུག་བསྔལ་མེད་པ་དང༌། བདེ་བ་ཉིད་ཡིན་པ་གསུམ་མོ། །

Enumeration Block 4:
བརྩོན་འགྲུས་ཡང་དག་པར་སྤེལ་བ་ལ་གཉིས་ཏེ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 5:
རྒྱས་པར་བཤད་པ་ལ་གསུམ་སྟེ། དཔུང་ཚོགས་བསྐྱེད་པ་དང༌། ལྷུར་བླང་བ་དང༌། བདག་ཉིད་དབང་དུ་བྱ་བའོ། །དང་པོ་ལ་བཞི་སྟེ། མོས་པ་དང༌། བརྟན་པ་དང༌། དགའ་བ་དང༌། དོར་བའི་དཔུང་ངོ༌། །དང་པོ་ལའང་བཞི་སྟེ། ཡུལ་དང༌། འབྲས་བུ་དང༌། རྒྱུ་དང༌། མཇུག་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། བདག་དང་གཞན་གྱི་ཉེས་པ་སྤང་བ་དང༌། ཡོན་ཏན་ཐམས་ཅད་བསྒྲུབ་པ་དང༌། བྱ་བའི་རྣམ་གྲངས་གསུམ་མོ། །

Enumeration Block 6:
དེ་ལ་གསུམ་སྟེ། འདྲེན་མ་ནི་ལས་ཀྱི་འབྲས་བུ་དང༌། གཅིག་ཏུ་དཀར་བའི་རྣམ་སྨིན་དང༌། གཅིག་ཏུ་གནག་པའི་རྣམ་སྨིན་ནོ། །དང་པོ་ལ་མདོར་བསྟན་པ་དང༌། མི་དགེ་བའི་མཐོང་བའི་འབྲས་བུ་ཕལ་ཆེ་བ་དང༌། དགེ་བའི་འབྲས་བུ་དང༌། མི་དགེ་བ་མཐོང་བའི་འབྲས་བུ་བཞི།

Enumeration Block 7:
བརྟན་པའི་སྟོབས་ལ་གཉིས་ཏེ། རྩོམ་པ་བསྟན་པ་དང༌། ཞུགས་པ་བརྟན་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། མི་ལྡོག་པའི་ཐབས་དང༌། བརྩམ་པའི་ཐབས་དང༌། དེ་ལྟར་མ་བྱས་པའི་ཉེས་པའོ། །

Enumeration Block 8:
གཉིས་པ་ཞུགས་པ་བརྟན་པ་ལའང་བཞི་སྟེ། མདོར་བསྟན་པ་དང༌། ལས་ཀྱི་ང་རྒྱལ་དང༌། ནུས་པའི་ང་རྒྱལ་དང༌། ཉོན་མོངས་པའི་ང་རྒྱལ་ལོ། །

Enumeration Block 9:
གཉིས་པ་ལས་ཀྱི་ང་རྒྱལ་ལ་མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པ་དང༌། གཞན་གྱི་དོན་དུ་དམན་པའི་ལས་ལ་འཇུག་པ་གསུམ་སྟེ།

Enumeration Block 10:
ནུས་པའི་ང་རྒྱལ་ལ་གཉིས་ཏེ། བསྟེན་པར་རིགས་པ་དང༌། བསྟེན་པའི་འཐད་པའོ། །དང་པོ་ལྔ་སྟེ། ཉེས་པ་དཔེས་བསྟན་པ་དང༌། དེ་འབྱུང་བའི་རྒྱུ་དང༌། ང་རྒྱལ་དེའི་ཆེ་བ་དང༌། དེ་བསྟེན་པར་འབད་པ་དང༌། མ་འབད་ན་དམ་བཅའ་བ་ལས་ཉམས་པའོ། །

Enumeration Block 11:
བསྟེན་པའི་ཐབས་ལ་གསུམ་སྟེ། གཉེན་པོའི་ང་རྒྱལ་གྱི་རང་བཞིན་དང༌། ཉོན་མོངས་པའི་ང་རྒྱལ་ལས་ང་རྒྱལ་གྱི་དོན་མེད་པ་དང༌། གཉེན་པོའི་ང་རྒྱལ་གྱིས་བསྔགས་པ་བརྗོད་པས་སྤྲོ་བ་བསྐྱེད་པའོ། །
