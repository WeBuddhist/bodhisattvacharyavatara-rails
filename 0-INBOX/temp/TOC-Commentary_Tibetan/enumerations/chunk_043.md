Enumeration Block 1:
**(བཞི་པ་)སྐྱོ་བ་བསྐྱེད་ཚུལ་ལ་གསུམ་ལས།**

Enumeration Block 2:
**(གཉིས་པ་)དབེན་པ་ལ་དགའ་བ་བསྐྱེད་ཚུལ་ལ།**
ཐུན་མོང་དུ་བསྟན་པ་དང༌། དགའ་བའི་ཁྱད་པར་རོ། །

Enumeration Block 3:
**(གཉིས་པ་)ཁྱད་པར་ལ་གཉིས་ལས།**

Enumeration Block 4:
**བྱང་ཆུབ་ཀྱི་སེམས་གཉིས་བསྒོམ་ཚུལ་ལ་གཉིས་ལས།**

Enumeration Block 5:
**(གཉིས་པ་)རྒྱས་བཤད་ལ།**
ཀུན་རྫོབ་བྱང་ཆུབ་ཀྱི་སེམས་བསྒོམ་ཚུལ་དང༌། དོན་དམ་བྱང་ཆུབ་ཀྱི་སེམས་བསྒོམ་ཚུལ་ལོ། །
**དང་པོ་ལ།**
བདག་གཞན་མཉམས་པ་བསྒོམ་པ་དང༌། བདག་གཞན་བརྗེ་བ་བསྒོམ་པའོ། །
**དང་པོ་ལ།**
བསྒོམ་པའི་འཐད་པ་མདོར་བསྟན་པ། རྒྱུ་མཚན་རྒྱས་པར་བཤད་པ། དེས་ན་བསྒོམ་པར་གདམས་པའོ། །

Enumeration Block 6:
**(གཉིས་པ་)རྒྱས་བཤད་ལ།**
ཐ་དད་ཡིན་ཡང་བསྒོམ་ཚུལ། ཞེན་པས་བསྒོམ་པར་ནུས་ཚུལ། བསྒོམ་ཚུལ་རིགས་པས་བསྒྲུབ་པ། མཉམ་པར་བསྒོམས་པའི་ཕན་ཡོན་ནོ། །

Enumeration Block 7:
**(གསུམ་པ་)རིགས་པས་བསྒྲུབ་པ་ལ།**
རྟགས་དགོད་པ་དང༌། ཁྱབ་པ་བསྒྲུབ་པའོ། །

Enumeration Block 8:
**(གཉིས་པ་)ཁྱབ་བསྒྲུབ་ལ།**
རྟགས་གཉིས་པའི་ཁྱབ་པ་བསྒྲུབ་པ་དང༌། རྟགས་དང་པོའི་ཁྱབ་པ་བསྒྲུབ་པའོ། །

Enumeration Block 9:
**(གཉིས་པ་)དང་པོའི་ཁྱབ་བསྒྲུབ་ལ་གསུམ་ལས།**
