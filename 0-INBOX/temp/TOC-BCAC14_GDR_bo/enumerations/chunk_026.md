Enumeration Block 1:

དེའི་དབང་དུ་ཅུང་ཟད་ཙམ་ཡང་མི་འགྱུར་བར་བྱ་བ་དང༌།
གཉེན་པོ་བརྟན་པའི་བསམ་པ་ཁྱད་པར་ཅན་བསྐྱེད་པར་བྱ་བའོ། །

Enumeration Block 2:
གསུམ་པ་དགའ་བའི་སྟོབས་ལ་གསུམ།
རྣམ་སྨིན་ལ་མི་ལྟོས་པར་དགེ་བ་ལ་འབད་པར་བྱ་བ་དང༌།
འབྲས་བུ་ཡིད་ལ་བྱས་ཏེ་དགེ་བ་བསྒྲུབ་པ་དང༌།
དགའ་བའི་སྟོབས་ལ་སྦྱར་བའི་ཚུལ་ལོ། །

Enumeration Block 3:

Enumeration Block 4:
གཉིས་པ་དྲན་པ་དང་ཤེས་བཞིན་གྱིས་སྤྱོད་པ་ཉམས་སུ་བླང་བ་ལྷུར་བྱ་བ་ལ་ལྔ།
བག་ཡོད་ལྷུར་བླང་བ་དང༌།
དྲན་པ་དང་ཤེས་བཞིན་ལྷུར་བླང་བ་དང༌།
དྲན་ཤེས་ཀྱིས་ཉེས་པའི་སྐབས་མི་དབྱེ་བ་དང༌།
ཉེས་པ་བྱུང་བ་དེ་མ་ཐག་ལྡོག་པར་བྱ་བ་དང༌།
རིགས་པའི་ལས་ལ་འབད་པར་བྱ་བའོ། །

Enumeration Block 5:
གསུམ་པ་སྤྱོད་པ་བསྒྲུབ་པ་ལ་བདག་ཉིད་དབང་དུ་བྱ་བ་ལ་གཉིས།
ལུས་སེམས་ཤིན་ཏུ་སྦྱངས་པས་དགེ་བ་ལ་ལྡང་བ་ཡང་བར་བྱ་བ་དང༌།
དཔེ་དོན་སྦྱར་བའོ། །

Enumeration Block 6:
གསུམ་པ་ཐུན་མོང་དང་ཐུན་མོང་མ་ཡིན་པའི་ཞི་གནས་ཀྱིས་བསྡུས་པའི་བསམ་གཏན་ལ་སློབ་ཚུལ་ལ་གཉིས།

དང་པོ་ལ་གསུམ།
བསམ་གཏན་བསྒོམ་པར་གདམས་པ་དང༌།
ཞི་གནས་ཀྱི་མི་མཐུན་ཕྱོགས་སྤང་བ་དང༌།
ཞི་གནས་ཇི་ལྟར་སྒོམ་པའི་ཚུལ་ལོ། །
དང་པོ་ལ་གཉིས།
ཞི་གནས་བསྒྲུབ་དགོས་པའི་རྒྱུ་མཚན་དང༌།
ཞི་གནས་ཀྱི་མི་མཐུན་ཕྱོགས་སྤང་བར་གདམས་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ་གཉིས།
འཇིག་རྟེན་གྱི་འདུ་འཛི་སོགས་སྤང་བ་དང༌།
ཕྱིན་ཅི་ལོག་གི་རྣམ་རྟོག་སྤང་བའོ། །
དང་པོ་ལ་གཉིས།

དེ་ཇི་ལྟར་སྤོང་བའི་ཚུལ་ལོ། །
