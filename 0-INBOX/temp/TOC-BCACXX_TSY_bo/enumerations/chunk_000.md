Enumeration Block 1:
དེ་ཇི་ལྟར་འཆད་པའི་ཚུལ་ནི་མཚན་གྱི་དོན་དང༌། ཕྱོགས་གང་དུ་གཏོགས་པ་དང༌། གཞུང་གི་དོན་དང་གསུམ་གྱིས་ངེས་པར་བྱ་བ་ལས་དང་པོ་ལ་ཡང་གསུམ་གྱི་དང་པོ་མཚན་བསྒྱུར་བ་ནི་

Enumeration Block 2:
གསུམ་པ་གཞུང་གི་དོན་ལ་རྩོམ་པ་ལ་འཇུག་པ་ཀླད་ཀྱི་དོན་དང༌། བརྩམ་པར་བྱ་བ་སྐབས་ཀྱི་དོན་དང༌། མཐར་ཕྱིན་པ་མཇུག་གི་དོན་དང་གསུམ་ལས་དང་པོ་ལ་གཉིས་ཏེ༊ དངོས་སུ་བརྗོད་པའི་དོན་དང༌། ཤུགས་ལ་གནས་པའི་དོན་ནོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཆོད་བརྗོད་ནི་རྐང་པ་གཉིས་ཀྱིས་སྟོན་ཏེ། དེ་ལ་ཡང་གསུམ་ལས་དང་པོ་དགོས་པའི་དོན་ལ་

Enumeration Block 3:
གཉིས་པ་བཤད་པར་དམ་བཅའ་བ་ནི་རྐང་པ་གཉིས་ཀྱིས་སྟོན་པ་ལ་ཡང་གསུམ་གྱི་དང༌པོ་དགོས་པའི་དོན་ནི་

Enumeration Block 4:
སྡོམ་པ་ནི་འདིར་མཚན་ཉིད་དང༌། དབྱེ་བ་དང༌། བྱ་བ་གསུམ་གྱིས་ངེས་པར་བྱ་བ་ལས་དང་པོ་ནི་

Enumeration Block 5:
གསུམ་པ་ཁེངས་སྐྱང་བ་ནི་རྐང་པ་བརྒྱད་ཀྱིས་སྟོན་པ་ལ་ཡང་གསུམ་གྱི་དང་པོ་དགོས་དོན་ནི་

Enumeration Block 6:
གཉིས་པ་ཤུགས་ལ་གནས་པའི་དོན་ནི་དགོས་འབྲེལ་བཞི་སྟེ། དེ་ལ་ཡང་སོ་སོའི་ངོ་བོ་ངོས་གཟུང་བ་དང༌། ཇི་ལྟར་བསྟན་ཚུལ་དང༌། དེ་དག་བསྟན་པའི་དགོས་པ་དང༌། གྲངས་ངེས་པ་དང་བཞི་ལས། དང་པོ་ལ་
