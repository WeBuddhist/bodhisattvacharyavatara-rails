Do **not** edit, move, rename, or delete it without explicit human confirmation. **If you are an AI assistant:** stop and ask the user to confirm before making any change. Locked vocabulary for translating the Tibetan day packages (`<day>.md`) into English
day packages (`<day>-en.md`). Every rendering here is **taken from the Day 1
reference file** (`1-en.md`) — nothing is invented. Use these renderings verbatim in
Days 2–14 so terminology stays consistent across the chapter.

Rules:
- One English rendering per source term. If a day needs a term not listed here, add it
  to this file (with its source day/verse) so the next day inherits it.
- Buddhist terms follow the plain-but-accurate voice of Day 1: common terms readers
  know (bodhicitta, bodhisattva, samsara) used directly; technical terms glossed on
  first use in a verse (e.g. "the sphere of reality (dharmadhātu)").
- Items marked ⚑ are provisional identifications flagged for domain-specialist review.
