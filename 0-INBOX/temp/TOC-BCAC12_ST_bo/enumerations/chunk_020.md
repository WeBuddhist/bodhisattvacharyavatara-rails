Enumeration Block 1:
རིག་པ་ཅན་གྱི་བདག་དགག་པ་ལ་གསུམ་སྟེ། རང་བཞིན་བེམ་པོ་ལ་བདག་དགག་པའི་ཐལ་བ་དགོད་པ་དང༌། སེམས་པ་གཞན་དང་ལྡན་པས་ཁྱབ་པ་མ་གྲུབ་པར་སེམས་པ་ལ་དེའི་ཁྱབ་པ་བསྒྲུབ་པ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 2:
བདག་མེད་པ་ལ་རྩོད་པ་སྤང་བ་ལ་ཡང་གཉིས་ཏེ། ལས་འབྲས་འབྲེལ་པར་མི་རིགས་པའི་རྩོད་པ་སྤང་བ་དང༌། སྙིང་རྗེ་བསྒོམ་པའི་ཡུལ་མི་འཐད་པ་སྤང་བའོ། །དང་པོ་ལ་དྲུག་སྟེ། རྩོད་པ་དགོད་པ་དང༌། ཁས་བླངས་མཚུངས་པ་དང༌། དངོས་པོའི་ལན་དང༌། དེ་ལ་ལུང་དང་འགལ་བ་སྤང་བ་དང༌། རྩོད་པ་སྤང་བ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 3:
སྙིང་རྗེའི་ཡུལ་དུ་མ་གྲུབ་པའི་རྩོད་པ་སྤང་བ་ལ་གཉིས་ཏེ། ཡུལ་མེད་པའི་རྩོད་པ་སྤང་བ་དང༌། ཡུལ་སེམས་ཅན་དུ་བསྒྲུབ་པའོ། །

Enumeration Block 4:
ལན་ལ་གཉིས་ཏེ། སེམས་ཅན་བཏགས་པ་བསྒྲུབ་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 5:
གཉིས་པ་དེ་ལ་རྩོད་པ་སྤང་བ་ལ་བཞི་སྟེ། རྫས་སུ་གྲུབ་པའི་གང་ཟག་ལ་མི་ལྟོས་པ་དང༌། བཏགས་པ་ཙམ་སྤང་བྱ་མ་ཡིན་པ་དང༌། རང་གི་ཚིག་དང་འགལ་བ་སྤང་བ་དང༌། མཚུངས་པར་དགོས་པ་སྤང་བའོ། །

Enumeration Block 6:
ད་ནི་མཐོང་ཚོར་འདི་ཉིད་བདག་ཡིན་ནོ་སྙམ་དུ་བརྟགས་པ་འགོག་པ་ལ་ཚུལ་བཞི་སྟེ། ལུས་དང༌། ཚོར་བ་དང༌། སེམས་དང༌། ཆོས་དྲན་པ་ཉེ་བར་གཞག་པའོ། །

Enumeration Block 7:
དེ་ལ་ལུས་དྲན་པ་ཉེ་བར་གཞག་པ་ལ་གསུམ་སྟེ། ཡན་ལག་སོ་སོ་ལུས་མ་ཡིན་པ་དང༌། ཡན་ལག་ཅན་གྱི་རྫས་ཀྱི་ལུས་མ་གྲུབ་པ་དང༌། སྤྱིའི་དོན་བསྡུ་བའོ། །

Enumeration Block 8:
དེ་དགག་པ་ལ་ལྔ་སྟེ། ཡན་ལག་རྣམས་ལ་ཆ་རེས་འབྲེལ་པ་དགག་པ་དང༌། བདག་ཉིད་ཐམས་ཅད་ཀྱིས་འབྲེལ་པ་དགག་པ་དང༌། ཚད་མའི་དོན་བསྡུ་བ་དང༌། ལུས་སུ་དམིགས་པ་འཁྲུལ་པ་ཡིན་པ་དང༌། འཁྲུལ་པར་བསྒྲུབ་པའོ། །

Enumeration Block 9:
ལྔ་པ་ལ་གཉིས་ཏེ། འཁྲུལ་པའི་རྒྱུ་དང༌། འཁྲུལ་པའི་ཤེས་བྱེད་དོ། །

Enumeration Block 10:
ཚོར་བ་དྲན་པ་ཉེ་བར་གཞག་པ་ལ་བཞི་སྟེ། ཚོར་བའི་རང་བཞིན་མ་གྲུབ་པ་དང༌། རྒྱུ་རེག་པ་མ་གྲུབ་པ་དང༌། ཡུལ་མ་གྲུབ་པ་དང༌། འཛིན་བྱེད་མ་གྲུབ་པའོ། །དང་པོ་ལ་ལྔ་སྟེ། སྡུག་བསྔལ་དོན་དམ་དུ་མ་གྲུབ་པ་དང༌། བདེ་བ་དོན་དམ་པར་མ་གྲུབ་པ་དང༌། རྩོད་པ་སྤང་བ་དང༌། སྐབས་ལ་སྦྱར་བ་དང༌། རྣམ་པར་དཔྱད་པའི་དོན་ལ་རྣལ་འབྱོར་དུ་བྱ་བ་ལྟ་བུར་སྦྱར་བའོ། །

Enumeration Block 11:
རྩོད་པ་སྤང་བ་ལ་གཉིས་ཏེ། ཚོར་བ་ཉམས་པའི་ཐལ་འགྱུར་དང༌། དེའི་གཏན་ཚིགས་མ་གྲུབ་ན་བདེ་བ་ལས་མ་འདས་པའོ། །

Enumeration Block 12:
རེག་པ་མ་གྲུབ་པ་ལ་ལྔ་སྟེ། དབང་པོ་དང་དོན་ཕྲད་པ་མེད་པ་དང༌། རྣམ་ཤེས་དང་ཕྲད་པ་མེད་པ་དང༌། ཚོགས་པ་ལ་ཡང་དག་པ་དགག་པ་དང༌། སྐབས་བསྡུ་བ་དང༌། དེས་གྲུབ་པའི་དོན་ཏོ། །

Enumeration Block 13:
རྡུལ་ཕྲན་དང་ཕྲད་པ་མེད་པ་ལ་བཞི་སྟེ། ཐལ་བ་དགོད་པ་དང༌། དེའི་རྟགས་བསྒྲུབ་པ་དང༌། ཚད་མའི་དོན་བསྡུ་བའོ། །

Enumeration Block 14:
འཛིན་བྱེད་མ་གྲུབ་པ་ལ་བཞི་སྟེ། སེམས་མྱོང་བྱེད་མ་ཡིན་པ་དང༌། རང་ཉིད་མྱོང་བྱེད་མ་ཡིན་པ་དང༌། དེ་དག་ལས་གཞན་མྱོང་བྱེད་མ་ཡིན་པ་དང༌། སྐབས་བསྡུ་བའོ། །

Enumeration Block 15:
སེམས་དྲན་པ་ཉེ་བར་གཞག་པ་ལ་གཉིས་ཏེ། ཡིད་ཀྱི་རང་བཞིན་མ་གྲུབ་པ་དང༌། རྣམ་པར་ཤེས་པ་ལྔའི་དམིགས་པ་མ་གྲུབ་པའོ། །

Enumeration Block 16:
ཆོས་དྲན་པ་ཉེ་བར་གཞག་པ་ལ་གཉིས་ཏེ། ཐམས་ཅད་སྐྱེ་བ་མེད་པར་བསྒྲུབ་པ་དང༌། དེ་ལ་རྩོད་པ་སྤོང་བའོ། །
