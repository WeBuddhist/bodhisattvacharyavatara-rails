Enumeration Block 1:
ད་ནི་གསུམ་པ་ཞུགས་པས་ཐར་ཕྱིན་པའི་བྱ་བ་ཡོངས་སུ་བསྔོ་བའི་གཞུང་དོན་ལ།
བསགས་པའི་དགེ་བ་བསྔོ་བ་དང༌། བཀའ་དྲིན་དྲན་པའི་ཕྱག་འཚལ་བའོ།།
དང་པོ་བསྔོ་བ་ལ། གཞན་གྱི་དོན་དང༌། རང་གི་དོན་དང༌། བསྟན་པའི་དོན་དུ་བསྔོ་བའོ།།
དང་པོ་གཞན་དོན་ལ། ཕལ་པའི་དོན་དང༌། མཆོག་གི་དོན་དུ་བསྔོ་བའོ།།
དང་པོ་ཕལ་པའི་དོན་ལ།
སྤྱིའི་དོན་དང༌། ངན་འགྲོའི་དོན་དང༌། བདེ་འགྲོའི་དོན་དུ་བསྔོ་བའོ།།
དང་པོ་སྤྱིའི་དོན་ལ་གཉིས་ལས།

Enumeration Block 2:
གཉིས་པ་ངན་འགྲོའི་དོན་དུ་བསྔོ་བ་ལ།
དམྱལ་བ་དང༌། དུད་འགྲོ་དང༌། ཡི་དྭགས་ཀྱི་དོན་དུ་བསྔོ་བའོ།།

Enumeration Block 3:
སྡུག་བསྔལ་རང་ཞི་བར་བསྔོ་བ་དང༌། གཞན་གྱི་མཐུ་ཡིས་ཞི་བར་བསྔོ་བའོ།།
དང་པོ་ལ་བཞི་ལས།

Enumeration Block 4:
གཉིས་པ་གཞན་གྱི་མཐུས་ཞི་བར་བསྔོ་བ་ལ་བཞི་ལས།

Enumeration Block 5:
གཉིས་པ་དུད་འགྲོའི་དོན་དུ་བསྔོ་བའི་སྤྱི་དོན་ལའང༌།
གནས་ལུས་སྡུག་བསྔལ་ཚེ་ཚད་བཞི་ལས།

Enumeration Block 6:
གསུམ་པ་བདེ་འགྲོའི་དོན་དུ་བསྔོ་བ་ལ།
རྒུད་པ་ཞི་བར་བསྔོ་བ་དང༌། འབྱོར་པ་ཐོབ་པར་བསྔོ་བའོ།།

Enumeration Block 7:
མིའི་ནང་དུའང་ལོང་བ་རྣམས་ཀྱིས་མིག་གསལ་པོ་ཐོབ་སྟེ་གཟུགས་མཛེས་པ་རྣམས་མཐོང་བར་ཤོག་ཅིག །

Enumeration Block 8:
གཉིས་པ་འབྱོར་པ་ཐོབ་པར་བསྔོ་བ་ལ་དྲུག་ལས།
