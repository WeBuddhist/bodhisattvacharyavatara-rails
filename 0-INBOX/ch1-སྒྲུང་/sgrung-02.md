# སྒྲུང་2། གསེར་འགྱུར་རྩི་ཡི་རྣམ་པ་མཆོག་ལྟ་བུ། །

> ལེའུ་དང་པོའི་སྡོམ། བུ་མོ་ཀླུ་སྒྲུབ་དེད་དཔོན་དང་། །རྒྱལ་པོ་ནོར་བཟང་མཛའ་བོའི་བུ། །ཚངས་པ་ལེགས་སྐྱེས་ཁྲོན་པའི་མི། །དགེ་སློང་དགའ་བྱེད་ཕྲའུ་དང་།།བྱམས་པའི་སྟོབས་དང་བཅུ་གསུམ་མོ། །

---

2. **གསེར་འགྱུར་རྩི་ཡི་རྣམ་པ་མཆོག་ལྟ་བུ། །** བྷེ་ཏའི་ཡུལ་གྲོང་ཁྱེར་ཛྙ་ཏར་བྲམ་ཟེ་རྣལ་འབྱོར་རྒྱལ་བའི་ལྷའི་ཆེན་མ་བློ་ལྡན་མ་ལ་བུ་བློ་གྲོས་འཕགས་བཙས་ཏེ། མཚན་མཁན་ལ་བསྟན་པས། ཚེ་རིང་ན་སྟོན་པ་གཉིས་པ་གཅིག་སྟེ། ཚེ་ཞག་བདུན་ལས་མེད་ཟེར་བ་ལ། ཀླུས་ཤིས་པ་བརྗོད་པས་ལོ་བདུན་དུ་གྱུར། ཡང་རྨ་བྱ་ཆེན་མོ་བསྒྲུབས་པས་ལོ་བཅོ་ལྔར་གྱུར་པའི་ཚེ། ཆུན་མ་གཟུགས་ལྡན་མའི་བྲམ་ཟེ་མཉེས་པར་བྱས་ཏེ། བདག་གི་བུ་བསོད་ནམས་འཕགས་ལ་སྨན་གྱི་མངའ་ཐང་གནང་བར་ཞུ་བྱས་པས། ཐུབ་ཆོད་དུ་སྦྱིན་དུ་མི་རུང་བས་ཐབས་སྦྱིན་ནོ། །ཞེས་དེ་ལ་གསོ་རིགས་ཀྱི་མན་ངག་ཐམས་ཅད་ཡོངས་རྫོགས་སུ་བསླབས་ཚར་བ་དང༌། བློ་གྲོས་འཕགས་པ་དང་རྒན་པས་ཞག་གསུམ་ན་ཁྱེད་གཉིས་སུ་མཁས་པ་ཞིག་ལ་མངའ་ཐང་ཐམས་ཅད་གཏོད་དོ་སློབས་ཤིག་ཟེར་རོ།། དེར་ཡུམ་ངོ་གནག་པའི་རྒྱུ་དྲིས་པས། གོང་ལྟར་བསྙད། ཁྱོད་བུ་ཐུ་བོ་ཡིན་ཡང་སྲིད་མི་ཐོབ་པ་ལ་མ་དགའ་ཟེར། མི་དགྱེས་མི་འཚལ་གྱིས་མར་མེ་སྟ་གོན་མཛོད་ཅིག་ཟེར་ནས། ནུབ་དང་པོ་ལ་ཡབ་ཀྱི་བཞེད་པ་གཅིག །གཉིས་པ་ལ་ཡབ་ཀྱི་ནོར་བ། གསུམ་པ་ལ་ཡིན་ལུགས་བཞིན་རྟོགས་ནས། ཉིན་གསུམ་རིམ་བཞིན་བཤད་པས། ནུ་བོས་ཡེ་མ་སྤོབས་པ། ཡུམ་གཉིས་ངོ་ལོག་པའི་ཚེ། ཕུ་བོས་ཡབ་ཡུམ་མི་དགྱེས་མི་འཚལ་གྱིས་སྲིད་ཁོ་ལ་གཏོད་ལ། བདག་རབ་ཏུ་འབྱུང་བར་ཞུས་པས༌དགྱེས་ཏེ་གནང་ནས། ན་ལེནྡྲར་སྒྲ་གཅན་འཛིན་བཟང་པོ་ལ་རབ་ཏུ་བྱུང་སྟེ། གནས་ལྔ་ཐམས་ཅད་ལན་ཪེ་གཟིགས་པའམ་གསན་པས་མཁྱེན་ཀྱང༌། བཅོ་ལྔའི་ལོ་གྲངས་ཚང་ནས། དཔལ་གྱི་རིར་མྱ་ངན་གྱི་གླིང་དུ་འགྲེངས་པས། ས་ར་ཧས་དྲིས་པ་ན། ཞག་བདུན་ལས་ཚེ་མེད་ཟེར་བས། ངས་རྐང་མགྱོགས་ཀྱི་དངོས་གྲུབ་སྦྱིན་གྱིས། རྩེ་ལྔར་འཇམ་དཔལ་ལ་ཞུས་ལ། འཆི་མེད་སྒྲོན་མ་ལ་གསོལ་བ་ཐོབ་གསུངས་པ་བཞིན་མཛད་པས། ཞག་ལྔ་ན་མཐོང་ལམ་གྱི་ཡོན་ཏན་བརྒྱ་ཕྲག་བཅུ་གཉིས་མངོན་དུ་གྱུར་ཏེ། ཚེའི་དངོས་གྲུབ་དེ་བསྐྱབ་པའི་བརྙེས་ནས་འཛམ་བུ་གླིང༌དུ༌བྱོན༌པས་མུ་གེ་ཆེན་པོ་འདུག་ནས། ཕྱིར་དབྱུ་གུ་མ་མཆེད་གསུམ་བསྒྲུབས་པས། མནལ་ལམ་དུ་ཟངས་གླིང་དུ་སོང་ལ། གསེར་འགྱུར་སློབས་གསུང་རྨིས་ནས། སང་རི་སུལ་ཞིག་ཏུ་སྐུ་ཁམས་སེང་དུ་བྱོན་པའི་ཚེ། སྦྲུལ་ནག་ཅིག་གིས་སྦྲུལ་དཀར་ཅིག་དེད་དེ། དྲུང་དུ་སླེབས་པ་དང༌། ཤིང་ལོ་ཞིག་སྦོར་བསྐུས་པས་འཕུར། མེ་ཏོག་ཅིག་མགོར་བསྐུས་པས་བབས་པ།ཡང་དེད་པས་འབྲས་བུ་ཞིག་ཁར་བཅུག་པས་མི་སྣང་བར་སོང་སྟེ། སློབ་དཔོན་གྱིས་ཀྱང་དེ་གསུམ་གྲར་བཏུམས་ཏེ་ཤིང་ལོས་འཕུར། མེ་ཏོག་གི་ཟངས་གླིང་དུ་བབས་ཏེ། གསེར་བྱིན་ལ་སློབས་བྱས་པས་འཕེལ་དུ་དྭོགས་ནས་མ་བྱིན། འདིར་ཐོན་པ་ཅི་ཡིན་ཟེར། ཤིང་ལོ་འདིའི་མཐུ་བྱས་པས། དེ་སྟེར་ན་བསླབ་ཟེར། བྱིན་ཏེ་ལོབས་པ་དང་གྲ་གསེབ་ཀྱི་ཤིང་ལོས་འཕུར་བ་དེད་པ་ཟིན་ཁར་འབྲས་བུས་བསྒྲིབས་ནས། མེ་ཏོག་གིས་བབས་ཏེ། བུ་མོ་གཙང་མའི་གསེར་ཁྲག་བཏང་ཞེས་པ་ལ། དེའི་ལག་ནས་བྱུང་བའི་གཡའ་བསྐྲུས་པ་བཏང་ཡང་མ་གྲུབ་པར། མཁའ་འགྲོ་མ་ལ་གསོལ་བ་བཏབ་པས་བཟོ་གནས་སུ་བུ་མོ་རླུང་གིས་སྔངས་ཏེ་འགོམས་པས་གསེར་མདུང་སྣད་པའི་ཁྲག་ལུགས་ཕོར་དུ་ལྷུང་སྟེ། རྩི་གྲུབ་ནས། དངོས་པོ་གང་ལ་དེས་རེག་ཚད་གསེར་དུ་འགྱུར་ཏེ། ཕྱིས་དཔེ་དེ་བཞིན་དུ། བྱང་སེམས་སྐྱེས་ཚད་སངས་རྒྱས་སུ་འགྱུར་བར་དགོངས་ནས། ས་ར་ཧས། དངོས་གྲུབ་མཆོག་གི་རྫས་གཅིག་གིས། །དངོས་གང་གསེར་དུ་གྱུར་པ་ལྟར། །བྱང་ཆུབ་མཆོག་གིས་སེམས་གཅིག་གིས། །ལུས་ཅན་རྒྱལ་བའི་སྐུཪ་འགྱུར་རོ། །ཞེས་སོ། །
