Enumeration Block 1:
གསུམ་པ་སེམས་དྲན་པ་ཉེ་བར་བཞག་པ་ལ་གཉིས་ལས།
དང་པོ་སེམས་རང་བཞིན་མེད་པའི་ཚུལ་བསྟན་པ་ནི།

Enumeration Block 2:
གཉིས་པ་སེམས་སྐྱེ་བ་མེད་པའི་ཚུལ་ནི།

Enumeration Block 3:
བཞི་པ་ཆོས་དྲན་པ་ཉེར་བཞག་ལ་གཉིས་ལས།
དང་པོ་དངོས་ནི།

Enumeration Block 4:
གཉིས་པ་རྩོད་པ་སྤོང་བ་ལ་གཉིས་ལས།
དང་པོ་བདེན་གཉིས་མི་འཐད་པར་ཐལ་བའི་རྩོད་པ་སྤོང་བ་ནི།

Enumeration Block 5:
གཉིས་པ་རྣམ་དཔྱོད་ཐུག་མེད་དུ་ཐལ་བའི་རྩོད་སྤོང་ནི།

Enumeration Block 6:
གསུམ་པ་གཏན་ཚིགས་ཀྱི་སྒྲོ་འདོགས་གཅོད་པའི་ཚུལ་ལ་གཉིས་ལས།
