Enumeration Block 1:
གཉིས་པ་ལ། དཔེ་དགག་པ་དང༌། དོན་དགག་པའོ། །

Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། རང་རིག་མེད་ཀྱང་དྲན་པ་སྐྱེ་བའི་དཔེ་དང༌། རང་རིག་མེད་ན་གཞན་རིག་མི་འཐད་པ་དགག་པའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། དངོས་དང༌། སེམས་ལས་སྒྱུ་མ་དེ་ཉིད་དང་གཞན་དུ་བརྗོད་དུ་མེད་པ་དགག་པའོ། །

Enumeration Block 4:
གསུམ་པ་སྟོང་ཉིད་རྟོགས་པའི་ལམ་དབུ་མ་ལའང་དགོས་ནུས་མེད་པར་ཐལ་བ་སྤང་བ་ལ་གཉིས། རྩོད་པ་དང༌། ལན་ནོ། །

Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། སྒྱུ་མ་མཁན་ལ་ཆགས་པ་སྐྱེ་བའི་རྒྱུ་མཚན་དང༌། སྟོང་ཉིད་རྟོགས་པའི་ཤེས་རབ་གོམས་པས་ཉོན་མོངས་བག་ཆགས་དང་བཅས་པ་སྤོང་བ་འཐད་པར་བསྟན་པ་དང༌། སྤངས་པའི་འབྲས་བུ་ཕུན་སུམ་ཚོགས་པ་འབྱུང་བར་བསྟན་པའོ། །
