Enumeration Block 1:
གསུམ་པ་ཞི་གནས་ཇི་ལྟར་སྒོམ་པའི་ཚུལ་ལ་གཉིས། བདག་གཞན་མཉམ་པར་སྒོམ་པའི་ཚུལ་དང༌། བདག་གཞན་བརྗེ་བའི་ཚུལ་ལོ། ། དང་པོ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་བཞི། བདག་གཞན་མཉམ་པར་སྒོམ་པའི་དོན་བཤད་པ་དང༌། བདག་གཞན་མཉམ་པར་སྒོམ་ཚུལ་དང༌། དེ་ལྟར་སྒོམ་པའི་ཕན་ཡོན་དང༌། བདག་གཞན་མཉམ་པར་གོམས་ན་དེ་ལྟར་བསྐྱེད་ནུས་པའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། བདེ་སྡུག་གི་འདོར་ལེན་མཚུངས་པ་མི་རིགས་པ་སྤང་པ་དང༌། མཚུངས་པར་བསྒོམ་རིགས་པའི་རྒྱུ་མཚན་བཤད་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བ་དང༌། རྩོད་པ་སྤང་བའོ། ། དང་པོ་ལ་གསུམ། རྟགས་དགོད་པ་དང༌། ཁྱབ་པ་བསྒྲུབ་པ་དང༌། བདག་གཞན་མཉམ་པར་བསྒོམ་དུ་མི་རུང་སྙམ་པའི་གེགས་བསལ་བའོ། །

Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། ཁྱབ་བསྒྲུབ་དངོས་དང༌། དེའི་གེགས་བསལ་བའོ། །

Enumeration Block 6:
གསུམ་པ་རྩོད་པ་སྤང་བ་ལ་གཉིས། སེམས་ཅན་གྱི་སྡུག་བསྔལ་བསམས་པས་བྱང་སེམས་རང་ཉིད་སྡུག་བསྔལ་གྱི་གཞན་དབང་དུ་འགྱུར་བ་མི་འཐད་པ་དང༌། སྡུག་བསྔལ་བསམས་པའི་དགོས་པའོ། །

Enumeration Block 7:
གསུམ་པ་ལ་ལྔ། གཞན་དོན་ལ་གཅིག་ཏུ་གཞོལ་བ་ལ་སྡུག་བསྔལ་ཆེན་པོ་མེད་པ་དང༌། དེའི་བདེ་བ་མཆོག་ཏུ་གྱུར་པས་གཞན་དོན་ལ་འཇུག་པ་དང༌། རང་གི་དྲེགས་པ་ཞི་བར་འགྱུར་བ་དང༌། ལན་དང་རྣམ་སྨིན་ལ་ལྟོས་པ་མེད་པ་དང༌། རྒྱུ་མཚན་དེས་ན་བདག་གཞན་མཉམ་པར་བསྒོམ་རིགས་པའོ། །
