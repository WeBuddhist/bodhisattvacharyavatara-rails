Enumeration Block 1:
གཉིས་པ་ལ་བཞི།
ཕྱག་ན་རྡོ་རྗེའི་སྟོབས་ཀྱིས་སྡུག་བསྔལ་ཞི་བ་དང༌།
སྤྱན་རས་གཟིགས་ཀྱི་ཐུགས་རྗེ་དང༌།
འཇམ་པའི་དབྱངས་ཀྱི་ཆོ་འཕྲུལ་དང༌།
ཉེ་བའི་སྲས་གཞན་གྱི་ནུས་པས་ཞི་བར་སྨོན་པའོ། །

Enumeration Block 2:
གསུམ་པ་བདེ་འགྲོའི་དོན་དུ་བསྔོ་བ་ལ་གཉིས།
སྡུག་བསྔལ་དང་བྲལ་བར་བསྔོ་བ་དང༌།
འདོད་པའི་དོན་གྲུབ་པར་བསྔོ་བའོ། །
དང་པོ་ལ་བཞི།
དབང་པོ་མ་ཚང་བ་མེད་ཅིང་མངལ་གྱི་ཟུག་རྔུ་མེད་པར་བསྔོ་བ་དང༌།
དབུལ་བའི་སྡུག་བསྔལ་དང་ཡིད་མི་བདེ་མེད་པར་བསྔོ་བ་དང༌།
ན་བའི་སྡུག་བསྔལ་དང་སྡང་བ་དང་ཕྲད་པའི་སྡུག་བསྔལ་མེད་པར་བསྔོ་བ་དང༌།
ཕྱོགས་སུ་འགྲོ་བའི་སྡུག་བསྔལ་དང་མི་མ་ཡིན་གྱི་གནོད་པ་ཞི་བར་བསྔོ་བའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གཉིས།
སྤྱིར་མིའི་དོན་དུ་བསྔོ་བ་དང༌།
བྱེ་བྲག་ཏུ་རབ་ཏུ་བྱུང་བའི་དོན་དུ་བསྔོ་བའོ། །
དང་པོ་ལ་གསུམ།
ཕུན་ཚོགས་ཐོབ་པར་བསྔོ་བ་དང༌།
ཡང་དག་པའི་ལམ་ལ་འཇུག་པར་བསྔོ་བ་དང༌།
གནས་སྐབས་འབྱོར་བ་དང་བདེ་བར་བསྔོ་བའོ། །
དང་པོ་ལ་བཞི།
རྟེན་དལ་འབྱོར་ཐོབ་ཅིང་ལོངས་སྤྱོད་ཕུན་སུམ་ཚོགས་པར་བསྔོ་བ་དང༌།
འཚེ་བ་མེད་ཅིང་གཟི་བརྗིད་ཕུན་སུམ་ཚོགས་པར་བསྔོ་བ་དང་།
གཟུགས་ཕུན་ཚོགས་དང་དམན་པ་མཆོག་ཏུ་གྱུར་པ་བསྔོ་བ་དང༌།
དགེ་བ་ཕུན་སུམ་ཚོགས་པར་བསྔོ་བའོ། །

Enumeration Block 4:
གཉིས་པ་ལ་གཉིས།
ཐར་ལམ་སྒྲུབ་པའི་བསམ་སྦྱོར་ཕུན་ཚོགས་དང་ལྡན་པར་སྨོན་པ་དང༌།
མཐུན་རྐྱེན་ཚང་ཞིང་འགལ་རྐྱེན་མེད་པར་སྨོན་པའོ། །

Enumeration Block 5:
གསུམ་པ་ལ་གསུམ།
ཚེ་རིང་ཞིང་སྣོད་ཀྱི་འཇིག་རྟེན་དག་པར་བསྔོ་བ་དང༌།
ཕན་འདོགས་པའི་སྐྱེ་བོས་གང་ཞིང་བདེ་བ་ལ་སྤྱོད་པར་བསྔོ་བ་དང༌།
དགོས་པའི་ཡོ་བྱད་ཚང་ཞིང་གནོད་པ་ཞི་བར་བསྔོ་བའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་ལྔ།
དགེ་འདུན་གྱི་དོན་དུ་སྤྱིར་བསྔོ་བ་དང༌།
དགེ་སློང་གི་དོན་དུ་བསྔོ་བ་དང༌།
དགེ་སློང་མའི་དོན་དུ་བསྔོ་བ་དང༌།
ཚུལ་ཁྲིམས་ཕུན་སུམ་ཚོགས་པར་བསྔོ་བ་དང༌།
འབྲས་བུ་བདེ་བ་ལ་ལོངས་སྤྱོད་པར་བསྔོ་བའོ། །

Enumeration Block 7:
གཉིས་པ་ལ་གསུམ།
བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་བཞེད་དོན་འགྲུབ་པར་བསྔོ་བ་དང༌།
སངས་རྒྱས་ཀྱི་མཛད་པ་མཐར་ཕྱིན་པར་བསྔོ་བ་དང༌།
ཉན་རང་གི་བཞེད་དོན་འགྲུབ་པར་བསྔོ་བའོ། །

Enumeration Block 8:
གཉིས་པ་རང་དོན་དུ་བསྔོ་བ་ལ་བཞི།
གནས་སྐབས་ཀྱི་འབྲས་བུ་ཐོབ་པར་སྨོན་པ་དང༌།
འཇམ་པའི་དབྱངས་ཀྱི་དངོས་སུ་རྗེས་སུ་འཛིན་པར་སྨོན་པ་དང༌།
བྱང་ཆུབ་སེམས་དཔའི་སྤྱོད་པ་ལ་གནས་པར་སྨོན་པ་དང༌།
གཞན་དོན་མཐར་ཕྱིན་པར་སྨོན་པའོ། །
