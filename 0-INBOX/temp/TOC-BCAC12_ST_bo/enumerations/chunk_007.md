Enumeration Block 1:
དགེ་བ་བསྒྲུབ་པ་ལ་བག་བྱ་བ་ལ་གཉིས་ཏེ། ལུས་ལ་མ་ཆགས་པར་བསྒྲུབ་པ་དང༌། དགེ་བ་བསྒྲུབ་པའི་ཐབས་ལ་བསླབ་པའོ། །དང་པོ་ལ་ལྔ་སྟེ། གཡོ་བ་མེད་པ་དང༌། མི་གཙང་བ་དང༌། སྙིང་པོ་མེད་པ་དང༌། མི་མཁོ་བ་དང༌། དེས་ན་ཉེ་བར་མཁོ་བ་ལ་སྦྱར་བའོ། །

Enumeration Block 2:
དགེ་བ་བསྒྲུབ་པ་ལ་ཐབས་མཁས་པའི་ཁྱད་པར་ལ་གསུམ་སྟེ། ཐ་མལ་པའི་སྤྱོད་པ་ལ་ཐབས་མཁས་པ་དང༌། ལས་ཀྱི་སྤྱོད་པ་ལ་ཐབས་མཁས་པ་དང༌། བྱེད་པ་པོའི་སྤྱོད་པ་ལ་ཐབས་མཁས་པའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་ལྔ་སྟེ། གཞན་གདམས་ངག་སྦྱིན་པ་ལ་ཇི་ལྟར་བསྒྲུབ་པ་དང༌། བདེན་པར་བརྗོད་པ་ལ་ཇི་ལྟར་བསྒྲུབ་པ་དང༌། བསོད་ནམས་བྱེད་པ་ལ་ཇི་ལྟར་བསྒྲུབ་པ་དང༌། བརྗོད་པའི་ཚུལ་ལ་ཇི་ལྟར་བསྒྲུབ་པ་དང༌། གཞན་ལ་གུས་པའི་བློའི་ཆེ་བའོ། །

Enumeration Block 4:
གསུམ་པ་ལ་གསུམ་སྟེ། སྨྲ་བ་དང་འབྲེལ་པ་དང༌། ལྟ་བ་དང་འབྲེལ་བ་དང༌། དགེ་བའི་ལས་དང་འབྲེལ་བའོ། །

Enumeration Block 5:
གསུམ་པ་ནི་བཞི་སྟེ། ཀུན་སློང་གི་བསམ་པ་དང༌། ཞིང་དང༌། སྦྱོར་བ་དང༌། རྣམ་པའི་ཁྱད་པར་རོ། །

Enumeration Block 6:
སེམས་ཅན་གྱི་དོན་བྱ་བའི་སྤྱོད་པ་ལ་བསླབ་པའི་ཚུལ་ལ་གསུམ་སྟེ། གཞན་དོན་ལ་ཆེད་ཆེར་བྱ་བ་དང༌། སེམས་ཅན་བསྡུ་བའི་སྤྱོད་པ་དང༌། སེམས་ཅན་གྱི་སེམས་རྗེས་སུ་སྲུང་བའི་སྤྱོད་པའོ། །

Enumeration Block 7:
གཉིས་པ་སེམས་ཅན་བསྡུ་བའི་སྤྱོད་པ་ལ། ཟང་ཟིང་གིས་བསྡུ་བ་དང༌། ཆོས་ཀྱིས་བསྡུ་བ་གཉིས་སོ། །དང་པོ་ལ་ཕྱི་རོལ་གྱི་བསྡུ་བ་དང༌། ནང་གི་བསྡུ་བ་གཉིས་སོ། །

Enumeration Block 8:
ཆོས་ཀྱིས་བསྡུ་བ་ལ་བཤད་པའི་སྣོད་དང༌། བཤད་པའི་ཚུལ་གཉིས་སོ། །

Enumeration Block 9:
བསླབ་པ་ཕུན་སུམ་ཚོགས་པའི་ཡན་ལག་ལ་དྲུག་སྟེ། དག་པའི་རྒྱུ་དང༌། བསླབ་པའི་གཞི་དང༌། ཆེད་དུ་བྱ་བ་དང༌། བསླབ་པའི་ཉེ་བར་སྟོན་པ་དང༌། ཤེས་བྱེད་དང༌། བསླབ་པ་མདོར་བསྡུ་བའོ། །
