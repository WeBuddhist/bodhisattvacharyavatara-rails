# पुब्बभाग नमोक्कार ^0

## 1. साधुकार ^1-0

साधु - साधु - साधु!!! ^1-1

## 2. रत्नत्रय वंदना ^2-0

अरहं सम्मासम्बुद्धो भगवा बुद्धं भगवन्तं अभिवादेमि। ^2-1
स्वाखातो भगवता धम्मो धम्मं नमस्सामि। ^2-2
सुपटिपन्नो भगवतो सावकसङ्घो सङ्घं नमामि। ^2-3

## 3. नमो तस्स ^3-0
