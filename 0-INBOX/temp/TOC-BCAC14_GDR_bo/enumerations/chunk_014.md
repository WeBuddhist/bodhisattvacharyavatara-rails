Enumeration Block 1:
གསུམ་པ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་ལྔ། ཉོན་མོངས་སྐྱེ་འདོད་པའི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། རྒོད་པ་སོགས་ཀྱི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། རྙེད་བཀུར་སོགས་ཀྱི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌།
གཞན་དོན་ལ་སེམས་པའི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། ཁྲོ་བ་དང་ཞུམ་པ་སོགས་སྐྱེ་འདོད་པའི་ཚེ་ཇི་ལྟར་བྱ་བའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། སོ་སོའི་གཉེན་པོས་བསྲུང་བ་དང༌། ཐུན་མོང་བའི་གཉེན་པོ་དང༌། གཉེན་པོ་བསྒོམ་པ་ལ་སྦྱོར་བའི་ཚུལ་ལོ། །

Enumeration Block 4:
གཉིས་པ་དགེ་བའི་ཆོས་སྡུད་པའི་ཚུལ་ཁྲིམས་ལ་བསླབ་ཚུལ་ལ་གཉིས། ཚུལ་ཁྲིམས་ལ་མི་སློབ་པའི་རྒྱུ་ལུས་ལ་ཆགས་པ་སྤང་པ་དང༌། དགེ་བ་བསྒྲུབ་པ་ལ་མཁས་པར་བྱ་བའོ། །

Enumeration Block 5:
དང་པོ་ལ་ལྔ། ལུས་ལ་ཆགས་པར་མི་རིགས་པའི་དཔེ་དང༌། ལུས་མི་གཙང་བར་བསྒོམ་པ་དང༌། ལུས་ལ་སྙིང་པོ་མེད་པ་བསམ་པ་དང༌། ལུས་ལ་ཆགས་པར་མི་རིགས་པའི་རྒྱུ་མཚན་དང༌།
མྱུར་དུ་འཇིག་པས་དགེ་བ་ལ་བཀོལ་བར་རིགས་པའོ། །

Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། ལུས་ལ་ཆ་དང་ཆར་ཕྱེ་ནས་བརྟགས་ན་ཡིད་བརྟན་རུང་བའི་སྙིང་པོ་ཅུང་ཟད་ཀྱང་མེད་པ་དང༌། སྙིང་པོ་མེད་པ་ལ་ཆགས་པར་མི་རིགས་པའོ། །

Enumeration Block 7:
ལྔ་པ་ལ་བཞི། མྱུར་དུ་འཆི་བས་འཇོམས་པའི་ལུས་འདི་དགེ་བ་ལ་བཀོལ་རིགས་པ་དང༌། བྱ་བ་ཅུང་ཟད་ཀྱང་མི་བྱེད་པར་ཞེན་པས་བསྐྱང་བར་མི་རིགས་པའི་དཔེ་དང༌།
གླ་རྔན་བྱིན་ནས་འདོད་དོན་སྒྲུབ་ཏུ་གཞུག་པ་དང༌། གྲུའི་བློ་བཞག་སྟེ་སེམས་ཅན་མཐའ་དག་གི་དོན་སྒྲུབ་རིགས་པའོ། །

Enumeration Block 8:
གཉིས་པ་ལ་གསུམ། ཐ་མལ་པའི་ཀུན་སྤྱོད་ཀུན་མཛེས་པར་བྱ་བ་དང༌། གཞན་དང་འགྲོགས་པའི་ཀུན་སྤྱོད་ཁ་ན་མ་ཐོ་བ་མེད་པ་ལ་མཁས་པར་བྱ་བ་དང༌།
སྒོ་གསུམ་གྱི་ལས་བྱེད་པའི་བྱ་བ་ལ་མཁས་པར་བྱའོ། །

Enumeration Block 9:
དང་པོ་ལ་གསུམ། གཞན་དང་ཕྲད་པའི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། ཡོ་བྱད་ལ་འདོར་ལེན་བྱེད་པ་སོགས་ཀྱི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། སྤྱོད་པ་མཛངས་པས་ཀུན་ཏུ་བྱ་བ་བསྒྲུབ་པའོ། །
