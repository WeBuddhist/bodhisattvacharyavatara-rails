Enumeration Block 1:
སེམས་དྲན་པ་ཉེ་བར་གཞག་པ་ལ་གཉིས་ཏེ། ཡིད་ཀྱི་རང་བཞིན་མ་གྲུབ་པ་དང༌། རྣམ་པར་ཤེས་པ་ལྔའི་དམིགས་པ་མ་གྲུབ་པའོ། །

Enumeration Block 2:
ཆོས་དྲན་པ་ཉེ་བར་གཞག་པ་ལ་གཉིས་ཏེ། ཐམས་ཅད་སྐྱེ་བ་མེད་པར་བསྒྲུབ་པ་དང༌། དེ་ལ་རྩོད་པ་སྤོང་བའོ། །

Enumeration Block 3:
རྩོད་པ་སྤང་བ་ལ་གཉིས་ཏེ། ཀུན་རྫོབ་མེད་པའི་རྩོད་པ་སྤང་བ་དང༌། ངེས་བྱེད་ཐུག་པ་མེད་པའི་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 4:
གཉིས་པ་ངེས་བྱེད་ཐུག་མེད་དུ་ཐལ་བ་སྤང་བ་ནི་གསུམ་སྟེ། ཡུལ་དང་ཡུལ་ཅན་གྱི་རྣམ་པར་གཞག་པ་སྤྱིར་བརྗོད་པ་དང༌། ཡུལ་ཅན་སྐྱེ་མེད་དུ་རྟོགས་པ་གཞན་ལ་ལྟོས་ན་ཐུགས་པ་མེད་པ་དང༌། རང་ལ་ཉེས་པ་མེད་པའོ། །

Enumeration Block 5:
དེ་ལ་གཉིས་ཏེ། དང་པོ་ཚིགས་བཅད་ལྔས་དངོས་པོར་འཛིན་པ་ལ་སྒྲུབ་བྱེད་མེད་པ་དང༌། རེ་ཞིག་ཅེས་བྱ་བ་ལ་སོགས་པས་གནོད་བྱེད་ཡོད་པས་བསྟན་ཏོ། །

Enumeration Block 6:
དེ་ལ་དང་པོ་ཆོས་ཐམས་ཅད་ལ་སྒྲུབ་བྱེད་ཀྱི་ཚད་མ་མེད་པ་ལ་གཉིས་ཏེ། སྤྱིར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 7:
རྒྱས་པར་བཤད་པ་ལ་གཉིས་ཏེ། ཕན་ཚུན་རྟེན་པ་དང༌། འབྲས་བུའི་ཤེས་པ་སྒྲུབ་བྱེད་དུ་རྟོག་པའོ། །
དང་པོ་ལ་གཉིས་ཏེ། གཉི་ག་མེད་པ་དང༌། དེ་དཔེ་ལ་སྦྱར་བའོ། །

Enumeration Block 8:
འདི་ལ་གསུམ་སྟེ། རྒྱུ་རྣམ་པར་དཔྱད་པ་རྡོ་རྗེ་གཟེགས་མ་དང༌། རང་གི་ངོ་བོ་ལ་རྣམ་པར་དཔྱད་པ་རྟེན་འབྲེལ་དང༌། འབྲས་བུ་ལ་རྣམ་པར་དཔྱད་པ་ཡོད་མེད་སྐྱེ་འགག་གོ ། 

Enumeration Block 9:
འདིའི་ཕྱོགས་ཆོས་བསྒྲུབ་པ་གཞུང་དུ་འཆད་པ་ན་གསུམ་སྟེ། ཕྱོགས་ཆོས་བསྒྲུབ་དངོས་དང༌། ཡོངས་གཅོད་མ་གྲུབ་ཀྱང་རྣམ་དཔྱད་ལ་ཚད་མར་མི་འགལ་བ་དང༌། གཏན་ཚིགས་ཀྱིས་ངེས་པའི་དོན་བརྗོད་པའོ། །

Enumeration Block 10:
རང་བཞིན་གྱིས་སྐྱེ་བ་དགག་པ་ལ་གཉིས་ཏེ། རང་བཞིན་གྱིས་སྐྱེ་བ་དགག་པ་དངོས་དང༌། དབུ་མ་ལ་རྩོད་པ་སྤང་བའོ། །
དང་པོ་ལ་གསུམ་སྟེ། རྒྱུ་མེད་པ་ལས་སྐྱེ་བ་དགག་པ་དང༌། གཞན་ལས་སྐྱེ་བ་དགག་པ་དང༌། རང་ལས་སྐྱེ་བ་དགག་པའོ། །
གཉི་ག་ལས་སྐྱེ་བ་ནི་རང་དང་གཞན་ལས་སྐྱེ་བ་བཀག་པ་ཉིད་ཀྱིས་ཁེགས་སོ། །
དང་པོ་ལ་བཞི་སྟེ། སྤྱིར་བསྟན་པ་དང༌། འབྲས་བུའི་རྣམ་པར་དབྱེ་བ་རྒྱུ་ལ་ལྟོས་པ་དང༌། རྒྱུའི་རྣམ་པར་དབྱེ་བ་རྒྱུ་ལ་ལྟོས་པ་དང༌། ནུས་པའི་རྣམ་པར་དབྱེ་བ་རྒྱུ་ལ་ལྟོས་པའོ། །

Enumeration Block 11:
གཞན་ལས་སྐྱེ་བ་འགེགས་པ་ན་གཞན་མི་རྟག་པ་ལས་སྐྱེ་བ་དགག་པ་དང༌། གཞན་རྟག་པ་ལས་སྐྱེ་བ་དགག་པའོ། །

Enumeration Block 12:
ད་ནི་གཞན་རྟག་པ་ལས་སྐྱེ་བ་འགེགས་པ་ན་གཉིས་ཏེ། དབང་ཕྱུག་ལས་སྐྱེ་བ་དགག་པ་དང༌། རྡུལ་ཕྲན་རྟོག་པ་ལས་སྐྱེ་བ་བྱེ་བྲག་པའི་ལུགས་དགག་པའོ། །
དང་པོ་ལ་གསུམ་སྟེ་དབང་ཕྱུག་མ་གྲུབ་པ་དང༌། འབྲས་བུ་མི་སྲིད་པ་དང༌། སྐྱེད་བྱེད་དུ་འགལ་བའོ། །
དང་པོ་ལ་བཞི་སྟེ། འབྱུང་བ་དགག་པ་དང༌། ནམ་མཁའ་དགག་པ་དང༌། བདག་དགག་པ་དང༌། བསམ་གྱིས་མི་ཁྱབ་པ་དགག་པའོ། །

Enumeration Block 13:
དེའི་ལན་སུན་དབྱུང་བ་ལ་གཉིས་ཏེ། རྟག་པ་འབྲས་བུ་མ་ཡིན་པ་དགག་པ་དང༌། མི་རྟག་པ་འབྲས་བུ་ཡིན་པ་དགག་པའོ། །

Enumeration Block 14:
དེ་ལ་གསུམ་སྟེ། འབྲས་བུ་རེས་འགའ་བར་འགལ་བ་དང༌། དེའི་ཁྱབ་པ་ལྟོས་མེད་ཀྱིས་བསྒྲུབ་པ་དང༌། ལྟོས་པ་ཉིད་དགག་པའོ། །

Enumeration Block 15:
དེ་ལ་གཉིས་ཏེ། ཐམས་ཅད་འབྲས་བུ་ཡིན་པས་ལྟོས་པ་འགལ་བ་དང༌། ལྟོས་ན་དབང་ཕྱུག་ཏུ་འགལ་བའོ། །

Enumeration Block 16:
གཉིས་པ་ནི་གསུམ་སྟེ། ཚོགས་པ་ཉིད་རྒྱུར་གྲུབ་པ་དང༌། རང་དབང་ཅན་ཉམས་པ་དང༌། འདོད་པའི་གཞན་དབང་དུ་གྱུར་པའོ། །

Enumeration Block 17:
རང་ལས་སྐྱེ་བ་དགག་པ་ལ་གཉིས་ཏེ། གཞན་གྱི་ལུགས་དགོད་པ་དང༌། དེ་སུན་དབྱུང་བའོ། །
དང་པོ་ལ་གསུམ་སྟེ། སྤྱིར་བསྟན་པ་དང༌། གཙོ་བོའི་རང་བཞིན་དང༌། འབྲས་བུའི་རང་བཞིན་ནོ། །

Enumeration Block 18:
དེ་དགག་པ་ལ་བཞི་སྟེ། གནོད་པ་སྤྱིར་བརྗོད་པ་དང༌། བདེ་བ་ལ་སོགས་པས་ཕྱི་རོལ་ཡིན་པ་དགག་པ་དང༌། གཙོ་བོ་རྟག་པ་མི་འཐད་པ་དང༌། ཡོད་པ་སྐྱེ་བ་འགལ་བའོ། །
དང་པོ་ལ་གསུམ་སྟེ། གཙོ་བོ་དགག་པ་དང༌། ཡོན་ཏན་དགག་པ་དང༌། འབྲས་བུ་དགག་པའོ། །

Enumeration Block 19:
བདེ་བ་ལ་སོགས་པ་ཕྱི་རོལ་གྱི་དོན་ཡིན་པ་དགག་པ་ལ་གཉིས་ཏེ། སྣང་བ་མི་དམིགས་པས་དགག་པ་དང༌། བདེ་བ་ལ་སོགས་པ་རྒྱུ་ཡིན་པ་དགག་པའོ། །

Enumeration Block 20:
དེ་དགག་པ་ལ་བཞི་སྟེ། བརྗོད་ཟིན་པའི་རིགས་པ་དྲན་པ་ལས་སྦྱར་བ་དང༌། ཐ་སྙད་དུའང་རང་གི་ཚིག་དང་འགལ་བ་དང༌། སྔ་མ་ཉིད་བརྟན་པར་མི་གནས་པ་དང༌། བཟློག་པ་ཉིད་དེ་ཁོ་ནར་མི་གནས་པའོ། །

Enumeration Block 21:
གཙོ་བོ་རང་བཞིན་རྟག་པ་དགག་པ་ལ་བཞི་སྟེ། སྣང་བ་མི་དམིགས་པས་དགག་པ་དང༌། ཕྲ་རགས་འགལ་བ་དང༌། གནས་སྐབས་མི་རྟག་པར་གྲུབ་པ་དང༌། རང་བཞིན་མི་རྟག་པར་བསྒྲུབ་པའོ། །

Enumeration Block 22:
སྐབས་སུ་བབ་པ་རང་ལས་སྐྱེ་བ་དགག་པ་ལ་བཞི་སྟེ། དགག་པའི་ཡུལ་བརྗོད་པ་དང༌། རང་གི་འདོད་པས་མ་ངེས་པ་དང༌། འཇུག་པ་འཆོལ་བ་དང༌། རྩོད་པ་སྤང་བའོ། །

Enumeration Block 23:
བཞི་པ་རྩོད་པ་སྤང་བ་ལ་གསུམ་སྟེ། འཇུག་པ་མཚུངས་པ་དང༌། འཇིག་རྟེན་རྨོངས་པར་འགལ་བ་དང༌། འབྲས་བུའི་འཇུག་པ་སླུ་བར་ཐལ་བའོ། །
