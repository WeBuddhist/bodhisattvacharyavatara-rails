# पञ्चसील याचना ^0

## 1. शील अधिष्ठान ^1-0

अहं पञ्च सीलं अधिट्ठामि। ^1-1

## 2. रत्नत्रय वंदना ^2-0

अरहं सम्मासम्बुद्धो भगवा, बुद्धं भगवन्तं अभिवादेमि।
स्वाखातो भगवता धम्मो, धम्मं नमस्सामि।
सुपटिपन्नो भगवतो सावकसङ्घो, सङ्घं नमामि। ^2-1

## 3. नमो तस्स ^3-0

नमो तस्स भगवतो अरहतो सम्मासम्बुद्धस्स।
नमो तस्स भगवतो अरहतो सम्मासम्बुद्धस्स।
नमो तस्स भगवतो अरहतो सम्मासम्बुद्धस्स। ^3-1

## 4. पंचशील ^4-0

१. पाणातिपाता वेरमणी सिक्खापदं समादियामि।
२. अदिन्नादाना वेरमणी सिक्खापदं समादियामि।
३. कामेसुमिच्छाचारा वेरमणी सिक्खापदं समादियामि।
४. मुसावादा वेरमणी सिक्खापदं समादियामि।
५. सुरामेरयमज्जपमादट्ठाना वेरमणी सिक्खापदं समादियामि। ^4-1

## 5. त्रिसरणगमन संपूर्ण ^5-0

भन्ते : तिसरणगमनं सम्पुण्णं।
उपासक : आम भन्ते। ^5-1
