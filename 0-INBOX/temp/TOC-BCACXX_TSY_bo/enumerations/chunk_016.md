Enumeration Block 2:
གཉིས་པ་ལ་གསུམ་ལས་དང་པོ་ལས་ཀྱི་ང་རྒྱལ་ལའང་གསུམ་གྱི་དང་པོ་ངོ་
བོ༌ནི༌བདག༌ཉིས༌ཅེས༌རྐང༌པ༌གཉིས༌དང༌། གཉིས༌པ༌གཞན༌གྱིས༌མི་ནུས་པའི་རྒྱུ་ནི་ཉོན་
མོངས་ནས་ཞེས་རྐང་པ་བཞི་དང༌། གསུམ་པ་བདག་གིས་བྱེད་པའི་བློ་ཡང་རྐང་པ་བཞི་སྟེ།

Enumeration Block 3:
གཉིས་པ་ནུས་པའི་ང་རྒྱལ་ལ་
བཞིའི་དང་པོ་དེ་བསྟེན་པར་རིགས་པ་ནི་ཤི་བའི་ཞེས་ཤོ་ཀ་གསུམ་གྱིས་སྟོན་པ་ན་

Enumeration Block 4:
གསུམ་པ་ཉོན་མོངས་ཀྱི་ང་རྒྱལ་
ལ་སྤང་བྱས་མི་ཚུགས་པ་དང༌། གཉེན་པོ་བསྲུངས་པ་དང༌། ང་རྒྱལ་ཉིད་ཀྱི་དོན་དང་གསུམ་
རིམ་པ་བཞིན་ཉོན་མོངས་ཞེས་དང་ཉམས་ཞེས་དང༌། བདག་ནི་ཞེས་ཤློོ་ཀ་རེ་རེས་བསྟན་
ཞིང༌།

Enumeration Block 5:
གསུམ་པ་དགའ་བའི་དཔུང་ལ་བསྟུན་ངཤད་གཉིས་ལས་དང་པོ་ནི་རྩེད་མོའི་
ཞེས་ཤློོ་ཀ་གཅིག་གོ །གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་དགའ་བ་ནི་བདེ་བའི་ཞེས་ཤློོ་ཀ་གཅིག་
སྟེ༑

Enumeration Block 6:
གཉིས་པ་དཔུང་ཚོགས་དེ་དག་གིས་ལྷུར་བླང་བར་བྱ་བ་ལ་གསུམ་སཏེ། གཉེན་
པོ་ལྷུར་བླང་ཚུལ་དང་། ཉེས་པ་སྤང་ཚུལ་དང་། རྗེས་སུ་མཐུན་པའི་བྱ་བ་སྒྲུབ་པའོ། །དང་པོ་
ལ་བག་ཡོད་པ་དང་དྲན་པ་ལྷུར་བླང་ཚུལ་གཉིས་འཐབ་རྙིང་ཞེས་དང་གཡུལ་དུ་ཞེས་ཤློོ་ཀ་རེ་
རེའོ། །གཉིས་པ་ལ་གཉིས་ལས་དང་པོ་སྐབས་མི་དབྱེ་བ་ནི་ཇི་ལྟར་ཞེས་ཤློོ་ཀ་གཉིས་ཏེ།

Enumeration Block 7:

Enumeration Block 8:
ད་ནི་བསམ་གཏན་གྱི་ལེའུ་སྟོན་པ་ལ་དོན་རྣམ་པ་གསུམ་གྱི་དང་པོ་དོན་གྱི་

Enumeration Block 9:
གཉིས་པ་མི་མཐུན་ཕྱོགས་སྤང་བ་ལ་བསྟན་བཤད་གཉིས་
ལས་དང་པོ་ནི་རྐང་པ་དྲུག་གིས་སྟོན་པ་ན་

Enumeration Block 10:
གཉིས་པ་ལ་གཉིས་ཏེ། འཇིག་རྟེན་སྤང་བ་
དང༌། རྣམ་རྟོག་དོར་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཉེས་དམིགས་ཀྱི་སྒོ་ནས་འདུ་འཛི་སྤང་
བ་དང༌། ཡོན་ཏན་གྱི་སྒོ་ནས་དབེན་པ་བསྟེན་པར་གདམས་པའོ། །དང་པོ་ལ་གཉིས་ཀྱི་
དང་པོ་སྤང་བའི་བློ་བསྐྱེད་པ་ནི་ཤློོ་ཀ་གཉིས་ཀྱིས་སྟོན་པ་ལ་

གཉིས་པ་སྤོང་བའི་ཐབས་བསྟན་པ་ལ་གསུམ་ལས་དང་པོ་ནང་སེམས་ཅན་
ལ་ཆགས་པ་སྤང་བ་ལ་གཉིས་ཀྱི་དང་པོ་ཆགས་པ་ཉིད་ཀྱི་ཉེས་པ་ལ་
