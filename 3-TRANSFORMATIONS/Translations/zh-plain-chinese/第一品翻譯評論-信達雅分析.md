# 《入菩薩行論》第一品　四譯本信達雅分析

**評論角度：** 翻譯評論  
**評估標準：** 信（忠實）、達（通順）、雅（典雅）  
**參照譯本：**
1. 隆蓮法師譯（根本頌，底本）
2. Claude 漢翻漢白話書面語版（以隆蓮為底本改寫）
3. Padmakara 英譯→中文（英文轉譯）
4. Claude 藏翻漢白話書面語版（直接從藏文翻譯）

---

## 一、信達雅標準在佛典翻譯中的意義

嚴復在《天演論》譯例言中提出「信達雅」三字，本是針對西方哲學與科學著作的翻譯標準，但其核心精神對佛典翻譯同樣適用，甚至更為嚴苛——因為佛典同時是哲學論著、修行指南，又是文學作品。

- **信（忠實）：** 譯文是否準確傳達原典的義理，術語是否有文本依據，是否引入了原文沒有的詮釋。
- **達（通順）：** 譯文在目標語言中是否自然流暢，讀者是否能無障礙地理解，句子結構是否符合目標語的語法習慣。
- **雅（典雅）：** 譯文是否具有文學品質，能否呈現原典的文體風格——在本論的情況下，即寂天論師「優美、謙遜、深入淺出」的獨特語調。

這三者往往形成張力：過於求信，則文字生硬；過於求達，則容易失真；過於求雅，則可能流於文學性的鋪張而掩蓋義理。

## 二、各譯本個別評析

### 2.1 隆蓮法師譯（根本頌）

隆蓮法師的譯本是現代中文世界最具學術地位的《入菩薩行論》譯本之一，以文言句式保留了原典的義理密度。

**信：★★★★★（極高）**

隆蓮法師兼通藏梵，譯文緊貼原典，術語選擇嚴謹。以偈 1.1 為例：「善逝具足法身及佛子，一切應禮敬處敬禮已」，其中「善逝」（Sugata）、「法身」（Dharmakāya）、「佛子」（菩薩）皆有明確的藏文對應，未有任何自由詮釋。賈曹傑《廣解》對每一術語的詮釋，與隆蓮譯文高度一致。

**達：★★★（中等）**

文言句式對現代讀者形成明顯的閱讀障礙。「如來勝子律儀趣入處，遵依經教總攝當宣說」這樣的倒裝結構，若無注解，一般讀者難以掌握語義流向。此為文言譯體的結構性限制，並非隆蓮的缺失，而是翻譯策略使然——她選擇保留義理的密度，而非追求現代讀者的閱讀便利。

**雅：★★★★（高）**

文言體本身帶有典雅的質感，節奏簡練有力。「百千生死苦痛欲摧壞，有情憂惱不安欲遣除」這樣的排比句式，在音節上整齊對稱，具有漢傳佛典特有的莊嚴氣象。然而，這種典雅是文言文的典雅，而非現代書面語的典雅，兩者屬於不同的審美體系。

**小結：** 隆蓮譯本是信雅俱備的學術底本，但「達」的不足使它不適合作為現代普通讀者的入門文本。它更適合作為學術研究、修行者研讀，或白話改寫的參照基礎。

### 2.2 Claude 漢翻漢白話書面語版

本版本以隆蓮譯本為底本，將文言結構轉化為現代書面語，並將佛教術語替換為白話對應詞（如「菩提心」→「覺悟之心」）。

**信：★★★（中等，有顧慮）**

這是本版本最值得商榷之處。「以隆蓮為底本進行改寫」本質上是**漢語到漢語的改寫**，而非直接從藏文翻譯，因此信度受到兩個層面的影響：

首先，隆蓮譯本本身已是翻譯，漢翻漢再增加一層詮釋距離。其次，術語替換帶來了義理上的位移風險。「覺悟之心」雖然是「菩提心」的白話說法，但「菩提」（bodhi）在佛教哲學中有其精確的意涵——它不僅是「覺悟」，更涉及對空性的究竟了解。用「覺悟之心」替換，雖便於理解，卻削弱了術語的哲學深度。

另一個問題是術語一致性。「覺悟之道的修行者」（菩薩）這個詞組冗長，而且在不同語境下（如偈 1.9 的「如來殊勝之子」、偈 1.31 的「菩薩」）呈現的方式不盡統一，容易讓讀者感到混亂。

具體改正案例值得一提：偈 1.1 曾出現「圍繞在佛陀身旁的修行者」這一錯誤，後經查閱賈曹傑注解更正為「踏上覺悟之道的修行者（佛子）」，這說明漢翻漢作業若不參照注疏，確實容易引入原文沒有的詮釋。

**達：★★★★（高）**

書面語流暢度明顯優於隆蓮的文言體。偈 1.5 的「如同漫漫長夜，濃雲密布，唯有閃電撕破黑暗的一瞬，萬象才得以清晰顯現，而後隨即又隱沒無蹤」，句子結構清晰，比喻形象，讀者能夠不費力地掌握意象。

然而部分段落仍殘留直譯的痕跡。偈 1.18「從真正生起這顆心的那一刻起，以堅定不退的心，真實地發願讓無邊無際的眾生全都解脫、獲得安穩，行覺悟之心便已開始」，這句話的邏輯主語在句中位移，讀者需要回讀才能釐清「誰在做什麼」。這是直譯結構在現代書面語中留下的生硬痕跡。

**雅：★★★（中等）**

本版本的「雅」處於中間地帶：比口語化更有品質，但尚未達到真正的文學優美。主要問題在於書面語雖然流暢，卻缺乏節奏感——讀起來像是一段說明文，而非一部具有內在韻律的修行指南。

偈 1.12「其他一切善業如同芭蕉樹，結果一次便凋謝枯竭，不再生長。而覺悟之心這棵樹卻永遠茂盛——它結果而不耗竭，反而不斷滋生，輾轉增長，生生不息」，後半段的節奏感相對較好，但「結果而不耗竭」這個表達仍稍顯刻意。

**小結：** 漢翻漢版本在「達」上有明顯進步，但「信」的隱憂不可忽視：它依賴隆蓮為底本，每加一層改寫，就多一層與原典的距離。作為入門讀本是合適的，但若以此版本作為研究或修行的依據，需謹慎對待術語的位移。

### 2.3 Padmakara 英譯→中文（轉譯版）

Padmakara Translation Group 的英譯本（2006 年修訂版）是國際學界最受肯定的《入菩薩行論》英譯之一，以流暢的現代英語見稱。本對照表中的中文版是在此評論過程中由英文轉譯而成。

**信：★★★（中等，結構性問題）**

這個版本面臨的根本困境是：它是**英譯的中文翻譯**，即二手翻譯。Padmakara 英譯本身有其詮釋立場（如脚注的使用、對某些術語的選擇），而轉成中文又再增加一層詮釋。

Padmakara 英譯忠實度整體上高，但在某些關鍵術語上採用了比隆蓮更自由的處理方式。例如偈 1.14 中 Padmakara 將「慈氏依怙」（彌勒菩薩）譯為「the Wise and Loving Lord」，中文轉譯為「智慧慈愛的彌勒」，這在達意上是準確的，但失去了「慈氏」這一專有名號的凝鍊感。

**達：★★★★（高）**

Padmakara 英文本身以流暢著稱，轉成中文後，自然度仍然相當高。偈 1.13「如同穿越危境有英雄護持，即使是被可怕罪業壓制的人，藉由菩提心也能立刻解脫」，句子的邏輯清晰，意象直接，讀者幾乎不需要停下來思考。

然而，英文句子結構轉成中文時，有時會產生語序的不適應。偈 1.25「這個帶給眾生利益的目標，是其他人甚至不為自己所願望的」，這個定語結構在中文中顯得較為繁複，是英文關係子句直譯中文的典型問題。

**雅：★★★★（偏高）**

Padmakara 英文原版具有相當的文學品質，其詩意在轉成中文後部分得以保留。偈 1.26「這消除苦痛的甘露，這在世間流浪者喜樂的根源，這珍貴的態度，這心靈的珍寶」，排比結構的使用使文字具有節奏感，優於漢翻漢版本的說明文語氣。

偈 1.36 的結尾「我向這些喜樂的源泉皈依——他們帶領連仇敵也走向圓滿的安樂」，「連仇敵也走向圓滿的安樂」這個細節，在漢翻漢版本中被處理為「即便有人傷害了他，也會因此沾染安樂」，Padmakara 版本更接近原典的深意：菩薩的悲心甚至能使傷害他的人最終走向解脫。

**小結：** Padmakara 轉譯版在「達」與「雅」上表現均衡，但「信」受到二手翻譯的結構性限制。它的最大價值在於提供了一個不同文化視角的詮釋參照，有助於發現漢文傳統翻譯中習以為常的表達是否遮蔽了某些義理面向。

### 2.4 Claude 藏翻漢白話書面語版

本版本直接從 བློ་ལྡན་ཤེས་རབ། 藏文版本翻譯，不以隆蓮為中介，是本次對照中唯一的第一手現代中文翻譯。

**信：★★★★（高）**

直接從藏文翻譯消除了漢翻漢的中間層，在義理忠實度上具有明顯優勢。偈 1.1「向具足法身的善逝者及其一切子嗣，向一切應當禮敬之處，我恭敬頂禮。依循經典教授，我將在此簡要說明如何進入善逝子嗣的戒行之道」，「戒行之道」（སྡོམ་ལ་འཇུག་པ།）更精確地呈現了藏文 sdom（戒律、律儀）的意涵，而漢翻漢版本的「修行之道」則較為模糊。

偈 1.2 的「而我在詩律的運用上也全無才能」，藏文 སྡེབ་སྦྱོར་མཁས་པ（詩律/prosody 的精通）被準確地翻譯，保留了寂天論師對自身文學能力的謙遜評價，這與原典的語義完全一致。

**達：★★★（中等）**

藏翻漢的最大挑戰在於：藏文句子結構與現代中文差異顯著，直譯容易帶出藏語的語序習慣。偈 1.18「從以堅定不退的心，為了徹底解脫無邊無際的眾生，真實受持行菩提心的那一刻起」，這個長句的動作主體（誰在做這件事）在中文中略顯模糊，需要讀者在句末才能掌握句子的語義重心——這是藏文末動詞結構在中文中留下的痕跡。

整體而言，藏翻漢版本的句子比漢翻漢版本稍顯凝重，在部分段落需要更多加工才能達到現代中文的自然流暢度。

**雅：★★★（中等）**

藏翻漢版本在文學品質上略低於隆蓮，也不及 Padmakara 轉譯版的詩意，但它有一種樸素的直接感——如同一個人認真地把所看到的說出來，沒有多餘的修飾。偈 1.25「這顆為了利益眾生而升起的珍寶之心——連眾生為自己都不曾有過——這前所未有的奇珍，竟然就這樣誕生了」，「竟然就這樣誕生了」帶有輕微的驚歎語氣，恰好呼應了原典「空前希有始誕生」的驚奇感，是本版本在「雅」上少有的亮點。

**小結：** 藏翻漢版本是信度最高的現代中文版，但在「達」和「雅」上仍需進一步潤色。它的價值在於提供了一個不受漢語佛典傳統習慣影響的全新視角，有助於發現隆蓮譯本中可能因文言習慣而形成的「盲點」。

## 三、跨版本比較：具體偈頌分析

### 偈 1.5（閃電比喻）

這首偈頌是一個測試「雅」的好例子：比喻形象如何在不同語言層次中保留其力量。

| 版本 | 譯文 | 評析 |
|------|------|------|
| 隆蓮 | 「猶如長夜黑暗陰雲覆，剎那電閃萬象暫顯明」 | 音節對稱，意象簡練，雅的典範 |
| 漢翻漢 | 「如同漫漫長夜，濃雲密布，唯有閃電撕破黑暗的一瞬，萬象才得以清晰顯現，而後隨即又隱沒無蹤」 | 意象展開充分，但節奏分散 |
| Padmakara轉 | 「就如同在烏雲密布的黑暗長夜，閃電突然劃破，萬象清晰顯現。同樣地，善念在世間偶爾升起，短暫而易逝」 | 有詩意，類比結構清晰 |
| 藏翻漢 | 「如同黑雲密布的漫漫長夜，閃電乍現，短短一瞬，萬象清晰顯露」 | 「乍現」二字有力，接近隆蓮的凝鍊感 |

**評論：** 在這首偈頌上，藏翻漢版本的「閃電乍現，短短一瞬」在凝鍊度上最接近隆蓮，是本次分析中藏翻漢表現最佳的例子之一。漢翻漢版本的「撕破黑暗」雖然形象，但「撕破」一詞帶有暴力感，稍微離開了原典清明的意象。

### 偈 1.2（作者謙遜自白）

這首偈頌是測試「信」的關鍵，因為它涉及寂天論師最具個人色彩的謙遜宣言。

| 版本 | 譯文 | 評析 |
|------|------|------|
| 隆蓮 | 「韻音善巧亦非我所能……唯為自心煉修造斯論」 | 「煉修」二字精準，「韻音善巧」保留了詩律技巧的意涵 |
| 漢翻漢 | 「我也不擅長優美的文辭……只是為了讓自己的心更加熟悉這些道理，在修行中漸漸增長」 | 流暢，謙遜語氣保留良好，但「更加熟悉」稍顯口語 |
| Padmakara轉 | 「在詩律的技藝上我也毫無能力。寫作只是為了讓自己的心習慣於此」 | 「毫無能力」謙遜有力；「習慣於此」稍嫌模糊 |
| 藏翻漢 | 「而我在詩律的運用上也全無才能……只是為了讓自己的心得以修習」 | 「詩律的運用」忠實於 སྡེབ་སྦྱོར；「全無才能」力度恰當 |

**評論：** 偈 1.2 是藏翻漢版本在「信」上最明顯優於漢翻漢的例子。藏文 སྡེབ་སྦྱོར་མཁས་པ 指的是詩律技藝（prosody），而非單純的「優美文辭」；藏翻漢版本的「詩律的運用」更準確地保留了這層意思，也更符合寂天論師作為詩人的自我意識。

### 偈 1.36（結尾皈依）

第一品的最後一偈，是整品在義理和情感上的收束，是測試「雅」的最佳位置。

| 版本 | 譯文 | 評析 |
|------|------|------|
| 隆蓮 | 「縱損彼者猶霑樂，安樂生處我皈依」 | 「猶霑樂」三字極凝鍊，「安樂生處」意象深遠 |
| 漢翻漢 | 「即便有人傷害了他，也會因此沾染安樂。我向這樣的安樂源泉皈依」 | 流暢，但「沾染安樂」的「沾染」一詞略有貶義感 |
| Padmakara轉 | 「他們帶領連仇敵也走向圓滿的安樂」 | 義理上最深刻：仇敵最終也走向解脫，而非只是「沾染」 |
| 藏翻漢 | 「即便傷害了他，也會與安樂相連——我向這安樂的源泉皈依」 | 「與安樂相連」比「沾染安樂」更中性，更符合藏文原意 |

**評論：** 這首偈頌揭示了漢翻漢版本一個值得注意的問題：「沾染安樂」的「沾染」在漢語中帶有被動、偶然甚至略帶負面的語感，而藏文 བདེ་འབྲེལ（與安樂相連）是中性甚至正面的。Padmakara 版本的「帶領連仇敵也走向圓滿的安樂」義理最深，但稍微過度詮釋了原文（原文並未明說「走向圓滿」）。藏翻漢版本的「與安樂相連」在信達之間取得最佳平衡。

## 五、結論與建議

### 核心發現

這次比較揭示了一個根本的翻譯困境：**信、達、雅三者在《入菩薩行論》的白話翻譯中形成了三角張力**。

- 最忠實的版本（隆蓮）最難讀；
- 最易讀的版本（漢翻漢）距離原典最遠；
- 最優美的版本各有所據，但沒有一個版本同時達成三項標準。

### 關於「漢翻漢」策略的反思

漢翻漢策略的本質是**在已有翻譯的基礎上進行改寫**，而非翻譯。改寫有其價值——它能快速生產易讀文本，但每一次改寫都是一次詮釋，都可能引入原文沒有的意思，或遮蔽原文的某些面向。

本次分析最鮮明的案例是偈 1.1：漢翻漢版本曾出現「圍繞在佛陀身旁的修行者」這一錯誤詮釋，根源正在於改寫者未能查核藏文原典，而只是在已有的中文基礎上進行猜測性改寫。這提示：漢翻漢策略**必須以注疏查核為前提**，否則信度的風險會隨每一次改寫而累積。

### 建議的翻譯路徑

若要生產一個兼顧信達雅的白話中文版本，建議採用以下路徑：

1. **以藏翻漢為信度基礎**：藏翻漢版本直接從藏文原典出發，義理忠實度最高，可作為白話版本的義理錨點。
2. **以 Padmakara 為文學參照**：Padmakara 在文學表達上相對成熟，轉譯其中文版本可提供節奏感和詩意的參考。
3. **以隆蓮術語為標準**：在術語選擇上，隆蓮的譯詞（如「善逝」、「佛子」、「菩提心」）已在漢語佛典傳統中形成共識，白話版本可保留這些術語，輔以簡短的行內說明，而非完全替換。
4. **以流暢性為最終測試**：每一句白話譯文，都應能夠朗讀而不生澀，且讀者在第一次聽讀時即能掌握意思。

最重要的一點：**任何翻譯選擇，都必須能追溯到藏文原典或權威注疏**。翻譯的謙遜，在某種意義上，也是寂天論師所示範的那種謙遜——知道自己所說的有限，並誠實地指出這個限制。
