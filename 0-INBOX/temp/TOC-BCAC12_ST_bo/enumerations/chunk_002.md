Enumeration Block 1:
དྲུག་པ་བཀུར་སྟིའི་མཆོད་པ་ལ་བསྟོད་པ་དང་། ཕྱག་འཚལ་བ་གཉིས་སོ། །

Enumeration Block 2:
སྐྱབས་སུ་འགྲོ་བ་ལ་བསྡུས་པའི་དོན་བདུན་ཏེ། རབ་ཏུ་དབྱེ་བ་དང་། ཁྱད་པར་རྣམ་པར་བཞག་པ་དང་། རང་བཞིན་དང་། འབྲས་བུའི་སྐྱབས་འགྲོ་དང་། སྨོན་པའི་སེམས་བསྐྱེད་ཀྱི་ཁྱད་པར་དང་། དགོས་པ་དང་། སྒྲའི་དོན་དང་། བསླབ་བྱའི་ཁྱད་པར་རོ། །དབྱེ་བ་ཐུན་མོང་དང་ཐུན་མོང་མ་ཡིན་པ་གཉིས་སོ། ཁྱད་པར་ནི་བཞི་སྟེ། སྐྱབས་གནས་དང་། དུས་ཀྱི་ཁྱད་པར་དང་། རྒྱུ་དང་། ཆེད་དུ་བྱ་བའོ། །

Enumeration Block 3:
སྡིག་པ་བཤགས་པ་ལ་བཞི་སྟེ། རྣམ་པར་སུན་དབྱུང་བ་དང་། རྟེན་གཟུང་བ་དང་། གཉེན་པོ་ལ་འབད་པ་དང་། སོར་ཆུད་པར་བྱ་བའོ། །དང་པོ་ལ་བཞི་སྟེ། བྱས་པའི་རྣམ་གྲངས་ལ་སོ་སོར་བརྟག་པ་དང་། མྱུར་དུ་བྲལ་བར་འདུན་པ་དང་། དོན་མེད་པ་སོ་སོར་བརྟག་པ་དང་། འབྲས་བུ་འཇིགས་པར་ཡིད་ལ་བྱ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། རྟེན་ལ་གསོལ་བ་གདབ་པ་དང་། ངོ་བོ་ལ་སོ་སོར་བརྟག་པ་དང་། ཡུལ་ལ་སོ་སོར་བརྟག་པའོ། །

Enumeration Block 4:
མྱུར་དུ་བྲལ་བར་འདུན་པ་ལ་བྲལ་བར་འདུན་པའི་རྣམ་པ་དང༌། ཡིད་བརྟན་གྱི་རྣམ་རྟོག་དགག་པའོ། །

Enumeration Block 5:
དོན་མེད་པར་བརྟག་པ་ལ་སྡིག་པ་བྱས་པའི་རྣམ་པ་དང༌། དོན་མེད་པར་བརྟག་པ་དང༌། དེ་འཐད་པས་བསྒྲུབ་པ་དང༌། མྱོང་བས་བསྒྲུབ་པ་དང༌། དོན་བསྡུ་བ་ལྔའོ། །

Enumeration Block 6:
འཇིགས་པ་ཡིད་ལ་བྱ་བ་ལ་བཞི་སྟེ། འཇིག་རྟེན་གཞན་དུ་འཕོ་བས་འབྲས་བུ་འབྱིན་པར་ངེས་པ་དང༌། འདི་ཉིད་དུ་མྱོང་བའི་འཇིགས་པ་དང༌། འཇིགས་པ་མི་ཟད་པ་འབྱིན་པའི་འཐད་པ་དང༌། སྡུག་བསྔལ་གྱིས་གདུངས་པའི་རྣམ་པའོ། །

Enumeration Block 7:
རྟེན་གྱི་སྟོབས་ལ་གསུམ་སྟེ། རྟེན་སྤྱིར་གཟུང་བ་དང༌། ཁྱད་པར་དུ་ཉེ་བའི་སྲས་ལ་རྟེན་དུ་གཟུང་བ་དང༌། རྟེན་དུ་བཟུང་ནས་དེ་དག་གི་བཀའ་ལྟར་རྗེས་སུ་བསྒྲུབ་པའོ། །

Enumeration Block 8:
གཉེན་པོ་ནི་སྟོབས་ལ་གཉིས་ཏེ། གཉེན་པོ་ལ་འབད་པར་རིགས་པའི་འཐད་པ་དང༌། མྱུར་དུ་འཇུག་པར་གདམས་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ནད་ཀྱི་དཔེ་དང༌། གཡང་སའི་དཔེའོ། །

Enumeration Block 9:
སོར་ཆུད་པའི་སྟོབས་ལ་གསུམ་སྟེ། ཕྱི་མ་ལ་བསྡམ་པ་དང༌། སྔ་མ་ལ་སྦྱང་བ་དང༌། སྐབས་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཉེས་དམིགས་ཀྱིས་འཇིགས་པ་ཡིད་ལ་བྱ་བ་དང༌། སྤང་བའི་བསམ་པའི་ཁྱད་པར་རོ། །

Enumeration Block 10:
རྗེས་སུ་ཡི་རང་བ་ལ་གསུམ་སྟེ། འཇིག་རྟེན་གྱི་དགེ་བ་ལ་ཡི་རང་བ་དང༌། ཉན་ཐོས་ཀྱི་དགེ་བ་ལ་ཡི་རང་བ་དང༌། སངས་རྒྱས་ཀྱི་དགེ་བ་ལ་ཡི་རང་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། མཐོ་རིས་སུ་བསྔོས་པའི་བསོད་ནམས་ཀྱི་ཆ་དང་མཐུན་པ་ལ་ཡི་རང་བ་དང༌། བྱང་ཆུབ་ཏུ་བསྔོ་བའི་ཐར་པའི་ཆ་དང་མཐུན་པ་ལ་ཡི་རང་བའོ། །
