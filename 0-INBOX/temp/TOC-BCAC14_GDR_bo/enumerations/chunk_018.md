Enumeration Block 1:
གཉིས་པ་ལ་གསུམ།
གྲངས་ཅན་པའི་བདག་དང་གཙོ་བོ་རང་དབང་ཅན་དགག་པ་དང༌།
རིགས་པ་ཅན་པའི་བདག་རང་དབང་ཅན་དགག་པ་དང༌།
འགྲོ་བ་ཀུན་སྤྲུལ་པ་ལྟ་བུར་ཤེས་པར་བྱས་ནས་ཁྲོ་བར་མི་རིགས་པའོ། །
དང་པོ་ལ་གཉིས།
གཙོ་བོས་རྣམ་འགྱུར་རང་དབང་དུ་བསྐྱེད་པ་དགག་པ་དང༌།
ཤེས་རིག་གི་སྐྱེས་བུ་ཡུལ་ལ་རང་དབང་དུ་ལོངས་སྤྱོད་པ་དགག་པའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་གསུམ།
རྟག་པས་འབྲས་བུ་བསྐྱེད་པ་མི་འཐད་པ་དང༌།
རྐྱེན་ལ་ལྟོས་པ་མི་འཐད་པ་དང༌།
རྐྱེན་དང་འབྲེལ་བ་མེད་པའོ། །

Enumeration Block 3:
གསུམ་པ་གནོད་པ་བྱེད་པ་ལ་ཇི་མི་སྙམ་པའི་བཟོད་པ་བསྒོམ་པ་ལ་གསུམ།
སྙིང་རྗེའི་ཐབས་ཡིད་ལ་བྱེད་པ་དང༌།
ཁྲོ་བའི་རྒྱུ་དགག་པ་དང༌།
མི་འདོད་པ་བྱུང་ན་རང་གི་ཉེས་པར་བསམ་པའོ། །
དང་པོ་ལ་གསུམ།
སེམས་ཅན་ཁ་ཅིག་མི་ཤེས་པའི་དབང་གིས་རང་ལ་གནོད་པ་བྱེད་པ་དང༌།
མི་ཤེས་པས་རང་ཡང་གསོད་ན་གཞན་ལ་གནོད་པ་བྱེད་པ་ངོ་མཚར་མི་ཆེ་བ་དང༌།
དེས་ན་དེ་ལ་སྙིང་རྗེ་བྱ་བར་རིགས་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལ་གསུམ།
བྱིས་པ་རང་གི་རང་བཞིན་ཡིན་ན་ཁྲོ་བར་མི་རིགས་པ་དང༌།
གནོད་པ་བྱེད་པའི་སྐྱོན་དེ་གློ་བུར་བ་ཡིན་ན་ཡང་ཁྲོ་བར་མི་རིགས་པ་དང༌།
དངོས་སམ་བརྒྱུད་པའི་རྒྱུ་ལ་བརྟགས་ནས་ཁྲོ་བར་མི་རིགས་པའོ། །

Enumeration Block 5:
གསུམ་པ་ལ་གཉིས།
དངོས་ཀྱི་དོན་དང༌།
རྩོད་པ་སྤང་བའོ། །
དང་པོ་ལ་ལྔ།
གཞན་གྱིས་རང་ལ་གནོད་པ་བྱེད་པ་རང་གི་ཉེས་པར་བསམ་པ་དང༌།
སྡུག་བསྔལ་གྱི་རྒྱུ་ལུས་བཟུང་བའི་ཉེས་དམིགས་ཡིན་པ་དང༌།
སྐྱེ་བ་སྔ་མར་སྡུག་བསྔལ་གྱི་རྒྱུ་ལ་སྲེད་པ་བྱས་པའི་ཉེས་དམིགས་ཡིན་པ་དང༌།
རང་གི་ལས་ཀྱིས་གཞན་སྡུག་བསྔལ་གྱི་རྒྱུ་ལ་སྦྱར་བ་ཡིན་པས་དེ་ལ་ཁྲོ་བར་མི་རིགས་པ་དང༌།
ཁྲོ་བ་ཉིད་ཕྱིན་ཅི་ལོག་ཅིང་མི་རིགས་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་གསུམ།
གཞན་རང་ལ་ཕན་བྱེད་དུ་མི་འཐད་པ་སྤང་པ་དང༌།
རང་གཞན་ལ་གནོད་བྱེད་དུ་མི་འཐད་དུ་སྤང་བ་དང༌།
ཕན་འདོགས་བྱེད་ལ་ལོག་པར་བསྒྲུབ་པ་དགག་པའོ། །

Enumeration Block 7:
གཉིས་པ་བརྙས་པ་སོགས་བསྒྲུབ་པ་ལ་བཟོད་པ་བྱ་རིགས་པ་ལ་བཞི།
བརྙས་སྨོད་སོགས་ཀྱིས་རང་གི་ལུས་ལ་མི་གནོད་པ་དང༌།
ཁྲོ་བ་དང་འབྲེལ་བའི་གང་ཟག་ལ་རང་གིས་ཁྲོ་བར་མི་རིགས་པ་དང༌།
རྙེད་པའི་བར་ཆད་བྱེད་པས་ཁྲོ་བར་མི་རིགས་པ་དང༌།
