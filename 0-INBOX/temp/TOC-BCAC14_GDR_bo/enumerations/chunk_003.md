Enumeration Block 1:
གསུམ་པ་དེ་ལ་ཕན་ཡོན་དེ་དག་འབྱུང་བའི་རྒྱུ་མཚན་ལ་གཉིས། ལུང་དགོད་པ་དང༌། རིགས་པས་སྒྲུབ་པའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སྨོན་སེམས་ལས་ཕན་ཡོན་ཐོབ་པའི་འཐད་པ་དང༌། འཇུག་སེམས་ལས་ཐོབ་པའི་འཐད་པའོ། །

Enumeration Block 3:
དང་པོ་ལ་བཞི། དགེ་བ་སྒྲུབ་པའི་བྱེད་ལས་མཐའ་ཡས་པས་ཕན་ཡོན་ཆེ་བ་དང༌། དེ་བས་ལྷག་པའི་ཕན་སེམས་གཞན་མེད་པ་དང༌།
སེམས་ཅན་རྣམས་ལ་དེ་འདྲ་བའི་ཕན་སེམས་རང་དོན་དུ་ཡང་མ་སྐྱེས་པ་དང༌། མཇུག་བསྡུས་ཏེ་བསྔགས་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། དངོས་དང༌། དེའི་འཐད་པ་དང༌། དོགས་པ་བསལ་བའོ། །

Enumeration Block 5:
བཞི་པ་ལ་གསུམ། མ་བཅོལ་ཡང་སྙིང་རྗེ་ཆེན་པོས་དྲངས་ནས་གྲོགས་མཛད་པས་བསྔགས་པར་འོས་པ་དང༌།
ཕན་པ་ཅུང་ཟད་བསྒྲུབ་པ་ལ་བསྟོད་པར་འོས་ན་ཕན་བདེ་མཐའ་དག་སྒྲུབ་པ་ལ་ཆེས་བསྔགས་པར་འོས་པ་དང༌། ཞིང་མཆོག་ཏུ་གྱུར་པས་བསྐྱབས་པར་འོས་པའོ། །

Enumeration Block 6:
གསུམ་པ་ལ་གསུམ། བྱང་ཆུབ་སེམས་དཔའ་ལ་ཅུང་ཟད་ཙམ་ཡང་སྨད་པར་མི་རིགས་པའི་རྒྱུ་མཚན་དང༌། དད་པ་བསྒོམ་པར་རིགས་པའི་རྒྱུ་མཚན་དང༌། དེས་ན་ཕྱག་འཚལ་ཞིང་སྐྱབས་སུ་འགྲོ་བར་འོས་པའོ། །

Enumeration Block 7:
དེ་ལྟར་གསུངས་པའི་ཕན་ཡོན་ཀྱང་བསྡུ་ན་གཉིས་ཏེ་གནས་སྐབས་དང་མཐར་ཐུག་གི་ཕན་ཡོན་ནོ། ། དང་པོ་ལ་ཡང་ངན་འགྲོར་མི་ལྟུང་བ་དང་བདེ་འགྲོར་སྐྱེ་བ་གཉིས་ཏེ།

Enumeration Block 8:
གཉིས་པ་བྱང་ཆུབ་ཀྱི་སེམས་གཉིས་བསྐྱེད་ནས་སྤྱོད་པ་ལ་སློབ་པའི་ཚུལ་ལ་གཉིས། བྱང་ཆུབ་ཀྱི་སེམས་གཟུང་བ་དང༌། སྤྱོད་པ་ཕ་རོལ་ཏུ་ཕྱིན་པ་ལ་སློབ་པའི་ཚུལ་ལོ། །

Enumeration Block 9:

དགེ་བ་ལ་རྗེས་སུ་ཡི་རང་བ་སོགས་མཐུན་རྐྱེན་ཚོགས་གསོག་པ་སྔོན་དུ་བཏང་སྟེ་སེམས་གཟུང་བ་དངོས་སོ། ། དང་པོ་ལ་གཉིས། ལེའུའི་གཞུང་བཤད་པ་དང༌། ལེའུའི་མཚན་ནོ། །

Enumeration Block 10:
དང་པོ་ལ་བཞི། མཆོད་པ་དང༌། ཕྱག་དང༌། སྐྱབས་འགྲོ་དང༌། སྡིག་པ་བཤགས་པའོ། ། དང་པོ་ལ་གཉིས། མཆོད་པ་ཕུལ་བའི་དགོས་པ་དང༌། མཆོད་པ་དངོས་སོ། །
