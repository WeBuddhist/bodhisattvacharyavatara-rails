Enumeration Block 1:
བདག་དང་གཞན་བརྗེ་བ་ལ་བཞི་སྟེ། མཚན་ཉིད་བྱ་བ་མདོར་བསྟན་པ་དང༌། མཚན་ཉིད་རྒྱས་པར་བཤད་པ་དང༌། བརྗེས་ནས་བསམ་པ་རྗེས་སུ་བསྒྲུབ་པའི་བྱ་བ་རྒྱས་པར་བཤད་པ་དང༌། སྦྱོར་བ་རྗེས་སུ་བསྒྲུབ་པའི་བྱ་བ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལའང་བསམ་པ་དང་སྦྱོར་བས་ཇི་ལྟར་བསྒྲུབ་པའོ། །

Enumeration Block 2:
མཚན་ཉིད་རྒྱས་པར་བཤད་པ་ལ་བཞི་སྟེ། གཞན་བླང་བ་དང༌། བདག་གཅེས་པར་འཛིན་པ་དོར་བ་དང༌། བདག་གཞན་གཙོ་བོར་བྱེད་པའི་སྐྱོན་ཡོན་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ནི་དེ་ལྟར་རྒྱུད་ནི་ཞེས་པ་ལ་སོགས་པ་བདག་གཞན་མཉམ་པའི་སྐབས་སུ་གསུངས་པའི་དོན་རྣམས་བཟླས་ནས་འདིར་ཡང་འཆད་པ་ན་བདུན་ཏེ། བརྗེ་བར་ནུས་པ་དང༌། དྲེགས་པ་ཞི་བ་དང༌། འབྲས་བུ་ལ་མི་ལྟོས་པ་དང༌། དགོས་པ་དེ་དག་གི་སྒྲུབ་བྱེད་ལ་འབད་པར་གདམས་པ་དང༌། གཞན་གྱི་དོན་ཆེད་ཆེར་གཟུང་བ་དང༌། གོམས་པས་གྲུབ་པ་དང༌། བདག་དང་གཞན་སྡུག་བསྔལ་ལས་སྒྲོལ་བའོ། །

Enumeration Block 3:
གཉིས་པ་བདག་གཅེས་པར་འཛིན་པ་དོར་བ་ལ་གཉིས་ཏེ། བདག་གི་ལུས་ལ་ཆགས་པས་སྐྲག་པའི་གནས་མ་ཡིན་པ་ལ་སྐྲག་པ་དང༌། ཉེས་དམིགས་སྣ་ཚོགས་ལ་སྦྱོར་བའོ། །

Enumeration Block 4:
གསུམ་པ་བདག་གཙོ་བོར་བྱེད་པའི་སྐྱོན་ཡོན་ལ་གཉིས་ཏེ། སྐྱོན་ཡོན་གཉིས་ཀའི་རྣམ་གྲངས་དང༌། བདག་གཅེས་པར་འཛིན་པའི་ཉེས་པའོ། །

Enumeration Block 5:
དང་པོ་ལ་དྲུག་སྟེ། སྦྱིན་པའི་དབང་དུ་བྱས་པ་དང༌། གནོད་པའི་དབང་དུ་བྱས་པ་དང༌། བསྟོད་གྲགས་ཀྱི་དབང་དུ་བྱས་པ་དང༌། ལས་ལ་སྦྱར་བའི་དབང་དུ་བྱས་པ་དང༌། ཕན་བདེའི་དབང་དུ་བྱས་པ་དང་དོན་བསྡུ་བའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་བཞི་སྟེ། མ་མཐོང་བའི་ཉེས་པ་དང༌། མཐོང་བའི་ཉེས་པ་དང༌། དོན་བསྡུ་བ་དང༌། འཇིགས་པའི་རྒྱུ་བདག་ཏུ་འཛིན་པ་དོར་བའོ། །

Enumeration Block 7:
བཞི་པ་དོན་བསྡུ་བ་ལ་ལྔ་སྟེ། བརྗེ་བའི་ཆེད་དུ་བྱ་བ་དང༌། རང་བཞིན་དང༌། བསམ་པའི་ཁྱད་པར་དང༌། སྦྱོར་བའི་ཁྱད་པར་ལས་ལོག་པའི་སྦྱོར་བ་དགག་པ་དང༌། ཡང་དག་པར་སྦྱོར་བ་བསྒྲུབ་པའོ། །

Enumeration Block 8:
བརྗེས་ནས་བསམ་པ་རྗེས་སུ་བསྒྲུབ་པ་ལ་གཉིས་ཏེ། མདོར་བསྟན་པ་དང༌། ཕྲག་དོག་བསྒོམ་པ་དང༌། འགྲན་སེམས་བསྒོམ་པ་དང༌། ང་རྒྱལ་བསྒོམ་པ་དང༌། བསྒོམ་པའི་འབྲས་བུའོ། །

Enumeration Block 9:
གཉིས་པ་ཕྲག་དོག་བསྒོམ་པ་ལ་གསུམ་སྟེ། འཇིག་རྟེན་གྱི་ཆོས་ལ་ཕྲག་དོག་བསྒོམ་པ་དང༌། ཡོན་ཏན་ལ་ཕྲག་དོག་བསྒོམ་པ་དང༌། བསྒོམས་ནས་ཇི་ལྟར་བསྒྲུབ་པའོ། །

Enumeration Block 10:
གསུམ་པ་འགྲན་སེམས་བསྒོམ་པ་ལ་གསུམ་སྟེ། བསམ་པས་བདག་ཏུ་བཟུང་བའི་བདག་གིས་རྙེད་བཀུར་ལ་འགྲན་པ་དང༌། དེའི་ཡོན་ཏན་ལ་འགྲན་པ་དང༌། ལེགས་པའི་རྣམ་གྲངས་ལ་འགྲན་པ་རྣམས། བདག་དང་ཞེས་པ་དང༌། ཅི་ནས་ཞེས་པ་དང༌། བདག་གི་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །
ང་རྒྱལ་བསྒོམ་པ་ལ་བཞི་སྟེ། ང་རྒྱལ་གྱི་རྣམ་པ་དང༌། བསྒོམ་པའི་ལེགས་པ་དང༌། བསྒོམས་ནས་བསྟེན་པར་བྱ་བའི་སྦྱོར་བ་དང༌། ང་རྒྱལ་དང་བྲལ་བའི་ཉེས་པའོ། །

Enumeration Block 11:
ལྔ་པ་བདག་གཞན་བརྗེ་བ་བསྒོམས་པའི་འབྲས་བུ་ནི་བཞི་སྟེ། མ་བརྗེས་པར་རང་རྗེས་སུ་བཟུང་བའི་ཉེས་པ་དང༌། འབྲས་བུའི་ཤེས་བྱེད་དང༌། འབྲས་བུའི་ཕྱིར་བསྒོམ་པ་ལ་འབད་པའོ། །

Enumeration Block 12:
སྦྱོར་བ་ཇི་ལྟར་བསྒྲུབ་པ་ལ་གཉིས་ཏེ། སྦྱོར་བ་སྒྲུབ་པའི་ཚུལ་དང༌། སྦྱོར་བ་ལ་སེམས་དབང་དུ་བྱ་བའོ། །དང་པོ་ལ་དྲུག་སྟེ། གཞན་ཕན་བདེ་ལ་སྦྱོར་བ་དང༌། ཉེས་པ་ཐམས་ཅད་དང་དུ་བླང་བ་དང༌། གཞན་གྱི་ཕྱིར་དམན་པའི་གནས་ཡང་དག་པར་བླང་བ་དང༌། སྦྱོར་བའི་དོན་བསྡུ་བ་དང༌། གནོད་པ་ཉམས་སུ་བླང་བ་དང༌། སེམས་ཡང་དག་པར་བསྲུང་བའོ། །
