Enumeration Block 1:
གསུམ་པ་ནི་གཞན་ཡང་ཞེས་པའོ། །ནུས་པའི་ང་རྒྱལ་ལ་གཉིས་ཏེ། བསྟེན་པར་རིགས་པ་དང༌། བསྟེན་པའི་འཐད་པའོ། །དང་པོ་ལྔ་སྟེ། ཉེས་པ་དཔེས་བསྟན་པ་དང༌། དེ་འབྱུང་བའི་རྒྱུ་དང༌། ང་རྒྱལ་དེའི་ཆེ་བ་དང༌། དེ་བསྟེན་པར་འབད་པ་དང༌། མ་འབད་ན་དམ་བཅའ་བ་ལས་ཉམས་པའོ། །

Enumeration Block 2:
བསྟེན་པའི་ཐབས་ལ་གསུམ་སྟེ། གཉེན་པོའི་ང་རྒྱལ་གྱི་རང་བཞིན་དང༌། ཉོན་མོངས་པའི་ང་རྒྱལ་ལས་ང་རྒྱལ་གྱི་དོན་མེད་པ་དང༌། གཉེན་པོའི་ང་རྒྱལ་གྱིས་བསྔགས་པ་བརྗོད་པས་སྤྲོ་བ་བསྐྱེད་པའོ། །

Enumeration Block 3:
ཉོན་མོངས་པའི་ང་རྒྱལ་ལ་གསུམ་སྟེ། རྐྱེན་ཉེ་ན་སྟོབས་བསྐྱེད་པ་དང་ཉོན་མོངས་པས་མ་གོས་པ་ཉིད་དུ་ལྷུར་བྱ་བ་དང༌། དེ་ཉིད་བཤད་པ་གསུམ། ཉོན་མོངས་ཞེས་པ་དང༌། ཉམ་ང་ཞེས་པ་དང༌། བདག་ནི་ཞེས་པ་ནས་རིམ་པ་བཞིན་ཏེ། ཉམས་ཆེ་བ་ནི་སྲོག་གི་བར་ཆད་དོ། །དགའ་བའི་དཔུང་ལ་གསུམ་སྟེ། འབྲས་བུ་ལ་ལྟོས་པ་མེད་པར་ལས་དམ་པ་ཉིད་ཀྱི་རོ་ལ་ཞེན་པར་བྱ་བ་དང༌། འབྲས་བུ་ཡིད་ལ་བྱས་ཏེ་ཞེན་པ་དང༌། དགའ་བའི་སྟོབས་ལ་ཇི་ལྟར་སྦྱར་བའི་ཚུལ་ལོ། །

Enumeration Block 4:
གཉིས་པ་ལ་གཉིས་ཏེ། འབྲས་བུ་འབྱུང་བར་ངེས་པ་དང༌། མཆོག་ཏུ་གྱུར་པར་ཡིད་ལ་བྱ་བའོ། །

Enumeration Block 5:
བཞི་པ་དོར་བའི་དཔུང་ལ་གཉིས་ཏེ། རེ་ཞིག་དོར་བ་དང༌། གཏན་དོར་བའོ། །

Enumeration Block 6:
ལྷུར་བླང་བ་ལ་ལྔ་སྟེ། བག་ཡོད་ལྷུར་བླང་བ་དང༌། དྲན་དང་ཤེས་བཞིན་ལྷུར་བླང་བ་དང༌། དེ་གཉིས་ཀྱི་མི་མཐུན་ཕྱོགས་འབྱུང་བའི་སྐབས་མི་དབྱེ་བ་དང༌། བྱུང་བ་བཟློག་པ་དང༌། རྗེས་སུ་མཐུན་པའི་བྱ་བ་བསྒྲུབ་པའོ། །

Enumeration Block 7:
བསམ་གཏན་ལ་གཉིས་ཏེ། མི་མཐུན་པའི་ཕྱོགས་སྤང་བ་དང༌། ཞི་གནས་ཀྱི་དམིགས་པ་ཡིད་ལ་བྱ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། མདོར་བསྟན་པ་དང༌། འཇིག་རྟེན་སྤང་བ་དང༌། རྣམ་རྟོག་དོར་བའོ། །

Enumeration Block 8:
གཉིས་པ་འཇིག་རྟེན་སྤང་བ་ལ་ལྔ་སྟེ། འཇིག་རྟེན་མི་སྤོང་བའི་རྒྱུ་དང༌། རྒྱུའི་གཉེན་པོའི་ཆེ་བ་དང༌། གཉེན་པོས་བསྒྲུབ་པའི་ཚུལ་དང༌། འདུ་འཛིའི་ཉེས་པ་དང༌། མི་གཡེང་བའི་ཡོན་ཏན་ནོ། །

Enumeration Block 9:
གསུམ་པ་གཉེན་པོས་བསྒྲུབ་པའི་ཚུལ་ལ་གཉིས་ཏེ། སེམས་ཅན་ལ་མ་ཆགས་པ་བསྒྲུབ་པ་དང༌། རྙེད་པ་ལ་སོགས་པ་ལ་མ་ཆགས་པ་བསྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཡུལ་ཅན་ཆགས་པའི་ཉེས་པ་དང༌། ཡུལ་འདོད་པའི་ཉེས་པའོ། །དང་པོ་ལ་ལྔ་སྟེ། འདོད་པ་མི་ཐོབ་པ་དང༌། འདོད་པ་མ་མཐོང་ན་གཡེང་བ་དང༌། ཆོ་ག་མི་ཤེས་པས་གདུང་བ་དང༌། ཐར་པ་མི་ཐོབ་པ་དང༌། དལ་འབྱོར་ཆུད་གསོན་པའོ། །

Enumeration Block 10:
ཡུལ་གྱི་ཉེས་པ་ནི་དོན་ཆེན་པོ་འཇིག་པ་དང༌། འགྲོ་བ་དམན་པར་ཁྲིད་པ་དང༌། མི་བརྟན་པ་དང༌། བསྟེན་པར་དཀའ་བ་དང༌། ཕན་པ་མི་ཐོབ་པ་དང༌། ཉེས་པ་ལ་སྦྱོར་བ་དང༌། ཉེས་པ་མདོར་བསྡུ་བ་དང༌། དེ་སྤང་བའི་ཚུལ་བརྒྱད་དོ། །

Enumeration Block 11:
རྙེད་པ་ལ་སོགས་པ་འཇིག་རྟེན་གྱི་ཆོས་ལ་མ་ཆགས་པ་བསྒྲུབ་པ་ལ་གཉིས་ཏེ། ཡུལ་ཅན་གྱི་ཉེས་པ་དང༌། ཡུལ་གྱི་ཉེས་པའོ། །

Enumeration Block 12:
འདུ་འཛིའི་ཉེས་པ་ལ་གསུམ་སྟེ། གཞན་རྗེས་སུ་འཛིན་པའི་མཐུ་མེད་པ་དང༌། དེའི་འཐད་པ་དང༌། དེ་དག་དང་འདྲེ་བར་མི་བྱེད་པའི་འཐད་པ་རྣམས། སེམས་ཅན་ཞེས་པ་དང༌། གང་ཕྱིར་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །

Enumeration Block 13:
ལྔ་པ་དབེན་པའི་ཡོན་ཏན་ཡིད་ལ་བྱ་བ་ནི་ལྔ་སྟེ། གྲོགས་དང༌། གནས་དང༌། འཚོ་བ་དང༌། སོ་སོར་རྟོག་པ་དང༌། མི་གཡེང་བའོ། །
