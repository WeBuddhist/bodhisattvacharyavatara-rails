Enumeration Block 1:
གཉིས་པ་ལ་གསུམ།
མི་གཙང་བར་མངོན་སུམ་དུ་གྱུར་པས་ཆགས་པར་མི་རིགས་པ་དང༌།
རྟགས་ལས་ངེས་པས་ཆགས་པར་མི་རིགས་པ་དང༌།
དེས་ན་གཙང་བར་ཞེན་པ་དགག་པའོ། །
དང་པོ་ལ་ལྔ།
རེག་བྱ་ལ་ཆགས་པར་མི་རིགས་པ་དང༌།
གཙང་བར་རྟོག་པ་དགག་པ་དང༌།
ལུས་སེམས་སོ་སོར་ཆགས་པའི་གནས་མ་ཡིན་པ་དང༌།
ཉེས་པ་དེ་དག་རང་ལ་སྦྱར་ནས་བསམ་པ་དང༌།
དབྱིབས་ཆགས་པའི་གནས་མ་ཡིན་པའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་བཞི།
མི་གཙང་བའི་འབྱུང་ཁུངས་ཡིན་པས་མི་གཙང་བར་བསམ་པ་དང༌།
དེའི་འབྲས་བུ་ཡིན་པས་མི་གཙང་བར་བསམ་པ་དང༌།
ལུས་མི་གཙང་བ་དཔེས་བསྟན་པ་དང༌།
རང་གི་ལུས་མི་གཙང་བར་བསམ་པའོ། །

Enumeration Block 3:
བཞི་པ་ལ་གཉིས།
ལུས་མི་གཙང་བར་བསམ་པ་དང༌།
དེ་ལ་ཆགས་ན་དུར་ཁྲོད་ཀྱི་ལུས་ལའང་ཆགས་པར་རིགས་པའོ། །

Enumeration Block 4:
གསུམ་པ་ལ་གསུམ།
བཅོས་མའི་རྒྱན་གྱིས་ལུས་གཙང་བར་མི་ནུས་པ་དང༌།
ལུས་འཇིག་པའི་རང་བཞིན་ལས་མ་འདས་པ་དང༌།
ཡིད་འབྱུང་བའི་གནས་སུ་བསམ་པའོ། །
དང་པོ་ལ་གཉིས།
ལུས་མི་གཙང་བ་ཙན་དན་སོགས་ཀྱི་དྲིས་གཙང་བར་བྱེད་མི་ནུས་པ་དང༌།
འབྲེལ་མེད་ཀྱི་དྲི་གཞན་ལ་ཆགས་པའི་རྒྱུ་མཚན་དུ་མི་རུང་བའོ། །

Enumeration Block 5:
གསུམ་པ་མི་འདོད་པ་དུ་མ་བསྐྱེད་པ་བསམ་པ་ལ་གཉིས།

Enumeration Block 6:
གཉིས་པ་ལ་གཉིས།
འདོད་པའི་དོན་མི་ཐོབ་པ་དང༌།
མི་འདོད་པ་དུ་མའི་སྐྱོན་དང་འབྲེལ་བའོ། །
དང་པོ་ལ་བཞི།
འདོད་པ་བསྟེན་པའི་སྐབས་མེད་པ་དང༌།
ངལ་བའི་སྡུག་བསྔལ་གྱིས་འདོད་པ་བསྟེན་མི་ནུས་པ་དང༌．
ཡུལ་གྱིས་བསྐལ་པས་འདོད་པའི་དོན་དང་ཕྲད་དཀའ་བ་དང༌།
གཞན་གྱི་དབང་དུ་གྱུར་པས་མི་འདོད་པ་དུ་མ་ཐོབ་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ་ལྔ།
རང་དབང་མེད་ཅིང་མྱུར་དུ་སྲོག་འདོར་བ་དང༌།
གཞན་གྱི་དབང་དུ་གྱུར་ཅིང་སྡུག་བསྔལ་སྣ་ཚོགས་དང་རྒྱུན་དུ་འབྲེལ་བ་དང༌།
ཐར་པ་ལ་གེགས་བྱེད་ཅིང་དལ་འབྱོར་ཆུད་གསོན་པ་དང༌།
ཉེས་དམིགས་བསམས་ནས་ཐར་པ་དོན་གཉེར་གྱི་བློ་བསྐྱེད་པ་དང༌།
འདོད་པ་ལ་ཆགས་པ་ཉེས་དམིགས་ཀུན་གྱི་འབྱུང་ཁུངས་སུ་བསམ་པའོ། །

Enumeration Block 8:
ལྔ་པ་ལ་གཉིས།
