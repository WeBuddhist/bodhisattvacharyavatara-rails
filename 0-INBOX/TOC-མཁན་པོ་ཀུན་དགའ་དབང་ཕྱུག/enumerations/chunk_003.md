Enumeration Block 1:
གཉིས་པ་སེམས་རྟེན་སྐྱེ་བར་དཀའ་བའི་ཚུལ་བསྟན་པ་ནི།

Enumeration Block 2:
བྱང་ཆུབ་སེམས་བསྐྱེད་ཀྱི་ཕན་ཡོན་དངོས་བསྟན་པ་ལ། སེམས་བསྐྱེད་སྤྱིའི་ཕན་ཡོན་དང༌། སྨོན་འཇུག་སོ་སོའི་ཕན་ཡོན། སེམས་བསྐྱེད་རྒྱུད་ལྡན་གྱི་གང་ཟག་གི་ཆེ་བའི་ཡོན་ཏན་བརྗོད་པའོ། །
དང་པོ་ལ་ཡང་། དགེ་བ་གཞན་ལས་ཁྱད་པར་དུ་འཕགས་པའི་ཕན་ཡོན་དང༌། མིང་དོན་གནས་འགྱུར་བའི་ཕན་ཡོན་དང་། ཕན་ཡོན་དཔེའི་སྒོ་ནས་བསྟན་པར་བྱ་བའོ། །
དང་པོ་ནི།

Enumeration Block 3:
གཉིས་པ་མིང་དོན་གནས་འགྱུར་བའི་ཕན་ཡོན་བསྟན་པ་ནི།

Enumeration Block 4:
གསུམ་པ་ཕན་ཡོན་དཔེའི་སྒོ་ནས་བསྟན་པ་ལ། དང་པོ། གསེར་འགྱུར་གྱི་རྩི་ཡི་དཔེའི་སྒོ་ནས་སངས་རྒྱས་ཐོབ་པར་བསྟན་པ་ནི།

Enumeration Block 5:
གཉིས་པ་རིན་པོ་ཆེའི་དཔེའི་སྒོ་ནས་དོན་ཆེ་བ་ཡིན་པར་བསྟན་པ་ནི།

Enumeration Block 6:
གསུམ་པ་འབྲས་བུ་ཅན་གྱི་ལྗོན་ཤིང་གི་དཔེས་བསྟན་པ་ནི།
