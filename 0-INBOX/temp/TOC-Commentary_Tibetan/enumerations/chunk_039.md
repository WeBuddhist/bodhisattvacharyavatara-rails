Enumeration Block 1:
ད་ནི་བསམ་གཏན་གྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཉམས་སུ་བླང་ཚུལ་ལ་སྤྱི་དོན་བཞི་སྟེ། བྱེད་ལས་མཚན་ཉིད་དབྱེ་བ་ཕན་ཡོན་ནོ། །

Enumeration Block 2:
ཁྱད་པར་གྱི་དབྱེ་བ་ནི་བཞི་སྟེ།

Enumeration Block 3:
ཡང་དག་པའི་གནས་པ་ལ་བརྟེན་ནས་སེམས་རྩེ་གཅིག་ཏུ་འཇོག་པའི་ཆ་ནི་ཞི་གནས་དང༌། ཆོས་ཀྱི་གནས་ལུགས་ཕྱིན་ཅི་མ་ལོག་པར་རབ་ཏུ་རྣམ་པར་འབྱེད་པའི་ཆ་ནི་ལྷག་མཐོང་ཞེས་བྱ་བར་གཉིས་ཏེ།

Enumeration Block 4:
རྟོགས་པ་དང་བཅས་ཤིང་དཔྱོད་པ་དང་བཅས་པ་དང༌། རྟོག་པ་མེད་ལ་དཔྱོད་པ་ཙམ་དང༌། རྟོག་པ་ཡང་མེད། དཔྱོད་པ་ཡང་མེད་པའི་ཡིད་ལ་བྱེད་པ་གསུམ་དུ་ཡང་འགྱུར་བ་སྟེ།

Enumeration Block 5:
དེ་བཞིན་དུ་ཞི་གནས་ཡིད་ལ་བྱེད་པ་དང༌། ལྷག་མཐོང་ཡིད་ལ་ བྱེད་པ་དང༌། ཟུང་དུ་འབྲེལ་བ་ཡིད་ལ་བྱེད་པ་དང་གསུམ་དུ་ཡང་འགྱུར་བ་སྟེ།

Enumeration Block 6:
དེ་བཞིན་དུ་རབ་ཏུ་འཛིན་པའི་རྒྱུ་མཚན་ཡིད་ལ་བྱེད་པ་དང༌། ཞི་གནས་ཀྱི་རྒྱུ་མཚན་ཡིད་ལ་བྱེད་པ་དང༌། བཏང་སྙོམས་ཀྱི་རྒྱུ་མཚན་ཡིད་ལ་བྱེད་པ་གསུམ་དུ་ཡང་འགྱུར་བ་སྟེ།

Enumeration Block 7:
རྒྱུན་སྦྱོར་དང་ལྡན་པའི་ཡིད་ལ་ཕྱེད་པ་དང༌། གུས་སྦྱོར་དང་ལྡན་པའི་ཡིད་ལ་བྱེད་པ་གཉིས་སུ་ཡང་འགྱུར་བ་སྟེ།

Enumeration Block 8:
དམིགས་པ་གང་ཡིན་ལ་དང་པོ་སེམས་འཇོག་པར་བྱེད་པ་དང༌། དེའི་རྒྱུན་མི་གཡེང་བར་ཀུན་ཏུ་འཇོག་པར་བྱེད་པ་དང༌། ཡེངས་ནའང་བཀུག་ནས་ངེས་པར་འཇོག་པར་བྱེད་པ་དང༌། གོང་ནས་གོང་དུ་བརྟག་བྱའི་དངོས་པོ་ལ་ཉེ་བར་འཇོག་པར་བྱེད་པ་ལ་སོགས་པ་དགུ་སྟེ།

Enumeration Block 9:
འབྲེལ་བཀོད་དེ་རྣམ་གཡེང་སྤང་ཚུལ། དེ་ཡི་དོན་རྒྱས་པར་བཤད་པ། བྱང་ཆུབ་ཀྱི་སེམས་གཉིས་བསྒོམ་ཚུལ་ལོ། །
