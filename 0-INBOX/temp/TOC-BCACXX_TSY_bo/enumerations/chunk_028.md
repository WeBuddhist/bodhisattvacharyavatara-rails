Enumeration Block 1:
གཉིས་པ་འབྲས་ཕྱོགས་ནས་སྟོང་པར་སྒྲུབ་པ་ལ་གཉིས་ལས་དང་པོ་མཐའ་གཉིས་ཀྱི་སྐྱེ་བ་དགག་པ་ལའང་གཉིས་ཀྱི་དང་པོ་ཡོད་སྐྱེ་དགག་པ་ནི་

Enumeration Block 2:
གཉིས་པ་མེད་སྐྱེ་དགག་པ་ལ་བཞིའི་དང་པོ་དངོས་མེད་ཉིད་བྱ་བར་མི་ནུས་པ་ནི་

Enumeration Block 3:
གསུམ་པ་ཤེས་རབ་ཐོབ་པའི་བྱ་བ་ལ་གཉིས་ལས་དང་པོ་འཇིག་རྟེན་གྱི་ཆོས་བརྒྱད་ལ་བློ་མཉམ་པར་བྱ་བ་ལ་

Enumeration Block 4:
གཉིས༌པ༌དེ༌ལྟར༌མ༌རྟོགས་པའི་སེམས་ཅན་ལ་སྙིང་རྗེ་བསྐྱེད་པ་ལ་གཉིས་ཏེ། དམིགས་པ་དང་རྣམ་པའོ། །དང་པོ་ལ་གསུམ་གྱི་

Enumeration Block 5:
གསུམ་པ་དེ་སྲིད་པའི་ཉེས་པ་སྤྱིར་བཤད་པ་ལ་གསུམ་ལས་དང་པོ་ཐར་པ་དང་འགལ་བ་ནི་

Enumeration Block 6:
གཉིས་པ་འགལ་བ་དེ་ཉིད་ངཟློག་དཀའ་བར་སྟོན་པ་ལ་ལྔའི་དང་པོ་གཉེན་པོ་སྟོབས་ཆུང་བ་ནི་

Enumeration Block 7:
གསུམ་པ་བརྩམས་པ་མཐར་ཕྱིན་པའི་བྱ་བ་ལ་གཉིས་ཏེ། བརྩམས་པའི་བསོད་ནམས་བསྔོ་བ་དང་། ། བཀའ་དྲིན་དྲན་པའི་ཕྱག་འཚལ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། གདུལ་བྱ་གཞན་དོན་དང༌། ·རྩོམ་པ་པོ་རང་དོན་དང་། ཐུན་མོང་བ་བསྟན་པའི་དོན་དུ་བསྔོ་བའོ། །དང་པོ་ལ་གཉིས་ལས་དང་པོ་འཇིག་རྟེན་པའི་དོན་དུ་བསྔོ་བ་ལ་ཡང་གཉིས་ཀྱི་དང་པོ་རྒྱུ་ལམ་ལ་འཇུག་པར་བསྔོ་བ་ནི་

Enumeration Block 8:
གཉིས་པ་འབྲས་བུ་ཐོབ་པར་བསྔོ་བ་ལ་གསུམ་ལས་དང་པོ་ཐ་མལ་པ་ལ་བསྔོ་བ་ལ་བཞིའི་དང་པོ་སྤྱིར་བསྔོ་བ་ནི་

Enumeration Block 9:
གཉིས་པ་ངན་འགྲོའི་དོན་དུ་བསྔོ་བ་ལ་གསུམ་ལས་དང་པོ་དམྱལ་བའི་དོན་དུ་བསྔོ་བ་ལ་གཉིས་ཏེ། དམྱལ་བའི་སྡུག་བསྔལ་རང་ཞི་བར་བསྔོ་བ་དང༌། གཞན་གྱི་མཐུས་ཞི་བར་བསྔོ་བའོ། ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་སྤྱིར་ཞི་བར་བསྔོ་བ་ནི་

Enumeration Block 10:
གཉིས་པ་ལ་བཞིའི་དང་པོ་རྡོ་རྗེ་འཛིན་གྱི་མཐུས་ཞི་བར་བསྔོ་བ་ལ་
