Enumeration Block 1:
གཉིས་པ་དེ་དག་འགལ་བའི་ཉེས་དམིགས་བསྟན་པ་ནི།

Enumeration Block 2:
གཉིས་པ་བདེ་བ་བྱུང་ཡང་བཟོད་ཚུལ་ནི།

Enumeration Block 3:
གསུམ་པ་འབྱོར་བ་བྱུང་ཡང་བཟོད་ཚུལ་ལ་བཞི་ལས།
དང་པོ་སེམས་བསྐྱེད་བསམས་ཏེ་བཟོད་ཚུལ་ནི།

Enumeration Block 4:
གཉིས་པ་ཁྱད་པར་མེད་པས་བཟོད་ཚུལ་ནི།

Enumeration Block 5:
གསུམ་པ་རང་ཡང་ཡོན་ཏན་བསྟེན་ཚུལ་ནི།

Enumeration Block 6:
བཞི་པ་གཞན་ལ་འགྲན་པ་སྤང་ཚུལ་ནི།

Enumeration Block 7:
གཉིས་པ་ཡིད་དུ་འོང་བའི་གེགས་ལ་བསྒོམ་པ་ལ།
དགྲ་ལ་སྡུག་བསྔལ་འབྱུང་བའི་གེགས་ལ་བཟོད་ཚུལ་དང༌། རང་ལ་བསྟོད་གྲགས་འབྱུང་བའི་གེགས་ལ་བཟོད་ཚུལ་ལོ། །
དང་པོ་ལ་གཉིས་ལས།
དང་པོ་སྨོན་པས་གཞན་ལ་གནོད་པ་མེད་ཚུལ་ནི།

Enumeration Block 8:
གཉིས་པ་གནོད་ནའང་རང་ཉིད་ཉམས་པར་འགྱུར་ཚུལ་ནི།

Enumeration Block 9:
གཉིས་པ་རང་ལ་བསྟོད་གྲགས་འབྱུང་བའི་གེགས་ལ་བཟོད་ཚུལ་ལ་ལྔ་ལས།
དང་པོ་གྲགས་པས་ཕན་པ་མེད་ཚུལ་ནི།

Enumeration Block 10:
གཉིས་པ་ཕན་པར་འདོད་པ་འཁྲུལ་ཚུལ་ནི།

Enumeration Block 11:
གསུམ་པ་དཔྱད་ན་སྙིང་པོ་མེད་ཚུལ་ནི།

Enumeration Block 12:
བཞི་པ་གྲགས་པའི་ཉེས་དམིགས་བསྟན་པ་ནི།

Enumeration Block 13:
ལྔ་པ་བཀག་པས་ཕན་ཡོན་ཐོབ་ཚུལ་ལ་གཉིས་ལས།
དང་པོ་ངན་འགྲོ་འགོག་ཚུལ་ནི།

Enumeration Block 14:
གཉིས་པ་འཆིང་བ་གཅོད་ཚུལ་ནི།

Enumeration Block 15:
གསུམ་པ་གནོད་བྱེད་བཟོད་པའི་གྲོགས་སུ་བསྟེན་པ་ལ།
གནོད་བྱེད་བཟོད་པའི་རྒྱུ་རུ་བསྟན་པ། དེ་ལ་དགའ་བས་ཕན་པ་སྒྲུབ་ཚུལ། དམ་པའི་ཆོས་བཞིན་མཆོད་པར་འོས་ཚུལ། སངས་རྒྱས་བཞིན་དུ་མཆོད་པར་རིགས་ཚུལ། དེས་ན་སེམས་ཅན་མགུ་བར་བྱ་བ། མགུ་བར་བྱས་པའི་ཕན་ཡོན་བསྟན་པའོ། །
དང་པོ་ནི།

Enumeration Block 16:
གཉིས་པ་དེ་ལ་ཕན་པ་བསྒྲུབ་ཚུལ་ནི།

Enumeration Block 17:
གསུམ་པ་དམ་པའི་ཆོས་བཞིན་མཆོད་ཚུལ་ནི།

Enumeration Block 18:
བཞི་པ་སངས་རྒྱས་བཞིན་དུ་མཆོད་ཚུལ་ལ་གཉིས་ལས།
དང་པོ་འབྲས་བུའི་ཆ་ནས་མཆོད་པར་རིགས་ཚུལ་ནི།
