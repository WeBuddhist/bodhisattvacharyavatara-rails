Enumeration Block 1:
དེས་ན་གཞན་དོན་ལ་གཉིས་ཏེ། སྡུག་བསྔལ་ཞི་བ་དང༌། མངོན་ཞེན་ཞི་བའོ། །

Enumeration Block 2:
དེ་དག་འདོད་པའི་ཡུལ་དུ་བཞག་པས་བསམ་པའི་དགེ་བ་བསྔོ་བ་ཐབས་ཀྱིས་སྟོན་པ་ནི་ལྔ་སྟེ། ཐབས་དང་འབྲེལ་པའི་བསྔོ་བ་དང༌། གཞན་གྱི་དོན་དུ་བསྔོ་བ་དང༌། རང་གི་དོན་དུ་བསྔོ་བ་དང༌། བདེ་བའི་འབྱུང་གནས་བསྟན་པའི་དོན་དུ་བསྔོ་བ་དང༌། བཀའ་དྲིན་རྗེས་སུ་དྲན་པས་ཕྱག་འཚལ་བའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གཉིས་ཏེ། འཇིག་རྟེན་པའི་དོན་དུ་བསྔོ་བ་དང༌། འཇིག་རྟེན་ལས་འདས་པའི་དོན་དུ་བསྔོ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། སྤྱིར་བསྔོ་བ་དང༌། བྱེ་བྲག་ཏུ་ངན་འགྲོའི་དོན་དུ་བསྔོ་བ་དང༌། བདེ་འགྲོའི་དོན་དུ་བསྔོ་བའོ། །

Enumeration Block 4:
ངན་འགྲོའི་དོན་དུ་བསྔོ་བ་ལ་གསུམ་སྟེ། དམྱལ་བའི་དོན་དུ་བསྔོ་བ་དང༌། དུད་འགྲོའི་དོན་དུ་བསྔོ་བ་དང༌། ཡི་དྭགས་ཀྱི་དོན་དུ་བསྔོ་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། སྡུག་བསྔལ་རང་ཞི་བ་དང༌། གཞན་གྱིས་ཞི་བར་བསྔོ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། སྤྱིར་ཞི་བར་བསྔོ་བ་དང༌། གྲང་བའི་དམྱལ་བ་ཞི་བར་བསྔོ་བ་དང༌། ཚ་བའི་དམྱལ་བ་ཞི་བར་བསྔོ་བའོ། །

Enumeration Block 5:
གཞན་གྱིས་ཞི་བ་ལ་བཞི་སྟེ། རྡོ་རྗེ་འཛིན་པའི་སྟོབས་ཀྱིས་ཞི་བ་དང༌། འཇིག་རྟེན་དབང་ཕྱུག་གི་ཐུགས་རྗེས་ཞི་བ་དང༌། འཇམ་པའི་དབྱངས་ཀྱི་ཆོ་འཕྲུལ་གྱིས་ཞི་བ་དང༌། ཉེ་བའི་སྲས་གཞན་གྱི་མཐུས་ཞི་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། གནོད་བྱེད་སྐྲག་པ་དང༌། དགའ་བ་དེས་ཁྱབ་པ་དང༌། མགོན་མཐོང་བ་དང༌། དེ་ལས་དང་པོ་ཉེས་སྤྱོད་ལས་ལྡོག་པ་བཞི།

Enumeration Block 6:
མཐོ་རིས་ཀྱི་དོན་དུ་བསྔོ་བ་ལ་གཉིས་ཏེ། སྡུག་བསྔལ་དང་བྲལ་བ་དང༌། འདོད་པ་ཐོབ་པའོ། །

Enumeration Block 7:
གཉིས་པ་ནི་གཉིས་ཏེ། སྤྱིར་སེམས་ཅན་གྱི་དོན་དུ་བསྔོ་བ་དང༌། བྱེ་བྲག་ཏུ་རབ་ཏུ་བྱུང་བའི་དོན་དུ་བསྔོ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། ཕུན་སུམ་ཚོགས་པ་ཐོབ་པ་དང༌། ཡང་དག་པའི་ལམ་ལ་འཇུག་པ་དང༌། ལོ་ཀ་པའི་བདེ་བ་ཐོབ་པའོ། །

Enumeration Block 8:
རབ་ཏུ་བྱུང་བའི་དོན་དུ་བསྔོ་བ་ནི་ལྔ་སྟེ། དགེ་སློང་གི་དོན་དུ་བསྔོ་བ་དང༌། དགེ་སློང་མའི་དོན་དུ་བསྔོ་བ་དང༌། ཚུལ་ཁྲིམས་ཕུན་སུམ་ཚོགས་པ་དང༌། ཤེས་རབ་ཕུན་སུམ་ཚོགས་པར་འགྱུར་བ་དང༌། འབྲས་བུ་སྡུག་བསྔལ་ལས་གྲོལ་བ་ལྔ།

Enumeration Block 9:
འཇིག་རྟེན་ལས་འདས་པའི་དོན་དུ་བསྔོ་བ་ལ། བྱང་ཆུབ་སེམས་དཔའི་དོན་དུ་བསྔོ་བ་དང༌། སངས་རྒྱས་ཀྱི་དོན་དུ་བསྔོ་བ་དང༌། ཉོན་ཐོས་དང་རང་རྒྱལ་བའི་དོན་དུ་བསྔོ་བ་གསུམ།
