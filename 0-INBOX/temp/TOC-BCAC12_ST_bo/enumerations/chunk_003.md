Enumeration Block 1:
རྗེས་སུ་ཡི་རང་བ་ལ་གསུམ་སྟེ། འཇིག་རྟེན་གྱི་དགེ་བ་ལ་ཡི་རང་བ་དང༌། ཉན་ཐོས་ཀྱི་དགེ་བ་ལ་ཡི་རང་བ་དང༌། སངས་རྒྱས་ཀྱི་དགེ་བ་ལ་ཡི་རང་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། མཐོ་རིས་སུ་བསྔོས་པའི་བསོད་ནམས་ཀྱི་ཆ་དང་མཐུན་པ་ལ་ཡི་རང་བ་དང༌། བྱང་ཆུབ་ཏུ་བསྔོ་བའི་ཐར་པའི་ཆ་དང་མཐུན་པ་ལ་ཡི་རང་བའོ། །

Enumeration Block 2:
དགེ་བའི་རྩ་བར་བསྔོ་བ་ལ་སྡུག་བསྔལ་དང་བྲལ་བར་སྤྱིར་སྨོན་པ་དང༌། ནད་ཀྱི་སྡུག་བསྔལ་སེལ་བར་སྨོན་པ་དང༌། བཀྲེས་པའི་སྡུག་བསྔལ་སེལ་བར་སྨོན་པ་དང༌། དབུལ་བའི་སྡུག་བསྔལ་སེལ་བར་སྨོན་པ་དང་བཞི་དེ་ལྟར་ཞེས་པ་དང༌། འགྲོ་བ་ཞེས་པ་དང༌། ཟས་དང་ཞེས་པ་དང༌། སེམས་ཅན་ཞེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །དེ་ལྟར་སྦྱོར་བ་བཤད་ནས། དངོས་གཞི་ལ་བཞི་སྟེ། ཐམས་ཅད་གཏང་བར་སྨོན་པ་དང༌། ཆུད་མི་ཟ་བའི་རྒྱུར་སྨོན་པ་དང༌། ལོངས་སྤྱོད་པའི་རྒྱུར་སྨོན་པ་དང༌། དམ་འཆའ་བའི་ཚིག་ཏུ་བརྗོད་པའོ། །

Enumeration Block 3:
དང་པོ་ཐམས་ཅད་གཏང་བར་སྨོན་པ་ནི་གསུམ་སྟེ། ཐམས་ཅད་གཏང་བའི་ཚུལ་དང༌། དེའི་འཐད་པ་དང༌། བཏང་ནས་རྗེས་སུ་བསྒྲུབ་པའི་ཚུལ་ལོ། །

Enumeration Block 4:
ཆུད་མི་ཟ་བའི་རྒྱུར་སྨོན་པ་ལ་གསུམ་སྟེ། སྤྱིར་བསྟན་པ་དང༌། བསམ་པ་ཆུད་མི་ཟ་བ་དང༌། སྦྱོར་བ་ཆུད་མི་ཟ་བའི་རྒྱུར་སྨོན་པ་གསུམ། བདག་ལ་ཞེས་པ་དང༌། གང་དག་ཅེས་པ་ནས་རིམ་པ་བཞིན་ནོ། །

Enumeration Block 5:
གསུམ་པ་ལོངས་སྤྱོད་པའི་རྒྱུར་སྨོན་པ་ནི་གསུམ་སྟེ། ཉེ་བར་མཁོ་བ་ལ་སྦྱར་བ་དང༌། བྱེད་པ་རྒྱ་ཆེ་བ་དང༌། ཡུལ་དང་དུས་ཆད་པ་མེད་པ་གསུམ་བདག་ནི་ཞེས་པ་དང༌། ས་སོགས་ཞེས་པ་དང༌། དེ་བཞིན་ཞེས་པ་ནས་རིམ་པ་བཞིན་ཏེ།

Enumeration Block 6:
འདིར་ཡང་རྣམ་པ་གཉིས་ཀྱིས་ངེས་པར་བྱ་སྟེ། སེམས་བསྐྱེད་པའི་རྒྱུ་མ་ཚང་བ་མེད་པའི་རང་བཞིན་དང༌། ཡང་དག་པར་བླངས་པ་དོན་ཡོད་པའོ། །

Enumeration Block 7:
རྐྱེན་གཞན་པོ་དེ་དག་གང་ཡིན་ཞེ་ན། གསུམ་སྟེ། རྒྱུ་སྙིང་རྗེ་གོམས་པ་དང༌། རྩ་བ་དད་པ་བརྟན་པ་དང༌། བསམ་པའི་རྟེན་གཞན་ནོ། །

Enumeration Block 8:
གཉིས་པ་ལ་ཡང་དག་པར་བླངས་པ་དོན་ཡོད་པ་ནི་བླང་བའི་དགོས་པ་དང༌། ལེན་པའི་ཚུལ་ལོ། །

Enumeration Block 9:
ལེན་པའི་ཚུལ་ལ་ལྔ་སྟེ། བླང་བའི་ཡུལ་དང༌། བླང་བའི་གཞི་དང༌། །དུས་དང༌། ཆོ་ག་དང༌། དུས་ཐམས་ཅད་པའི་སྡོམ་པ་བླང་བར་མི་ནུས་པའི་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 10:
མཇུག་ལ་གཉིས་ཏེ། རང་དགའ་བ་བསྐྱེད་པ་དང༌། གཞན་དགའ་བ་བསྐྱེད་དུ་གཞུག་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། རང་གི་དོན་ཐོབ་པས་དགའ་བ་བསྐྱེད་པ་དང༌། གཞན་གྱི་དོན་ཐོབ་པས་དགའ་བ་བསྐྱེད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། དོན་གྲུབ་པར་བརྟག་པ་དང༌། ཉེས་པས་མི་གོས་པར་བག་ཡོད་པར་བྱ་བ་དང༌། རྙེད་པས་དཀའ་བར་བརྟག་པའོ། །

Enumeration Block 11:
གཞན་གྱི་དོན་ལ་གསུམ་སྟེ། སྡུག་བསྔལ་སེལ་བར་ནུས་པ་དང༌། སྒྲིབ་པ་སེལ་བར་ནུས་པ་དང༌། ཕན་བདེ་བསྒྲུབ་ནུས་པའོ། །

Enumeration Block 12:
དང་པོ་ལ་ལྔ་སྟེ། འགྲོ་བའི་ཞེས་པས་འཆི་བའི་སྡུག་བསྔལ་དང༌། འགྲོ་བའི་ཞེས་པས་དབུལ་བའི་སྡུག་བསྔལ་དང༌། འགྲོ་བའི་ཞེས་པས་ན་བའི་སྡུག་བསྔལ་དང༌། སྲིད་ལམ་ཞེས་པས་དུབ་པའི་སྡུག་བསྔལ་དང༌། འགྲོ་བ་ཞེས་པས་ངན་འགྲོའི་སྡུག་བསྔལ་སེལ་བའི་སྒོ་ནས་བསྟན་ཏོ། །

Enumeration Block 13:
དེ་ལ་ཐུན་མོང་དུ་འགྲུབ་པའི་རྒྱུ་བག་ཡོད་པ་ལ་གཉིས་ཏེ་མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 14:
དེ་ལྟར་མདོར་བསྟན་ནས་རྒྱས་པར་འཆད་པ་ན་གཉིས་ཏེ། བྱང་ཆུབ་ཀྱི་སེམས་ལ་བག་བྱ་བ་དང༌། བསླབ་པ་ལ་བག་བྱ་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། མི་འདོར་བའི་འཐད་པ་དང༌། དོར་བའི་ཉེས་དམིགས་སོ། །

Enumeration Block 15:
དོར་བའི་ཉེས་པ་ལ་གསུམ་སྟེ། ངན་འགྲོར་འགྲོ་བ་དང༌། གཞན་གྱི་དོན་ཉམས་པ་དང༌། ས་ཐོབ་པ་ལ་ཐོགས་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། འགྲོ་བ་ཐམས་ཅད་བསླུས་པ་དང༌། དེ་ལུང་གིས་བསྒྲུབ་པ་དང༌། ལུང་གཞན་དང་འགལ་བ་སྤང་བའོ། །
