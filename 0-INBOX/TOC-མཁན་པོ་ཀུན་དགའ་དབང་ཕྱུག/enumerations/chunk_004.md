Enumeration Block 1:
གཉིས་པ་རིན་པོ་ཆེའི་དཔེའི་སྒོ་ནས་དོན་ཆེ་བ་ཡིན་པར་བསྟན་པ་ནི།

Enumeration Block 2:
གསུམ་པ་འབྲས་བུ་ཅན་གྱི་ལྗོན་ཤིང་གི་དཔེས་བསྟན་པ་ནི།

Enumeration Block 3:
བཞི་པ་སྐྱེལ་མ་དཔའ་བོའི་དཔེས་བསྟན་པ་ནི།

Enumeration Block 4:
ལྔ་པ་དུས་མཐའི་མེའི་དཔེས་མ་ངེས་པའི་སྡིག་པ་དྲུང་ནས་འབྱིན་པའི་ཚུལ་བསྟན་པ་ནི།

Enumeration Block 5:
དྲུག་པ་འདིར་མ་བཤད་པ་གཞུང་གཞན་དུ་ཞལ་འཕངས་པ་ནི།

Enumeration Block 6:
གཉིས་པ་སྨོན་འཇུག་སོ་སོའི་ཕན་ཡོན་བསྟན་པ་ལ།
