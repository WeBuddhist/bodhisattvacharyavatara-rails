Enumeration Block 1:
གཉིས་པ་ལ་བཞི། སྡུག་བསྔལ་འབྱུང་ངེས་པ་དང༌། དེ་བཟོད་དཀའ་བ་དང༌། བདེ་བ་འདོད་པ་དང༌། དགེ་བ་ལ་མི་བརྩོན་པ་འགལ་བ་དང༌། སྡུག་བསྔལ་ལས་ཐར་པའི་ཐབས་ལ་བརྩོན་པར་བསྐུལ་བའོ། །

Enumeration Block 2:
གསུམ་པ་སྒྱིད་ལུག་པའི་ལེ་ལོ་སྤང་བ་ལ་གསུམ། སྒྱིད་ལུག་པའི་གཉེན་པོ་ལ་འབད་པར་གདམས་པ་དང༌། གཉེན་པོ་ཇི་ལྟར་ཉམས་སུ་ལེན་པའི་ཚུལ་ལུང་ལས་གསུངས་པ་དང༌། འབད་ན་ལེ་ལོ་བཀག་ནས་བྱང་ཆུབ་སྒྲུབ་ནུས་པའོ། །

Enumeration Block 3:
གསུམ་པ་ལ་བཞི། བརྩོན་པའི་སྟོབས་བསྐྱེད་ན་བྱང་ཆུབ་ཐོབ་ནུས་པར་བསམ་པ་དང༌། བྱང་ཆུབ་སྒྲུབ་པའི་དཀའ་སྤྱད་ལ་ངན་འགྲོའི་སྡུག་བསྔལ་གྱི་ཆ་ཙམ་ཡང་མེད་པས་བཟོད་རིགས་པ་དང༌། སྨན་པའི་རྒྱལ་པོས་ཆོ་ག་འཇམ་པོས་ནད་ཆེན་པོ་གསོ་བར་མཛད་པས་བཟོད་རིགས་པ་དང༌། དེ་ལ་སྡུག་བསྔལ་མེད་ཅིང་བདེ་བས་རྒྱས་པས་དགའ་བར་རིགས་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། རྐང་ལག་སོགས་གཏོང་བའི་དཀའ་སྤྱད་ཀྱིས་འཇིགས་མི་རིགས་པ་དང༌། ངན་འགྲོའི་སྡུག་བསྔལ་ཆ་ཙམ་ཡང་མྱོང་མི་དགོས་པ་དང༌། ནད་ཆེན་པོ་གཞོམ་པའི་ཆེད་དུ་སྡུག་བསྔལ་ཆུང་ངུ་བཟོད་རིགས་པའི་དཔེའོ། །

Enumeration Block 5:
གསུམ་པ་ལ་གསུམ། སྟོན་པས་གསོ་སྤྱད་ཀྱི་སྡུག་བསྔལ་ཙམ་ཡང་མྱོང་མི་དགོས་པར་ནད་ཆེན་པོ་གསོ་བའི་ཐབས་སྟོན་པར་མཛད་པ་དང༌། ལུས་གཏོང་བ་ལ་དཀའ་བའི་བློ་ཡོད་པའི་ཚེ་གཏོང་བ་བཀག་པ་དང༌། ཚོད་མ་གཏོང་བ་དང་འདྲ་བར་གོམས་པའི་ཚེ་ལུས་གཏོང་བར་གསུངས་པས་དཀའ་བ་མེད་པའོ། །

Enumeration Block 6:
བཞི་པ་ལ་བཞི། ལམ་སྒྲུབ་པའི་རིམ་པ་ལ་མི་མཁས་པའི་གང་ཟག་ལ་ལུས་སེམས་མི་བདེ་བ་ཡོད་ཀྱང་མཁས་པ་ལ་དཀའ་སྤྱད་ཀྱི་སྡུག་བསྔལ་མེད་པ་དང༌། དེས་ན་སེམས་དཔའ་ཆེན་པོ་འཁོར་བར་གནས་པ་ལ་སྐྱོ་བའི་རྒྱུ་མེད་པ་དང༌། རྒྱུ་མཚན་དེས་ན་ལམ་བགྲོད་པ་ལ་ཐེག་པ་དམན་པ་ལས་མཁས་པར་བཤད་པ་དང༌། དེས་ན་སེམས་དཔའི་སྤྱོད་པ་ལ་སྒྱིད་ལུག་པར་མི་རིགས་པའོ། །

Enumeration Block 7:
གཉིས་པ་བརྩོན་འགྲུས་ཀྱི་སྟོབས་སྤེལ་བ་ལ་གསུམ། བརྩོན་འགྲུས་ཀྱི་མཐུན་རྐྱེན་སྟོབས་སྤེལ་བ་དང༌། དྲན་པ་དང་ཤེས་བཞིན་གྱིས་སྤྱོད་པ་ཉམས་སུ་བླང་བ་ལྷུར་བྱ་བ་དང༌། སྤྱོད་པ་བསྒྲུབ་པ་ལ་བདག་ཉིད་དབང་དུ་བྱ་བའོ། ། དང་པོ་ལ་གཉིས། སྟོབས་བཞི་ངོས་བཟུང་བའི་སྒོ་ནས་མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
