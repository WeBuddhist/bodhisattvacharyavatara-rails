Enumeration Block 1:
བཟོད་པའི་ལེའུ་ལ་གཉིས་ཏེ། བཟོད་པ་ལྷུར་བྱ་བ་བསྐྱེད་པ་དང༌། བཟོད་པ་བསྒྲུབ་པའི་ཐབས་ཡིད་ལ་བྱེད་པའོ། །དང་པོ་ནི་ཁྲོ་བའི་ཉེས་དམིགས་དངོས་སུ་བརྗོད་པས་བཟོད་པའི་འབྲས་བུ་ཤུགས་ལས་འགྲུབ་སྟེ། དེ་སྟོན་པ་ན་གསུམ་སྟེ། མ་མཐོང་བའི་འབྲས་བུ་དང༌། མཐོང་བའི་འབྲས་བུ་དང༌། མཐོང་བ་དང་མ་མཐོང་བའི་འབྲས་བུ་བསྡུས་ཏེ་བསྟན་པའོ། །

Enumeration Block 2:
བཟོད་པ་བསྒྲུབ་པའི་ཐབས་ཡིད་ལ་བྱ་བ་ལ་གཉིས་ཏེ། ཁྲོ་བའི་མཚན་མ་བཟློག་པ་དང༌། བཟོད་པའི་འབྲས་བུ་ཡིད་ལ་བྱ་བའོ། །དང་པོ་ལ་བཞི་སྟེ། རྒྱུའི་ངོ་བོ་དང༌། རྒྱུ་དེ་བཟློག་པའི་ཐབས་ལ་འབད་པ་དང༌། རྒྱུ་བཟློག་པའི་ཐབས་དང༌། རྒྱུའི་རྒྱུ་བཟློག་པའི་ཐབས་ཡིད་ལ་བྱ་བའོ། །

Enumeration Block 3:
བཞི་པ་རྒྱུའི་རྒྱུ་བཟློག་པའི་ཐབས་ཡིད་ལ་བྱ་བ་ལ་གསུམ་སྟེ། མི་འདོད་པ་དང་འདོད་པའི་ཆོས་ཀྱི་རབ་ཏུ་དབྱེ་བ་སྤྱིར་བསྟན་པ་དང༌། མི་འདོད་པ་བྱེད་པ་ལ་ཁྲོ་བ་དགག་པ་དང༌། འདོད་པའི་ཆོས་ཀྱི་གེགས་བྱེད་པ་ལ་ཁྲོ་བ་དགག་པའོ། །

Enumeration Block 4:
མི་འདོད་པ་བྱེད་པ་ལ་ཁྲོ་བའི་རྒྱུ་མཚན་དགག་པ་ནི་གསུམ་སྟེ། བདག་ལ་ཉེས་པ་བྱེད་པ་ལ་མི་བཟོད་པ་དགག་པ་དང༌། བདག་གི་བཤེས་ལ་ཉེས་པ་བྱེད་པ་ལ་མི་བཟོད་པ་དགག་པ་དང༌། བདག་གི་དགྲ་ལ་ལེགས་པ་བྱེད་པ་ལ་མི་བཟོད་པ་དགག་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། བདག་ལ་སྡུག་བསྔལ་བསྒྲུབ་པ་ལ་མི་བཟོད་པ་དགག་པ་དང༌། བརྙས་སོགས་བསྒྲུབ་པ་ལ་མི་བཟོད་པ་དགག་པ་གཉིས་སོ། །དང་པོ་ལ་གསུམ་སྟེ། སྡུག་བསྔལ་ཉིད་ལ་སོ་སོར་བརྟག་པ་སྡུག་བསྔལ་དང་དུ་ལེན་པ་དང༌། དེ་ཉིད་ལ་རྟོག་པ་ཆོས་ལ་ངེས་པར་སེམས་པ་དང༌། གནོད་བྱེད་ཀྱི་སེམས་ཅན་ལ་རྟོག་པ་གནོད་པ་བྱེད་པ་ལ་ཇི་མི་སྙམ་པ་གསུམ་མོ། །དང་པོ་ལ་ལྔ་སྟེ། སྡུག་བསྔལ་རང་བཞིན་དུ་བརྟག་པ་དང༌། བདེ་བ་ལ་སྦྱོར་བའི་སྡུག་བསྔལ་དོན་ཆེན་པོར་བརྟག་པ་དང༌། སྡུག་བསྔལ་བསྟེན་པར་མི་དཀའ་བར་བརྟག་པ་དང༌། སྦྱོར་བའི་ཡོན་ཏན་བརྟག་པ་དང༌། རང་བཞིན་གྱི་ཡོན་ཏན་བརྟག་པའོ། །

Enumeration Block 5:
ཆོས་ལ་ངེས་པར་རྟོག་པའི་བཟོད་པ་ལ་བཞི་སྟེ། རྒྱུ་ལ་རག་ལས་པས་རང་དབང་ཅན་མ་ཡིན་པ་དང༌། རང་དབང་གི་མཚན་ཉིད་དགག་པ་དང༌། ཁྲོ་བ་བཟློག་པའི་དགོས་པ་དང༌། དོན་བསྡུ་བའོ། །
དང་པོ་ནི་གཉིས་ཏེ། ཁྲོ་བ་དང་ཁྲོ་བ་ཅན་རང་དབང་ཅན་མ་ཡིན་པ་དང༌། དེ་དག་གི་རྐྱེན་རང་དབང་ཅན་མ་ཡིན་པའོ། །དང་པོ་ནི་བཞི་སྟེ། དོན་གྱི་དངོས་པོ་དགོད་པ་དང༌། དཔེ་དོན་གྱི་ཆོས་མཚུངས་པར་སྤྱིར་བསྟན་པ་དང༌། དོན་ལ་སྦྱར་བ་དང༌། སྐབས་བསྡུ་བའོ། །

Enumeration Block 6:
དེ་ལའང་གྲངས་ཅན་གྱི་འདོད་པ་དགག་པ་དང༌། རིགས་པ་ཅན་གྱི་འདོད་པ་དགག་པ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 7:
གྲངས་ཅན་པའི་འདོད་པ་འགོག་པ་ན། གཙོ་བོ་དགག་པ་དང༌། རྣམ་འགྱུར་དགག་པ་དང༌། སྐྱེས་བུ་དགག་པའོ། །

Enumeration Block 8:
སྐྱེས་བུ་དགག་པ་ལ་བྱེད་པ་པོ་ལ་འགལ་བ་དང༌། ཡུལ་ལ་ལོངས་སྤྱོད་པ་རེས་འགའ་བ་དང་འབྲེལ་པ་དགག་པའོ། །
