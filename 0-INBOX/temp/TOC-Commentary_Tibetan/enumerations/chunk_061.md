Enumeration Block 1:
**(གཉིས་པ་)རྩོད་པ་སྤང་བ་ལ་གཉིས་ལས།**
**(དང་པོ་)བདེན་གཉིས་མི་འཐད་པར་ཐལ་བ་སྤང་བ་ནི།**

Enumeration Block 2:
**(གཉིས་པ་)དཔྱོད་ཚུལ་མི་འཐད་པར་ཐལ་བར་སྤང་བ་ནི།**

Enumeration Block 3:
**(གསུམ་པ་)གཟུང་འཛིན་དགག་པ་ལ་གསུམ་ལས།**
**(དང་པོ་)སྒྲུབ་བྱེད་བརྟགས་ཏེ་དགག་པ་ནི།**

Enumeration Block 4:
**(གཉིས་པ་)ལྟོས་པས་དོན་ལ་མེད་ཚུལ་ནི།**

Enumeration Block 5:
**(གསུམ་པ་)དཔེ་དང་སྦྱོར་བ་དགག་པ་ནི།**

Enumeration Block 6:
**(གསུམ་པ་)མཐར་འཛིན་མཐའ་དག་དགག་པ་ལ།**
རྒྱུ་འབྲས་ཀྱི་མཐའ་ལ་ཞེན་པ་དགག་པ། ཡོད་མེད་ཀྱི་མཐའ་དག་ཞེན་པ་དགག་པ། སྐྱེ་འགག་དང་བྲལ་བའི་དོན་ལ་གདམས་པའོ། །
**དང་པོ་ལའང༌།**
རྒྱུ་མེད་དུ་འདོད་པ་དགག་པ། མི་མཐུན་པས་སྐྱེད་པ་དགག་པ། རྟེན་འབྲེལ་གྱི་དོན་ལ་གདམས་པའོ། །
**དང་པོ་ནི།**

Enumeration Block 7:
**(གཉིས་པ་)མི་མཐུན་པས་བསྐྱེད་པ་དགག་པ་ལ།**
དབང་ཕྱུག་དང༌། རྡུལ་ཕྲན་དང༌། གཙོ་བོ་རྟག་པས་བསྐྱེད་པ་དགག་པའོ། །
**དང་པོ་ནི།**

Enumeration Block 8:
**(དང་པོ་)རང་བཞིན་པ་རྟགས་ཏེ་དགག་པ་ནི།**

Enumeration Block 9:
**(གཉིས་པ་)བྱེད་པོར་འདོད་པ་དགག་པ་ནི།**
