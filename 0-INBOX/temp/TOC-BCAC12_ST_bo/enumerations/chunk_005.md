Enumeration Block 1:
དེ་ལྟར་བསམ་པ་མི་མཐུན་པར་བརྟག་པ་བཤད་ནས་སྦྱོར་བ་སྡུག་བསྔལ་གྱིས་མི་སྐྱེ་བ་ལ་གསུམ་སྟེ། མི་སྦྱོར་བའི་ཉེས་པ་དང༌། སྦྱོར་བའི་ཡོན་ཏན་དང༌། སྦྱོར་བ་དེ་ལྷུར་བྱ་བའི་ཐབས་སོ། །དང་པོ་ལ་གཉིས་ཏེ། མི་སྦྱོར་བའི་ཉེས་པ་དབང་དུ་བྱས་པའི་དཔེ་དང༌། དཔེ་ལས་ཁྱད་པར་དུ་འཕགས་པའི་ཆོས་སོ། །

Enumeration Block 2:
སྦྱོར་བའི་ཡོན་ཏན་ལ་གསུམ་སྟེ། རང་དོན་དང༌། གཞན་དོན་དང༌། དམ་བཅས་པ་མཐར་ཕྱིན་པའོ། །

Enumeration Block 3:
སྦྱོར་བ་དེ་ལྷུར་བླངས་པའི་ཐབས་ལ་ལྔ་སྟེ། ཉོན་མོངས་པ་སྤངས་པ་ལ་བར་མ་ཆད་པ་དང༌། གུས་པ་དང༌། མི་བཟོད་པའི་བདག་ཉིད་གཉེན་པོ་བསྟེན་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ་དང༌། ཉོན་མོངས་པའི་རྗེས་སུ་མི་ཕྱོགས་པའོ། །

Enumeration Block 4:
འདི་ལ་གཉིས་ཏེ། རྟེན་གཞན་མེད་པ་དང༌། ཕྱིན་ཅི་ལོག་གི་དམིགས་པ་ཡིན་པའོ། །དང་པོ་ལ་བཞི་སྟེ། བཟློག་པ་དཔེར་བརྗོད་པ་དང༌། རྗེས་སུ་མཐུན་པའི་དོན་དང༌། སྤོང་བྱེད་ཀྱི་གཉེན་པོའི་རང་བཞིན་དང༌། སྐབས་ཀྱི་དོན་མི་ལྡོག་པའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 5:
ཤེས་བཞིན་གྱི་ལེའུ་ལ་ལྔ་སྟེ། བསླབ་པ་བསྲུང་བའི་ཐབས་སུ་སེམས་བསྲུང་བ་དང༌། སེམས་བསྲུང་བའི་ཐབས་སུ་དྲན་པ་དང་ཤེས་བཞིན་བསྲུང་བ་དང༌། དྲན་པ་དང་ཤེས་བཞིན་གྱི་སེམས་བསྲུང་བའི་སྤྱོད་པ་ལ་བསླབ་པའི་ཚུལ་དང༌། བསྒྲུབ་པ་ཕུན་སུམ་ཚོགས་པའི་ཡན་ལག་དང༌། མཚན་ཉིད་ལ་སྦྱོར་བ་མདོར་བརྗོད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། སེམས་བསྲུང་བས་ཐམས་ཅད་བསྲུང་བ་དང༌། ཐམས་ཅད་སེམས་ལ་རག་ལས་པ་འཐད་པ་དང༌། སེམས་བསྲུང་བར་འབད་པར་བྱ་བའོ། །དང་པོ་ལ་ལྔ་སྟེ། རྗེས་འགྲོས་བསྟན་པ་དང༌། ལྡོག་པས་བསྟན་པ་དང༌། ལྡོག་པ་དེ་ཉིད་བསྒྲུབ་པ་དང༌། སེམས་བསྲུངས་ན་འཇིགས་པ་མེད་པ་དང༌། དོན་བསྡུ་བ་ལྔ་བསླབ་པ་ཞེས་པ་དང༌།

Enumeration Block 6:
དེའི་འཐད་པ་ལ་གཉིས་ཏེ། ཉེས་པ་ཐམས་ཅད་སེམས་ལ་རག་ལས་པ་དང༌། དགེ་བ་ཐམས་ཅད་སེམས་ལ་རག་ལས་པའོ། །
དང་པོ་ལ་གསུམ་སྟེ། ལུང་གིས་མདོར་བསྟན་པ་དང༌། དེ་ཉིད་བསྒྲུབ་པ་དང༌། སྐབས་ལ་སྦྱར་བའོ། །

Enumeration Block 7:
དགེ་བའི་སེམས་ལ་རག་ལས་པ་ལ་དྲུག་སྟེ། སྦྱིན་པ་དང༌། ཚུལ་ཁྲིམས་དང༌། བཟོད་པ་དང༌། བརྩོན་འགྲུས་དང༌། བསམ་གཏན་དང༌། ཤེས་རབ་སེམས་ལ་རག་ལས་པའོ། །

Enumeration Block 8:
གསུམ་པ་ལ་གསུམ་སྟེ། དོན་གྱི་དངོས་པོ་དང༌། རྗེས་སུ་མཐུན་པའི་དཔེ་དང༌། དོན་ལ་སྦྱོར་བའོ། །

Enumeration Block 9:
གསུམ་པ་ནི་སེམས་བསྲུང་བ་ལ་འབད་པར་བྱ་བ་ལ་དྲུག་སྟེ། སྤྱིར་བསྟན་པ་དང༌། དེས་ཐམས་ཅད་གྲུབ་པ་དང༌། ཇི་ལྟར་བསྲུང་བའི་རྣམ་པ་དང༌། བསྲུང་བར་རིགས་པའི་འཐད་པ་དང༌། བསྲུངས་བའི་ལེགས་པ་དང༌། དྲན་པ་ལྷུར་བླངས་པ་མཇུག་བསྡུ་བའོ། །

Enumeration Block 10:
སེམས་བསྲུང་བའི་ཐབས་སུ་དྲན་པ་དང་ཤེས་བཞིན་བསྲུང་བ་ལ་གསུམ་སྟེ། མདོར་བསྟན་པ་དང༌། ཤེས་བཞིན་མེད་པའི་ཉེས་པ་དང༌། ཤེས་བཞིན་བསྲུང་བའི་ཐབས་སུ་བསྲུང་བའོ། །

Enumeration Block 11:
གཉིས་པ་ལ་ལྔ་སྟེ། བྱ་བ་ལ་མཐུ་ཆུང་བ་དང༌། ཤེས་རབ་ཕུན་སུམ་ཚོགས་པར་མི་འགྱུར་བ་དང༌། ཚུལ་ཁྲིམས་ཕུན་སུམ་ཚོགས་པར་མི་འགྱུར་བ་དང༌། བསགས་པའི་དགེ་བ་འཇིགས་པ་དང༌། བསགས་པའི་དགེ་བ་མི་འགྲུབ་པའོ། །

Enumeration Block 12:
ཤེས་བཞིན་བསྲུང་བའི་ཐབས་སུ་དྲན་པ་བསྲུང་བ་ལ་འབད་པ་ལ་གསུམ་སྟེ། དངོས་གྱི་དོན་བརྗོད་པ་དང༌། དེའི་རྒྱུ་བསྟན་པ་དང༌། དྲན་པ་ལས་ཤེས་བཞིན་ངེས་པར་སྐྱེ་བའི་ཚུལ་ལོ། །
