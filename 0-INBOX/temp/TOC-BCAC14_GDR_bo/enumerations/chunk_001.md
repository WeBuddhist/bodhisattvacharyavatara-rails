Enumeration Block 1:
གཉིས་པ་ལམ་གྱི་རིམ་པ་བཤད་པ་དངོས་ལ་གཉིས། དལ་འབྱོར་གྱི་རྟེན་ལ་སྙིང་པོ་བླང་བའི་ཕྱིར་བསྐུལ་བ་དང༌། སྙིང་པོ་ཇི་ལྟར་ལེན་པའི་ཚུལ་བཤད་པའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སྤྱིའི་རྣམ་གཞག་དང༌། སོ་སོའི་དོན་བཤད་པའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། བྱང་ཆུབ་ཀྱི་སེམས་སྒོམ་པའི་ཕན་ཡོན་བསམ་པ་དང༌། སེམས་གཉིས་བསྐྱེད་ནས་སྤྱོད་པ་ལ་སློབ་པའི་ཚུལ་ལོ། །

Enumeration Block 4:
དང་པོ་ལ་གཉིས། ལེའུའི་གཞུང་བཤད་པ་དང༌། ལེའུའི་མཚན་ནོ། ། དང་པོ་ལ་གཉིས། སྡིག་པ་སྤོང་ཞིང་དགེ་བ་སྒྲུབ་རིགས་པར་གདམས་པ་དང༌། བྱང་ཆུབ་ཀྱི་སེམས་ཀྱི་ཕན་ཡོན་རྒྱས་པར་བསམ་པའོ། །

Enumeration Block 5:
གཉིས་པ་ལ་བཞི། བྱང་ཆུབ་ཀྱི་སེམས་ཀྱི་ཕན་ཡོན་བཤད་པ་དང༌། བྱང་ཆུབ་ཀྱི་སེམས་ངོས་བཟུང་བ་དང༌། དེ་ལ་ཕན་ཡོན་དེ་དག་འབྱུང་བའི་རྒྱུ་མཚན་དང༌། བྱང་ཆུབ་ཀྱི་སེམས་སྒོམ་པའི་གང་ཟག་ལ་བསྟོད་པའོ། །

Enumeration Block 6:
དང་པོ་ལ་གསུམ། སྡིག་པ་མཐའ་དག་འཇོམས་ཤིང་དགེ་བ་མཐའ་དག་སྒྲུབ་ནུས་པ་དང༌། མིང་དང་དོན་ཁྱད་པར་ཅན་ཐོབ་པ་དང༌། ཕན་ཡོན་དཔེས་བཤད་པའོ། །

Enumeration Block 7:
དང་པོ་ལ་གསུམ། སྡིག་པ་ཆེན་པོ་འཇོམས་པ་དང༌། བདེ་མཆོག་སྒྲུབ་ནུས་པ་དང༌། ཇི་ལྟར་འདོད་པའི་དོན་སྒྲུབ་ནུས་པའོ། །

Enumeration Block 8:
གསུམ་པ་ལ་དྲུག །དམན་པ་མཆོག་ཏུ་བསྒྱུར་བའི་དཔེ། རྙེད་དཀའ་ཞིང་རིན་ཐང་ཆེ་བའི་དཔེ། འབྲས་བུ་མི་ཟད་ཅིང་འཕེལ་བའི་དཔེ། འཇིགས་པ་ཆེན་པོ་ལས་སྐྱོབ་ནུས་པའི་དཔེ། སྡིག་པ་ཚེགས་མེད་པར་འཇོམས་པའི་དཔེ། ཕན་ཡོན་མདོ་ལས་བསྟན་པའི་ཚུལ་ལོ། །
