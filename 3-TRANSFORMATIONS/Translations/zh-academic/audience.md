# 讀者概況 —— `zh-academic`

## 1. 人口與地區
- **年齡：** 成人。
- **地區：** 台灣、香港、海外華人及其他閱讀繁體中文的讀者。
- **在家／出家：** 皆有。

## 2. 背景知識與閱讀程度
- **佛學背景：** 熟悉漢傳佛教常用術語（如來、菩薩、般若、布施）。
- **對本論的了解：** 多數讀過如石法師或索達吉堪布等譯本。

## 3. 使用情境
精讀、研究、與鳩摩羅什及玄奘譯本對照、配合藏文與梵文閱讀。

## 4. 動機與困難
希望讀到依藏文、術語一致、可靠的現代中文譯本；不滿意意譯或前後譯名不一。
