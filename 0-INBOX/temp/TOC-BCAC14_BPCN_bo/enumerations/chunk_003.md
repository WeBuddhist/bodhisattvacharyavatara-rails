Enumeration Block 1:
དེ་ཉིད་ལས་བྱང་ཆུབ་ཀྱི་སེམས་དེ་ནི་རྣམ་པ་གཉིས་ཏེ། བྱང་ཆུབ་ཏུ་སྨོན་པའི་སེམས་དང༌། བྱང་ཆུབ་ཏུ་འཇུག་པའི་སེམས་སོ། །

Enumeration Block 2:
དེ་ནི་མ་ཡིན་ཏེ་ལུང་གིས་མི་འགྲུབ་པ་དང༌། རིགས་པས་མི་འགྲུབ་པ་དང༌། ཆོ་གའི་དོན་མ་ཡིན་པའི་ཕྱིར་རོ། །

Enumeration Block 3:
སྒོམ་རིམ་བར་པ་ལས་བྱང་ཆུབ་ཀྱི་སེམས་དེ་ནི་རྣམ་པ་གཉིས་ཏེ། ཀུན་རྫོབ་དང་དོན་དམ་པའོ། །

Enumeration Block 4:
དེས་ཀྱང་མདོ་གང་ལ་བརྟེན་པ་དང༌། བསྟན་བཅོས་གང་ལས་མཛད་པའོ། །

Enumeration Block 5:
བསྟན་བཅོས་ནི་གཉིས་ཏེ། ཚིག་རྒྱས་པ་བསླབ་བཏུས་ལ་སོགས་པ་དང༌། ཚིག་བསྡུས་ཤིང་དོན་རྒྱས་པ་གཞུང་འདི་ལ་སོགས་པ་ཡིན་ཏེ།

Enumeration Block 6:
བྱང་ཆུབ་སེམས་དེ་མདོར་བསྡུས་ན།།
རྣམ་པ་གཉིས་སུ་ཤེས་བྱ་སྟེ། །
བྱང་ཆུབ་སྨོན་པའི་སེམས་དང་ནི། །
བྱང་ཆུབ་འཇུག་པ་ཉིད་ཡིན་ནོ། ། །
