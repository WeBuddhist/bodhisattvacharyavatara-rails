Enumeration Block 1:
གསུམ་པ་ལ་གསུམ། རང་རྒྱུད་ཀྱི་ཉོན་མོངས་རྩ་བ་ནས་ཕྱུང་ན་དེ་གནས་པའི་རྟེན་མེད་པ་དང༌། རྒྱུ་ཕྱིན་ཅི་ལོག་ལས་བྱུང་བས་བརྩོན་པ་བསྟེན་ན་སྤོང་ནུས་པ་དང༌།
རྩ་བ་ནས་ཕྱུང་ན་དེ་གནས་པའི་རྟེན་གང་ན་ཡང་མེད་ཅིང་སྤོང་རིགས་པའོ། །

Enumeration Block 2:
གཉིས་པ་ཚུལ་ཁྲིམས་ལ་སློབ་པའི་ཚུལ་དགེ་བའི་ཆོས་ཀུན་དག་པར་བསྲུང་བའི་ཐབས་དྲན་པ་དང་ཤེས་བཞིན་སྐྱོང་ཚུལ་གྱིས་ཁྱད་པར་དུ་བྱས་ནས་བཤད་པ་ལ་གཉིས། སྤྱིའི་རྣམ་གཞག་དང༌།
ཡན་ལག་གི་དོན་ནོ། །

Enumeration Block 3:
དང་པོ་ལ་གསུམ། སེམས་བསྐྱེད་ནས་བསླབ་པ་ལ་སློབ་དགོས་པའི་རྒྱུ་མཚན་དང༌། ཐབས་ཤེས་རེ་རེ་བ་ལ་བསླབས་པས་སངས་རྒྱས་མི་འགྲུབ་པར་བསྟན་པ་དང༌། བསླབ་པ་ལ་སློབ་པའི་རིམ་པ་བཤད་པའོ། །

Enumeration Block 4:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ་གཉིས། ལེའུའི་གཞུང་བཤད་པ་དང༌། ལེའུའི་མཚན་ནོ། ། དང་པོ་ལ་གཉིས། ཉམས་སུ་ལེན་ཚུལ་རྒྱས་པར་བཤད་པ་དང༌། ཚིག་ཙམ་མ་ཡིན་པར་དོན་ཉམས་སུ་བླང་དགོས་པས་མཇུག་བསྡུ་བའོ། །

Enumeration Block 5:
དང་པོ་ལ་བཞི། བསླབ་པ་བསྲུང་བའི་ཐབས་སེམས་བསྲུང་བ་དང༌། སེམས་བསྲུང་བའི་ཐབས་དྲན་པ་དང་ཤེས་བཞིན་བསྲུང་བ་དང༌། དྲན་པ་དང་ཤེས་བཞིན་གྱིས་སེམས་བསྲུང་བའི་སྤྱོད་པ་ལ་བསླབ་པའི་ཚུལ་དང༌།
བསླབ་པ་ཕུན་སུམ་ཚོགས་པའི་ཡན་ལག་གོ ། དང་པོ་ལ་གསུམ། སེམས་བསྲུངས་པས་ཐམས་ཅད་བསྲུངས་པར་འགྱུར་བ་དང་། དེའི་རྒྱུ་མཚན་དང༌། སེམས་བསྲུང་བ་ལ་འབད་པའོ། །

Enumeration Block 6:
དང་པོ་ལ་གསུམ། སེམས་བསྲུང་དགོས་པ་མདོར་བསྟན་པ་དང༌། སེམས་ཉམས་པའི་ཉེས་པ་དང༌། སེམས་བསྲུང་བའི་ཕན་ཡོན་ནོ། །

Enumeration Block 7:
གསུམ་པ་ལ་གཉིས། མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །

Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། ཉེས་པ་སེམས་ལ་རག་ལས་པ་དང༌། ཡོན་ཏན་སེམས་ལ་རག་ལས་པའོ། ། དང་པོ་ལ་གསུམ། ལུང་དང༌། རིགས་པ་དང༌། དོན་བསྡུ་བའོ། །
