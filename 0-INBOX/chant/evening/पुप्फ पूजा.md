# पुप्फ पूजा ^0

## 1. पूजा वचन ^1-0

वण्ण गन्ध गुणोपेतं, एतं कुसुमसन्तति। ^1-1
पूजयामि मुनिन्दस्स, सिरीपाद सरोरुहे। ^1-2

## 2. अनित्यता भावना ^2-0

पूजेमि बुद्धं कुसुमेन नेन, ^2-1
पुज्जेन मेतेन लभामि मोक्खं। ^2-2
पुप्फं मिलायाति यथा इदं मे, ^2-3
कायो तथा याति विनासभावं। ^2-4
