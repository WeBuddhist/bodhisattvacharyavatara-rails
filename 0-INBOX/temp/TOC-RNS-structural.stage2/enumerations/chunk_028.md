Enumeration Block 1:
གཉིས་པ་ཕྱི་ཡོ་བྱད་ལ་ཆགས་པའི་རྣམ་རྟོག་སྤང་བ་ལ།
འདོད་པ་སྤྱད་པའི་གནས་སྐབས་མེད་ཚུལ། ཚེ་འདིར་སྡུག་བསྔལ་མང་པོ་བསྐྱེད་ཚུལ། གཏན་དུ་འཁོར་བའི་གནས་སུ་འཆིང་ཚུལ། དེས་ན་འདོད་པས་སྐྱོ་བ་བསྐྱེད་ཚུལ་ལོ།།

Enumeration Block 2:
བཞི་པ་སྐྱོ་བ་བསྐྱེད་ཚུལ་ལ་གསུམ་ལས།

Enumeration Block 3:
གཉིས་པ་དབེན་པ་ལ་དགའ་བ་བསྐྱེད་ཚུལ་ལ།
ཐུན་མོང་དུ་བསྟན་པ་དང༌། དགའ་བའི་ཁྱད་པར་རོ།།

Enumeration Block 4:
གཉིས་པ་ཁྱད་པར་ལ་གཉིས་ལས།

Enumeration Block 5:
བྱང་ཆུབ་ཀྱི་སེམས་གཉིས་བསྒོམ་ཚུལ་ལ་གཉིས་ལས།

Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ། ཀུན་རྫོབ་བྱང་ཆུབ་ཀྱི་སེམས་བསྒོམ་ཚུལ་དང༌། དོན་དམ་བྱང་ཆུབ་ཀྱི་སེམས་བསྒོམ་ཚུལ་ལོ།།
དང་པོ་ལ། བདག་གཞན་མཉམ་པ་བསྒོམ་པ་དང༌། བདག་གཞན་བརྗེ་བ་བསྒོམ་པའོ།།
དང་པོ་ལ། བསྒོམས་པའི་འཐད་པ་མདོར་བསྟན་པ། རྒྱུ་མཚན་རྒྱས་པར་བཤད་པ། དེས་ན་བསྒོམ་པར་གདམས་པའོ།།

Enumeration Block 7:
གཉིས་པ་རྒྱས་བཤད་ལ།
ཐ་དད་ཡིན་ཡང་བསྒོམ་ཚུལ། ཞེན་པས་བསྒོམ་པར་ནུས་ཚུལ། བསྒོམ་ཚུལ་རིགས་པས་བསྒྲུབ་པ། མཉམ་པར་བསྒོམས་པའི་ཕན་ཡོན་ནོ།།
