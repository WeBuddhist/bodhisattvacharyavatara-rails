Enumeration Block 1:
གཉིས་པ་ཆ་ལ་གནས་ན་འཁྲུལ་བར་འགྱུར་ཚུལ་ནི།

Enumeration Block 2:
གསུམ་པ་ཚོགས་པའང་བདེན་པ་མེད་པར་བསྟན་པ་ནི།

Enumeration Block 3:
བཞི་པ་ཡན་ལག་ཐོ་ཡོར་ལྟ་བུར་བསྟན་པ་ནི།

Enumeration Block 4:
ལྔ་པ་ཉིང་ལག་ནམ་མཁའ་ལྟ་བུར་བསྟན་པ་ནི།

Enumeration Block 5:
དྲུག་པ་དེས་ན་རྨི་ལམ་ལྟ་བུར་བསྒོམ་ཚུལ་ནི།

Enumeration Block 6:
གཉིས་པ་ཚོར་བ་དྲན་པ་ཉེ་བར་གཞག་པ་ལའང་
ཟག་བཅས་ཀྱི་ཚོར་བ་བདེ་སྡུག་བཏང་སྙོམས་སུ་སྣང་བ་རྣམས་དོན་དམ་དུ་བདེན་པར་འདོད་པ་བརྟགས་ནས་འགོག་པ་སྟེ། དེ་ཡང་རང་བཞིན་བརྟགས་ཏེ་དགག་པ། རྒྱུ་ལ་བརྟགས་ཏེ་དགག་པ། དེས་ན་སྲེད་པ་སྤང་ཚུལ། མཐོང་སོགས་བརྟགས་ཏེ་དགག་པ། རང་གཞན་བརྟགས་ཏེ་དགག་པའོ། །
དང་པོ་ལ་གསུམ་ལས།
དང་པོ་ཚོར་བ་དོན་ལ་མེད་ཚུལ་ནི།

Enumeration Block 7:
གཉིས་པ་དེ་ལས་འཕྲོས་པའི་བརྒལ་ལན་ནི།

Enumeration Block 8:
གསུམ་པ་གཉེན་པོ་རྣམ་དཔྱོད་བསྒོམ་ཚུལ་ནི།
གཉིས་པ་རྒྱུ་ལ་བརྟགས་ཏེ་དགག་པ་ལ་གསུམ་ལས།
དང་པོ་དབང་དོན་རེག་པ་མེད་ཚུལ་ནི།

Enumeration Block 9:
གཉིས་པ་རྣམ་ཤེས་རེག་པ་མེད་ཚུལ་ནི།

Enumeration Block 10:
གསུམ་པ་ཚོགས་པའང་དོན་ལ་མེད་ཚུལ་ནི།

Enumeration Block 11:
གསུམ་པ་དེས་ན་སྲེད་པ་སྤང་ཚུལ་ནི།

Enumeration Block 12:
བཞི་པ་མཐོང་སོགས་བརྟགས་ཏེ་དགག་པ་ནི།

Enumeration Block 13:
ལྔ་པ་རང་གཞན་བརྟགས་ཏེ་དགག་པ་ནི།
