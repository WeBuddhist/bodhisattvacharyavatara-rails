Enumeration Block 1:
དེ་ལ་ཐུན་མོང་དུ་འགྲུབ་པའི་རྒྱུ་བག་ཡོད་པ་ལ་གཉིས་ཏེ་མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 2:
དེ་ལྟར་མདོར་བསྟན་ནས་རྒྱས་པར་འཆད་པ་ན་གཉིས་ཏེ། བྱང་ཆུབ་ཀྱི་སེམས་ལ་བག་བྱ་བ་དང༌། བསླབ་པ་ལ་བག་བྱ་བའོ། །

Enumeration Block 3:
དོར་བའི་ཉེས་པ་ལ་གསུམ་སྟེ། ངན་འགྲོར་འགྲོ་བ་དང༌། གཞན་གྱི་དོན་ཉམས་པ་དང༌། ས་ཐོབ་པ་ལ་ཐོགས་པའོ། །
དང་པོ་ལ་གསུམ་སྟེ། འགྲོ་བ་ཐམས་ཅད་བསླུས་པ་དང༌། དེ་ལུང་གིས་བསྒྲུབ་པ་དང༌། ལུང་གཞན་དང་འགལ་བ་སྤང་བའོ། །

Enumeration Block 4:
གཉིས་པ་གཞན་གྱི་དོན་ལས་ཉམས་པ་ལ་གསུམ་སྟེ། རང་ལ་ལྕི་བའི་ལྟུང་བ་བཅོམ་པ་དང༌། གཞན་གྱི་དགེ་བའི་བར་ཆད་བྱས་པའང་དེ་དང་མཚུངས་པ་དང༌། དེ་དག་གི་འཐད་པའོ། །

Enumeration Block 5:

Enumeration Block 6:
བཞི་པ་ངན་འགྲོར་དགེ་བ་བྱར་མེད་པ་ནི་བཞི་སྟེ། དགེ་བའི་སྐབས་མེད་པ་དང༌། དེའི་འཐད་པ་དང༌། ངན་འགྲོ་ལས་བཟློག་པར་མི་ནུས་པ་དང༌། དེའི་ཤེས་བྱེད་ཀྱི་ལུང་ངོ༌། །

Enumeration Block 7:
གཉིས་པ་དགེ་བ་བསྒྲུབ་པ་ལ་བག་བྱ་བ་ལ་གསུམ་སྟེ། སྔོན་བསགས་ཀྱི་སྡིག་པ་མང་བ་དང༌། རང་ཟད་པར་མི་འགྱུར་བ་དང༌། དེས་ན་གཉེན་པོ་དགེ་བ་ལ་འབད་པའོ། །

Enumeration Block 8:
གསུམ་པ་དེས་ན་གཉེན་པོ་དགེ་བ་ལ་འབད་པ་ནི་མ་འབད་པའི་ཉེས་པ་སྤྱིར་བསྟན་པ་དང༌། ཚེ་འདིའི་ཉེས་པ་དང༌། གཞན་གྱི་ཉེས་པ་དང༌། དེ་ལ་སྨད་པས་ལྡོག་པར་གདམས་པའོ། །

Enumeration Block 9:
གསུམ་པ་ནི་ཉོན་མོངས་པ་སྤང་བ་ལ་བག་བྱ་བ་ནི་གསུམ་སྟེ། བསམ་པ་མི་མཐུན་པ་བརྟག་པ་དང༌། སྦྱོར་བ་སྡུག་བསྔལ་གྱིས་སྐྱོ་བར་དོར་བ་དང༌། སྤང་བར་ནུས་པ་ཉིད་དུ་སྤྲོ་བ་བསྐྱེད་པའོ། །

Enumeration Block 10:
མི་བཟོད་པ་བསྐྱེད་པ་ལ་གཉིས་ཏེ། སེམས་ལ་གནོད་པ་དང༌། ལུས་ལ་གནོད་པའོ། །

Enumeration Block 11:

Enumeration Block 12:

Enumeration Block 13:

Enumeration Block 14:
