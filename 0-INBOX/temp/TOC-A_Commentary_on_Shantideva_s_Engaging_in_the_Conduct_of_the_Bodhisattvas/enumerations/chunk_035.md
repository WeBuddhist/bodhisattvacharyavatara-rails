Enumeration Block 1:
གཉིས་པ་མཚན་ཉིད་ནི།

Enumeration Block 2:
གསུམ་པ་དབྱེ་བ་ནི།

Enumeration Block 3:
ཡང་ཁྱད་པར་གྱི་དབྱེ་བ་ནི་རྣམ་པ་དྲུག་སཏེ།

Enumeration Block 4:
བཞི་པ་ཕན་ཡོན་ནི།

Enumeration Block 5:
གཉིས་པ་གཞུང་དོན་ལ།
འབྲེལ་བཀོད་དེ་ངོས་བཟུང༌། མི་མཐུན་ཕྱོགས་སྤང་ཚུལ། གཉེན་པོའི་སྟོབས་བསྐྱེད་ཚུལ་ལོ། །
དང་པོ་ནི།

Enumeration Block 6:
དང་པོ་མདོར་བསྟན་ནི།

Enumeration Block 7:
དང་པོ་གང་ལས་ལེ་ལོ་འབྱུང་ཚུལ་ནི།

Enumeration Block 8:
གཉིས་པ་དེ་ཉིད་རིམ་གྱིས་སྤང་ཚུལ་ལ།
མི་སྦྱོར་བའི་ལེ་ལོ་སྤང་བ། ངན་ཞེན་གྱི་ལེ་ལོ་སྤང་བ། སྒྱིད་ལུག་པའི་ལེ་ལོ་སྤང་བའོ། །
དང་པོ་ལ་ལྔ་ལས།
དང་པོ་ངེས་པར་འཆི་བ་བསམས་ཏེ་ལེ་ལོ་སྤང་བ་ནི།

Enumeration Block 9:
གཉིས་པ་མྱུར་དུ་འཆི་བ་བསམ་སྟེ་ལེ་ལོ་སྤང་ཚུལ་ནི།

Enumeration Block 10:
གསུམ་པ་དམྱལ་བའི་སྡུག་བསྔལ་བསམས་ཏེ་ལེ་ལོ་སྤང་བ་ནི།
