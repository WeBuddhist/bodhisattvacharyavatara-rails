Enumeration Block 1:
གསུམ་པ་འཁྲུལ་བ་ཅན་ལ་སྨད་པ་ནི།
Enumeration Block 2:
གཉིས་པ་གཞན་ལའང་དཔགས་ཏེ་ཆགས་པ་སྤང་པ་ལ་བརྒྱད་ལས།
དང་པོ་མི་གཙང་གནས་ལ་རེག་པ་སྤང་ཚུལ་ནི།
Enumeration Block 3:
གཉིས་པ་རྒྱུ་ལ་བསམས་ཏེ་ཆགས་པ་སྤང་ཚུལ་ནི།
Enumeration Block 4:
གསུམ་པ་དེ་ཡིས་གཞན་ཡང་བཙོག་པར་བྱེད་ཚུལ་ནི།
Enumeration Block 5:
བཞི་པ་གཞན་ལའང་བལྟས་ཏེ་རྣམ་པར་དཔྱད་ཚུལ་ནི།
Enumeration Block 6:
ལྔ་པ་གཞན་རྒྱུས་གཞན་ལ་ཆགས་པ་སྤང་ཚུལ་ནི།
Enumeration Block 7:
དྲུག་པ་འཇིགས་པའི་གནས་ལ་ཞེན་པ་རྨོངས་ཚུལ་ནི།
Enumeration Block 8:
བདུན་པ་གྲོང་གི་གནས་ལ་དགའ་བ་སྤང་ཚུལ་ནི།
Enumeration Block 9:
བརྒྱད་པ་འདི་དང་ཕྱི་མར་གནོད་པར་འགྱུར་ཚུལ་ནི།
Enumeration Block 10:
གཉིས་པ་ཕྱི་ཡོ་བྱད་ལ་ཆགས་པའི་རྣམ་རྟོག་སྤང་པ་ལ།
འདོད་པ་སྤྱད་པའི་གནས་སྐབས་མེད་ཚུལ། ཚེ་འདིར་སྡུག་བསྔལ་མང་པོ་བསྐྱེད་ཚུལ། གཏན་དུ་འཁོར་བའི་གནས་སུ་ འཆིང་ཚུལ། དེས་ན་འདོད་པས་སྐྱོ་བ་བསྐྱེད་ཚུལ་ལོ། །
དང་པོ་ནི།
Enumeration Block 11:
གཉིས་པ་སྡུག་བསྔལ་སྐྱེད་ཚུལ་ནི།
Enumeration Block 12:
གསུམ་པ་འཁོར་བར་འཆིང་ཚུལ་ནི།
Enumeration Block 13:
བཞི་པ་སྐྱོ་བ་བསྐྱེད་ཚུལ་ལ་གསུམ་ལས།
དང་པོ་ཉེས་དམིགས་དཔེ་ཡིས་བསྟན་པ་ནི།
Enumeration Block 14:
གཉིས་པ་དོན་མེད་དཀའ་བ་སྤྱད་ཚུལ་ནི།
Enumeration Block 15:
གསུམ་པ་ཉེས་པ་དཔེ་ལས་འདས་ཚུལ་ནི།
Enumeration Block 16:
གཉིས་པ་དབེན་པ་ལ་དགའ་བ་བསྐྱེད་ཚུལ་ལས།
ཐུན་མོང་དུ་བསྟན་པ་དང༌། དགའ་བའི་ཁྱད་པར་རོ། །
དང་པོ་ནི།
Enumeration Block 17:
གཉིས་པ་ཁྱད་པར་ལ་གཉིས་ལས།
དང་པོ་རྒྱལ་པོ་ལས་མཆོག་ཏུ་འགྱུར་ཚུལ་ནི།
Enumeration Block 18:
གཉིས་པ་དབང་པོ་ལས་མཆོག་ཏུ་འགྱུར་ཚུལ་ནི།
