# उपोसथ सील ^0

## 1. शील अधिष्ठान ^1-0

अहं उपोसथसीलं अधिट्ठामि। ^1-1

## 2. रत्नत्रय वंदना ^2-0

अरहं सम्मासम्बुद्धो भगवा, बुद्धं भगवन्तं अभिवादेमि।
स्वाखातो भगवता धम्मो, धम्मं नमस्सामि।
सुपटिपन्नो भगवतो सावकसङ्घो, सङ्घं नमामि। ^2-1

## 3. नमो तस्स ^3-0

नमो तस्स भगवतो अरहतो सम्मासम्बुद्धस्स। ^3-1

## 4. त्रिसरणगमन ^4-0

(तीन बार कहना) ^4-1

बुद्धं सरणं गच्छामि।
धम्मं सरणं गच्छामि।
सङ्घं सरणं गच्छामि। ^4-2

दुतियम्पि ^4-3

बुद्धं सरणं गच्छामि।
धम्मं सरणं गच्छामि।
सङ्घं सरणं गच्छामि। ^4-4

ततियम्पि ^4-5

बुद्धं सरणं गच्छामि।
धम्मं सरणं गच्छामि।
सङ्घं सरणं गच्छामि। ^4-6

## 5. त्रिसरणगमन संपूर्ण ^5-0

भन्ते : तिसरणगमनं सम्पुण्णं।
उपासक : आम भन्ते। ^5-1
