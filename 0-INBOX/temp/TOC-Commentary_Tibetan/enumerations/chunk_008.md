Enumeration Block 1:
དགོས་འབྲེལ་བཀོད་པའི་དགོས་པ། དགོས་འབྲེལ་སོ་སོའི་ངོ་བོ། ཐ་དད་གྲངས་ངེས་དཔྱད་པ། གཞུང་གིས་ཇི་ལྟར་བསྟན་ཚུལ་ལོ། །

Enumeration Block 2:
**(གཉིས་པ་)སོ་སོའི་ངོ་བོ་ལ་གསུམ་ལས།**

Enumeration Block 3:
**(གཉིས་པ་)བསྟན་འཆོས་ཀྱི་རང་བཞིན་ལ།**

Enumeration Block 4:
འདིར་ནི། (གཉིས་ཏེ)བསམས་ནས་ཆོས་ལ་འཇུག་ཚུལ་དང༌། ཞུགས་ནས་ཇི་ལྟར་སྒྲུབ་ཚུལ་ལོ། །

Enumeration Block 5:
**(གཉིས་པ་) སྒྲུབ་ཚུལ་ལ།**
བསམ་པ་བྱང་ཆུབ་ཀྱི་མཆོག་ཏུ་སེམས་བསྐྱེད་གཟུང་ཚུལ་དང༌། སྦྱོར་བ་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཉམས་སུ་བླང་ཚུལ་ལོ། །

Enumeration Block 6:
**དང་པོ་ལ་གཉིས་ལས།**
**(དང་པོ་)སྤྱི་དོན་ལ།**
སྐྱེ་ཚུལ། ངོ་བོ། དབྱེ་བ། ཕན་ཡོན་ནོ། །
