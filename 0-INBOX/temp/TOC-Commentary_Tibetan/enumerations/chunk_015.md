Enumeration Block 1:
**(བཞི་པ་)སྡིག་བཤགས་ཀྱི་སྤྱི་དོན་ལ་བཞི་ལས།**

Enumeration Block 2:
**གཞུང་དོན་ལ།**
བཤགས་ཚུལ་ཐུན་མོང་དུ་བསྟན་པ་དང༌། གཉེན་པོ་ཁྱད་པར་དུ་བཤད་པའོ། །
**དང་པོ་ལ་གཉིས་ལས།**

Enumeration Block 3:
**གཉེན་པོ་ལ།**
རྣམ་པར་སུན་འབྱིན་པའི་སྟོབས་དང༌། རྟེན་ལ་སྐྱབས་པའི་སྟོབས་དང༌། གཉེན་པོ་སྤྱོད་པའི་སྟོབས་དང༌། སླན་ཆད་སྡོམ་པའི་སྟོབས་སོ། །
**དང་པོ་ལ།**
འགྱོད་པས་མྱུར་དུ་བཤགས་ཚུལ། དོན་མེད་སྡིག་པ་སྤྱད་ཚུལ། མྱུར་དུ་འཆི་བས་འགྱོད་ཚུལ་ལོ། །

Enumeration Block 4:
**(གཉིས་པ་)དོན་མེད་སྤྱད་པ་ལ་གསུམ་ལས།**

Enumeration Block 5:
**(གསུམ་པ་)འཆི་བས་འགྱོད་ཚུལ་ལ་བཞི་ལས།**
