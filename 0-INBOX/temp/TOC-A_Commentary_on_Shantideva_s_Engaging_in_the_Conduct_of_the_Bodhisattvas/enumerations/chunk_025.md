Enumeration Block 1:
གསུམ་པ་བསྲུང་བར་གདམས་པ་ནི།

Enumeration Block 2:
བཞི་པ་ཇི་ལྟར་བསྲུང་བ་ལ་གཉིས་ལས།
དང་པོ་དོན་དངོས་ནི།

Enumeration Block 3:
གཉིས་པ་ཕན་ཡོན་ནི།

Enumeration Block 4:
གསུམ་པ་དོན་བསྡུ་ནི།

Enumeration Block 5:
གཉིས་པ་སེམས་བསྲུང་བའི་ཐབས་སུ་དྲན་ཤེས་བཞིན་བསྲུང་བ་ལ།
བསྲུང་བར་གདམས་པ། ཉམས་པའི་ཉེས་དམིགས། ཇི་ལྟར་སྲུང་ཚུལ་ལོ། །
དང་པོ་ནི།

Enumeration Block 6:
གཉིས་པ་ཉེས་དམིགས་ལ།
སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །
དང་པོ་བསྟན་པ་ནི།

Enumeration Block 7:
གཉིས་པ་བཤད་པ་ལ།
ཤེས་བཞིན་ཉམས་པའི་ཉེས་པ་དང༌། དྲན་པ་ཉམས་པའི་ཉེས་དམིགས། །
དང་པོ་ལ་གཉིས་ལས།
དང་པོ་ཤེས་རབ་གསུམ་ལས་ཉམས་ཚུལ་ནི།

Enumeration Block 8:
གཉིས་པ་ཚུལ་ཁྲིམས་རྣམ་དག་ཉམས་ཚུལ་ནི།

Enumeration Block 9:
གཉིས་པ་དྲན་པ་ཉམས་པ་ལ་གཉིས་ལས།
དང་པོ་ངན་འགྲོ་སྐྱེད་ཚུལ་ནི།

Enumeration Block 10:
གཉིས་པ་བདེ་འགྲོ་འཇོམས་ཚུལ་ནི།

Enumeration Block 11:
གསུམ་པ་སྲུང་ཚུལ་ལ།
དྲན་པ་སྲུང་ཚུལ་དང༌། ཤེས་བཞིན་བསྲུང་ཚུལ་ལོ། །
དང་པོ་ལ་གསུམ་ལས།
དང་པོ་ངོ་བོ་སྲུང་ཚུལ་ནི།

Enumeration Block 12:
གཉིས་པ་རྒྱུ་ལ་གདམས་པ་ནི།

Enumeration Block 13:
གསུམ་པ་དེའི་ཕན་ཡོན་ནི།

Enumeration Block 14:
གཉིས་པ་ཤེས་བཞིན་ལ།
ཤེས་བཞིན་བརྟན་པར་སྲུང་ཚུལ། དེ་ཉིད་རྒྱས་པར་བཤད་ པ། མཚན་ཉིད་བསྡུས་ཏེ་བསྟན་པའོ། །
དང་པོ་ནི།

Enumeration Block 15:
གཉིས་པ་རྒྱས་བཤད་ལ།
ལུས་དང་སེམས་ལ་བརྟག་པ། བརྟགས་ནས་དབང་དུ་བྱ་བ། དེའི་སྤྱོད་ལམ་སྦྱང་བ། བསླབ་བྱ་ཉམས་སུ་བླང་ཚུལ་ལོ། །
དང་པོ་ལ་བཞི་ལས།
དང་པོ་ལུས་ལ་བརྟགས་ནས་སྤྱོད་ཚུལ་ནི།

Enumeration Block 16:
གཉིས་པ་སེམས་ལ་བརྟགས་ནས་འཇོག་ཚུལ་ནི།

Enumeration Block 17:
གསུམ་པ་གནང་བའི་གནས་སྐབས་ཤེས་ཚུལ་ནི།

Enumeration Block 18:
བཞི་པ་གང་ལ་ཞུག་པ་ཐོག་མར་སྒྲུབ་ཚུལ་ནི།
