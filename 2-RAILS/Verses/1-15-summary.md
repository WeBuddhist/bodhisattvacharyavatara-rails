## མཆན་འགྲེལ། (གཞན་དགའི་མཆན་འགྲེལ)

ད་ནི་བྱང་ཆུབ་ཀྱི་སེམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་བསྟན་པའི་ཕྱིར་ཕན་ཡོན་བསྟན་མ་ཐག་པའི། **བྱང་ཆུབ་** ཀྱི་**སེམས་དེ་མདོར་བསྡུ་ན།** **རྣམ་པ་གཉིས་སུ་ཤེས་** པར་**བྱ་སྟེ།** འགྲོ་བ་ཐམས་ཅད་འཁོར་བ་ལས་སྒྲོལ་ཏེ་རྫོགས་པའི་**བྱང་ཆུབ་** ཆེན་པོར་བཀོད་པར་**སྨོན་པའི་སེམས་དང་ནི།** སེམས་སྔ་མ་དེ་སྔོན་དུ་སོང་ནས་སྡོམ་པ་བླངས་ཏེ་**བྱང་ཆུབ་** ཐོབ་པའི་ཕྱིར་ཚོགས་རྣམས་ལ་**འཇུག་པ་ཉིད་ཡིན་ནོ། །** ཉིད་ཀྱི་སྒྲས་འདི་གཉིས་ཁོ་ནའོ་ཞེས་པའི་དོན་ནོ། །

## དོན་འགྲེལ། (Commentary explanations)

### kunpal — མཁན་པོ་ཀུན་བཟང་དཔལ་ལྡན། (Nectar Drops)

**ས་བཅད། གཉིས་པ་བྱང་སེམས་རབ་དབྱེ་གཉིས་བསྟན།** ཕན་ཡོན་བསྟན་མ་ཐག་ཏུ། མདོར་བསྡུ་ན། བྱང་སེམས་ **རྣམ་གཉིས།** (**ཀ**) **སྨོན་སེམས་** (**smon pa** = aspiration bodhicitta / ***praṇidhicitta***) — རྫོགས་བྱང་ཆེན་མོར་སྨོན་ལམ་འདེབས་ཤིང་ (འགྲོ་བ་ཀུན་བྱང་ཆུབ་མཐར་ཕྱིན་ཆེད་) འདོད་པ་ // (**ཁ**) **འཇུག་སེམས་** (**'jug pa** = application bodhicitta / ***bodhiprasthānacitta***) — སྨོན་སེམས་སྔོན་དུ་སོང་བར་ (***pūrvam eti***) སྡོམ་པ་བླངས་ཏེ་ (***ādarśabhūta***) ཚོགས་གཉིས་ (***pāramitā***) ལ་འཇུག་པ། གཉིས་ཀ་ (ཐུན་མོང་) **བྱང་ཆུབ་ཀྱི་སེམས** = ***bodhicitta***.

([[1-SOURCES/Commentaries/Transcluded/BCAC19_KKP_bo_segmented.md#^1-15]])

### gyaltsab — རྒྱལ་ཚབ་དར་མ་རིན་ཆེན། (Gateway for Bodhisattvas)

**ས་བཅད། གཉིས་པ། བྱང་སེམས་རྣམ་གཉིས་ཀྱི་འབྱེད་པ།** ཕན་ཡོན་ཐམས་ཅད་བསྟན་མ་ཐག་བྱང་སེམས་ཀྱི་རྣམ་གཉིས་བཤད། **སྨོན་སེམས་** = འགྲོ་བ་ཐམས་ཅད་རྫོགས་བྱང་ཆེན་མོར་བཀོད་པར་ (***pratisthāpayitum***) སྨོན་པའི་བསམ་པ་བྱུང་ཡང་། ལམ་གྱི་ (***mārgaka***) སྤྱད་ཡེར་ (***prasthāna***) མ་བྱས་པ། **འཇུག་སེམས་** = སྨོན་སེམས་སྔོན་དུ་འཆར་ཏེ། སྡོམ་པ་ (***vrata***) བླངས་ཏེ་ (Atiśa ལས། མདུལ་གྱི་སྒོ་ (ritual taking) ལས་བླངས་ཞེས་གདམས།) ཚོགས་གཉིས་ལ་འཇུག་པ། (**GDR ལ་:** བྱང་སེམས་ཀྱི་དབྱེ་བ་ **22** ཡོད་མོད་ "**མདོར་བསྡུ་ན་ (sankhena / mdo'r bsdu na) རྣམ་གཉིས**" ཞེས་བཤད་ <གྲུབ་མཐའི་ཐིག་མགྲིང།>)

([[1-SOURCES/Commentaries/Transcluded/BCAC14_GDR_bo_segmented.md#^1-15]])

### ngulchu-thogmed — དངུལ་ཆུ་ཐོགས་མེད། (Ocean of Good Explanations)

**ས་བཅད། (གཉིས་པ།) བྱང་སེམས་རྣམ་གཉིས་བཤད།** **སྨོན་སེམས་** = རྫོགས་བྱང་ཆེན་མོར་སྨོན་ (བདེ་བར་གཤེགས་གཅིག་མ་ཡིན་ཐམས་ཅད་ཆེད་); **འཇུག་སེམས་** = སྨོན་སེམས་སྔོན་དུ་སོང་ནས་ (***pūrvam agataḥ***) སྡོམ་བླངས་ཏེ་ (***śīla-saṃvara***) ཚོགས་ལ་འཇུག། **Gaṇḍavyūha** ལས་ལུང་གཏད། (→ ལུང།)

([[1-SOURCES/Commentaries/Transcluded/BCAC14_NTS_bo_segmented.md#^1-15]])

### sabzang — ས་བཟང་མ་ཏི་པཎ་ཆེན། (Clear Illumination)

**ས་བཅད། གཉིས་པ་བྱང་སེམས་རྣམ་གཉིས་བཤད།** **སྨོན་སེམས་** = འགྲོ་བ་ཐམས་ཅད་རྫོགས་བྱང་ཆེན་མོར་བཀོད་བར་འདོད་པ་ (***icchā***) ཙམ། **འཇུག་སེམས་** = སྨོན་སེམས་སྔོན་དུ་འཆར་ (***agret***) ནས་སྡོམ་བླངས་ (Atiśa's ritual — མདུལ་གྱི་སྒོ་ ལ་སོགས་) ཚོགས་ལ་འཇུག། *(SMPLG ལ་ "འཇུག་སེམས་" གི་ཐིག་མགྲིང་གལ་ཆེ།: ***bodhiprasthānacitta*** = ལམ་དང་ (སྒྲུབ་ཐབས་) ལ་འཇུག་གི་བྱང་ཆུབ་ཀྱི་སེམས་སྟེ། "ལམ་གྱི་ཚོགས་ལ་འཇུག་པའི་བྱང་སེམས།"*) **Gaṇḍavyūha** ལུང་གཏད། (→ ལུང།)

([[1-SOURCES/Commentaries/Transcluded/BCAC14_SMPLG_bo_segmented.md#^1-15]])

### minyak-kunzang-sonam — མི་ཉག་ཀུན་བསོད། (Inexhaustible Treasury Vase)

**ས་བཅད། གཉིས་པ་བྱང་སེམས་རྣམ་གཉིས་ཀྱི་ཐིག་མགྲིང་།** བྱང་སེམས་ **22** ཡིས་ (***22 bhūmis***) དབྱེ་ཡང་ "མདོར་བསྡུ་ན་ **རྣམ་གཉིས་**" (**MKS** གལ་ཆེ།):

**སྨོན་སེམས་** = (**a**) ཕྱི་མའི་རྒྱུར་བྱང་ཆུབ་ **result** (***phala-bhūta***) བྱང་ཆུབ་སེམས་དཔའི་གོ་འཕང་ལ་ (ལྷ་མི་ལ་སོགས་བདེ་བ་) ལ་འདོད་ (***icchā***) ཙམ་ // **འཇུག་སེམས་** = (**b**) **རྒྱུ་** (***hetu***) ལམ་དང་ (ཚོགས་གཉིས།) ལ་མངོན་པར་མོས་ (***abhilāṣa***) ཤིང་སྡོམ་པ་བླངས་ཏེ་འཇུག། **(གལ་ཆེ།) MKS ལ་:** "***nyid***" (ཉིད་ = **ཁོ་ན།** "**these two only**") ཞེས་ KS གི་མཆན་འགྲེལ་འདི་གཉིས་ཁོ་ན་ཡིན་ (not others) ཞེས་གསལ་བར་མཛད།

མདོར་ Na། **སྨོན་སེམས་** = རྒྱུ་ (ལམ།) མ་ཡིན་ཞིང་ འབྲས་བུར་ (གོ་འཕང་) འདོད་ = **result-oriented bodhicitta**. **འཇུག་སེམས་** = རྒྱུ་ (ལམ་) ལ་འཇུག་ = **path-oriented bodhicitta.** (**NKW ལ་:** འདི་གཉིས་ཀྱི་ **sub-types 6** གསུང་: སྨོན་ pa tsam / སྨོན་ sems bskyed (ritual) / སྨོན་ non-degenerate = 3; འཇུག་ pa tsam / འཇུག་ sems bskyed (ritual) / འཇུག་ non-degenerate = 3)

[[1-SOURCES/Commentaries/Transcluded/BCAC19_MKS_bo_segmented.md]] ལས་ལུང་། Śikṣāsamuccaya: "བླ་ན་མེད་པ་ཡང་དག་རྫོགས་པའི་བྱང་ཆུབ་ཏུ་སྨོན་པ་... དཀོན་ནོ། །དེ་བས་ཀྱང་གང་... འཇུག་པ་... ཤིན་ཏུ་ཡང་དཀོན་ནོ།" (→ ལུང།) **Gaṇḍavyūha** ལས་ (→ ལུང།) "གང་སྨོན་པ་དེ་དཀོན། འཇུག་པ་ཤིན་ཏུ་དཀོན།"

([[1-SOURCES/Commentaries/Transcluded/BCAC19_MKS_bo_segmented.md#^1-15]])

### khenpo-kunga — མཁན་པོ་ཀུན་དགའ་དབང་ཕྱུག། (Commentary on the Bodhicaryāvatāra)

**ས་བཅད། གཉིས་པ། བྱང་སེམས་རྣམ་གཉིས་འབྱེད་བཤད།** (**རྣམ་གཉིས་** (**NKW** ལ་):

**སྨོན་སེམས་** = **འབྲས་བུར་འདོད།** འགྲོ་བ་ཀུན་རྫོགས་བྱང་ཆེན་མོར་ (***buddhatva***) བཀོད་བར་སྨོན་ལམ་འདེབས་ཤིང་། ལམ་གྱི་ཚོགས་ (**path/pāramitās**) ལ་མ་འཇུག་པ།

**འཇུག་སེམས་** = **རྒྱུར་འཇུག།** སྨོན་སེམས་སྔོན་དུ་འཆར་ (***pūrvam eti***) ནས་སྡོམ་བླངས་ (ལས་བྱང་དངོས་ཀྱི་མདུལ་གྱི་སྒོ་ལས་ (**NKW ལ་**: Atiśa's ritual method) བླངས་) ཏེ་ཚོགས་གཉིས་ (***sambhāra-dvaya***) ལ་དངོས་སུ་འཇུག་པ།

*(NKW གལ་ཆེ།: 22 ལ་མཐུན་ཞིང་ (གྲུབ་མཐའི་རྣམ་དབྱེ་) མདོར་ན་རྣམ་གཉིས་ཀྱི་ **sub-types 6** གསུང། // **.Gaṇḍavyūha** ལུང་གཏད།)*

([[1-SOURCES/Commentaries/Transcluded/BCAC20_NKW_bo_segmented.md#^1-15]])

### tenzin-gyatso — རྒྱལ་བ་བསྟན་འཛིན་རྒྱ་མཚོ། (Teaching on Entering the Bodhisattva's Way of Life)

ཞེས་བྱང་ཆུབ་ཀྱི་སེམས་དེ་ངོ་བོའི་སྒོ་ནས་ཕྱེ་སྟེ་མདོར་བསྡུས་ན། བྱང་ཆུབ་ཏུ་སྨོན་པའི་སེམས་དང་། བྱང་ཆུབ་ཏུ་འཇུག་པའི་སེམས་ཉིད་ཡིན་ནོ།

([[1-SOURCES/Commentaries/Transcluded/BCAC20_TG_bo.toc.md#^1-15]])

## ལུང། (Scriptural quotations)

**སྨོན་བ་དཀོན། འཇུག་པ་ཤིན་ཏུ་དཀོན།** (སྡོང་བོ་བཀོད་པ་ / Gaṇḍavyūha Sūtra ལས།):
> རིགས་ཀྱི་བུ་སེམས་ཅན་གྱི་འཇིག་རྟེན་སེམས་ཅན་གང་དག་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ཏུ་སྨོན་པ་དེ་དག་ཀྱང་དཀོན་ནོ། །དེ་བས་ཀྱང་གང་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ཏུ་འཇུག་པའི་སེམས་ཅན་དེ་དག་ནི་ཤིན་ཏུ་དཀོན་ནོ།

## གཙོ་གནད། (Main teaching points)

1. **བྱང་སེམས་རྣམ་གཉིས་ཀྱི་དབྱེ་བ།** — མདོར་བསྡུ་ན་ **སྨོན་སེམས་** (**praṇidhicitta**) དང་ **འཇུག་སེམས་** (**prasthānacitta** / ***bodhiprasthāna***) གཉིས། འགྲེལ་བ་ཀུན་གྱིས་གྲུབ་མཐའ་མཐུན།
   ([[1-SOURCES/Commentaries/Transcluded/BCAC19_KS_bo.md#^1-15]])

2. **ཉིད་ = འདི་གཉིས་ཁོ་ན།** (**KS mchan-grel**) — "ཉིད་ཀྱི་སྒྲས་འདི་གཉིས་ཁོ་ནའོ་ཞེས་པའི་དོན་ནོ།" (**nyid** = "**these two only**" — exclusion particle) ཞེས་ **KS** གསལ་ཞིང་ **MKS** ལས་མཐུན།
   ([[1-SOURCES/Commentaries/Transcluded/BCAC19_KS_bo.md#^1-15]])

3. **སྨོན་སེམས་ = འབྲས་བུར་འདོད། འཇུག་སེམས་ = རྒྱུར་འཇུག།** — (**MKS / NKW**) སྨོན་སེམས་ = རྫོགས་བྱང་གི་གོ་འཕང་ (***phala / buddhatva***) ལ་སྨོན། འཇུག་སེམས་ = ཚོགས་གཉིས་ (***pāramitā / sambhāra***) ལ་འཇུག་ = **path/cause-oriented.**
   ([[1-SOURCES/Commentaries/Transcluded/BCAC19_MKS_bo_segmented.md#^1-15]])

4. **འཇུག་སེམས་ལ་སྡོམ་པ་བླང་དགོས།** — (**GDR / SMPLG / NKW**) "**སྡོམ་པ་བླངས་ཏེ**" (**vrata / ādarśa-bhūta / śīla-saṃvara**) ཞེས་ **Atiśa** ལས་རིམ་གྱིས་བསྟན། མདུལ་གྱི་སྒོ་ (ritual) ལས་བླང་དགོས་ཞེས་གདམས།
   ([[1-SOURCES/Commentaries/Transcluded/BCAC14_GDR_bo_segmented.md#^1-15]])

5. **NKW: Sub-types 6.** — སྨོན་སེམས་ (tsam / ritual / non-degenerate = 3) + འཇུག་སེམས་ (tsam / ritual / non-degenerate = 3) = **total 6 sub-types.** (**22 classifications exist** but here = brief / "mdo'r bsdu.")
   ([[1-SOURCES/Commentaries/Transcluded/BCAC20_NKW_bo_segmented.md#^1-15]])
