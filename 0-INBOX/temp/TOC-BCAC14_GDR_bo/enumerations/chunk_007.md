Enumeration Block 1:
ལྔ་པ་ལ་གསུམ།
ལུས་ལོངས་སྤྱོད་དགེ་རྩ་གཏོང་བའི་བསམ་པ་སྦྱང་བ་དང༌།
དགེ་བ་ཆུད་མི་ཟ་བའི་རྒྱུ་རུ་སྨོན་པ་དང༌།
ལོངས་སྤྱོད་པའི་རྒྱུ་རུ་སྨོན་པའོ། །
དང་པོ་ལ་གསུམ།
གཏོང་བའི་ཚུལ་དང༌།
ངེས་པར་གཏོང་རིགས་པའི་རྒྱུ་མཚན་དང༌།
བཏང་ནས་ཇི་ལྟར་སྒྲུབ་པའི་ཚུལ་ལོ། །

Enumeration Block 2:
གཉིས་པ་ལ་གཉིས།
ཐམས་ཅད་ལ་ཆགས་པ་སྤངས་ཤིང་བཏང་བས་མྱང་འདས་ཐོབ་པ་དང༌།
སེམས་ཅན་སྦྱིན་པའི་ཞིང་མཆོག་ཡིན་པས་དེ་ལ་གཏོང་རིགས་པའོ། །

Enumeration Block 3:
གསུམ་པ་ལ་གསུམ།
དེང་ཕྱིན་ཆད་རང་གི་ལུས་ལ་རང་དབང་ཡོད་པའི་བློ་དོར་བ་དང༌།
དེའི་དོན་རྒྱས་པར་བཤད་པ་དང༌།
རིགས་པའི་ལས་ལ་སྦྱར་བའོ། །

Enumeration Block 4:
གཉིས་པ་ལ་གསུམ།
གཞན་ལ་ཕན་པ་འབའ་ཞིག་གི་རྒྱུར་སྨོན་པ་དང༌།
བསམ་པ་ཆུད་མི་ཟ་བའི་རྒྱུར་སྨོན་པ་དང༌།
སྦྱོར་བ་ཆུད་མི་ཟ་བའི་རྒྱུར་སྨོན་པའོ། །

Enumeration Block 5:
གཉིས་པ་ལ་གསུམ།
རང་ཉིད་གཞན་གྱི་ཉེར་མཁོ་མཐའ་དག་གི་རྒྱུར་སྨོན་པ་དང༌།
དུས་དང་བྱེད་ལས་རྒྱ་ཆེ་བར་སྨོན་པ་དང༌།
ཡུལ་དུས་ཆད་པ་མེད་པར་སྨོན་པའོ། །

Enumeration Block 6:
གསུམ་པ་མཇུག་ལ་གཉིས།
རང་དགའ་བ་བསྒོམ་པ་དང༌།
གཞན་དགའ་བ་བསྐྱེད་དུ་གཞུག་པའོ། །
དང་པོ་ལ་གཉིས།
རང་གི་དོན་གྲུབ་པ་དང༌།
གཞན་གྱི་དོན་གྲུབ་པའོ། །
དང་པོ་ལ་གསུམ།
སེམས་གཟེངས་བསྟོད་དེ་དགའ་བ་བསྒོམ་པ་དང༌།
སེམས་དེ་རྙེད་ནས་བག་ཡོད་བསྒོམ་པ་དང༌།
རྙེད་དཀའ་བའི་སེམས་རྙེད་པས་དགའ་བ་བསྒོམ་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ་གསུམ།
སེམས་ཅན་གྱི་སྡུག་བསྔལ་སེལ་ནུས་པ་དང༌།
དེའི་རྒྱུ་སྒྲིབ་པ་སེལ་ནུས་པ་དང༌།
ཕན་བདེ་མཐའ་དག་སྒྲུབ་ནུས་པའོ། །
དང་པོ་ལ་ལྔ།
འགྲོ་བའི་འཆི་བདག་འཇོམས་པ་དང༌།
དབུལ་བ་འཇོམས་པ་དང༌།
ནད་འཇོམས་པ་དང༌།
སྤྱིར་སྲིད་པའི་སྡུག་བསྔལ་འཇོམས་པ་དང༌།
ཁྱད་པར་ངན་འགྲོའི་སྡུག་བསྔལ་འཇོམས་པའོ། །

Enumeration Block 8:
གཉིས་པ་ལ་གཉིས།
ཉོན་སྒྲིབ་སེལ་བ་དང༌．
ཤེས་སྒྲིབ་སེལ་བའོ། །

Enumeration Block 9:
གསུམ་པ་ལ་གཉིས།
ཕན་པ་མཐའ་དག་བསྒྲུབ་པ་དང༌།
བདེ་བ་མཐའ་དག་བསྒྲུབ་པའོ། །
