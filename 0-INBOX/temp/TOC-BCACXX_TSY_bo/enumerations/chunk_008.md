Enumeration Block 1:
གཉིས་པ་དེའི་འཐད་པ་ནི་ཤློ་ཀ་གཉིས་ཏེ།

Enumeration Block 2:
གསུམ་པ་རྩོད་པ་སྤང་བ་ནི། མི་གང་ཞེས་ཤྰཀ་གཅིག་སྟེ།

Enumeration Block 3:
གཉིས་པ་ནི་ཤྰཀ་གསུམ་སྟེ།

Enumeration Block 4:
གསུམ་པ་ནི་དེ་ལྟར་ཞེས་ཤློཀ་གཅིག་གིས་སྟོན་པ་ན་

Enumeration Block 5:
གསུམ་པ་དེས་དེར་གདམས་པ་ལ་གཉིས་ཀྱི་དང་པོ་དངོས་ནི་དེ་ལྟས་ཞེས་རྐང་པ་གཉིས་སོ།།
གཉིས་པ་དེ་ལྟར་མ་བྱས་པའི་ཉེས་པ་ནི་དེང་ནས་ཞེས་རྐང་པ་བཅུས་སྟོན་པ་ལ་ཐོག་མར།

Enumeration Block 6:
གཉིས་པ་རྟེན་དལ་འབྱོར་ལ་བག་བྱ་བ་ལ་གསུམ་སྟེ། དེ་རྙེད་དཀའ་བ་དང༌།
མ་རྙེད་པའི་ཉེས་པ་དང༌། རྙེད་ནས་མི་འབད་པ་སྨད་པའོ། །དང་པོ་ལ་རྐང་པ་བརྒྱད་ཀྱིས་
སྟོན་པ་ལ་

Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་ངན་འགྲོར་དགེ་བ་མི་སོགས་པ་ནི་ངདག་གི་ཞེས་ཤོ་ལོ་ཀ་གཉིས་ཀྱིས་སྟོན་པ་ན་

Enumeration Block 8:
གཉིས་པ་དེ་ནས་བདེ་འགྲོ་མི་ཐོབ་པ་ནི་དགེ་བ་ཞེས་ཤོ་ལོ་ཀ་གཅིག་གོ ༑གསུམ་པ་དེའི་འཐད་པ་ལ་ལུང་ནི་དེ་ཉིད་ཕྱིར་ན་ཞེས་ཤློཀ་གཅིག་སྟེ།

Enumeration Block 9:
རིགས་པ་ཡང་ཤྰཀ་གཉིས་ཏེ།

Enumeration Block 10:
གསུམ་པ་ལ་གཉིས་ཀྱི་དང་པོ་མདོར་བསྟན་པ་ནི་ཤཱཀ་གཅིག་གིས་སྟོན་པ་ན་

Enumeration Block 11:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གསུམ་གྱིས་དང་པོ་བསླུས་རྨོངས་ཀྱི་ཉེས་
དམིགས་ནི་གལ་ཏེ་ཞེས་ཤོ་ལོ་ཀ་གཉིས་ཏེ།

Enumeration Block 12:
གཉིས་པ་བསླུས་ཤིང་རྨོངས་པའི་དོན་ནི་ཤིན་ཏུ་རྙེད་དཀའ་ཞེས་རྐང་པ་དྲུག་སྟེ།

Enumeration Block 13:
གསུམ་པ་དེ་དག་གི་རྒྱུ་ནི་རྐང་པ་གཉིས་ཏེ།
