Enumeration Block 1:
**(བཞི་པ་)གཉིས་པསྦྱོར་བས་བསྒྲུབ་ཚུལ་ལ།**
སྒྲུབ་ཚུལ་དངོས་དང༌། དབང་དུ་བྱེད་ཚུལ་ལོ། །
**དང་པོ་ལ་གསུམ་ལས།**

Enumeration Block 2:
**(གཉིས་པ་)དབང་དུ་བྱེད་ཚུལ་ལ་བདུན་ལས།**

Enumeration Block 3:
**(གཉིས་པ་)དོན་དམ་བྱང་ཆུབ་ཀྱི་སེམས་བསྒོམ་པ་ལ་གསུམ་ལས།**

Enumeration Block 4:
**ད་ནི་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཉམས་སུ་བླང་ཚུལ་ལ་སྤྱི་དོན་བཞི་སྟེ།**
བྱེད་ལས་མཚན་ཉིད་དབྱེ་བ་ཕན་ཡོན་ནོ། །

Enumeration Block 5:
**(གསུམ་པ་)དབྱེ་བ་ལ་གཉིས་ལས།**
