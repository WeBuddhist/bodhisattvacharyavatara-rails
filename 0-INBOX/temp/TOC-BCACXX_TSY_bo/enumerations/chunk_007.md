Enumeration Block 1:
གཉིས་པ་སྡོམ་པའི་སྤྱི་དོན་ལ་ཡང་གསུམ་སྟེ། རང་བཞིན་ངེས་པར་བྱ་བ་དང༌།
དོན་རྗེས་སུ་སྒྲུབ་པ་དང༌། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་ངོ་བོ་དང༌། རྒྱུ་དང༌། འབྲས་བུ་
གསུམ་ལས་དང་པོ་ནི་སྔར་བདེ་གཤེགས་སྲས་ཀྱི་སྡོམ་ལ་ཞེས་པར་བཤད་ཟིན་པས་གཉིས་
པ་ལ་གཉིས་ཏེ། སྐྱེ་བའི་དང། གཏོང་བའི་རྒྱུའོ། །

Enumeration Block 2:
གསུམ་པ་འབྲས་བུ་ལ་ཡང་གཉིས་ལས་

Enumeration Block 3:
གཉིས་པ་དོན་རྗེས་སུ་སྒྲུབ་པ་ལ་གསུམ་སྟེ། ཡང་དག་པར་བླང་
བ་དང༌། བླངས་ནས་ཇི་ལྟར་བསླབ་པ་དང༌། ཉམས་ན་ཕྱིར་བཅོས་པའོ། །

Enumeration Block 4:
གཉིས་པ་ཇི་ལྟར་བསླབ་པར་བྱ་བ་ལ་གསུམ་སྟེ། མཚན་ཉིད་ཤེས་པར་བྱ་བ་ལ་བསླབ་པ་
དང༌། བྱ་བ་རྗེས་སུ་སྒྲུབ་པ་ལ་བསླབ་པ་དང༌། ཐབས་ལ་མཁས་པའི་ཁྱད་པར་ལ་བསླབ་
པའོ། །

Enumeration Block 5:
ད་ནི་གསུམ་པ་མཇུག་གི་ཆོ་ག་ལ་གཉིས་ཏེ། སྤྱིར་བསྟན་པ་དང༌། བྱེ་བྲག་ཏུ་
བཤད་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་རང་དགའ་བ་བསྐྱེད་པ་དང༌ ། གཞན་
དགའ་བ་སྐྱེད་དུ་གཞུག་པ་གཉིས་ལས་དང་པོ་ལའང་གཉིས་ཏེ། རང་དོན་གྲུབ་པ་དང༌།
གཞན་དོན་འགྲུབ་པས་སོ། །

Enumeration Block 7:
གཉིས་པ་ལ་ཡང་
གསུམ་གྱི་དང་པོ་རྒུད་པ་སེལ་བ་ནི་

Enumeration Block 8:
དེ་ལྟར་བསམ་པ་སེམས་བསྐྱེད་ཟིན་ནས་ད་ནི་སྤྱིའི་གསུམ་པ་ཇི་ལྟར་འཇུག་
པའི་སྦྱོར་བ་བྱང་ཆུབ་སེམས་དཔའི་བསླབ་པ་སྟོན་པ་ལ་གཉིས་ཏེ། བསླབ་པ་གྲུབ་པའི་
ཐབས་དང༌། བསྒྲུབ་བྱ་བསླབ་པའི་རང་བཞིན་ནོ། །

Enumeration Block 9:
དེ་ཉིད་གཞུང་གིས་
འཆད་པ་ལ་བསྟན་བཤད། བསྡུ་བ་གསུམ་གྱི།

Enumeration Block 10:
གཉིས་པ་གསུམ་སྟེ། བསྒྲུབ་བྱ་བསླབ་པ་དང༌། རྟེན་དལ་འབྱོར་དང༌། སྤང་བྱ་ཉོན་མོངས་
ལ་བག་བྱ་བའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་བསླབ་པ་མི་འདོར་བའི་འཐད་པ་ནི་

Enumeration Block 11:
གཉིས་པ་འདོར་བའི་ཉེས་དམིགས་ལ་གསུམ་སྟེ། རྣམ་སྨིན་ངན་འགྲོར་༼ལྟུང་
བ་དང༌ ། སྤྱོད་པ་གཞན་དོན་ཉམས་པ་དང༌། འབྲས་བུ་ཐར་པ་ལ་ཐོགས་པའོ། །དང་པོ་
ལའང་གསུམ་གྱི་དང་པོ་དངོས་ནི་
