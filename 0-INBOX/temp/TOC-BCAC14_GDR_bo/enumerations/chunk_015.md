Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། ཐ་མལ་པའི་ཀུན་སྤྱོད་ཀུན་མཛེས་པར་བྱ་བ་དང༌། གཞན་དང་འགྲོགས་པའི་ཀུན་སྤྱོད་ཁ་ན་མ་ཐོ་བ་མེད་པ་ལ་མཁས་པར་བྱ་བ་དང༌། སྒོ་གསུམ་གྱི་ལས་བྱེད་པའི་བྱ་བ་ལ་མཁས་པར་བྱའོ། །

Enumeration Block 2:
དང་པོ་ལ་གསུམ། གཞན་དང་ཕྲད་པའི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། ཡོ་བྱད་ལ་འདོར་ལེན་བྱེད་པ་སོགས་ཀྱི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། སྤྱོད་པ་མཛངས་པས་ཀུན་ཏུ་བྱ་བ་བསྒྲུབ་པའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་ལྔ། ཕན་པར་སྨྲ་བ་ལ་ཇི་ལྟར་བྱ་བ། བདེན་པར་སྨྲ་བ་ལ་ཇི་ལྟར་བྱ་བ། བསོད་ནམས་བྱེད་པ་ལ་ཇི་ལྟར་བྱ་བ། གཞན་གྱི་ཡོན་ཏན་བརྗོད་པའི་ཚེ་ཇི་ལྟར་བྱ་བ། གཞན་དགའ་བར་བྱས་པའི་ཕན་ཡོན་ནོ། །

Enumeration Block 4:
གསུམ་པ་ལ་གསུམ། སྨྲ་བའི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། བལྟ་བའི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། དགེ་བའི་ལས་འབའ་ཞིག་དང་འབྲེལ་བར་བྱ་བའོ། །

Enumeration Block 5:
གསུམ་པ་ལ་གསུམ། སྦྱིན་པའི་ཞིང་ཁྱར་པར་ཅན་ལ་སྦྱིན་པ་བྱ་བ་དང༌། དགེ་བའི་ལས་རྣམས་རང་སྟོབས་ཀྱིས་བྱ་བ་དང༌། དགེ་བ་གོང་ནས་གོང་དུ་ཁྱད་ཞུགས་ཤིང་དགོས་པ་བརྟགས་ནས་བྱ་བའོ། །

Enumeration Block 6:
གསུམ་པ་སེམས་ཅན་དོན་བྱེད་ཀྱི་ཚུལ་ཁྲིམས་ལ་བསླབ་པ་ལ་གསུམ། གཞན་དོན་ལྷུར་བླང་བ་དང༌། རང་ཉེས་པས་མ་གོས་པར་གཞན་བསྡུ་བའི་སྤྱོད་པ་དང༌། སེམས་ཅན་གྱི་སེམས་རྗེས་སུ་བསྲུང་ཞིང་ཉེས་པས་མི་གོས་པའི་སྤྱོད་པ་ལ་བསླབ་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། ཟང་ཟིང་གིས་བསྡུ་བ་དང༌། ཆོས་ཀྱིས་བསྡུ་བའོ། །

Enumeration Block 8:
དང་པོ་ལ་གསུམ། ཟས་གོས་སྦྱིན་པ་དང་མི་སྦྱིན་པའི་ཁྱད་པར་དང༌། བྱ་བ་ཕྲན་ཚེགས་ཀྱི་ཆེད་དུ་ལུས་ལ་གནོད་པར་མི་བྱ་བ་དང༌། ལུས་སྦྱིན་པར་གཏོང་བའི་དུས་དང་དགོས་པ་བཤད་པའོ། །

Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། ཆོས་བཤད་དུ་མི་རུང་བའི་ཉན་པ་པོའི་ལུས་ཀྱི་ཀུན་སྤྱོད་དང༌། སྣོད་ཀྱི་བསམ་པའི་ཁྱད་པར་བརྟག་པ་དང༌། རྒྱ་ཆེན་པོ་ལ་མོས་པ་དམན་པ་ལ་སྦྱར་བར་མི་བྱའོ། །

Enumeration Block 10:
གསུམ་པ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །
དང་པོ་ལ་གསུམ། ལུས་ཀྱི་སྤྱོད་ལམ་ཉེས་པ་དང་བཅས་ཤིང་གཞན་མ་དད་པ་སྤང་བ་དང༌། ལམ་ལ་སོགས་པ་སྟོན་པའི་ཚེ་ཇི་ལྟར་བྱ་བ་དང༌། ཉལ་བའི་ཀུན་སྤྱོད་ཇི་ལྟར་བྱ་བའོ། །
