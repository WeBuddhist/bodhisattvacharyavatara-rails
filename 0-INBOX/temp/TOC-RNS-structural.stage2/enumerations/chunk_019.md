Enumeration Block 1:
གཉིས་པ་བཤེས་ལ་ཉེས་པ་བྱུང་དུས་བཟོད་པ་བསྒོམ་པ་ལ།
ཆོས་ལ་ངེས་པར་སེམས་པའི་བཟོད་པ། གནོད་པས་ཇི་མི་སྙམ་པའི་བཟོད་པ། སྡུག་བསྔལ་དང་དུ་ལེན་པའི་བཟོད་པའོ།།

Enumeration Block 2:
གཉིས་པ་གནོད་པས་ཇི་མི་སྙམ་པ་ལ་བཞི་ལས།

Enumeration Block 3:
གསུམ་པ་སྡུག་བསྔལ་དང་དུ་ལེན་པ་ལ་གཉིས་ལས།

Enumeration Block 4:
གསུམ་པ་དགྲ་ལ་ལེགས་པ་བྱུང་དུས་བསྒོམ་པ་ལ།
བསྟོད་པ་བྱུང་ཡང་བཟོད་ཚུལ། བདེ་བ་བྱུང་ཡང་བཟོད་ཚུལ། འབྱོར་པ་བྱུང་ཡང་བཟོད་ཚུལ་ལོ།།
དང་པོ་ལ་གཉིས་ལས།

Enumeration Block 5:
གསུམ་པ་འབྱོར་པ་བྱུང་ཡང་བཟོད་ཚུལ་ལ་བཞི་ལས།

Enumeration Block 6:
གཉིས་པ་ཡིད་དུ་འོང་བའི་གེགས་ལ་བསྒོམ་པ་ལ།
དགྲ་ལ་སྡུག་བསྔལ་འབྱུང་བའི་གེགས་ལ་བཟོད་ཚུལ་དང༌། རང་ལ་བསྟོད་གྲགས་འབྱུང་བའི་གེགས་ལ་བཟོད་ཚུལ་ལོ།
དང་པོ་ལ་གཉིས་ལས།

Enumeration Block 7:
གཉིས་པ་རང་ལ་བསྟོད་གྲགས་འབྱུང་བའི་གེགས་ལ་བཟོད་ཚུལ་ལ་ལྔ་ལས།
