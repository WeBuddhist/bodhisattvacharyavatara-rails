Enumeration Block 1:
**གཞུང་དོན་ལ།**
སྡུག་བསྔལ་རང་ཞི་བར་བསྔོ་བ་དང༌། གཞན་གྱི་མཐུ་ཡིས་ཞི་བར་བསྔོ་བའོ། །

Enumeration Block 2:
**དང་པོ་ལ་བཞི་ལས།**

Enumeration Block 3:
**(གཉིས་པ་)གཞན་གྱི་མཐུས་ཞི་བར་བསྔོ་བ་ལ་བཞི་ལས།**

Enumeration Block 4:
**(གཉིས་པ་)དུད་འགྲོའི་དོན་དུ་བསྔོ་བའི་སྤྱི་དོན་ལའང༌།**
གནས་ལུས་སྡུག་བསྔལ་ཚེ་ཚད་བཞི་ལས

Enumeration Block 5:
**(གསུམ་པ་)ཡི་དྭགས་ཀྱི་དོན་དུ་བསྔོ་བའི་སྤྱི་དོན་ལའང་**
སྔ་མ་ལྟར་བཞི་ལས།

Enumeration Block 6:
**(གསུམ་པ་)བདེ་འགྲོའི་དོན་དུ་བསྔོ་བ་ལ།**
རྒུད་པ་བཞི་པར་བསྔོ་བ་དང༌། འབྱོར་བ་ཐོབ་པར་བསྔོ་བའོ། །
