Enumeration Block 1:
**(གཉིས་པ་)རྒྱུ་ལ་བརྟགས་ཏེ་དགག་པ་ལ་གསུམ་ལས།**

**(དང་པོ་)དབང་དོན་རེག་པ་མེད་ཚུལ་ནི།**

Enumeration Block 2:
**(གཉིས་པ་)རྣམ་ཤེས་རེག་པ་མེད་ཚུལ་ནི།**

Enumeration Block 3:
**(གསུམ་པ་)ཚོགས་པའང་དོན་ལ་མེད་ཚུལ་ནི།**

Enumeration Block 4:
དེ་ལ་གཉིས་ལས།

**(དང་པོ་)ཡིད་ཤེས་བདེན་མེད་དུ་བསྟན་པ་ནི།**

Enumeration Block 5:
**(གཉིས་པ་)དབང་ཤེས་སྐྱེ་མེད་དུ་བསྒྲུབ་པ་ནི།**

Enumeration Block 6:
**(བཞི་པ་)ཆོས་དྲན་པ་ཉེ་བར་གཞག་པ་ལ།**

དཔྱད་ན་སྐྱེ་བ་མེད་ཚུལ། དེ་ལ་རྩོད་པ་སྤང་བ། གཟུང་འཛིན་བདེན་པ་དགག་པའོ། །

**དང་པོ་ནི།**

Enumeration Block 7:
**(གཉིས་པ་)རྩོད་པ་སྤང་བ་ལ་གཉིས་ལས།**

**(དང་པོ་)བདེན་གཉིས་མི་འཐད་པར་ཐལ་བ་སྤང་བ་ནི།**
