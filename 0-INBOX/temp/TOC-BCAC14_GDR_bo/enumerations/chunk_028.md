Enumeration Block 4:
ལྔ་པ་མི་གཡེང་བའི་ཁྱད་པར་ལ་གཉིས།
མཁས་པས་དབེན་པ་བསྟེན་པར་རིགས་པ་དང༌།

Enumeration Block 5:

དགེ་བའི་ཕྱོགས་མི་ཉམས་ཤིང་འཕེལ་བ་དང༌།
དེས་ན་བདག་ཉིད་དབེན་པ་བསྟེན་པར་རིགས་པའོ། །

Enumeration Block 6:
གཉིས་པ་ཕྱིན་ཅི་ལོག་གི་རྣམ་རྟོག་སྤང་བ་ལ་གཉིས།

Enumeration Block 7:
དང་པོ་ལ་གསུམ།
འདོད་པ་ལ་སྦྱང་བའི་འབྲས་བུ་འཇིགས་པ་དང་བཅས་པར་བསམ་པ་དང༌།
ལུས་ལ་སོགས་པའི་ངོ་བོ་མི་གཙང་བར་བསམ་པ་དང༌།
མི་འདོད་པ་དུ་མ་བསྐྱེད་པར་བསམ་པའོ། །

Enumeration Block 8:

དགེ་བ་ལ་བརྩོན་པར་གདམས་པ་དང༌།
འདོད་པའི་ཉེས་དམིགས་བསམ་པའོ། །

Enumeration Block 9:
གཉིས་པ་ལ་གཉིས།
དུར་ཁྲོད་ཀྱི་གནས་ཚུལ་ལ་བལྟས་ཏེ་ཉེས་དམིགས་བསམ་པ་དང༌།
གསོན་པའི་ཆོས་ལ་སྦྱར་ཏེ་བསམ་པའོ། །

Enumeration Block 10:
དང་པོ་ལ་དྲུག །
རོ་མྱང་བར་བྱ་བའི་འབྲས་བུ་མེད་པ་དང༌།
མཐར་དུར་ཁྲོད་དུ་བོར་བ་ལས་མ་འདས་པ་དང༌།

རྒྱན་གདགས་པར་མི་རིགས་པ་དང༌།
ཤིན་ཏུ་འཇིགས་པར་རིགས་པ་དང༌།
གོས་ཀྱིས་གཡོགས་པ་ལ་ཆགས་པར་མི་རིགས་པའོ། །

Enumeration Block 12:
