Enumeration Block 1:
གུས་པའི་ཡུལ་དུ་བརྟག་པ་ལ་གཉིས་ཏེ། རང་གི་ཡོན་ཏན་གྱིས་གུས་པར་བྱ་བ་དང༌། སྟོན་པ་ལ་དད་པས་གུས་པར་བྱ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། ཕན་འདོགས་ཆེ་བ་དང༌། བསམ་པའི་ཡོན་ཏན་ལ་མི་ལྟོས་པ་དང༌། དེས་ན་སྟོན་པ་དང་འདྲ་བར་བལྟ་བའོ། །

Enumeration Block 2:
དེ་ལ་ལྔ་སྟེ། ལུང་གི་མདོར་གཞག་པ་དང༌། དེ་ཉིད་བསྒྲུབ་པ་དང༌། དེས་ན་གུས་པའི་ཡུལ་དུ་མཉམ་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 3:
ལྔ་པ་དོན་བསྡུ་བ་ནི་གསུམ་སྟེ། འབྲས་བུ་མཉམ་པ་དང་ཡོན་ཏན་མི་མཉམ་པ་དང༌། སེམས་ཅན་དང་ཞིང་དམ་པ་ཉིད་དུ་གྲུབ་པ་བསྡུ་བའོ། །

Enumeration Block 4:
དེ་ལྟར་རང་གི་ཡོན་ཏན་གྱི་གུས་པའི་ཡུལ་དུ་བསྒྲུབས་ནས་གཉིས་པ་སྟོན་པ་ལ་དད་པས་གུས་པར་བྱ་བ་ནི། སྟོན་པས་སེམས་ཅན་བདག་གིར་མཛད་པ་དང༌། སྟོན་པས་སེམས་ཅན་བདག་ཏུ་མཛད་པའོ། །དང་པོ་ལ་དྲུག་སྟེ། མདོར་དགོད་པ་དང༌། གནོད་པ་ལ་བཟོད་པར་བྱ་བ་དང༌། ཁེངས་པ་སྤང་བ་དང༌། གནོད་པ་སྤང་བ་དང༌། ཐུབ་པ་མི་དགོས་པའི་སྡིག་པ་བཤགས་པ་དང༌། ཕྱིན་ཆད་བསྡམ་པའོ། །

Enumeration Block 5:
དེ་ལྟར་ཁྲོ་བའི་མཚན་མ་བཟློག་ནས་བཟོད་པའི་འབྲས་བུ་ཡིད་ལ་བྱ་བ་ལ་བཞི་སྟེ། མདོར་བསྟན་པ་དང༌། འབྲས་བུའི་དབང་དུ་བྱས་པའི་དཔེ་དང༌། དཔེ་ལས་ཁྱད་པར་དུ་འཕགས་པ་དང༌། འབྲས་བུའི་རྣམ་གྲངས་བསྡུ་བའོ། །

Enumeration Block 6:
བརྩོན་འགྲུས་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ལ་བཞི་སྟེ། བརྩོན་འགྲུས་ལ་སྤྲོ་བ་བསྐྱེད་པ་དང༌། བརྩོན་འགྲུས་ཀྱི་ངོ་བོ་དང༌། མི་མཐུན་པའི་ཕྱོགས་སྤང་བ་དང༌། བརྩོན་འགྲུས་ཡང་དག་པར་སྤེལ་བའོ། །

Enumeration Block 7:
གསུམ་པ་ལ་བཞི་སྟེ། མི་མཐུན་ཕྱོགས་མདོར་བསྟན་པ་དང༌། སྦྱོར་བ་མེད་པའི་ལེ་ལོ་སྤང་བ་དང༌། བྱ་བ་ངན་པ་ལ་ལེ་ལོ་སྤང་བ་དང༌། སྒྱིད་ལུག་པའི་ལེ་ལོ་སྤང་བའོ། །

Enumeration Block 8:
གཉིས་པ་སྦྱོར་བ་མེད་པའི་ལེ་ལོ་སྤང་བ་ལ་གསུམ་སྟེ། མི་སྦྱོར་བའི་རྒྱུ་བརྟགས་ཏེ་བཟློག་པ་དང༌། ཚེ་འདིའི་ཉེས་པ་བརྟགས་ཏེ་བཟློག་པ་དང༌། ཚེ་ཕྱི་མའི་སྡུག་བསྔལ་བརྟགས་ཏེ་བཟློག་པའོ། །དང་པོ་ནི་སྙོམ་ལས་ཞེས་པ་སྟེ། སྙོམ་ལས་དང༌། བསམ་པ་འཁོར་བས་མི་སྐྱོ་བ་ལ་ལེ་ལོ་སྐྱེའོ་ཞེས་པའོ། །གཉིས་པ་ལ་བདུན་ཏེ། མི་རྟག་པས་ངེས་པར་ཟིན་པ་དང༌། དཔེ་ལ་མཐོང་བ་དང༌། རང་ལ་འབབ་པ་དང༌། དུས་ལ་སྡོད་པར་མི་ནུས་པ་དང༌། འཆི་བའི་ཚེ་དུས་ལས་འདས་པ་དང༌། དུས་ལས་བསྡད་པར་མི་ནུས་པ་ཉིད་བཤད་པ་དང༌། སྡུག་བསྔལ་གྱི་རྣམ་པ་ཉིད་བརྗོད་པའོ། །

Enumeration Block 9:
ཕྱི་མའི་སྡུག་བསྔལ་བརྟགས་ཏེ་བཟློག་པ་ནི་བཞི་སྟེ། སྡུག་བསྔལ་ངེས་པར་འབྱུང་བ་དང༌། བརྣག་པར་དཀའ་བ་དང༌། འགལ་བ་འདུ་བ་དང༌། དེ་ལས་ཐར་པའི་ཐབས་ལས་བསྐུལ་བའོ། །

Enumeration Block 10:
བཞི་པ་ནི་སྒྱིད་ལུག་གི་ལེ་ལོ་སྤང་བ་ལ་གསུམ་སྟེ། གཉེན་པོ་འབྲས་བུ་དང་བཅས་ཏེ་མདོར་བསྟན་པ་དང༌། རྒྱུ་མེད་པས་སྒྱེད་ལུག་པའི་གཉེན་པོ་ཡིད་ལ་བྱ་བ་དང༌། སྦྱོར་མི་བཟོད་པས་སྒྱིད་ལུག་པའི་གཉེན་པོ་ཡིད་ལ་བྱ་བའོ། །
