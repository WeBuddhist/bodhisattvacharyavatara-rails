# Termbase — Bodhisattva Challenge, English translation stream

Vocabulary contract for translation output in `Plans/the-bodhisattva-challenge/en/Days/`. **One rendering per term.**

Forked from the-bodhisattva-challenge English termbase, which governs *authored*
day content. This one governs *translation* of the Tibetan day file's three prose
sections. It keeps that file's core spine and drops its authoring-only rules.

**The two files are meant to differ.** Where they disagree inside `Days/` output
generated by `dalai-lama-plan-translation`, this file wins. In particular,
`termbase.md` permits "positive energy" for `བསོད་ནམས་` in one section as a
description of what days 15–25 did; that carve-out is not inherited here.

Register target: CEFR A2–B1. One idea per sentence, active voice, under 20 words.

## Diacritics

**No diacritics in body prose.** Shantideva, Manjushri, Samantabhadra, bodhicitta.

Two exemptions, and only two:

1. **Verse quotations**, reproduced verbatim from `bca-english-plain.md`, keep
   whatever the source has — including "Mañjuśrī".
2. **The italicised title of a work.** Write _Bodhicaryāvatāra_ with diacritics.
   This matches `requirements.md`, which prescribes that spelling in the opening
   formula of every introduction, and every existing day file. Other work titles
   follow the same rule: diacritics inside the italics, none outside.

The distinction is between a *term* used in prose (no diacritics) and a *cited
title* (diacritics). Do not extend the exemption to any other category.

## High-frequency terms — one plain rendering each

These appear in most day files. The rendering is fixed; the scholarly alternative
in the right-hand column is **not** available, because it fails the A2–B1 reader
this stream is written for.

| Tibetan | Write | Not |
|---|---|---|
| སྡིག་པ། | wrongdoing | misdeeds, negativity, negative karma, demerit, sin |
| དགེ་བ། | doing good / good actions | virtue, merit, wholesome deeds |
| བག་མེད། | carelessness / being careless | heedlessness, non-conscientiousness |
| ལེ་ལོ། | laziness | sloth, indolence |
| འགྱོད་བཤགས། | confess with regret | confess with remorse, repent |
| བཤགས་པ། | confession, confessing | repentance, expiation |
| བག་ཡོད། | being careful, paying attention | conscientiousness, heedfulness |
| མི་རྟག་པ། | nothing lasts, does not last | impermanence (as an abstract noun) |
| འཆི་བདག་ / གཤིན་རྗེ། | the Lord of Death | Yama alone, the Death Lord |

**`སྡིག་པ།` is "wrongdoing" everywhere** — in prose and in the category label
_(Avoiding wrongdoing)_ alike. "Misdeeds" is retired: listing two renderings for
one term is exactly what a one-rendering-per-term contract forbids.

**`དགེ་བ།` is never "merit".** `བསོད་ནམས་` is merit; `དགེ་བ་` is the good action
that produces it. Collapsing them loses a distinction the source keeps.
