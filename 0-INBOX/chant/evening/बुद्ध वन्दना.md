# बुद्ध वन्दना ^0

इतिपि सो भगवा अरहं सम्मासम्बुद्धो, ^1
विज्जाचरणसम्पन्नो सुगतो लोकविदू। ^2
अनुत्तरो पुरिसदम्मसारथि, ^3
सत्था देवमनुस्सानं बुद्धो भगवाति। ^4
