Enumeration Block 1:
དེས་ན་འདི་ལྟར་བཤད་པར་བྱ་སྟེ། བློའི་དབྱེ་བ་དང༌། གནོད་བྱེད་ཀྱི་རིམ་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 2:
དེ་ལ་རྩོད་པ་སྤང་བ་ལ་གཉིས་ཏེ། སྤྱོད་པ་དོན་མེད་པས་རྩོད་པ་སྤང་བ་དང༌། རྟོགས་པ་ཁྱད་མེད་པའི་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 3:
དེ་ལ་དངོས་པོར་འཛིན་པའི་རྩོད་པ་སྤོང་བ་ནི། ཀུན་རྫོབ་ཀྱི་སྒོ་ཅན་གྱི་གནོད་པ་སྤོང་བ་དང༌། དོན་དམ་གྱི་སྒོ་ཅན་གྱི་གནོད་པ་སྤོང་བའོ། །

Enumeration Block 4:
དེ་ལ་བྱེ་བྲག་ཏུ་སྨྲ་བས་གཟུགས་ལ་སོགས་པ་ཤེས་བྱའི་གཞི་ལྔ་དོན་དམ་པར་ཚད་མས་གྲུབ་པར་འདོད་པས། ཚད་མ་དང་འགལ་བའི་རྩོད་པ་སྤང་བ་དང༌། བཅོམ་ལྡན་འདས་ཀྱིས་གསུངས་པས་ལུང་གི་གནོད་པ་སྤང་པའོ། །

Enumeration Block 5:
དེ་ལ་དགོངས་ཏེ་གསུངས་པ་ཞེས་བྱ་བ་ལ། དགོངས་ཏེ་གསུངས་པའི་དགོས་པ་དང༌། དགོངས་གཞི་དང༌། དངོས་ཀྱི་དོན་ལ་གནོད་པའི་ཚད་མ་དང་གསུམ་དགོས་སོ། །

Enumeration Block 6:
འདི་ལ་བཞི་སྟེ། ཚོགས་ཀྱི་རྟེན་གསུངས་པས་མི་གནོད་པ་དང༌། ཉིང་མཚམས་སྦྱོར་བར་གསུངས་པས་མི་གནོད་པ་དང༌། ལས་ཀྱི་རྟེན་གསུངས་པས་མི་གནོད་པ་དང༌། འཁོར་བ་དང་མྱ་ངན་ལས་འདས་པའི་ཐ་དད་རྣམ་པར་བཞག་པས་མི་གནོད་པའོ། །

Enumeration Block 7:
རྣལ་འབྱོར་སྤྱོད་པའི་གནོད་པ་སྤོང་བ་ན་གཉིས་ཏེ། འཛིན་པ་མ་གྲུབ་པ་དང༌། རྟེན་མ་གྲུབ་པ་སྤང་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། རྣམ་བརྫུན་གྱི་གནོད་པ་སྤང་བ་དང༌། རྣམ་བདེན་གྱི་གནོད་པ་སྤང་བ་དང༌། རང་ལ་གནོད་པ་སྤང་བ་སྟེ་རང་གི་ལུགས་རྣམ་པར་གཞག་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། རྒོལ་བ་དང་ལན་ནོ། །

Enumeration Block 8:
རྣམ་བདེན་གྱི་གནོད་པ་སྤང་བ་ལ་གཉིས་ཏེ། སྣང་བ་སེམས་ཡིན་པ་ལ་གནོད་པ་བརྗོད་པ་དང༌། རང་རིག་པ་ལ་སྒྲུབ་བྱེད་དགག་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། གནོད་པ་མདོར་གཞག་པ་དང༌། དེའི་ཁྱབ་པ་ལུང་གིས་བསྒྲུབ་པ་དང༌། དེ་ཉིད་རིགས་པས་བརྟན་པར་བྱ་བའོ། །

Enumeration Block 9:
འདི་ལ་གསུམ་སྟེ། ལུང་དགོད་པ་དང༌། དེ་ལ་ཤེས་པར་བྱེད་པའི་དཔེ་དང༌། དོན་ལ་སྦྱར་བའོ། །

Enumeration Block 10:
གསུམ་པ་དེ་ཉིད་རིགས་པས་བརྟན་པར་བྱ་བ་ལ་གཉིས་ཏེ། མར་མེའི་གསལ་བས་མ་ངེས་པ་སྤང་བ་དང༌། ལྷན་ཅིག་སྐྱེས་པའི་སྔོན་པོས་མ་ངེས་པ་སྤང་བའོ། །

Enumeration Block 11:
གཉིས་པ་སྒྲུབ་བྱེད་དགག་པ་ལ་གསུམ་སྟེ། སྤྱིར་མེད་པ་དང༌། དེ་ཉིད་ཀྱིས་ཡོད་པར་ངེས་པའི་ཐ་སྙད་འགལ་བ་དང༌། སྒྲུབ་བྱེད་ཀྱི་རྗེས་དཔག་མེད་པའོ། །

Enumeration Block 12:
གསུམ་པ་སྒྲུབ་བྱེད་ཀྱི་རྗེས་དཔག་མེད་པ་ལ་གཉིས་ཏེ། འབྲས་བུའི་རྟགས་འཁྲུལ་པ་དང༌། རང་བཞིན་གྱི་རྟགས་འཁྲུལ་པའོ། །

Enumeration Block 13:
རྟེན་མ་གྲུབ་པ་ལ་བཞི་སྟེ། རྒོལ་བ་དགོད་པ་དང༌། རིགས་པ་དགག་པ་དང༌། དེའི་འདོད་པ་ལ་གནོད་པ་བརྗོད་པ་དང༌། དེའི་ཁྱབ་པ་བསྒྲུབ་པའོ། །

Enumeration Block 14:
ཡུལ་ཅན་ལམ་དུ་བསྒྲུབ་པ་ལ་གསུམ་སྟེ། ཀུན་རྫོབ་པའི་ཡུལ་ཅན་ལམ་དུ་བསྒྲུབ་པ་དང༌། དོན་དམ་པའི་ཡུལ་ཅན་ལམ་དུ་བསྒྲུབ་པ་དང༌། ཤེས་པ་གཉིས་ཀྱིས་བྱེད་པ་མཇུག་བསྡུས་ཏེ་བསྟན་པའོ། །

Enumeration Block 15:
དེས་ན་ཡུལ་ཅན་གྱི་ཤེས་པ་ལམ་དུ་བསྒྲུབ་པ་ལ་གསུམ་སྟེ། ཡུལ་ཅན་གྱི་ཤེས་པ་ལམ་དུ་བསྒྲུབ་པ་དངོས་དང༌། དེ་ལ་ཉན་ཐོས་ཀྱི་རྩོད་པ་སྤང་བ་དང༌། ཤེས་པ་གཉིས་ཀྱིས་བྱེད་པ་མདོར་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། རྩོད་པ་དང༌། ལན་ནོ། །

Enumeration Block 16:
ལན་ལ་བཞི་སྟེ། ཕྱོགས་གཅིག་སྒྱུ་མར་རྟོགས་པ་གཉེན་པོ་མ་ཡིན་པ་དང༌། ཐམས་ཅད་སྒྱུ་མར་རྟོགས་པ་གཉེན་པོ་ཡིན་པ་དང༌། དེ་ལ་སྣང་བ་མེད་པའི་ཡེ་ཤེས་སྐྱེ་བའི་ཚུལ་དང༌། ཕྲིན་ལས་འཇུག་པ་འབད་པ་ལ་མི་ལྟོས་པའོ། །

Enumeration Block 17:
གཉིས་པ་ཐམས་ཅད་སྒྱུ་མར་རྟོགས་པ་ལམ་དུ་བསྒྲུབ་པ་ནི་གསུམ་སྟེ། ཡོད་པར་འཛིན་པ་སྤོང་བ་དང༌། མེད་པར་འཛིན་པ་སྤོང་བ་དང༌། དེའི་འཐད་པའོ། །

Enumeration Block 18:
བཞི་པ་ཕྲིན་ལས་འཇུག་པ་འདབ་པ་ལ་མི་ལྟོས་པ་ནི་གསུམ་སྟེ། རྒྱུད་དག་པའི་གདུལ་བྱ་ལ་རྒྱལ་བའི་སྐུ་སྣང་བ་དང༌། སྣང་བ་དེས་ཕན་པ་ལ་འཇུག་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 19:
དེ་ལ་རྩོད་པ་སྤང་བ་ལ་གསུམ་སྟེ། རྩོད་པ་དགོད་པ་དང༌། ལུང་གི་རྟགས་དགོད་པ་དང༌། དེའི་ཁྱབ་པ་བསྒྲུབ་པའོ། །

Enumeration Block 20:
དེ་ལྟ་བུའི་ཡུལ་ཅན་ལམ་དུ་བསྒྲུབ་པ་ལ་ཉན་ཐོས་ཀྱི་རྩོད་པ་སྤང་བ་ལ་དྲུག་སྟེ། རྒོལ་བ་དགོད་པ་དང༌། དེ་ལམ་དུ་ལུང་གིས་སྒྲུབ་བྱེད་དང༌། ལུང་དེ་བཀར་བསྒྲུབ་པ་དང༌། ལུང་ངེས་དོན་དུ་བསྒྲུབ་པ་དང༌། སྐབས་ཀྱི་དོན་བསྡུ་བ་དང༌། བཀར་བསྒྲུབ་པའི་སྒྲུབ་བྱེད་རྒྱས་པར་བཤད་པའོ། །
