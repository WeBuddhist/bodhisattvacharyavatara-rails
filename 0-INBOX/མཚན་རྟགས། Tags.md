### ༡. མི་དང་སྤྱི་ཚོགས་ལས་བྱུང་བའི་དཀའ་ངལ་གདོང་ལེན། (Interpersonal & Social Challenges)

གཞན་གྱིས་སྨད་ར་གཏོང་བ། རྒྱབ་བཤད་རྒྱག་པ། མགོ་སྐོར་བཏང་བ་སོགས་མི་འབྲེལ་གྱི་དཀའ་ངལ་ལ་གདོང་ལེན་བྱེད་པའི་མཚན་རྟགས།

| མཚན་རྟགས། (Tags) | གང་ལ་སྦྱར་བའི་གནས་སྐབས། (Application) |

| --- | --- |

| `#གནོད་ལན་མི་སློག་པ།` | དགྲ་བོའམ་གཞན་གྱིས་གནོད་པ་བྱས་ཀྱང་ཚུར་འཁོན་ལན་མི་སློག་པ། |

| `#དྲིན་ལན་ལོག་འཇལ།` | རང་གིས་ཕན་བཏགས་པའི་མིས་ཚུར་གནོད་པ་བྱས་པའི་དཀའ་ངལ་ལམ་ཁྱེར། |

| `#བརྙས་བཅོས་ཁྱད་བསད།` | གཞན་གྱིས་མཐོང་ཆུང་དང་བརྙས་བཅོས་བྱས་པར་དང་ལེན་བྱེད་པ། |

| `#མི་ཁ་བཟོད་པ།` | མི་མང་པོས་སྐྱོན་བརྗོད་དང་ངན་སྨྲས་བྱས་པར་མི་འཇིགས་པ། |

### ༢. རྒྱུ་ནོར་དང་དཔལ་འབྱོར་གྱི་དཀའ་ངལ་གདོང་ལེན། (Material & Financial Loss)

| མཚན་རྟགས། (Tags) | གང་ལ་སྦྱར་བའི་གནས་སྐབས། (Application) |

| --- | --- |

| `#ནོར་ཤོར་བ་ལམ་ཁྱེར།` | རང་གི་རྒྱུ་ནོར་གཞན་གྱིས་འཕྲོག་པའམ་བརླག་པའི་སྐབས་ཀྱི་སེམས་ཁམས། |

| `#རྙེད་བཀུར་ལ་མི་ཆགས་པ།` | ཁེ་སྤོགས་དང་བཀུར་སྟི་མ་ཐོབ་པའམ་ཤོར་བའི་སྐབས་ཀྱི་ལམ་སྟོན། |

| `#ཆོག་ཤེས་བསྟེན་པ།` | དགོས་མཁོ་མ་འགྲུབ་པའི་དཀའ་ངལ་སྐབས་ཡོད་རྒུས་ཆོག་ཤེས་བྱེད་པ། |

| `#འདོད་ཡོན་གྱི་བསླུ་བྲིད།` | དངོས་པོའི་འདོད་རྔམས་ལས་བྱུང་བའི་དཀའ་ངལ་ལ་གདོང་ལེན་བྱེད་པ། |

### ༣. ལུས་ཁམས་དང་འབྱུང་བའི་དཀའ་ངལ་གདོང་ལེན། (Physical Harm & Environmental Hardships)

ནད་མནར་བ། རྨས་སྐྱོན་ཕོག་པ། ས་ཆུ་མེ་རླུང་གི་གནོད་པ་སོགས་ལུས་ཀྱི་དཀའ་ངལ་ལ་བཀོལ་བའི་མཚན་རྟགས།

| མཚན་རྟགས། (Tags) | གང་ལ་སྦྱར་བའི་གནས་སྐབས། (Application) |

| `#ཚ་གྲང་བཟོད་པ།` | གནམ་གཤིས་དང་ཁོར་ཡུག་གི་ཚ་གྲང་གི་དཀའ་ངལ་ལ་བཟོད་བསྲན་བྱེད་པ། |

| `#ནད་ཀྱི་སྡུག་བསྔལ།` | སྨན་བཅོས་དཀའ་བའི་ནད་གཞི་ཕོག་སྐབས་སེམས་མི་ཞུམ་པའི་ཐབས། |

### ༤. ནང་སེམས་ཀྱི་དཀའ་རྙོག་དང་མི་བདེ་བ་གདོང་ལེན། (Psychological & Emotional Struggles)
