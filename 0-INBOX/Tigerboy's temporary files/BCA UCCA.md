# Bodhicaryavatara (Verses 1-5) - UCCA Semantic Analysis[cite: 1]

**Universal Conceptual Cognitive Annotation (UCCA)** breaks the verses down into semantic Scenes, Participants, and Processes. This structural analysis demonstrates that the core meaning is preserved regardless of syntactic divergence between Tibetan and English.[cite: 1]

## Annotation Legend[cite: 1]
*   **[H]** = Parallel Scene (Main Clause)[cite: 1]
*   **[P]** = Process (Action/Event)[cite: 1]
*   **[S]** = State (Condition)[cite: 1]
*   **[A]** = Participant (Who/What)[cite: 1]
*   **[D]** = Adverbial (Time, Manner, Location)[cite: 1]
*   **[C]** = Center (Head of phrase)[cite: 1]
*   **[E]** = Elaborator (Modifier)[cite: 1]
*   **[L]** = Linker (Conjunction)[cite: 1]

### Verse 1-1 (Homage & Intent)[cite: 1]
```text
[Root]
 ├─ [H] Scene 1 (Prostration)
 │   ├─ [A] Participant: I (Implied in Tibetan context)
 │   ├─ [D] Adverbial: གུས་པར་ (reverently)
 │   ├─ [P] Process: ཕྱག་འཚལ་ཏེ (prostrate)
 │   └─ [A] Participant: Objects of refuge
 │       ├─ [C] Center: བདེ་གཤེགས་ (Sugatas)
 │       │   └─ [E] Elaborator: ཆོས་ཀྱི་སྐུ་མངའ་ (possessing Dharmakaya)
 │       ├─ [C] Center: སྲས་བཅས་ (with their heirs)
 │       └─ [C] Center: ཕྱག་འོས་ཀུན་ལའང་ (and all worthy of veneration)
 ├─ [L] Linker: ནི་ (as for / then)
 └─ [H] Scene 2 (Explanation)
     ├─ [A] Participant: I (Implied)
     ├─ [D] Adverbial: ལུང་བཞིན་ (according to scripture)
     ├─ [D] Adverbial: མདོར་བསྡུས་ནས་ (briefly)
     ├─ [P] Process: བརྗོད་པར་བྱ (will explain)
     └─ [A] Participant: Topic
         └─ [P] Process: འཇུག་པ་ (engaging)
             └─ [A] Participant: བདེ་གཤེགས་སྲས་ཀྱི་སྡོམ་ལ་ (in the vows of the heirs of Sugatas)
```[cite: 1]

### Verse 1-2 (Humility)[cite: 1]
```text
[Root]
 ├─ [H] Scene 1 (No new teachings)
 │   ├─ [A] Participant: འདིར་ (here)
 │   ├─ [P] Process: བརྗོད་མེད། (is nothing stated)
 │   └─ [E] Elaborator: སྔོན་ཆད་མ་བྱུང་བ་ (that has not occurred before)
 ├─ [H] Scene 2 (No skill)
 │   ├─ [A] Participant: བདག་ལ་ (in me)
 │   └─ [S] State: སྡེབ་སྦྱོར་མཁས་པའང་... ཡོད་མིན་ཏེ། (skill in composition does not exist)
 ├─ [L] Linker: དེ་ཕྱིར་ (Therefore)
 ├─ [H] Scene 3 (No altruistic motive)
 │   ├─ [A] Participant: བདག་ལ་ (in me)
 │   └─ [S] State: གཞན་དོན་བསམ་པ་... མེད། (thought of benefiting others does not exist)
 └─ [H] Scene 4 (Actual Intent)
     ├─ [A] Participant: ངས་ (I)
     ├─ [P] Process: འདི་བརྩམས། (composed this)
     └─ [D] Adverbial: རང་གི་ཡིད་ལ་བསྒོམ་ཕྱིར་ (in order to cultivate my own mind)
```[cite: 1]

### Verse 1-3 (Purpose)[cite: 1]
```text
[Root]
 ├─ [H] Scene 1 (Personal Benefit)
 │   ├─ [D] Adverbial: དགེ་བ་བསྒོམ་ཕྱིར་ (For the sake of cultivating virtue)
 │   ├─ [A] Participant: བདག་གི་དད་པའི་ཤུགས། (the strength of my faith)
 │   ├─ [D] Adverbial: རེ་ཞིག་ (for a short while)
 │   ├─ [P] Process: འཕེལ་འགྱུར་ལ། (may increase)
 │   └─ [A] Participant: འདི་དག་གིས་ཀྱང་ (through these [words])
 └─ [H] Scene 2 (Benefit to Others)
     ├─ [A] Participant: གཞན་གྱིས་ཀྱང་། (others)
     │   └─ [E] Elaborator: བདག་དང་སྐལ་བ་མཉམ་པ་ (equal in fortune to me)
     ├─ [P] Process: མཐོང་ན་ (if [they] see)
     │   └─ [A] Participant: འདི་དག་ (these)
     └─ [S] State: དོན་ཡོད་འགྱུར། (it may be meaningful)
```[cite: 1]

### Verse 1-4 (Preciousness of Life)[cite: 1]
```text
[Root]
 ├─ [H] Scene 1 (Rarity)
 │   ├─ [A] Participant: དལ་འབྱོར་འདི་ནི་ (This leisure and endowment)
 │   └─ [S] State: རྙེད་པར་ཤིན་ཏུ་དཀའ། (are very hard to find)
 ├─ [H] Scene 2 (Condition)
 │   ├─ [P] Process: ཐོབ་པར་གྱུར་པ་ལ། (Having obtained)
 │   └─ [A] Participant: སྐྱེས་བུའི་དོན་སྒྲུབ་ (accomplishment of human purpose)
 ├─ [H] Scene 3 (Failure to act)
 │   ├─ [L] Linker: གལ་ཏེ་... ན། (If)
 │   ├─ [A] Participant: འདི་ལ་ (here / in this life)
 │   └─ [P] Process: ཕན་པ་མ་བསྒྲུབས་ (does not accomplish benefit)
 └─ [H] Scene 4 (Consequence)
     ├─ [D] Adverbial: ཕྱིས་ (later)
     ├─ [A] Participant: འདི་ཡང་དག་འབྱོར་པར་ (this perfect endowment)
     └─ [P] Process: ག་ལ་འགྱུར། (how will [it] arise?)
```[cite: 1]

### Verse 1-5 (The Lightning Metaphor)[cite: 1]
```text
[Root]
 ├─ [L] Linker: ཇི་ལྟར་ ... དེ་བཞིན་ (Just as ... so too)
 ├─ [H] Scene 1 (Metaphor)
 │   ├─ [D] Adverbial: མཚན་མོ་མུན་ནག་སྤྲིན་རུམ་ན། (in the dark clouds of night)
 │   ├─ [A] Participant: གློག་ (lightning)
 │   ├─ [P] Process: འགྱུ་ (flash)
 │   ├─ [D] Adverbial: སྐད་ཅིག་ (for an instant)
 │   └─ [P] Process: རབ་སྣང་སྟོན་པ་ (shows illumination)
 └─ [H] Scene 2 (Subject)
     ├─ [A] Participant: སངས་རྒྱས་མཐུ་ཡིས་ (by the power of the Buddhas)
     ├─ [D] Adverbial: བརྒྱ་ལམ་ན། (rarely)
     ├─ [A] Participant: འཇིག་རྟེན་བསོད་ནམས་བློ་གྲོས་ (the world's intelligence for merit)
     ├─ [D] Adverbial: ཐང་འགའ་ (briefly)
     └─ [P] Process: འབྱུང་། (arises)
```[cite: 1]
