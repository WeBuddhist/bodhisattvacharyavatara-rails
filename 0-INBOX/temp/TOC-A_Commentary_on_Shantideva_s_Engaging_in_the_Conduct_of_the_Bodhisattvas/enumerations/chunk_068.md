Enumeration Block 1:
གཉིས་པ་གཟུགས་དང་གཟི་བརྗིད་ལྡན་པར་བསྔོ་བ་ནི།

Enumeration Block 2:
གསུམ་པ་དགེ་ཞིང་ཕུན་སུམ་ཚོགས་པར་བསྔོ་བ་ནི།

Enumeration Block 3:
བཞི་པ་ཞིང་ཁམས་ཡོངས་སུ་དག་པར་བསྔོ་བ་ནི།

Enumeration Block 4:
ལྔ་པ་ཆོས་ཀྱི་མཐུན་རྐྱེན་ཚང་བར་བསྔོ་བ་ནི།

Enumeration Block 5:
དྲུག་པ་འཇིག་རྟེན་དར་ཞིང་དགེ་བར་བསྔོ་བ་ནི།

Enumeration Block 6:
གཉིས་པ་མཆོག་གི་དོན་དུ་བསྔོ་བ་ལ་བདུན་ལས།
དང་པོ་དགེ་འདུན་གནས་དང་བཅས་པའི་དོན་དུ་བསྔོ་བ་ནི།

Enumeration Block 7:
གཉིས་པ་དགེ་སློང་ཕ་མའི་དོན་དུ་བསྔོ་བ་ནི།

Enumeration Block 8:
གསུམ་པ་རབ་བྱུང་སྤྱིའི་དོན་དུ་བསྔོ་བ་ནི།

Enumeration Block 9:
བཞི་པ་ཁྱད་པར་མཁས་པའི་དོན་དུ་བསྔོ་བ་ནི།

Enumeration Block 10:
ལྔ་པ་སངས་རྒྱས་རྒྱུན་དུ་མཆོད་པར་བསྔོ་བ་ནི།

Enumeration Block 11:
དྲུག་པ་དམ་པའི་དགོངས་པ་འགྲུབ་པར་བསྔོ་བ་ནི།

Enumeration Block 12:
བདུན་པ་ཉན་རང་རྣམས་ཀྱང་བདེ་བར་བསྔོ་བ་ནི།

Enumeration Block 13:
གཉིས་པ་རང་གི་དོན་དུ་བསྔོ་བ་ལ་གསུམ་ལས།
དང་པོ་ཚེ་རབས་མང་པོའི་དོན་དུ་བསྔོ་བ་ནི།

Enumeration Block 14:
གཉིས་པ་མགོན་དང་བཅས་པའི་དོན་དུ་བསྔོ་བ་ནི།

Enumeration Block 15:
གསུམ་པ་གཞན་དོན་འགྲུབ་པའི་དོན་དུ་བསྔོ་བ་ནི།

Enumeration Block 16:
གསུམ་པ་བསྟན་པའི་དོན་དུ་བསྔོ་བ་ནི།

Enumeration Block 17:
གཉིས་པ་བཀའ་དྲིན་དྲན་པའི་ཕྱག་འཚལ་བ་ནི།

Enumeration Block 18:
བཞི་པ་དོན་དེ་ལེགས་པར་བསྒྱུར་བའི་ཚུལ་ནི།
