Enumeration Block 1:
གཉིས་པ་བདག་གཞན་བརྗེ་བའི་ཚུལ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། ། དང་པོ་ལ་གཉིས། བདག་གཞན་བརྗེ་བའི་ཚུལ་དང༌། དེ་ལྟར་གོམས་སུ་རུང་བའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 2:
གཉིས་པ་ལ་གསུམ། བདག་གཞན་བརྗེ་བའི་ཚུལ་བཤད་པ་དང༌། བརྗེས་ནས་བསམ་པས་རྗེས་སུ་སྒྲུབ་པའི་ཚུལ་དང༌། སྦྱོར་བས་རྗེས་སུ་སྒྲུབ་པའི་ཚུལ་ལོ། ། དང་པོ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 3:
དང་པོ་ལ་གསུམ། གཞན་གཅེས་འཛིན་གོམས་པར་བྱ་བ་དང༌། བདག་གཅེས་འཛིན་འབད་པས་སྤང་བར་བྱ་བ་དང༌། བདག་དང་གཞན་གཙོ་བོར་བྱེད་པའི་སྐྱོན་དང་ཡོན་ཏན་བསམ་པའོ། །

Enumeration Block 4:
དང་པོ་ལ་ལྔ། བདག་གཞན་བརྗེ་ནུས་ཤིང་རློམ་པ་ཞི་བར་འགྱུར་བ་དང༌། རྣམ་སྨིན་ལ་མི་ལྟོས་པར་དེ་བསྒོམ་པ་ལ་འབད་པར་གདམས་པ་དང༌། དེས་ན་གཞན་དོན་ཆེད་ཆེར་བྱ་བ་དང༌།
གོམས་ན་བསྐྱེད་ནུས་པ་དང༌། བདག་གཞན་སྡུག་བསྔལ་ལས་སྒྲོལ་འདོད་པས་བདག་གཞན་བརྗེ་བ་བསྒོམ་པར་བྱ་བའོ། །

Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། བདག་གཅེས་འཛིན་འཇིགས་པ་མཐའ་དག་གི་རྒྱུ་ཡིན་པ་དང༌། ཉེས་སྤྱོད་མཐའ་དག་ལ་སྦྱོར་བྱེད་ཡིན་པ་བསམ་པའོ། །

Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། བདག་གཞན་གཅེས་པར་གཟུང་བའི་ཉེས་དམིགས་དང་ཕན་ཡོན་གྱི་རྣམ་གྲངས་དང༌། དེས་ན་བདག་གཅེས་འཛིན་དོར་རིགས་པའོ། །

Enumeration Block 7:
དང་པོ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། །དོན་བསྡུ་བའོ། །

Enumeration Block 8:
དང་པོ་ལ་ལྔ། སྦྱིན་པའི་དབང་དུ་བྱས་པ་དང་། གནོད་པའི་དབང་དུ་བྱས་པ་དང༌། བསྟོད་གྲགས་ཀྱི་དབང་དུ་བྱས་པ་དང༌། ལས་ལ་སྦྱོར་བའི་དབང་དུ་བྱས་པ་དང། ཕན་བདེའི་དབང་དུ་བྱས་པའོ། །

Enumeration Block 9:
གཉིས་པ་ལ་བཞི། མ་མཐོང་བའི་ཉེས་དམིགས་དང༌། མཐོང་བའི་ཉེས་དམིགས་དང༌། ཉེས་དམིགས་བསྡུས་ཏེ་བསྟན་པ་དང༌། དེས་ན་བདག་གཅེས་འཛིན་འདོར་བར་རིགས་པའོ། །

Enumeration Block 10:
གཉིས་པ་དོན་བསྡུ་བ་ལ་གསུམ། བདག་གཞན་བརྗེ་བའི་ཚུལ་དང༌། བརྗེས་ནས་ལོག་པར་སྦྱོར་བ་དགག་པ་དང༌། ཕྱིན་ཅི་མ་ལོག་པར་བསྒྲུབ་པའོ། །

Enumeration Block 11:
གཉིས་པ་བདག་གཞན་བརྗེས་ནས་བསམ་པས་རྗེས་སུ་སྒྲུབ་པའི་ཚུལ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །
