Enumeration Block 1:
གཉིས་པ་སེམས་བསྲུང་བའི་ཐབས་སུ་དྲན་ཤེས་བཞིན་བསྲུང་བ་ལ།
བསྲུང་བར་གདམས་པ། ཉམས་པའི་ཉེས་དམིགས། ཇི་ལྟར་སྲུང་ཚུལ་ལོ།།

Enumeration Block 2:
གཉིས་པ་ཉེས་དམིགས་ལ། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ།།

Enumeration Block 3:
གཉིས་པ་བཤད་པ་ལ། ཤེས་བཞིན་ཉམས་པའི་ཉེས་པ་དང༌། དྲན་པ་ཉམས་པའི་ཉེས་དམིགས་སོ།།
དང་པོ་ལ་གཉིས་ལས།

Enumeration Block 4:
གཉིས་པ་དྲན་པ་ཉམས་པ་ལ་གཉིས་ལས།

Enumeration Block 5:
གསུམ་པ་སྲུང་ཚུལ་ལ།
དྲན་པ་སྲུང་ཚུལ་དང༌། ཤེས་བཞིན་བསྲུང་ཚུལ་ལོ།།
དང་པོ་ལ་གསུམ་ལས།

Enumeration Block 6:
གཉིས་པ་ཤེས་བཞིན་ལ། ཤེས་བཞིན་བརྟན་པར་སྲུང་ཚུལ། དེ་ཉིད་རྒྱས་པར་བཤད་པ། མཚན་ཉིད་བསྡུས་ཏེ་བསྟན་པའོ།།

Enumeration Block 7:
གཉིས་པ་རྒྱས་བཤད་ལ། ལུས་དང་སེམས་ལ་བརྟག་པ། བརྟགས་ནས་དབང་དུ་བྱ་བ། དེའི་སྤྱོད་ལམ་སྦྱང་བ། བསླབ་བྱ་ཉམས་སུ་བླང་ཚུལ་ལོ།།
དང་པོ་ལ་བཞི་ལས།

Enumeration Block 8:
དབང་དུ་བྱ་བ་ལ།
ཚུལ་མིན་ལས་བཟློག་ཚུལ། ཚུལ་བཞིན་ལ་འཇུག་ཚུལ། དལ་བའི་དོན་སྒྲུབ་ཚུལ་ལོ།།
དང་པོ་ལ་ལྔ་ལས།
