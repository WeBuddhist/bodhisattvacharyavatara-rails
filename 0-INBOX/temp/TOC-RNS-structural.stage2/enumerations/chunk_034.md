Enumeration Block 1:
གཉིས་པ་ཞིང་དུ་གསུངས་པའི་ལུང་འགལ་སྤང་བ་ནི།

Enumeration Block 2:
གསུམ་པ་ཧ་ཅང་ཐལ་བ་སྤང་བ་ལ་གསུམ་ལས།
དང་པོ་ཉིང་མཚམས་མི་སྦྱོར་བར་ཐལ་བ་སྤང་བ་ནི།

Enumeration Block 3:
གཉིས་པ་དགེ་སྡིག་མི་འབྱུང་བར་ཐལ་བ་སྤང་བ་ནི།

Enumeration Block 4:
གསུམ་པ་སྤྱོད་པ་དོན་མེད་དུ་ཐལ་བ་སྤང་བ་ནི།

Enumeration Block 5:
གཉིས་པ་དོན་དམ་ལ་བརྟེན་པའི་རྩོད་སྤང་ལ།
འཁྲུལ་པ་མེད་ན་སྒྱུ་མ་མི་དམིགས་པར་ཐལ་བ་སྤང་བ། འཁྲུལ་གཞི་མེད་ན་འཁོར་འདས་མི་འབྱུང་བར་ཐལ་བ་སྤང་བའོ།།
དང་པོ་ལ་རྒོལ་ལན་གཉིས་ལས།
དང་པོ་རྒོལ་བ་ནི།

Enumeration Block 6:
གཉིས་པ་ལན་ལ། མཚུངས་ཚུལ་མདོར་བསྟན།
བརྒལ་ལན་རྒྱས་པར་བཤད་པ། སྐབས་དོན་བསྡུ་བའོ།།
དང་པོ་ནི།

Enumeration Block 7:
གཉིས་པ་བརྒལ་ལན་ལ།
སྒྱུ་མ་སེམས་སུ་འདོད་པ་དགག་པ་དང༌། དོན་སེམས་གཉི་ག་མིན་པ་དགག་པའོ།།
དང་པོ་ལ་ལྔ་ལས།
དང་པོ་ལུང་དང་རིགས་པས་དགག་པ་ནི།

Enumeration Block 8:
གཉིས་པ་དཔེ་ལས་འཁྲུལ་པ་སྤང་བ་ནི།

Enumeration Block 9:
གསུམ་པ་སྒྲུབ་བྱེད་མངོན་སུམ་མེད་ཚུལ་ནི།

Enumeration Block 10:
བཞི་པ་རྗེས་དཔག་འདོད་པའང་དགག་པ་ནི།
