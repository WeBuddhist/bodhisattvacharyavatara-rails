Enumeration Block 1:
གཉིས་པ་བརྩོན་འགྲུས་ཀྱི་སྟོབས་སྤེལ་བ་ལ་གསུམ། བརྩོན་འགྲུས་ཀྱི་མཐུན་རྐྱེན་སྟོབས་སྤེལ་བ་དང༌། དྲན་པ་དང་ཤེས་བཞིན་གྱིས་སྤྱོད་པ་ཉམས་སུ་བླང་བ་ལྷུར་བྱ་བ་དང༌།
སྤྱོད་པ་བསྒྲུབ་པ་ལ་བདག་ཉིད་དབང་དུ་བྱ་བའོ། ། དང་པོ་ལ་གཉིས། སྟོབས་བཞི་ངོས་བཟུང་བའི་སྒོ་ནས་མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་བཞི། མོས་པའི་སྟོབས་དང༌། བརྟན་པའི་སྟོབས་དང༌། དགའ་བའི་སྟོབས་དང༌། དོར་བའི་སྟོབས་སོ། ། དང་པོ་ལ་བཞི། མོས་པའི་ཡུལ་དང༌། འབྲས་བུ་དང༌། མོས་པའི་རྒྱུ་དང། མཇུག་བསྡུ་བའོ། །

Enumeration Block 3:
དང་པོ་ལ་གསུམ། ཉེས་པ་དོར་བ་དང༌། ཡོན་ཏན་ལེན་པ་དང༌། བྱས་པ་དང་མ་བྱས་པའི་རྣམ་གྲངས་ལ་བརྟག་པའོ། །

Enumeration Block 4:
གཉིས་པ་མོས་པའི་འབྲས་བུ་ལ་གཉིས། ཆོས་ལ་མོས་པ་གཏོང་མི་རིགས་པ་དང༌། དེའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 5:
གསུམ་པ་མོས་པའི་རྒྱུ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། འདྲེས་མའི་ལས་འབྲས་བསམ་པ་དང༌། གཅིག་ཏུ་དཀར་བའི་ལས་འབྲས་བསམ་པ་དང༌། གནག་པའི་ལས་འབྲས་བསམ་པའོ། །

Enumeration Block 7:
གཉིས་པ་བརྟན་པའི་སྟོབས་ལ་གཉིས། བརྩོན་པ་བརྟན་པ་དང༌། བརྩམས་ནས་ཞུགས་པ་བརྟན་པར་བྱེད་པའོ། ། དང་པོ་ལ་གཉིས། ལེགས་པར་བརྟགས་ནས་རྩོམ་པ་དང༌། བརྩམས་ནས་དོར་བའི་ཉེས་དམིགས་སོ། །

Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། བསྡུས་ཏེ་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །

Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། ལས་ཀྱི་ང་རྒྱལ་དང༌། ནུས་པ་ལ་ང་རྒྱལ་བྱ་བ་དང༌། ཉོན་མོངས་པ་ལ་ང་རྒྱལ་བྱ་བའོ། །

Enumeration Block 10:
དང་པོ་ལ་གསུམ། ལས་ཀྱི་ང་རྒྱལ་ངོས་བཟུང་བ་དང༌། དེ་ལྟར་བྱེད་པའི་རྒྱུ་མཚན་དང༌། གཞན་གྱི་དམན་པའི་ལས་ལ་ཡང་ཁུར་འཛིན་པའི་ང་རྒྱལ་བྱ་བའོ། །

Enumeration Block 11:
གཉིས་པ་ལ་ལྔ། ནུས་པ་ལ་ང་རྒྱལ་མེད་པའི་ཉེས་པ་དང༌། ང་རྒྱལ་བྱས་པའི་ཕན་ཡོན་དང༌། གཉེན་པོའི་ང་རྒྱལ་ལ་གནས་པར་བྱ་བ་དང་། ཉོན་མོངས་པའི་ང་རྒྱལ་བྱ་བར་མི་རིགས་པ་དང༌།
གཉེན་པོའི་ང་རྒྱལ་གྱི་ཕན་ཡོན་ནོ། །
