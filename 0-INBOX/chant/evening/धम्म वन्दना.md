# धम्म वन्दना ^0

स्वाक्खातो भगवता धम्मो, ^1
सन्दिट्ठिको अकालिको। ^2
एहिपस्सिको ओपनयिको, ^3
पच्चत्तं वेदितब्बो विञ्ञूहीति। ^4
