# Termbase — English stream

One rendering per term, for `en/Days/`. Compiled from usage in days 1–31. Where the plan differs from a translation track, the plan wins inside `Days/` — this is a lay daily-practice text, not a scholarly translation.

**No diacritics anywhere in prose.** Shantideva, Manjushri, bodhicitta, Maitribala.

## Core terms — use by name, never paraphrase, never define

| Tibetan | English | Note |
|---|---|---|
| བྱང་ཆུབ་སེམས། | bodhicitta | Never "the mind of enlightenment", never "awakening mind". |
| བྱང་ཆུབ་སེམས་དཔའ། | bodhisattva | Lowercase. Not "Bodhisattva" mid-sentence, not "great being". |
| འཁོར་བ། | samsara | Not "the endless cycle", not "cyclic existence". |
| ལས། | karma | Singular. "Karmic result", not "karmas". |
| བསོད་ནམས། | merit | Not "positive energy" in §2. Days 15–25 use "positive energy" in §3; acceptable there, but prefer merit. |
| སྐྱབས་འགྲོ། | refuge / going for refuge | |
| དཀོན་མཆོག་གསུམ། | the Three Jewels | Gloss once per file: (Buddha, Dharma, and Sangha). |
| ཆོས། | Dharma | Capital D when the teaching; "dharma" lowercase only inside a quoted verse that has it so. |
| དགེ་འདུན། | Sangha | |

## Terms needing a one-clause gloss on first use

| Tibetan | English | Gloss |
|---|---|---|
| བར་དོ། | bardo | the state between death and the next life |
| ངན་སོང། | the lower realms | — |
| བག་ཆགས། | a latent imprint | what an action leaves on the mind |
| ཉོན་མོངས། | the afflictions | — |
| གཤིན་རྗེ། | Yama / the Lord of Death | Match whichever the verse uses. |
| སྟོབས་བཞི། | the four powers | regret, reliance, applying the antidotes, and restraint |
| སུན་འབྱིན་པའི་སྟོབས། | the power of regret | first of the four |

## Avoid

| Do not write | Write instead |
|---|---|
| the god realms | the heavens |
| cyclic existence | samsara |
| negative karma / demerit | misdeeds, wrongdoing |
| sentient beings (in prose) | beings, people |
| Bodhisattva Shantideva | Master Shantideva, then Shantideva |
| the endless cycle of rebirth | samsara |
| His Holiness the 14th Dalai Lama | His Holiness the Dalai Lama, then the Dalai Lama |
