Enumeration Block 1:
འདི་ལ་མི་འཐད་པའི་ཕྱོགས་དང༌། འཐད་པའི་ཕྱོགས་དང༌། ཀླན་ཀ་སྤང་བའོ། །

Enumeration Block 2:
འདིར་སེམས་བསྐྱེད་ནི་གཉིས་ཏེ། དབུ་མ་ལུགས་དང༌། སེམས་ཙམ་ལུགས་ཀྱི་སེམས་བསྐྱེད་དོ། །

Enumeration Block 3:
སྤྱིར་མི་འཐད་པ་དང་། ཁྱད་པར་དུ་མི་འཐད་པའི་ཕྱིར་རོ། །

Enumeration Block 4:
བླང་བྱ་ཡུལ་གྱི་ཁྱད་པར། ལེན་པ་པོ་གང་ཟག་གི་ཁྱད་པར། ལེན་བྱེད་ཆོ་གའི་ཁྱད་པར། མི་ཉམས་པར་བསྲུང་བའི་ཁྱད་པར་རོ། །

Enumeration Block 5:
ཉན་ཐོས་པ་རྣམས་ཀྱི་སོ་སོ་ཐར་པ་དང༌། ཐེག་ཆེན་པ་རྣམས་ཀྱི་སོ་སོ་ཐར་པའོ། །དང་པོ་ལ་མི་འཐད་པའི་ཕྱོགས་དང༌། འཐད་པའི་ཕྱོགས་སོ། །

Enumeration Block 6:
ཐེག་ཆེན་གྱི་རྒྱུད་ཀྱི་སོ་སོ་ཐར་པའི་སྡོམ་པ་ལ་ཡང་། མི་འཐད་པའི་ཕྱོགས་དང༌། འཐད་པའི་ཕྱོགས་སོ། །

Enumeration Block 7:
བྱང་སེམས་སོ་སྐྱེའི་སོ་སོ་ཐར་པ་དང༌། ཐེག་ཆེན་འཕགས་པའི་སོ་སོ་ཐར་པའོ། །དང་པོ་ལ་གསུམ་སཏེ། ལེན་བྱེད་ཆོ་གའི་ཁྱད༌པར༌དང༌། མི་ཉམས་པར་བསྲུང༌བའི་ཁྱད་པར་དང༌། ཉམས་ན་ཕྱིར་བཅོས་པའི་ཁྱད་པར་རོ། །
