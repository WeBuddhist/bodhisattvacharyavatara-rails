Enumeration Block 1:
ཐོབ་ཚུལ་གྱི་སྒོ་ནས་བརྡ་ལས་ཐོབ་པ་དང༌། ཆོས་ཉིད་ཀྱིས་ཐོབ་པའི་སེམས་བསྐྱེད་གཉིས་སོ། །

Enumeration Block 2:
ཚེ་འདིར་ཐོས་བསམ་སོགས་དགེ་བ་ཡང་ཡང་གོམས་པའི་སྟོབས་ལས་བྱུང་བ་སྟེ་ལྔ་ལས།
དང་པོ་ནི་མི་བརྟན་པ། ལྷག་མ་བཞི་ནི་བརྟན་པའོ། །

Enumeration Block 3:
དེ་ཡང་ཁྱད་པར་དྲུག་སྟེ།

Enumeration Block 4:
འདིར་དོན་དམ་སེམས་བསྐྱེད་ནི་གཉིས་ཏེ།
དང་པོ་མ་སྐྱེས་པ་གསར་དུ་སྐྱེས་པའི་སེམས་བསྐྱེད་དང༌། སྐྱེས་པ་རྒྱུན་དུ་ལྡན་པའི་དོན་དམ་སེམས་བསྐྱེད་དོ། །

Enumeration Block 5:
ས་མཚམས་ཀྱི་སྒོ་ནས་རྣམ་པ་བཞི་སྟེ།
བྱང་སེམས་སོ་སོ་སྐྱེ་བོའི་སེམས་བསྐྱེད་དང་། མ་དག་པའི་སེམས་བསྐྱེད་དང་། དག་པའི་སེམས་བསྐྱེད་ང་། སངས་རྒྱས་ཀྱི་སའི་སེམས་བསྐྱེད་དོ། །

Enumeration Block 6:
ཡང་ཀུན་རྫོབ་སེམས་བསྐྱེད་དམ། བརྡ་ལས་བྱུང་བའི་སེམས་བསྐྱེད་ལ། ངོ་བོའི་སྒོ་ནས་དབྱེ་ན། སྨོན་པ་དང་འཇུག་པའི་སེམས་བསྐྱེད་གཉིས་སོ། །

Enumeration Block 7:
འདི་ལ་མི་འཐད་པའི་ཕྱོགས་དང༌། འཐད་པའི་ཕྱོགས་དང་ཀླན་ཀ་སྤང་བའོ། །མི་འཐད་པའི་ཕྱོགས་གང་ཞེ་ན། དམིགས་པ་དང༌། གྲོགས་དང༌། བསམ་སྦྱོར་དང༌། ཆོ་ག་དང༌། ངོ་བོའི་ཁྱད་པར་གཞན་དུ་འདོད་པའོ། །

Enumeration Block 8:
བྱང་ཆུབ་ཀྱི་སེམས་དེ་ནི་རྣམ་པ་གཉིས་ཏེ། བྱང་ཆུབ་ཏུ་སྨོན་པའི་སེམས་དང༌།
བྱང་ཆུབ་ཏུ་འཇུག་པའི་སེམས་སོ། །
