Enumeration Block 1:
གསུམ་པ་གཞན་དོན་ལ་བསམས་ན་ལེགས་ཚུལ་ནི།

Enumeration Block 2:
བཞི་པ་ལུས་ལ་ཞེན་ན་འཆིང་ཚུལ་ནི།

Enumeration Block 3:
ལྔ་པ་ལྟོས་པ་མེད་ན་ལེགས་ཚུལ་ནི།

Enumeration Block 4:
དྲུག་པ་བརྟགས་ཏེ་ཆགས་ཞེན་སྤང་ཚུལ་ནི།

Enumeration Block 5:
བདུན་པ་དེས་ན་བཏང་ཞིང་བསྲུང་ཚུལ་ནི།

Enumeration Block 6:
གཉིས་པ་དོན་དམ་བྱང་ཆུབ་ཀྱི་སེམས་བསྒོམ་པ་ལ་གསུམ་ལས།
དང་པོ་བྱིས་པའི་སྤྱོད་པ་སྤང་ཚུལ་ནི།

Enumeration Block 7:
གཉིས་པ་རིགས་པས་བསྟན་པར་བྱེད་ཚུལ་ནི།

Enumeration Block 8:
གསུམ་པ་མཉམ་བཞག་ཟབ་མོ་བསྒོམ་ཚུལ་ནི།

Enumeration Block 9:
ད་ནི་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཉམས་སུ་བླང་ཚུལ་ལ་སྤྱི་དོན་བཞི་སྟེ།
བྱེད་ལས་མཚན་ཉིད་དབྱེ་བ་ཕན་ཡོན་ནོ། །
དང་པོ་བྱེད་ལས་ནི།

Enumeration Block 10:
གཉིས་པ་མཚན་ཉིད་ནི།

Enumeration Block 11:
གསུམ་པ་དབྱེ་བ་ལ་གཉིས་ལས།
དང་པོ་ཐུན་མོང་གི་དབྱེ་བ་ནི།

Enumeration Block 12:
གཉིས་པ་ཁྱད་པར་གྱི་དབྱེ་བ་ལ།
བདེན་གཉིས་ཤེས་པའི་ཤེས་རབ་དང༌། གྲུབ་མཐའ་ཤེས་པའི་ཤེས་རབ་དང༌། སྟོང་ཉིད་ཤེས་པའི་ཤེས་རབ་བོ། །
དང་པོ་ལ།
བདེན་གཉིས་ཀྱི་རང་བཞིན། མ་ཤེས་པའི་ཉེས་དམིགས། ཤེས་པའི་ཕན་ཡོན་ནོ། །
དང་པོ་ལ།
ངོ་བོ། དབྱེ་བ། ཐ་དད། གྲངས་ངེས། མིང་དོན། བསྒོམ་ཚུལ། འཁྲུལ་སྤོང་ངོ༌། །
དང་པོ་ངོ་བོ་ལ།

Enumeration Block 13:
གཉིས་པ་དབྱེ་བ་ནི།
