Enumeration Block 1:
དང་པོ་ལ་ལྔ་ལས།
Enumeration Block 2:
དང་པོ་ངེས་པར་འཆི་བ་བསམས་ཏེ་ལེ་ལོ་སྤང་བ་ནི།
Enumeration Block 3:
གཉིས་པ་མྱུར་དུ་འཆི་བ་བསམ་སྟེ་ལེ་ལོ་སྤང་ཚུལ་ནི།
Enumeration Block 4:
གསུམ་པ་དམྱལ་བའི་སྡུག་བསྔལ་བསམས་ཏེ་ལེ་ལོ་སྤང་བ་ནི།
Enumeration Block 5:
བཞི་པ་ཉེས་པ་གཞན་ཡང་བསམས་ཏེ་ལེ་ལོ་སྤང་པ་ནི།
Enumeration Block 6:
ལྔ་པ་དལ་འབྱོར་དཀོན་པ་བསམས་ཏེ་ལེ་ལོ་སྤང་བ་ནི།
Enumeration Block 7:
གཉིས་པ་ངན་ཞེན་གྱི་ལེ་ལོ་སྤང་བ་ནི།
Enumeration Block 8:
གསུམ་པ་སྒྱིད་ལུག་པའི་ལེ་ལོ་སྤང་བ་ལ་གཉིས་ལས།
Enumeration Block 9:
དང་པོ་མདོར་བསྟན་ནི།
Enumeration Block 10:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས་ལས།
Enumeration Block 11:
དང་པོ་འབྲས་བུ་བྱང་ཆུབ་ལ་སྒྱིད་ལུག་སྤང་པ་ནི།
Enumeration Block 12:
གཉིས་པ་རྒྱུའི་དཀའ་སྤྱད་ལ་འཇིགས་པ་སྤང་པ་ལ་བཞི་ལས།
Enumeration Block 13:
དང་པོ་ཁྱད་པར་བསམས་ཏེ་འཇིགས་པ་སྤང་བ་ནི།
Enumeration Block 14:
གཉིས་པ་གོམས་པར་བྱས་ན་དཀའ་བ་མེད་ཚུལ་ནི།
Enumeration Block 15:
གསུམ་པ་འཁོར་བར་གནས་ཀྱང་སྐྱོ་བ་སྤང་པ་ནི།
Enumeration Block 16:
བཞི་པ་ཕན་ཡོན་བསམས་ཏེ་སྒྱིད་ལུག་སྤང་ཚུལ་ནི།
Enumeration Block 17:
གཉིས་པ་གསུམ་པགཉེན་པོ་ལའང་གཉིས་ལས།
དང་པོ་མདོར་བསྟན་ནི།
Enumeration Block 18:
གཉིས་པ་རྒྱས་བཤད་ལ།
དཔུང་ཚོགས་བསྐྱེད་པ་དང༌། བརྩོན་འགྲུས་སྤེལ་བའོ། །
དང་པོ་ལ།
འདུན་པ་དང༌། བརྟན་པ་དང༌། དགའ་བ་དང༌། དོར་བའི་དཔུང་ཚོགས་བསྐྱེད་པའོ། །
དང་པོ་འདུན་པ་ལའང༌།
འདུན་པ་མེད་ན་དོན་གཉིས་ཉམས་ཚུལ། འདུན་པ་ཆོས་ཀྱི་རྩ་བར་གསུངས་ཚུལ། དེའི་ཡང་རྩ་བ་ལས་འབྲས་བསམ་པ། དེས་ན་འདུན་པ་བསྐྱེད་པར་གདམས་པའོ། །
