Enumeration Block 1:
གསུམ་པ་ཕན་གནོད་ཀྱི་ཞིང་ལ་བསམ་སྟེ་ཡང་སེམས་ཅན་ལ་གུས་པར་བྱ་བ་ནི།

Enumeration Block 2:
གཉིས་པ་ལེའུའི་མཚན་བསྟན་པ་ནི།

Enumeration Block 3:
གསུམ་པ་བྱང་ཆུབ་ཀྱི་སེམས་མི་ཉམས་པར་གོང་ནས་གོང་དུ་སྤེལ་བར་བྱེད་པའི་ལེའུ་ལ་གསུམ་ཡོད་པ་ལས། དང༌པོ་བྱང་ཆུབ་ཀྱི་སེམས་སྤེལ་བའི་གྲོགས་བརྩོན་འགྲུས་ཀྱི་ལེའུ་ལ་རྣམ་པ་གཉིས་ཏེ།
ལེའུའི་གཞུང་དང༌། ལེའུའི་མཚན་ནོ། །
དང་པོ་ལ་གཉིས། བརྩོན་འགྲུས་རྩོམ་དགོས་པའི་རྒྱུ་མཚན་མདོར་བསྟན་པ་དང༌། བརྩོན་འགྲུས་ཇི་ལྟར་བརྩམ་པའི་ཚུལ་རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 4:
གཉིས་པ་བརྩོན་འགྲུས་ཇི་ལྟར་བརྩམ་པའི་ཚུལ་རྒྱས་པར་བཤད་པ་ལ། བརྩོན་འགྲུས་ཀྱི་ངོ་བོ་ངོས་གཟུང་བ་དང་། བརྩོན་འགྲུས་ཀྱི་མི་མཐུན་ཕྱོགས་སྤོང་བ་གདམས་པ་དང༌། མཐུན་ཕྱོགས་སྒྲུབ་པ་དང་གསུམ།

Enumeration Block 5:
གཉིས་པ་ལ་དེའི་མི་མཐུན་ཕྱོགས་སྤོང་བའི་ཚུལ་བསྟན་པ་ལ་གཉིས་ཏེ། ལེ་ལོ་རྒྱུ་འབྲས་དང་བཅས་པ་ངོས་བཟུང་བ་དང་། དེ་དག་ཇི་ལྟར་སྤོང་བའི་གཉེན་པོ་བཤད་པའོ། །

Enumeration Block 6:
གཉིས་པ་དེ་དག་ཇི་ལྟར་སྤོང་བར་བྱེད་པའི་གཉེན་པོ་བཤད་པ་ལ་གསུམ། སྙོམ་ལས་འཛིན་པའི་ལེ་ལོའི་གཉེན་པོ་བསྟན་པ་དང༌། བྱ་བ་ངན་ཞེན་གྱི་ལེ་ལོའི་གཉེན་པོ་བསྟན་པ་དང༌།
