Enumeration Block 1:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གཉིས་ཏེ། མཚན་ཉིད་དང༌། བྱ་བ་བཤད་པའོ། །དང་པོ་ལ་བཞི་ལས་དང་པོ་གཞན་བླང་བའི་མཚན་ཉིད་ལ་གསུམ་གྱི་དང་པོ་

Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ་ཕན་ཡོན་ནི་

Enumeration Block 3:
གསུམ་པ་དོན་གྱི་སྒོ་ནས་བསྡུ་བ་ལ་གཉིས་ལས་དང་པོ་

Enumeration Block 4:
གཉིས་པ་བདག་དོར་བའི་མཚན་ཉིད་ལ་གསུམ་གྱི་དང་པོ་

Enumeration Block 5:
གསུམ་པ་བདག་གཞན་གཙོ་བོར་བྱེད་པའི་སྐྱོན་དང་ཡོན་ཏན་ལ་གཉིས་ལས་དང་པོ་

Enumeration Block 6:
གཉིས་པ་བདག་གཙོ་བོར་བྱེད་པའི་ཉེས་པ་ལ་གཉིས་ལས་དང་པོ་

Enumeration Block 7:
བཞི་པ་སྐབས་ཀྱི་དོན་བསྡུ་བ་ལ་བསམ་སྦྱོར་གཉིས་ལས་དང་པོ་ནི་

Enumeration Block 8:
གཉིས་པ་ལ་གཉིས་ལས་དང་པོ་

Enumeration Block 9:
གཉིས་པ་བརྗེས་པའི་བྱ་བ་བཤད་པ་ལ་བསམ་སྦྱོར་གཉིས་ལས་དང་པོ་ལ་གསུམ་གྱི་དང་པོ་

Enumeration Block 10:
གཉིས་པ་བཤད་པ་ལ་བཞི་ལས་དང་པོ་མཐོ་བ་ལ་ཕྲག་དོག་སྒོམ་པ་ལ་གསུམ་གྱི་དང་པོ་

Enumeration Block 11:
གཉིས་པ་མཉམ་པ་ལ་འགྲན་སེམས་བསྒོམ་པ་ལ་གཉིས་ལས་དང་པོ་

Enumeration Block 12:
གསུམ་པ་དམ་པ་ལ་ང་རྒྱལ་སྒོམ་པ་ལ་གཉིས་ལས་དང་པོ་

Enumeration Block 13:
གསུམ་པ་བསྡུ་བ་ལ་གསུམ་གྱི་དང་པོ་

Enumeration Block 14:
གཉིས་པ་སྦྱོར་བས་བསྒྲུབ་པའི་བྱ་བ་ལ་གཉིས་ལས་དང་པོ་སྦྱོར་བས་སྒྲུབ་ཚུལ་ལ་གཉིས་ཀྱི་དང་པོ་

Enumeration Block 15:
གཉིས་པ་སྦྱོར་བ་ལ་སེམས་དབང་དུ་བྱ་བ་ལ་གསུམ་ལས་དང་པོ་གཉེན་པོ་དབང་དུ་བྱ་བ་ལ་བསྟན་བཤད་བསྡུ་བ་གསུམ་གྱི་དང་པོ་ནི་

Enumeration Block 16:
གསུམ་པ་གཉེན་པོའི་ཐབས་ལ་མཁས་པར་བྱ་བ་ལ་བསྟན་བཤད་གཉིས་ལས་དང་པོ་ནི་

Enumeration Block 17:
གཉིས་པ་ལ་གཉིས་ཏེ། ལུས་བདག་ཉིད་ལ་མི་མཁོ་བར་བརྟག་པ་དང༌། གཞན་དོན་དུ་གཟུང་བའི་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས་ལས་དང་པོ་ལུས་སྐྱོང་བའི་ཉེས་དམིགས་ལ་དེས་སྡུག་བསྔལ་འཕེལ་བ་དང༌། ཞར་ལ་ཆོག་ཤེས་པའི་ཕན་ཡོན་གཉིས་ལས། དང་པོ་ནི་

Enumeration Block 18:
གཉིས་པ་ལུས་ལ་བདག་གིར་འཛིན་པ་མི་རིགས་པ་ལ་གཉིས་ལས་དང་པོ་

Enumeration Block 19:
གཉིས་པ་བྱེ་བྲག་ཏུ་བྱས་པ་མི་ཤེས་པ་ལ་བསྟན་བཤད་གཉིས་ལས་དང་པོ་ནི་

Enumeration Block 20:
གསུམ་པ་ཐུན་མོང་གི་བྱ་བ་གདམས་པ་གཉིས་ལས་དང་པོ་
