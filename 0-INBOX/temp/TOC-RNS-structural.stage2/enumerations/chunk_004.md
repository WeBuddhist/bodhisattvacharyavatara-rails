Enumeration Block 1:
དང་པོ་ལ་གཉིས་ལས།

Enumeration Block 2:
ཕན་ཡོན་ཅན་ཇི་ལྟར་བླང་ཚུལ་ལ་གསུམ་སྟེ།
སྦྱོར་བ་ཡན་ལག་བདུན་པ་བྱ་བ། དངོས་གཞི་བྱང་ཆུབ་སེམས་བསྐྱེད་གཟུང་བ། མཇུག་ཏུ་ཇི་ལྟར་བྱ་བའི་རིམ་པའོ།།

Enumeration Block 3:
མཆོད་བསྟོད་ལ། མཆོད་པ་དབུལ་བ་དང༌། བསྟོད་དབྱངས་བསྒྲག་པའོ།།

Enumeration Block 4:
དང་པོ་ལ། མདོར་བསྟན།
རྒྱས་བཤད།
དོན་བསྡུ་གསུམ་ལས།

Enumeration Block 5:
གཉིས་པ་རྒྱས་བཤད་ལ། ཡིད་ཀྱི་མཆོད་པ། ལུས་ཀྱི་མཆོད་པ། འབྱོར་བའི་མཆོད་པའོ།།
དང་པོ་ལ་གསུམ་ལས།

Enumeration Block 6:
གཉིས་པ་ལུས་ཀྱི་མཆོད་པ་ལ་གཉིས་ལས།

Enumeration Block 7:
གསུམ་པ་འབྱོར་བའི་མཆོད་པ་ལ།
ཁྲུས་དང་དབྱི་བ་གོས་རྒྱན་དྲི་བཟང་དང༌།།
མེ་ཏོག་བདུག་སྤོས་ཞལ་ཟས་སྣང་གསལ་དང༌།།
ས་གཞི་ཕོ་བྲང་གདུགས་ཀྱི་མཆོད་པ་དང༌།།
རོལ་མོ་དབུལ་ཞིང་སྨོན་ལམ་གདབ་པའོ།།
