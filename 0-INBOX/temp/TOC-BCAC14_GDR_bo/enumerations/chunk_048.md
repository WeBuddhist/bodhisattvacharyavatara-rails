Enumeration Block 1:
ལེའུ་བཅུ་པ། བསྔོ་བ། བཞི་པ་ལུས་ལོངས་སྤྱོད་དགེ་རྩ་གཞན་དོན་དུ་གཏོང་བའི་སྦྱིན་པ་ལ་སློབ་ཚུལ་བསྔོས་པའི་ཡན་ལག་གི་སྒོ་ནས་བཤད་པ་ལ་གཉིས། ལེའུའི་གཞུང་བཤད་པ་དང༌། ལེའུའི་མཚན་ནོ། །

Enumeration Block 2:
དང་པོ་ལ་གསུམ། འགྲོ་བ་ཀུན་བྱང་ཆུབ་སེམས་དཔའི་སྤྱོད་པ་ལ་འཇུག་པར་བསྔོ་བས་མདོར་བསྟན་པ་དང༌། བསྔོ་བ་རྒྱས་པར་བཤད་པ་དང༌། བཀའ་དྲིན་རྗེས་སུ་དྲན་པས་ཕྱག་འཚལ་བའོ། །

Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། གཞན་དོན་དུ་བསྔོ་བ་དང༌། རང་དོན་དུ་བསྔོ་བ་དང༌། བདེ་བའི་འབྱུང་གནས་བསྟན་པ་རྒྱས་པའི་དོན་དུ་བསྔོ་བའོ། །

Enumeration Block 4:
དང་པོ་ལ་གཉིས། འཇིག་རྟེན་པའི་དོན་དུ་བསྔོ་བ་དང༌། འཇིག་རྟེན་ལས་འདས་པའི་དོན་དུ་བསྔོ་བའོ། །

Enumeration Block 5:
དང་པོ་ལ་བཞི། ནད་པ་སོགས་ཀྱི་སྡུག་བསྔལ་ཞི་བའི་དོན་དུ་བསྔོ་བ་དང༌། ངན་འགྲོའི་སྡུག་བསྔལ་ཞི་བའི་དོན་དུ་བསྔོ་བ་དང༌། བདེ་འགྲོའི་དོན་དུ་བསྔོ་བ་དང༌།
སེམས་ཅན་ཀུན་གྱི་དོན་དུ་བསྔོ་བ་བསྡུས་ཏེ་བསྟན་པའོ། ། དང་པོ་ལ་གཉིས། གནས་སྐབས་ཀྱི་བདེ་བའི་དོན་དུ་བསྔོ་བ་དང༌། མཐར་ཐུག་གི་བདེ་བའི་དོན་དུ་བསྔོ་བའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། དམྱལ་བའི་སྡུག་བསྔལ་ཞི་བ་དང༌། དུད་འགྲོ་དང༌། ཡི་དྭགས་ཀྱི་དོན་དུ་བསྔོ་བའོ། །

Enumeration Block 7:
དང་པོ་ལ་གཉིས། སྡུག་བསྔལ་མྱུར་དུ་ཞི་བར་བསྔོ་བ་དང༌། གཞན་གྱི་མཐུས་ཞི་བར་བསྔོ་བའོ། །

Enumeration Block 8:
དང་པོ་ལ་གསུམ། སྡུག་བསྔལ་སྤྱིར་ཞི་བར་བསྔོ་བ་དང༌། གྲང་དམྱལ་གྱི་སྡུག་བསྔལ་ཞི་བ་དང༌། ཚ་དམྱལ་གྱི་སྡུག་བསྔལ་ཞི་བར་བསྔོ་བའོ། །

Enumeration Block 9:
གསུམ་པ་ལ་བཞི། བྱང་ཆུབ་སེམས་དཔའི་ཚོགས་གཉིས་ཀྱི་སྤྲིན་ལས་བྱུང་བའི་ཆུས་སྡུག་བསྔལ་ཞི་བར་བསྔོ་བ་དང༌། ཉེ་འཁོར་བའི་སྡུག་བསྔལ་ཞི་བ་དང༌། དམྱལ་བའི་གནས་དངོས་གཞི་དང༌།
ཉེ་འཁོར་བའི་སྡུག་བསྔལ་གཞན་ཞི་བར་བསྔོ་བའོ། །
