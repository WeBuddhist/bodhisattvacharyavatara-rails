Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། མདོ་སྡེ་པ་ལ་སོགས་པའི་དངོས་སྨྲ་བ་སྤྱིར་དགག་པ་དང༌། སེམས་ཙམ་པའི་འདོད་པ་བྱེ་བྲག་ཏུ་དགག་པ་དང༌།
སྟོང་ཉིད་རྟོགས་པའི་ལམ་དབུ་མ་པ་ལ་དགོས་ནུས་མེད་པར་ཐལ་བ་སྤང་བའོ། ། དང་པོ་ལ་གཉིས། མངོན་སུམ་གྱིས་གནོད་པ་དགག་པ་དང༌། ལུང་གིས་གནོད་པ་དགག་པའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་གསུམ། འདུས་བྱས་མི་རྟག་པ་སོགས་སུ་སྟོན་པའི་ལུང་དྲང་དོན་དུ་བསྟན་པ་དང༌། ངེས་དོན་ཡིན་པ་དགག་པ་དང༌། དེ་ལ་འགལ་བ་སྤང་བའོ། །

Enumeration Block 3:
གསུམ་པ་ལ་ལྔ། ཀུན་རྫོབ་ཏུ་ཡང་མ་གྲུབ་པ་སྤང་བ་དང༌། ཚོགས་གསོག་པ་མི་འཐད་པ་སྤང་བ་དང༌། ཉིང་མཚམས་སྦྱོར་བ་མི་འཐད་པ་སྤང་བ་དང༌། དགེ་སྡིག་གི་རྣམ་དབྱེ་མི་འཐད་པ་སྤང་བ་དང༌།
འཁོར་འདས་ཀྱི་རྣམ་དབྱེ་སོ་སོར་ངེས་པ་མི་འཐད་པ་སྤང་བའོ། །

Enumeration Block 4:
གཉིས་པ་སེམས་ཙམ་པའི་འདོད་པ་བྱེ་བྲག་ཏུ་དགག་པ་ལ་འདོད་པ་བརྗོད་པ་དང༌། དེ་དགག་པའོ། །

Enumeration Block 5:
གཉིས་པ་ལ་རྩོད་པ་མཚུངས་པ་དང། དེའི་ལན་དགག་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་འདོད་པ་བརྗོད་པ་དང༌། དེ་དགག་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ། གཉིས་མེད་ཀྱི་ཤེས་པ་གང་གིས་ཀྱང་མ་མཐོང་བ་དང༌། དྲིས་པའི་ལན་གྱི་རང་རིག་དགག་པའོ། །

Enumeration Block 8:
གཉིས་པ་རང་རིག་དགག་པ་ལ། ཤེས་པ་འདི་ལ་ཁ་ཕྱིར་ཕྱོགས་གཟུང་བའི་རྣམ་པ་དང༌།
ནང་ཁོ་ནར་ཕྱོགས་པའི་འཛིན་པའི་རྣམ་པ་གཉིས་ཡོད་ལ་ཕྱི་མ་རང་རིག་པའི་མངོན་སུམ་ཡིན་པས་དེས་ཤེས་པ་ཐམས་ཅད་དམིགས་པ་ཡིན་ནོ་ཞེ་ན།
དེ་ལ་ལུང་གིས་དགག་པ་དང༌། རིགས་པས་དགག་པ་དང༌། རང་རིག་ཡོད་པའི་སྒྲུབ་བྱེད་དགག་པ་དང༌། བཏགས་ཡོད་རྣམས་དངོས་པོ་བདེན་གྲུབ་ཀྱི་རྟེན་ཅན་དུ་འདོད་པ་དགག་པའོ། །

Enumeration Block 9:
གཉིས་པ་ལ། དཔེ་དགག་པ་དང༌། དོན་དགག་པའོ། །
