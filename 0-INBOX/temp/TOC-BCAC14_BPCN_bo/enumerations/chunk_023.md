Enumeration Block 1:
མཚན་ཉིད་དབྱེ་བསྡུ་སྐྱོན་ཡོན་དང༌། །
ཉམས་ལེན་རྣམ་ངེས་ཁྱད་པར་དང༌། །
གྲངས་དང་གོ་རིམ་ངེས་ཚིག་གོ །

Enumeration Block 2:
སྦྱིན་པ་ལ་གསུམ་ལས།

Enumeration Block 3:
ཕྱི་ལ་གསུམ་སྟེ། བསམ་པ་དང་སྦྱོར་བ་དང་རྗེས་ཀྱི་བྱ་བའོ། །

Enumeration Block 4:
བསམ་པ་ལ་འདི་ལྟར། ཡོ་བྱད་མཆོག་སློང་བ་ལ་གསུམ་སྟེ།

Enumeration Block 5:
ནང་གི་གཏོང་ཚུལ་ལ་ཡང་བསམ་སྦྱོར་རྗེས་གསུམ་ལས།

Enumeration Block 6:
གཉིས་ཀའི་སྦྱིན་པ་གཏོང་ཚུལ་ལ་ཡང་གསུམ་ལས།
