Enumeration Block 1:
སེམས་བསྲུང་བའི་ཐབས་སུ་དྲན་པ་དང་ཤེས་བཞིན་བསྲུང་བ་ལ་གསུམ་སྟེ། མདོར་བསྟན་པ་དང༌། ཤེས་བཞིན་མེད་པའི་ཉེས་པ་དང༌། ཤེས་བཞིན་བསྲུང་བའི་ཐབས་སུ་བསྲུང་བའོ། །

Enumeration Block 2:
གཉིས་པ་ལ་ལྔ་སྟེ། བྱ་བ་ལ་མཐུ་ཆུང་བ་དང༌། ཤེས་རབ་ཕུན་སུམ་ཚོགས་པར་མི་འགྱུར་བ་དང༌། ཚུལ་ཁྲིམས་ཕུན་སུམ་ཚོགས་པར་མི་འགྱུར་བ་དང༌། བསགས་པའི་དགེ་བ་འཇིགས་པ་དང༌། བསགས་པའི་དགེ་བ་མི་འགྲུབ་པའོ། །

Enumeration Block 3:
ཤེས་བཞིན་བསྲུང་བའི་ཐབས་སུ་དྲན་པ་བསྲུང་བ་ལ་འབད་པ་ལ་གསུམ་སྟེ། དངོས་གྱི་དོན་བརྗོད་པ་དང༌། དེའི་རྒྱུ་བསྟན་པ་དང༌། དྲན་པ་ལས་ཤེས་བཞིན་ངེས་པར་སྐྱེ་བའི་ཚུལ་ལོ། །

Enumeration Block 4:
གཉིས་པ་ནི་གཉིས་ཏེ། ཉམས་པའི་ཉེས་པ་ཡིད་ལ་བྱ་བ་དང༌། མི་ཉམས་པའི་རྐྱེན་བསྟེན་པའོ། །

Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་སྟེ། ཕྱིའི་རྐྱེན་དགེ་བའི་བཤེས་གཉེན་བསྟེན་པ་དང༌། ནང་གི་རྐྱེན་ཚུལ་བཞིན་དུ་ཡིད་ལ་བྱེད་པ་དང༌། དེའི་ཕན་ཡོན་གཞན་བསྟན་པའོ། །

Enumeration Block 6:
འདི་ལ་གསུམ་སྟེ། སྡོམ་པའི་སྤྱོད་པ་ལ་བསླབ་པ་དང༌། དགེ་བ་བསྡུ་བའི་སྤྱོད་པ་ལ་བསླབ་པ་དང༌། སེམས་ཅན་གྱི་དོན་བྱེད་པའི་སྤྱོད་པ་ལ་བསླབ་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། རང་བཞིན་ལ་སྦྱར་བ་དང༌། ཉམས་པ་བསྲུང་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། ལུས་ལ་རང་བཞིན་མེད་པར་སྦྱར་བ་དང༌། སེམས་ལ་རང་བཞིན་མེད་པར་སྦྱར་བ་དང༌། རང་བཞིན་ལས་འདའ་བར་གནང་བའི་དུས་སོ། །དང་པོ་ལ་བཞི་སྟེ། རེ་ཞིག་རྣལ་དུ་བཞག་པ་དང༌། ལྟ་བ་དང་འབྲེལ་པ་དང༌། དེ་ལས་གཞན་དང་འབྲེལ་པ་དང༌། འབྱུང་བར་འགྱུར་བའི་བྱ་བ་ལ་བརྟག་པ་ལ་ལེགས་པར་བསྒྲུབ་པའོ། །

Enumeration Block 7:
རང་བཞིན་ལས་འདའ་བར་གནང་བའི་དུས་ལ་ལུས་ཀྱི་སྤྱོད་པ་རང་བཞིན་ལས་འདའ་བར་གནང་བའི་དུས་དང༌། དེ་ལ་ཤེས་བྱེད་དགོད་པ་དང༌། རྩོད་པ་སྤང་བ་དང༌། དེ་ལྟར་བྱས་པའི་ཡོན་ཏན་དང༌། མ་བྱས་པའི་ཉེས་པ་དང༌། སྐབས་བསྡུ་བ་དྲུག་གོ །

Enumeration Block 8:
ཉམས་པ་བསྲུང་བ་ལ་གཉིས་ཏེ། ལུས་ཀྱི་སྡོམ་པ་ཉམས་པ་བསྲུང་བ་དང༌། སེམས་ཀྱི་སྡོམ་པ་ཉམས་པ་བསྲུང་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། གཡེང་བའི་རྐྱེན་གྱིས་མི་འཕྲོགས་པར་བྱ་བ་དང༌། ཀུན་སློང་གི་བསམ་པས་བརྟག་པའོ། །

Enumeration Block 9:
སེམས་ཀྱི་སྡོམ་པ་ཉམས་པ་བསྲུང་བ་ལ་གཉིས་ཏེ། གཉེན་པོའི་རང་བཞིན་དང༌། དེ་ལ་ཇི་ལྟར་སྦྱོར་བ་མདོར་བརྗོད་པའོ། །

Enumeration Block 10:
དགེ་བ་བསྒྲུབ་པ་ལ་བག་བྱ་བ་ལ་གཉིས་ཏེ། ལུས་ལ་མ་ཆགས་པར་བསྒྲུབ་པ་དང༌། དགེ་བ་བསྒྲུབ་པའི་ཐབས་ལ་བསླབ་པའོ། །དང་པོ་ལ་ལྔ་སྟེ། གཡོ་བ་མེད་པ་དང༌། མི་གཙང་བ་དང༌། སྙིང་པོ་མེད་པ་དང༌། མི་མཁོ་བ་དང༌། དེས་ན་ཉེ་བར་མཁོ་བ་ལ་སྦྱར་བའོ། །
