Enumeration Block 1:
གསུམ་པ་སྤྱོད་པ་བསྒྲུབ་པ་ལ་བདག་ཉིད་དབང་དུ་བྱ་བ་ལ་གཉིས། ལུས་སེམས་ཤིན་ཏུ་སྦྱངས་པས་དགེ་བ་ལ་ལྡང་བ་ཡང་བར་བྱ་བ་དང༌། དཔེ་དོན་སྦྱར་བའོ། །

Enumeration Block 2:
དང་པོ་ལ་ཡང་གཉིས་ཏེ་ད་དུང་ལོང་ཡོད་སྙམ་པའི་ཕྱི་ཤོལ་བྱེད་པ་དང༌། བྱ་བ་ངན་པ་ལ་ཆགས་པས་ཟིལ་གྱིས་ནོན་པའོ། །

Enumeration Block 3:
ཞུམ་པ་ལ་ཡང་གསུམ་སྟེ་ཐོབ་བྱ་སངས་རྒྱས་ཀྱི་ཡོན་ཏན་མཐའ་ཡས་པས་བདག་གིས་ཐོབ་མི་ནུས་སྙམ་པ་དང༌།
རྐང་ལག་གཏོང་བ་སོགས་བྱ་དཀའ་བ་དཔག་ཏུ་མེད་པ་བདག་གིས་བསྒྲུབ་པར་མི་ནུས་སྙམ་པ་དང༌།
འཁོར་བར་སྐྱེ་བ་མཐའ་ཡས་པ་ལེན་དགོས་པས་དེའི་ཚེ་འཁོར་བའི་སྡུག་བསྔལ་བཟོད་མི་ནུས་སྙམ་དུ་ཞུམ་པའོ། །

Enumeration Block 4:
གསུམ་པ་ཐུན་མོང་དང་ཐུན་མོང་མ་ཡིན་པའི་ཞི་གནས་ཀྱིས་བསྡུས་པའི་བསམ་གཏན་ལ་སློབ་ཚུལ་ལ་གཉིས། ལེའུའི་གཞུང་བཤད་པ་དང༌། ལེའུའི་མཚན་ནོ། །

Enumeration Block 5:
དང་པོ་ལ་གསུམ། བསམ་གཏན་བསྒོམ་པར་གདམས་པ་དང༌། ཞི་གནས་ཀྱི་མི་མཐུན་ཕྱོགས་སྤང་བ་དང༌། ཞི་གནས་ཇི་ལྟར་སྒོམ་པའི་ཚུལ་ལོ། །

Enumeration Block 6:
དང་པོ་ལ་གཉིས། ཞི་གནས་བསྒྲུབ་དགོས་པའི་རྒྱུ་མཚན་དང༌། ཞི་གནས་ཀྱི་མི་མཐུན་ཕྱོགས་སྤང་བར་གདམས་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། འཇིག་རྟེན་གྱི་འདུ་འཛི་སོགས་སྤང་བ་དང༌། ཕྱིན་ཅི་ལོག་གི་རྣམ་རྟོག་སྤང་བའོ། ། དང་པོ་ལ་གཉིས། འཇིག་རྟེན་ལ་ཆགས་པའི་རྒྱུ་ངོས་བཟུང་བ་དང༌། དེ་ཇི་ལྟར་སྤོང་བའི་ཚུལ་ལོ། །

Enumeration Block 8:
གཉིས་པ་ལ་བཞི། གཉེན་པོ་ངོས་བཟུང་བ་དང༌། གཉེན་པོ་བསྐྱེད་པའི་ཐབས་དང༌། འདུ་འཛིའི་ཉེས་དམིགས་དང༌། དབེན་པ་བསྟེན་པའི་ཕན་ཡོན་ནོ། །

Enumeration Block 9:
དང་པོ་ལ་གཉིས། ཆགས་པ་སྤང་བར་གདམས་པ་དང༌། ཆགས་པ་སྤོང་བྱེད་ཀྱི་གཉེན་པོ་ངོས་བཟུང་བའོ། །

Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། ནང་སེམས་ཅན་ལ་ཆགས་པ་སྤང་བ་དང༌། ཕྱི་རྙེད་བཀུར་སོགས་ལ་ཆགས་པ་སྤང་བའོ། ། དང་པོ་ལ་གཉིས། ཆགས་པའི་ཉེས་དམིགས་དང༌། ཉེས་དམིགས་ཤེས་ནས་སྤང་བའོ། །

Enumeration Block 11:
དང་པོ་ལ་ལྔ། འདོད་པའི་དོན་དང་མི་ཕྲད་པ་དང༌། འདོད་ཡོན་གྱིས་གཡེན་སྤྱོ་བ་དང༌། ཐོབ་ཀྱང་ཆོག་མི་ཤེས་པ་དང༌། ཐར་པ་ལ་གེགས་བྱེད་པ་དང༌། དལ་འབྱོར་ཆུད་གསོན་པའོ། །

Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། ཉེས་དམིགས་བསམ་པ་དང༌། དེ་སྤོང་བའི་ཚུལ་ལོ། །

Enumeration Block 13:
དང་པོ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 14:
དང་པོ་ལ་གསུམ། དོན་ཆེན་པོ་འཇིག་ཅིང་ངན་འགྲོར་འཁྲིད་པ་དང༌། བྱིས་པའི་གྲོགས་མི་བསྟེན་ཞིང་བསྟེན་པར་དཀའ་བ་དང༌། དེ་ལས་ཕན་པ་མི་ཐོབ་ཅིང་གནོད་པ་ལ་སྦྱོར་བའོ། །

Enumeration Block 15:
གཉིས་པ་ཕྱི་རྙེད་བཀུར་སོགས་ལ་ཆགས་པ་སྤང་བ་ལ་གཉིས། ཡུལ་ཅན་གྱི་ཉེས་པ་དང༌། ཡུལ་གྱི་ཉེས་པའོ། །

Enumeration Block 16:
དང་པོ་ལ་གཉིས། ང་རྒྱལ་གྱི་ཉེས་དམིགས་དང༌། ཆགས་པའི་ཉེས་དམིགས་སོ། །
