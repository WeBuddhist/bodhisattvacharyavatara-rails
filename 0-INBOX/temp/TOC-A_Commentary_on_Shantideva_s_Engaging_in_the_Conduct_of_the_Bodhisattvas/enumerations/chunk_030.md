Enumeration Block 1:
གཉིས་པ་ཁྲོ་བའི་ཉེས་དམིགས་རྒྱས་པར་བཤད་པ་ནི།

Enumeration Block 2:
གསུམ་པ་སྐྱོན་ཡོད་བསྡུས་ཏེ་བསྟན་པ་ནི།

Enumeration Block 3:
གཉིས་པ་སྒོམ་ཚུལ་ལ།
མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །
དང་པོ་ལ་གསུམ་ལས།
དང་པོ་ཁྲོ་བའི་རྒྱུ་ལ་བརྟགས་པ་ནི།

Enumeration Block 4:
གཉིས་པ་དེ་ཉིད་སྤང་བར་རིགས་ཚུལ་ནི།

Enumeration Block 5:
གསུམ་པ་གཉེན་པོ་དགའ་བ་བསྐྱེད་པ་ནི།

Enumeration Block 6:
རྒྱས་བཤད་ལ།
གང་ལས་ཁྲོ་བ་འབྱུང་ཚུལ་དང༌། དེ་ཡི་གཉེན་པོ་སྒོམ་ཚུལ་ལོ། །
དང་པོ་ནི།

Enumeration Block 7:
གཉིས་པ་གཉེན་པོ་ལ།
ཡིད་དུ་མི་འོང་པ་ལ་བཟོད་པ་སྒོམ་ཚུལ། ཡིད་དུ་འོང་བའི་གེགས་ལ་བཟོད་པ་སྒོམ་ཚུལ། གནོད་བྱེད་བཟོད་པ་འགྲུབ་པའི་གྲོགས་སུ་བསྟན་པའོ། །
དང་པོ་ལ།
བདག་ལ་ཉེས་པ་བྱུང་དུས་བསྒོམ་པ། བཤེས་ལ་ཉེས་པ་བྱུང་དུས་བསྒོམ་པ། དགྲ་ལ་ལེགས་པ་བྱུང་དུས་བསྒོམ་པའོ། །
དང་པོ་ལའང༌།
སྡུག་བསྔལ་བྱུང་དུས་བསྒོམ་པ་དང༌། བརྙས་སོགས་བྱུང་དུས་བསྒོམ་པའོ། །
དེའི་དང་པོ་ལ།
སྡུག་བསྔལ་དང་དུ་ལེན་པའི་བཟོད་པ། ཆོས་ལ་ངེས་པར་སེམས་པའི་བཟོད་པ། གནོད་པས་ཇི་མི་སྙམ་པའི་བཟོད་པའོ། །
དང་པོ་ལ་དྲུག་ལས།
དང་པོ་སྡུག་བསྔལ་ཆོས་ཀྱི་བསྐུལ་མར་བསྟན་པ་ནི།

Enumeration Block 8:
གཉིས་པཐར་བའི་དོན་དུ་བཟོད་པར་བྱ་བ་ནི།

Enumeration Block 9:
གསུམ་པ་གོམས་པའི་དབང་གིས་བཟོད་པར་བྱ་བ་ནི།

Enumeration Block 10:
བཞི་པ་ལེགས་པར་བརྟགས་ནས་བཟོད་པར་བྱ་བ་ནི།

Enumeration Block 11:
ལྔ་པ་རྙོག་པ་སྤངས་ཏེ་ཉོན་མོངས་འཇོམས་ཚུལ་ནི།

Enumeration Block 12:
དྲུག་པ་ཡོན་ཏན་བསམས་ཏེ་དང་དུ་བླང་བ་ནི།

Enumeration Block 13:
གཉིས་པ་ཆོས་ལ་ངེས་པར་སེམས་པ་ལ།
བཟོད་པས་ཁྲོ་བ་བཟློག་ཚུལ་དང༌། དེ་ལ་རྩོད་པ་སྤང་པའོ། །
དང་པོ་ལ།
གཞན་ལ་རང་དབང་མེད་པས་བཟོད་ཚུལ། རང་དབང་ཡོད་པར་འདོད་པ་དགག་པ། སྐབས་དོན་བསྡུས་ཏེ་དོན་ལ་སྦྱར་བའོ། །
རང་དབང་མེད་ཚུལ་ལ།
རྐྱེན་གྱིས་བསྐུལ་བས་རང་དབང་མེད་ཚུལ་དང༌། སེམས་པ་མེད་པས་རང་དབང་མེད་ཚུལ་ལོ། །
དང་པོ་ལ་གསུམ་ལས།
དང་པོ་མདོར་བསྟན་ནི།

Enumeration Block 14:
གཉིས་པ་རྒྱས་བཤད་ནི།

Enumeration Block 15:
གསུམ་པདོན་བསྡུ་ནི།

Enumeration Block 16:
གཉིས་པ་སེམས་པ་མེད་ཚུལ་ནི།
