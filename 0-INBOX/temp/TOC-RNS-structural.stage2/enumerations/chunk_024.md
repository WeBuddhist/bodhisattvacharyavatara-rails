Enumeration Block 1:
གསུམ་པ་ང་རྒྱལ་ལ་གཉིས་ལས།

Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ལ། ལས་དང༌། ནུས་པ་དང༌།
ཉོན་མོངས་པའི་ང་རྒྱལ་བཤད་པ་གསུམ་ལས།

Enumeration Block 3:
གཉིས་པ་ནུས་པའི་ང་རྒྱལ་ལ་གསུམ་ལས།

Enumeration Block 4:
གསུམ་པ་དགའ་བའི་དཔུང་ལ་གསུམ་ལས།

Enumeration Block 5:
གཉིས་པ་བརྩོན་འགྲུས་སྤེལ་བ་ལ།
གཉེན་པོ་བསྐྱེད་དེ་བརྩོན་འགྲུས་སྤེལ་བ་དང༌། དབང་དུ་བྱས་ཏེ་བརྩོན་འགྲུས་སྤེལ་བའོ།།
དང་པོ་ལ་བཞི་ལས།

Enumeration Block 6:
གཉིས་པ་དབང་དུ་བྱས་ཏེ་བརྩོན་འགྲུས་སྤེལ་བ་ལ་གཉིས་ལས།

Enumeration Block 7:
གཉིས་པ་གཞུང་དོན་ལ། འབྲེལ་བཀོད་དེ་རྣམ་གཡེང་སྤང་ཚུལ། དེ་ཡི་དོན་རྒྱས་པར་བཤད་པ། བྱང་ཆུབ་ཀྱི་སེམས་གཉིས་བསྒོམ་ཚུལ་ལོ།།
