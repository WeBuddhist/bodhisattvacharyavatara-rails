Enumeration Block 1:
གསུམ་པ་ཤེས་རབ་ཐོབ་པའི་བྱ་བ་ལ།
རང་ཁྱད་འཕགས་གིས་སྟོང་ཉིད་བསྒོམ་ཚུལ་དང༌། གཞན་ལ་སྙིང་རྗེ་བསྒོམ་ཚུལ་ལོ།།
དང་པོ་ལ་གཉིས་ལས།

Enumeration Block 2:
གཉིས་པ་སྙིང་རྗེ་བསྒོམ་པ་ལ།
དམིགས་ཡུལ་སེམས་ཅན་ཀུན་ལ་བསྒོམ་པ་དང༌། རྣམ་པ་ཕན་བདེ་འབྱུང་བའི་སྙིང་རྗེའོ།།
དང་པོ་ལ། ཚེ་འདིའི་དཀའ་སྤྱད་དང༌། ཕྱི་མའི་སྡུག་བསྔལ་དང༌། འཁོར་བའི་ཉེས་དམིགས་བསམས་ཏེ་བསྒོམ་པའོ།།

Enumeration Block 3:
གསུམ་པ་འཁོར་བའི་ཉེས་དམིགས་བསམས་ཏེ་བསྒོམ་པ་ལ་གསུམ་ལས།

Enumeration Block 4:
གཉིས་པ་རྣམ་པ་ལ་གཉིས་ལས།

Enumeration Block 5:
ད་ནི་གསུམ་པ་ཞུགས་པས་ཐར་ཕྱིན་པའི་བྱ་བ་ཡོངས་སུ་བསྔོ་བའི་གཞུང་དོན་ལ།
བསགས་པའི་དགེ་བ་བསྔོ་བ་དང༌། བཀའ་དྲིན་དྲན་པའི་ཕྱག་འཚལ་བའོ།།
དང་པོ་བསྔོ་བ་ལ། གཞན་གྱི་དོན་དང༌། རང་གི་དོན་དང༌། བསྟན་པའི་དོན་དུ་བསྔོ་བའོ།།
དང་པོ་གཞན་དོན་ལ། ཕལ་པའི་དོན་དང༌། མཆོག་གི་དོན་དུ་བསྔོ་བའོ།།
དང་པོ་ཕལ་པའི་དོན་ལ།
སྤྱིའི་དོན་དང༌། ངན་འགྲོའི་དོན་དང༌། བདེ་འགྲོའི་དོན་དུ་བསྔོ་བའོ།།
དང་པོ་སྤྱིའི་དོན་ལ་གཉིས་ལས།

Enumeration Block 6:
གཉིས་པ་ངན་འགྲོའི་དོན་དུ་བསྔོ་བ་ལ།
དམྱལ་བ་དང༌། དུད་འགྲོ་དང༌། ཡི་དྭགས་ཀྱི་དོན་དུ་བསྔོ་བའོ།།
