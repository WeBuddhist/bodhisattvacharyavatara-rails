Enumeration Block 1:
གཉིས་པ་རྡུལ་ཕྲན་རྟག་པས་བསྐྱེད་པ་དགག་པ་ནི།

Enumeration Block 2:
གསུམ་པ་གཙོ་བོ་རྟག་པས་བསྐྱེད་པ་དགག་པ་ལ་གཉིས་ལས།
དང་པོ་འདོད་པ་བརྗོད་པ་ནི།

Enumeration Block 3:
གཉིས་པ་དེ་ཉིད་དགག་པ་ལ་ལྔ་ལས།
དང་པོ་རང་བཞིན་ཡོན་ཏན་རྣམ་འགྱུར་དགག་པ་ནི།

Enumeration Block 4:
གཉིས་པ་བདེ་སོགས་དོན་དུ་གྲུབ་པ་དགག་པ་ནི།

Enumeration Block 5:
གསུམ་པ་བདེ་སོགས་རྟག་པར་འདོད་པ་དགག་པ་ནི།

Enumeration Block 6:
བཞི་པ་རྒྱུ་ལ་འབྲས་བུ་གནས་པ་དགག་པ་ནི།

Enumeration Block 7:
ལྔ་པ་གཉེན་པོའི་ཚུལ་ལ་རྩོད་པ་སྤང་བ་ནི།
