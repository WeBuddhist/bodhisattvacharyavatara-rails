Enumeration Block 1:
གལ་ཏེ་རྒྱན་ལ་སོགས་པ་དང་ལྡན་པས་ཆགས་པའི་གནས་སུ་འཛིན་ན་གཙང་མའི་མཚན་མ་དགག་པ་ལ་བཞི་སྟེ། བཅོས་པའི་རྒྱན་གྱིས་ལུས་གཙང་བར་མི་འགྱུར་བ་དང༌། བཅོས་པའི་རྒྱན་ཆགས་པའི་གནས་མ་ཡིན་པ་དང༌། ལུས་ཀྱི་རང་བཞིན་འཇིག་པ་ཡིན་པ་དང༌། ཡིད་འབྱུང་བའི་གནས་ཡིན་པ་རྣམས།

Enumeration Block 2:
རྒྱུ་གནོད་པ་མང་བ་ལ་གཉིས་ཏེ། བསྟན་པ་དང༌། བཤད་པའོ།

Enumeration Block 3:
རྒྱས་པར་སྟོན་པ་ལ་གཉིས་ཏེ། འདོད་པ་ཉིད་མི་ཐོབ་པ་དང༌། དེ་ལས་གཞན་པའི་ཉེས་པ་དང་འབྲེལ་པའོ།

Enumeration Block 4:
གཉིས་པ་ནི་བཅུ་སྟེ། རང་དབང་མེད་པ་དང༌། སྲོག་འདོར་བའི་འཇིགས་པས་སྡུག་བསྔལ་བ་དང༌། གཞན་གྱི་དབང་དུ་གྱུར་པ་དང༌། ལུས་ཀྱིས་སྡུག་བསྔལ་སྣ་ཚོགས་མྱང་བ་དང༌། དུས་གསུམ་གྱིས་བསྡུས་པའི་སྡུག་བསྔལ་དང༌། ཐར་པའང་འགོག་པ་དང༌། ཉེས་པ་མདོར་བསྡུ་བ་དང༌། དལ་བ་ཆུད་གསོན་པ་དང༌། ཉེས་པ་དེ་དག་དབང་དུ་བྱས་ཏེ་ཐར་པའི་ཐབས་ལ་འབད་པ་དང༌། ཉེས་པའི་འབྱུང་གནས་ཐམས་ཅད་ལས་ཕུལ་དུ་བྱུང་བ་བཅུ།

Enumeration Block 5:
དབེན་པ་ལ་དགའ་བ་བསྐྱེད་པ་ལ་གཉིས་ཏེ། ཕུན་སུམ་ཚོགས་པའི་ཁྱད་པར་དང༌། བདེ་བའི་ཁྱད་པར་རོ། །དང་པོ་ལ་བསྟན་པ་དང༌། འགལ་རྐྱེན་མེད་པ་དང༌། མཐུན་རྐྱེན་ཡོད་པའོ།

Enumeration Block 6:
ཞི་གནས་ཀྱི་དམིགས་པ་ཡིད་ལ་བྱ་བ་ལ་གཉིས་ཏེ། བདག་དང་གཞན་མཉམ་པ་དང༌། བརྗེ་བའོ། །
དང་པོ་ལ་ལྔ་སྟེ། མདོར་བསྟན་པ་དང༌། སྡུག་བསྔལ་ཅན་བདག་ཏུ་བཟུང་བས་མཉམ་པ་དང༌། སྡུག་བསྔལ་སྤང་བྱ་ཡིན་པས་མཉམ་པ་དང༌། མཉམ་པར་བསྒོམས་པའི་ཡོན་ཏན་དང༌། མཉམ་པར་བསྒོམ་པར་ནུས་པའོ།

Enumeration Block 7:
གཉིས་པ་ལ་བསྟན་པ་དང༌། དེ་ཉིད་བསྒྲུབ་པ་གཉིས་སོ།

Enumeration Block 8:
གསུམ་པ་སྡུག་བསྔལ་སྤང་བྱ་ཉིད་དུ་འདྲ་བས་མཉམ་པ་བསྒོམ་པ་ན་དྲུག་སྟེ། སྦྱོར་བ་མདོར་བརྗོད་པ་དང༌། དེའི་ཁྱབ་པ་བསྒྲུབ་པ་དང༌། ཁྱབ་པ་བསྒྲུབ་པའི་མཚན་ཉིད་བསྒྲུབ་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ་དང༌། ཚད་མ་ངེས་པའི་དོན་བསྡུ་བ་དང༌། མ་ངེས་པའི་རྩོད་པ་སྤང་བའོ།

Enumeration Block 9:
དེ་ལ་བཞི་སྟེ། དུས་ཐ་དད་པས་འཁྲུལ་པ་བརྗོད་པའི་ཐལ་བ་དང༌། བདག་གཅིག་ཏུ་འཛིན་པ་འཁྲུལ་པར་བསྒྲུབ་པ་དང༌། ལུས་ཀྱི་ཆ་ཐ་དད་ཀྱི་འཁྲུལ་པ་ཡོད་པར་ཐལ་བ་དང༌། དེ་ལ་དཔེ་མ་གྲུབ་པར་ཐལ་བ་སྤང་བའོ།

Enumeration Block 10:
བཞི་པ་མཉམ་པར་བསྒོམས་པའི་ཡོན་ཏན་ནི་ལྔ་སྟེ། གཞན་དོན་ལ་བདེ་བས་འཇུག་པ་དང༌། གཞན་དོན་བསྒྲུབ་པའི་བདེ་བ་མཆོག་ཏུ་གྲུབ་པ་དང༌། རང་གི་དྲེགས་པ་ཞི་བ་དང༌། འབྲས་བུ་ལ་ལྟོས་པ་མེད་པ་དང༌། དགོས་པ་དེ་དག་གི་སྒྲུབ་བྱེད་ལ་འབད་པར་གདགས་པའོ།

Enumeration Block 11:
བདག་དང་གཞན་བརྗེ་བ་ལ་བཞི་སྟེ། མཚན་ཉིད་བྱ་བ་མདོར་བསྟན་པ་དང༌། མཚན་ཉིད་རྒྱས་པར་བཤད་པ་དང༌། བརྗེས་ནས་བསམ་པ་རྗེས་སུ་བསྒྲུབ་པའི་བྱ་བ་རྒྱས་པར་བཤད་པ་དང༌། སྦྱོར་བ་རྗེས་སུ་བསྒྲུབ་པའི་བྱ་བ་རྒྱས་པར་བཤད་པའོ།

Enumeration Block 12:
མཚན་ཉིད་རྒྱས་པར་བཤད་པ་ལ་བཞི་སྟེ། གཞན་བླང་བ་དང༌། བདག་གཅེས་པར་འཛིན་པ་དོར་བ་དང༌། བདག་གཞན་གཙོ་བོར་བྱེད་པའི་སྐྱོན་ཡོན་དང༌། དོན་བསྡུ་བའོ། །
དང་པོ་ནི་དེ་ལྟར་རྒྱུད་ནི་ཞེས་པ་ལ་སོགས་པ་བདག་གཞན་མཉམ་པའི་སྐབས་སུ་གསུངས་པའི་དོན་རྣམས་བཟླས་ནས་འདིར་ཡང་འཆད་པ་ན་བདུན་ཏེ། བརྗེ་བར་ནུས་པ་དང༌། དྲེགས་པ་ཞི་བ་དང༌། འབྲས་བུ་ལ་མི་ལྟོས་པ་དང༌། དགོས་པ་དེ་དག་གི་སྒྲུབ་བྱེད་ལ་འབད་པར་གདམས་པ་དང༌། གཞན་གྱི་དོན་ཆེད་ཆེར་གཟུང་བ་དང༌། གོམས་པས་གྲུབ་པ་དང༌། བདག་དང་གཞན་སྡུག་བསྔལ་ལས་སྒྲོལ་བའོ།
