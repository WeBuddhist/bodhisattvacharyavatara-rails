Enumeration Block 1:

གཉིས་ཏེ།

Enumeration Block 2:
གཉིས་པ་ཡུལ་ཅན་ལམ་དུ་སྒྲུབ་པ་ལ་གཉིས་ལས་དང་པོ་ཀུན་རྫོབ་སྒྱུ་མར་ཤེས་པ་ལམ་
དུ་སྒྲུབ་པ་ལ་གསུམ་གྱི་དང་པོ་སྐབས་དོན་ནི་རྐང་པ་བཅུ་སཏེ།

Enumeration Block 3:
གཉིས་པ་ཞར་ལ་ངསྒོམ་བྱ་ལམ་གྱི་རང་བཞིན་ལ་གཉིས་ཀྱི་དང་པོ་ཡུལ་ཅིར་
ཡང་མི་གནས་པར་ནི་རྐང་པ་དྲུག་སྟེ།

Enumeration Block 4:
གསུམ་པ་ལམ་གྱིས་ཐོབ་པའི་འབྲས་བུ་ལ་གསུམ་ལས་དང་པོ་ཀུན་སློང་མེད་
ཀྱང་དོན་སྒྲུབ་པ་དཔེས་བསྟན་པ་ནི་དེ་ལྟ་ན་སངས་རྒྱས་ཀྱི་གཞན་དོན་མི་མཛད་པར་
འགྱུར་ཏེ།

Enumeration Block 5:
གཉིས་པ་དོན་དམ་པ་སྟོང་པར་ཤེས་པ་ལམ་དུ་སྒྲུབ་པ་ལ་གཉིས་ལས་དང་པོ་
རྒོལ་བ་ནི་རྐང་པ་གཉིས་ཏེ།

Enumeration Block 6:
གཉིས་པ་ལན་ལ་གསུམ་གྱི་དང་པོ་ལུང་གིས་
མདོར་བསྟན་པ་ནི་གང་ཕྱིར་ཞེས་རྐང་པ་གཉིས་ཏེ།

Enumeration Block 7:
གཉིས་པ་རྒལ་ལན་གྱིས་རྒྱས་པར་བཤད་པ་ལ་གསུམ་སྟེ། མ་གྲུབ་པའི་རྒོལ་
བ་དགོད༌པ༌དང༌ ། ཐེག་ཆེན་གྱི་གཞུང་བཀར་བསྒྲུབ་པ་དང༌། དོན་ལམ་དུ་སྒྲུབ་པའོ།།
དང་པོ་ནི་གལ་ཏེ་ཞེས་རྐང་པ་གཅིག་སྟེ།

Enumeration Block 8:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ་ཁྱད་པར་གྱི་རྒྱུ་མཚན་བརྟག་པ་ནི་ཁྱོད་
ཀྱི་ལུང་རྣམས་ཡིད་ཆེས་སུ་ཇི་ལྟར་གྲུབ་ཅེས་འདྲི་བའོ། །གཉིས་པ་བརྗོད་པའི་རྒྱུ་མཚན་
དགག་པ་ལ་གཉིས་ལས་དང་པོ་ལུང་གི་རྒྱུ་མཚན་དགག་པ་ལའང་གཉིས་ཀྱི་དང་པོ་ཡིན་
པའི་རྒྱུ་མཚན་དགག་པ་ནི། གང་ཕྱིར་ཞེས་རྐང་པ་དྲུག་སྟེ།
