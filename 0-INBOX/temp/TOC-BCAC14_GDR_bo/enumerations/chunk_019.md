Enumeration Block 1:
གཉིས་པ་ལ་གསུམ།
གཞན་རང་ལ་ཕན་བྱེད་དུ་མི་འཐད་པ་སྤང་པ་དང༌།
རང་གཞན་ལ་གནོད་བྱེད་དུ་མི་འཐད་དུ་སྤང་བ་དང༌།
ཕན་འདོགས་བྱེད་ལ་ལོག་པར་བསྒྲུབ་པ་དགག་པའོ། །

Enumeration Block 2:
གཉིས་པ་བརྙས་པ་སོགས་བསྒྲུབ་པ་ལ་བཟོད་པ་བྱ་རིགས་པ་ལ་བཞི།
བརྙས་སྨོད་སོགས་ཀྱིས་རང་གི་ལུས་ལ་མི་གནོད་པ་དང༌།
ཁྲོ་བ་དང་འབྲེལ་བའི་གང་ཟག་ལ་རང་གིས་ཁྲོ་བར་མི་རིགས་པ་དང༌།
རྙེད་པའི་བར་ཆད་བྱེད་པས་ཁྲོ་བར་མི་རིགས་པ་དང༌།
གཞན་རང་ལ་མ་དད་པར་བྱེད་པས་ཁྲོ་བར་མི་རིགས་པའོ། །

Enumeration Block 3:
གསུམ་པ་ལ་ལྔ།
རྙེད་པ་མྱུར་དུ་འཇིགས་པས་དེའི་བར་ཆད་ལ་ཁྲོ་བར་མི་རིགས་པ་དང༌།
ལོག་པའི་རྙེད་པ་བསྒྲུབ་པ་དགག་པ་དང༌།
རྙེད་པ་ལ་སྲེད་པ་མི་རིགས་པ་དཔེས་བསྒྲུབ་པ་དང༌།
རྙེད་པ་ལ་སྲེད་པར་མི་རིགས་པའི་རྒྱུ་མཚན་དང༌།
རྙེད་པ་སྒྲུབ་རིགས་པ་དགག་པའོ། །

Enumeration Block 4:
བཞི་པ་ལ་གཉིས།
རང་ལ་མི་སྙན་པ་སྨྲ་བ་དད་པ་ཉམས་བྱེད་ཡིན་པས་ཁྲོ་ན་གཞན་ལ་མི་སྙན་པ་སྨྲ་བ་ལ་ཡང་ཁྲོ་བར་རིགས་པ་དང༌།
གཞན་ལ་མ་དད་པ་ལ་བཟོད་ན་ཉོན་མོངས་ཀྱི་རྐྱེན་གྱིས་རང་ལ་མ་དད་པ་ལ་ཡང་བཟོད་རིགས་པའོ། །

Enumeration Block 5:
གཉིས་པ་བདག་གི་བཤེས་ལ་ཉེས་པ་བྱེད་པ་ལ་ཁྲོ་བ་དགག་པ་ལ་གཉིས།
ཆོས་ལ་ངེས་པར་སེམས་པའི་བཟོད་པས་དགག་པ་དང༌།
གནོད་པ་བྱེད་པ་ལ་ཇི་མི་སྙམ་པའི་བཟོད་པས་དགག་པའོ། །
དང་པོ་ལ་གཉིས།
སྐུ་གཟུགས་སོགས་ལ་གནོད་པ་བྱེད་པ་ལ་ཁྲོ་མི་རིགས་པའི་རྒྱུ་མཚན་དང༌།
དེ་བཞིན་དུ་བཤེས་ལ་གནོད་པ་བྱེད་པ་ལ་བཟོད་རིགས་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ་བཞི།
སེམས་ཡོད་འབའ་ཞིག་ལ་ཁྲོ་བར་མི་རིགས་པ་དང༌།
ཁྲོ་བར་མི་རིགས་པའི་རྒྱུ་མཚན་དང༌།
རང་གི་ཉེས་པར་བསམ་པ་དང༌།
བཟོད་པའི་ཕན་ཡོན་བསམ་པའོ། །

Enumeration Block 7:
བཞི་པ་ལ་གསུམ།
བདག་གི་དགེ་བ་མི་ཉམས་པའི་དོན་དུ་འབད་པ་དང༌།
སྡུག་བསྔལ་ཆུང་ངུ་དང་དུ་བླངས་ནས་དམྱལ་བའི་སྡུག་བསྔལ་གྱི་རྒྱུ་ལྡོག་པར་བྱ་བ་དང༌།
དོན་ཆེན་པོ་སྒྲུབ་པའི་དཀའ་སྤྱད་ལ་དགའ་བར་རིགས་པའོ། །

Enumeration Block 8:
གཉིས་པ་ལ་གཉིས།
དཔེ་དང༌།
དོན་ནོ། །

Enumeration Block 9:
གསུམ་པ་ལ་གཉིས།
སྔར་ལུས་ཇི་ཙམ་ཆུད་ཟོས་ཀྱང་རང་དོན་དང་གཞན་དོན་གང་ཡང་མ་གྲུབ་པས་འགྱོད་པ་དང༌།
ད་ལྟའི་དཀའ་སྤྱད་བཟོད་པར་བྱས་ནས་འགྲོ་བ་མཐའ་དག་གི་དོན་བསྒྲུབ་པ་ལ་དགའ་བར་རིགས་པའོ། །

Enumeration Block 10:
གསུམ་པ་བདག་གི་དགྲ་ལ་ལེགས་པ་བྱེད་པ་ལ་ཁྲོ་བ་དགག་པ་ལ་གསུམ།
དགྲ་ལ་བསྟོད་པ་དང་གྲགས་པ་བསྒྲུབ་པ་ལ་མི་བཟོད་པ་སྤང་བ་དང༌།
བདེ་བ་བསྒྲུབ་པ་ལ་མི་བཟོད་པ་སྤང་བ་དང༌།
རྙེད་པ་བསྒྲུབ་པ་ལ་མི་བཟོད་པ་སྤང་བའོ། །
དང་པོ་ལ་གཉིས།
རང་བདེ་བའི་རྒྱུ་ཡིན་པས་འདོད་རིགས་པ་དང༌།
གཞན་བདེ་བའི་རྒྱུ་ཡིན་པས་མི་འདོད་པ་མི་རིགས་པའོ། །

Enumeration Block 11:
གཉིས་པ་ལ་གཉིས།
གཞན་བདེ་བ་མི་འདོད་ན་རང་གི་བདེ་བ་ཉམས་པར་འགྱུར་བ་དང༌།
དེས་ན་གཞན་བདེ་བ་འདོད་རིགས་པའོ། །

Enumeration Block 12:
གསུམ་པ་ལ་གཉིས།
རང་གི་འདོད་པ་གྲུབ་པར་བསམ་པ་དང༌།
མི་འདོད་པ་མེད་པར་བསམ་པའོ། །
