Enumeration Block 1:
བཞི་པ་སངས་རྒྱས་བཞིན་དུ་མཆོད་ཚུལ་ལ་གཉིས་ལས།
དང་པོ་འབྲས་བུའི་ཆ་ནས་མཆོད་པར་རིགས་ཚུལ་ནི།

Enumeration Block 2:
གཉིས་པ་ཡོན་ཏན་གྱི་ཆ་ནས་མཆོད་པར་རིགས་ཚུལ་ནི།

Enumeration Block 3:
ལྔ་པ་དེས་ན་མགུ་བར་བྱ་བ་ལ་བཞི་ལས།
དང་པོ་རྒྱལ་བའི་བཀའ་དྲིན་བསམས་ཏེ་མགུ་བར་བྱ་བ་ནི།

Enumeration Block 4:
གཉིས་པ་གཞན་ལ་གནོད་པ་བྱས་ན་མི་དགྱེས་པ་འབྱུང་ཚུལ་ནི།

Enumeration Block 5:
གསུམ་པ་དེའི་སྡིག་པ་བཤགས་དེ་དགྱེས་པ་བསྐྱེད་ཚུལ་ནི།

Enumeration Block 6:
བཞི་པ་རང་བཞིན་རྣམ་དག་བསམས་ཏེ་གུས་པར་བྱ་བ་ནི།

Enumeration Block 7:
དྲུག་པ་མགུ་བའི་ཕན་ཡོན་བསྟན་པ་ལ།
དོན་གཉིས་འགྲུབ་ཚུལ་མདོར་བསྟན། དཔེ་ཡིས་རྒྱས་པར་བཤད། སྐབས་དོན་བསྡུས་ཏེ་བསྟན་པའོ། །
དང་པོ་མདོར་བསྟན་ནི།

Enumeration Block 8:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས་ལས།
དང་པོ་གནོད་པ་སྤང་ཚུལ་དཔེ་ཡིས་བཤད་པ་ནི།

Enumeration Block 9:
གཉིས་པ་མགུ་བར་བྱེད་ཚུལ་དཔེ་ཡིས་བཤད་པ་ནི།

Enumeration Block 10:
གསུམ་པ་དོན་བསྡུ་ནི།

Enumeration Block 11:
གསུམ་པཕན་ཡོན་ནི།

Enumeration Block 12:
ད་ནི་བརྩོན་འགྲུས་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཉམས་སུ་བླང་ཚུལ་ལ་སྤྱི་དོན་བཞི་སཏེ།
བྱེད་ལས་མཚན་ཉིད་དབྱེ་བ་ཕན་ཡོན་ནོ། །
དང་པོ་བྱེད་ལས་ནི།

Enumeration Block 13:
གཉིས་པ་མཚན་ཉིད་ནི།

Enumeration Block 14:
གསུམ་པ་དབྱེ་བ་ནི།
