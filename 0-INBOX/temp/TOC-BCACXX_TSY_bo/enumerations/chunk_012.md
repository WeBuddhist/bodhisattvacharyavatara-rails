Enumeration Block 1:
གཉིས་པ་བསྒྲུབ་བྱ་བསླབ་པའི་རང་བཞིན་ཕ་རོལ་ཏུ་ཕྱིན་པ་དྲུག་ཡིན་ཏེ།

Enumeration Block 2:
དེ་དག་ཉིད་སྟོན་པ་ལ་སྤྱི་དོན་གཞུང་དོན་གཉིས་ལས་དང་པོ་ནི་གསུམ་གྱིས་ངེས་པར་བྱ་སཏེ།
ཕར་ཕྱིན་དྲུག་གི་རང་བཞིན་ངེས་པར་བྱ་བ་དང༌། དེ་དག་ཉམས་སུ་ལེན་ཚུལ་དང༌། བླངས་པའི་འབྲས་བུའོ། །དང་པོ་ལ་གསུམ་སྟེ། སོ་སོའི་ངོ་བོ་དང༌། གྲངས་ངེས་པ་དང༌། གོ་རིམ་ངེས་པའོ། །དང་པོ་ལ་སྦྱིན་པའི་མཚན་ཉིད་བདོག་པ་ཀུན་གཏོང་བ་སྟེ།

Enumeration Block 3:
གཉིས་པ་ཉམས་སུ་ལེན་ཚུལ་ལ་གསུམ་སཏེ། རང་གིས་བླངས་པ་དང༌། གཞན་དགོད༌པ་དང༌། གཉིས་ཀའི་ཐབས་ལ་མཁས་པར་བྱ་བའོ། །

Enumeration Block 4:
ད་ནི་གཉིས་པོ་དེ་དག་གི་གཞུང་དོན་སྟོན་པ་ལ་སྦྱིན་པ་དང་ཚུལ་ཁྲིམས་གཉིས་ནི་ལེའུ་ལོགས་སུ་མ་མཛད་པར་ཞར་ལ་བཤད་ཟིན་ནས། བཟོད་པའི་ལེའུ་ལ་གསུམ་སྟེ། བཟོད་པ་བསྒོམ་པར་འོས་པ་དང༌། བཟོད་པ་བསྒོམ་པའི་ཐབས་དང༌། དེ་སྒོམ་པའི་འབྲས་བུའོ། །དང་པོ་ལའང་གསུམ་གྱི་དང་པོ་མ་མཐོང་བའི་འབྲས་བུ་ནི་སྐལ་པ་ཞེས་ཤྰཀ་གཅིག་སྟེ།

Enumeration Block 5:
གཉིས་པ་ལ་གཉིས་ལས་དང་པོ་མདོར་བསྟན་པ་ལ་ཡང་གཉིས་ཀྱི་དང་པོ་སྤང་བྱའི་རྒྱུ་ངོས་བཟུང་བ་ནི་མི་འདོད་ཅེས་ཤོ་ལོ་ཀ་གཅིག་གོ །

Enumeration Block 6:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གཉིས་ཀྱི་དང་པོ་གང་ལ་ཁྲོ་བའི་ཡུལ་གྱི་དབྱེ་བ་སྤྱིར་བསྟན་པ་ནི་ཤློ་ཀ་གཅིག་སྟེ།

Enumeration Block 7:
གཉིས་པ་དེ་ལ་ཁྲོ་བ་དགག་པ་ལ་གཉིས་ཏེ། མི་འདོད་པ་བྱེད་པ་དང༌། འདོད་པའི་གགས་བྱེད་པ་ལ་ཁྲོ་ང་དགག་པའོ། །དང་པོ་ལ་གསུམ་ལས་དང་པོ་བདག་ཉིད་ཉེས་པ་བྱེད་པ་ལ་ཁྲོ་བ་དགག་པ་ལ་གཉིས་ཀྱི་དང་པོ་བདག་ལ་སྡུག་བསྔལ་སྒྲུབ་པ་ལ་སྡུག་བསྔལ་དང་ལེན་གྱི་བཟོད་པ་བསྒོམ་པ་ལ་བཞི་ལས་དང་པོ་སྡུག་བསྔལ་འཁོར་བའི་རང་བཞིན་དུ་བརྟག་པ་ནི་རྐང་པ་གཉིས་ཏེ།
