Enumeration Block 1:
གསུམ་པ་སྨོན་ལམ་སྟོབས་ཀྱི་མཆོད་པ་ནི།

Enumeration Block 2:
བཞི་པ་བླ་ན་མེད་པའི་མཆོད་པ་ནི།

Enumeration Block 3:
ལྔ་པ་བསྟོད་པ་དབྱངས་ཀྱི་མཆོད་པ་ནི།

Enumeration Block 4:
གཉིས་པ་ང་རྒྱལ་གྱི་གཉེན་པོ་ལ་ཕྱག་འཚལ་བའི་ཡན་ལག་ནི།

Enumeration Block 5:
གསུམ་པ་ལོག་པར་སྨོན་པའི་ལས་ཀྱི་སྒྲིབ་པའི་གཉེན་པོ་ལ་སྐྱབས་སུ་འགྲོ་བའི་ཡན་ལག་ནི།

Enumeration Block 6:
དོན་རྣམ་པ་བདུན་ལས།
དང་པོ། སྐྱབས་འགྲོའི་དབྱེ་བ་ནི།
ཐེག་པ་ཐུན་མོང་བའི་སྐྱབས་འགྲོ་དང་། ཐེག་ཆེན་ཐུན་མོང་མ་ཡིན་པའི་སྐྱབས་འགྲོ་སྟེ། སྤྱིར་རྩ་བའི་དབྱེ་བ་ལ་རྣམ་པ་གཉིས། གཉིས་པ།
ཐེག་པ་ཆེ་ཆུང་གི་སྐྱབས་འགྲོའི་ཁྱད་པར་རྣམ་པར་བཞག་པ་ལ་ནང་གསེས་ཀྱི་རྣམ་པ་བཞི་ལས།
དང་པོ། སྐྱབས་གནས་ཀྱི་ཁྱད་པར་ནི།
