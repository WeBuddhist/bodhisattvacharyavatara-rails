Enumeration Block 1:
**(གཉིས་པ་)ཉོན་མོངས་སྤང་བ་ལ།**
སྤོང་བའི་བློ་བསྐྱེད་པ། སྤོང་བའི་ཐབས་བསྟེན་པ། སྤོང་ནུས་པའི་ཚུལ་ལོ། །
**དང་པོ་ལ།**
དགྲའི་མཆོག་ཏུ་བརྟགས་ཏེ་སྤང་ཚུལ་དང༌། བདག་ལ་གནོད་པར་བསམས་ཏེ་སྤང་ཚུལ་ལོ། །
**དང་པོ་ལ་བཞི་ལས།**

Enumeration Block 2:
**(གཉིས་པ་)**
ཐབས་ལ་བརྩོན་པས་ཉོན་མོངས་གཞོམ་ཚུལ། དེའི་སྡུག་བསྔལ་བཟོད་ཚུལ། གཉེན་པོ་སྟོབས་ལྡན་བསྐྱེད་ཚུལ་ལོ། །

Enumeration Block 3:
**(གཉིས་པ་)བཟོད་ཚུལ་ལ་གསུམ་ལས།**

Enumeration Block 4:
**(གསུམ་པ་)སྤོང་པར་ནུས་ཚུལ་ལ།**
གནས་གཞན་མེད་པས་སྤོང་བར་ནུས་ཚུལ་དང༌། རང་བཞིན་མེད་པས་སྤོང་བར་ནུས་ཚུལ་ལོ།

Enumeration Block 6:
**(གཉིས་པ་)ཤེས་བཞིན་བསྲུང་བ་ལ།**
བསླབ་པ་སྲུང་བའི་ཐབས་སུ་སེམས་བསྲུང་བ། སེམས་སྲུང་བའི་ཐབས་སུ་དྲན་ཤེས་བསྲུང་བ། ཐབས་དེ་དག་ཉམས་སུ་བླང་བར་གདམས་པའོ། །
**དང་པོ་ལ་**
མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུའོ། །

Enumeration Block 7:
**(གཉིས་པ་)རྒྱས་བཤད་ལ་**
(བཞི་སྟེ་)མ་བསྲུང་བའི་ཉེས་དམིགས། སེམས་བསྲུངས་བའི་ཕན་ཡོན། དེ་བསྲུང་བར་གདམ་པ། ཚུལ་ཇི་ལྟར་བསྲུང་བའོ། །
